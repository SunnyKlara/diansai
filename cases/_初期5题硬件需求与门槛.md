# 初期 5 题 · 硬件需求与开做门槛对照

> 配套 `_初期刷题名单与规划.md`。开刷前先过这张表，避免"开做才发现缺件"或"盲目采购"。
> 数据来源：各题 `02_硬件/材料清单_BOM.md`（真实 BOM，非凭空）。
> **核心结论先说**：5 题里有 2 题（2025G/2021A）的"胜负手"在算法、**可纯 PC 验证、几乎不依赖新硬件就能推进大半**；另 3 题（2024H/2023E/2023A）需要实物装配/强电/贵重专用件，是"采购+搭建"工程。**所以开局先打 PC 可验证的，硬件重的并行采购。**

## 怎么读这张表

**门槛分级**：
- 🟢 **低**：核心工作(算法)可纯 PC 验证，硬件便宜/可选，没仪器也能推进大半
- 🟡 **中**：需主控 + 若干模块 + 示波器，但无强电、无复杂机械
- 🔴 **高**：强电/危险 ‖ 重机械装配 ‖ 贵重专用件，且关键指标必须实物才能验

**PC 可替代**：标"✅大半"= 不买任何新硬件就能把主要算法跑通（用 Python 造信号做金标准 → C 移植）。

## ⚠️ 最容易被忽略的卡点：测试仪器

很多人只盯着器件，忘了**仪器才是练习阶段的真门槛**（赛场会提供，但平时家里/实验室不一定有）：

| 仪器 | 哪些题需要 | 赛场提供? | 没有的影响 |
|---|---|---|---|
| 示波器(≥50~100MHz) | 全部，尤其 2025G/2021A/2023A | ✅ | 信号链/波形无法验证，但算法仍可 PC 验 |
| 信号发生器 | 2021A/2025G | ✅ | 2025G/2021A 可用板上 DDS(AD9833) 自发自收替代 |
| 直流稳压电源 | 全部 | ✅ | 可用适配器/电池临时替代 |
| 电子负载 | 2023A(电源) | ✅ | 电源题带载测试做不了 |
| 万用表 | 全部 | 自备 | 必备，便宜 |
| 隔离变压器/隔离探头 | 2023A(强电) | 部分 | **安全红线，强电没隔离别上电** |

> 👉 **请确认你能否稳定用到示波器**。这一条直接决定 2023A(强电)能不能在赛前练，也影响 2025G/2021A 信号链调试。

## 逐题硬件需求

### ① 2025G 电路模型探究　🟢→🟡　PC可替代 ✅大半
| 类别 | 需要什么 | 备注 |
|---|---|---|
| 主控 | STM32F407VET6 | 要双ADC同步+片内DAC+FPU；**不能用F103** |
| 专用模块 | AD9833 DDS ×2、OPA2277 精密运放 ×4、REF3016 基准 | 信号链精度是胜负手 |
| 接口 | BNC 母座/线缆、0.1% 精密电阻 | 信号完整性 |
| 仪器 | 示波器（验证信号链）；DDS 可自发自收，省信号源 | |
| 显示 | OLED SSD1306 | |
| **估价** | **约 ¥286**（全题最低之一） | |
| **PC 可先做** | FFT/同步采样/频响提取/THD **算法全部可 PC 造信号验证** | 占工作量约 60~70% |

### ② 2021A 信号失真度THD　🟡 + ⚠硬约束　PC可替代 ✅大半
| 类别 | 需要什么 | 备注 |
|---|---|---|
| 主控 | **TMS320F28379D LaunchPad（题目强制 TI MCU+片内ADC）** | ⚠ **硬约束**：没 TI 板就得先采购(¥150)；备选 MSP432 |
| 专用模块 | OPA2277/AD8065 运放、CD4051 量程切换、REF3030 基准 | 抗混叠+量程 |
| 接口 | BNC/SMA 输入、钳位保护、0.1% 电阻 | |
| 仪器 | 示波器、信号源（可外接标准失真信号） | |
| **估价** | **约 ¥249**（含 TI 板 ¥150） | |
| **PC 可先做** | THD/谐波/加窗(平顶窗)/同步采样 **算法可 PC 验证** | 复用①的脚手架 |

> 🔑 2021A 唯一的"必须买"是 **TI MCU**。先确认有没有，没有则它在采购清单里优先级最高（也是开做前提）。

## 按"开做门槛"重排序（硬件视角）

| 实际可开做顺序 | 题 | 门槛 | 理由 |
|---|---|---|---|
| 1 | ①2025G | 🟢算法 | 算法纯 PC 可验证，硬件便宜，开局零阻力 |
| 2 | ②2021A | 🟢算法(⚠TI板) | 算法复用①；只卡一块 TI MCU 是否到位 |
| 3 | ③2024H | 🔴装车 | 控制律可仿真先行，实车并行采购组装 |
| 4 | ④2023E | 🔴贵 | 协议/PID 可仿真先行，OpenMV+云台采购 |
| 5 | ⑤2023A | 🔴🔴强电 | 仿真先行，功率级需仪器+安全条件，最后做 |

> 注意：这和名单的"复用优先级"一致——**PC 可验证的恰好也是开做门槛最低的**，开局两条线天然重合。

## 分层采购优先级（建议）

- **第一批·开局必备（不买做不了）**：
  - 确认/补 ①的 STM32F407 板、AD9833 ×2、OPA2277、BNC 套件、0.1% 电阻 → 约 ¥150
  - 确认/补 ②的 **TI MCU(F28379D 或 MSP432)** → ¥150（若已有则省）
- **第二批·按题追加（启动③④时再买）**：小车底盘+电机+循迹+IMU(¥395)、OpenMV+云台(¥500+)
- **第三批·强电(⑤,谨慎)**：先确认示波器/电子负载/隔离条件再下单，否则别采购
- **赛场提供、平时不必买**：示波器、信号发生器、电子负载、直流电源（练习阶段尽量蹭实验室）
