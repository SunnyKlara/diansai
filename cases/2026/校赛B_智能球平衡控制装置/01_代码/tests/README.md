## 实测结果（2026，本机 Python 3.14）

| 测试 | 指标 | 实测 | 题目要求 | 结论 |
|---|---|---|---|---|
| 定高 10cm | 稳态误差 | **0.13 cm** | ≤±1cm（满分）| ✅ |
| 定高 15cm | 稳态误差 | **0.21 cm** | ≤±1cm | ✅ |
| 定高 20cm | 稳态误差 | **0.32 cm** | ≤±1cm | ✅ |
| 跟踪 10→20cm | 调节时间 | **0.80 s** | ≤5s | ✅ |
| 跟踪 20→10cm | 调节时间 | **0.96 s** | ≤5s | ✅ |
| 抗扰（6s 向下冲击）| 恢复后稳态误差 | **0.63 cm** | 能自恢复 | ✅ |

悬浮所需风速 ≈ 8.64 m/s；u_ff(10/15/20cm)=0.70/0.78/0.86。

曲线见 `golden_curve.png`（上：球高 vs 目标；下：风机占空比）。
