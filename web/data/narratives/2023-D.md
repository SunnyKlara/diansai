> **小白补课：什么是"调制"**
> - **'**载波**'** = 高频正弦波（如 2 MHz 的正弦），它本身不携带信息——**只是个"运送工具"**
> - **'**调制**'** = 把"信息（如人声 / 数据）"** 装到载波上——**有 3 种装法**：
>   - **AM（Amplitude Modulation）**：**让载波"幅度"** 跟着信息变**——**像"音量随说话变"**
>   - **FM（Frequency Modulation）**：**让载波"频率"** 跟着信息变**——**像"声调随说话变"**
>   - **PM（Phase Modulation）**：**让载波"相位"** 跟着信息变**——**像"节奏随说话变"**
> - **'**键控（Keying）**'** = 数字版调制——**信息只有 0 / 1 两个值**——**对应到 ASK / PSK / FSK**
> - 一句话：**调制 = 把信息"嫁接"** 到载波上的 N 种方式**

## 第一个谜：怎么用 ADC 抓住 2 MHz 载波

**奈奎斯特定理**：**采样率 ≥ 2 × 信号最高频率**——**载波 2 MHz → 至少 4 MSPS 采样率**——**工程上要 8~10 MSPS 留余量**。

**第一笔账：MCU 内置 ADC 够不够**

| MCU 平台 | 内置 ADC 最大采样率 | 评价 |
|---|---|---|
| **STM32F103** | 1 MSPS | **远不够** |
| **STM32F407** | 2.4 MSPS | **勉强 1 MHz 信号，不够 2 MHz** |
| **MSP432P401R** | 1 MSPS | **不够** |
| **TM4C129** | 2 MSPS | **不够** |
| **STM32H743** | 5 MSPS（双 ADC 交错 10 MSPS） | **够** |
| **MSPM0G3507** | 4 MSPS | **够** |

**国一选择**：**MSPM0G3507（4 MSPS） 或 STM32H743（10 MSPS 交错模式）**——**满足 2 MHz 载波采样**。

**'**双 ADC 交错（Interleaved ADC）**' 是什么**？——**两个 ADC 在不同时刻采样**——**采样率叠加**——**比如各 5 MSPS 交错 = 10 MSPS 等效**：

```
ADC1 在 t = 0, 200ns, 400ns, 600ns... 采样（5 MSPS）
ADC2 在 t = 100ns, 300ns, 500ns, 700ns... 采样（5 MSPS）
合并 = 10 MSPS
```

**这段说明的其实是**——**'**两个 ADC 错相 100 ns 启动 → 采样率翻倍**'**——**国一队伍的高级技巧**。

**第二笔账：方案 B - 外置高速 ADC**

| 型号 | 位数 | 采样率 | 价格 |
|---|---|---|---|
| **AD9226**（ADI） | 12 位 | 65 MSPS | 50 元 |
| **AD9280**（ADI） | 8 位 | 32 MSPS | 30 元 |
| **ADC0820**（NSC） | 8 位 | 666 kSPS | 8 元（**太慢**） |
| **ADS5292**（TI） | 12 位 | 80 MSPS | 80 元 |

**国一选择**：**AD9226（12 位 65 MSPS）**——**外接 FPGA 或 STM32 H7 高速 GPIO**——**1 V 输入范围 → 直接接 100 mV 信号**。

**第三笔账：欠采样（Undersampling）—— 高级技巧**

如果不想买高速 ADC——**用"欠采样"** 也能搞**：

```
带通信号 1.95 MHz~2.05 MHz（中心 2 MHz、带宽 100 kHz）
按奈奎斯特 → 4 MSPS
但带通采样定理：采样率 ≥ 2 × 带宽 = 200 kSPS
代入正确的"折叠"** 公式 → 信号搬到 0~100 kHz 等效频带
```

**'**欠采样**'** 的精髓：**用 250 kSPS 采样率 → 等效采到 2 MHz 信号**——**前提是信号是"带通"**（**已知中心频率**）。

**这段说明的其实是**——**'**只关心"调制信息"** 而不关心"载波本身"** → 用欠采样把 2 MHz 折叠到 250 kHz 测量**'**——**省 16 倍 ADC 速度**——**MSP432 1 MSPS 就够**。

**国一队伍**：**欠采样 + MSP432 1 MSPS** 或 **直接采样 + MSPM0 4 MSPS**——**两套方案都行**。

## 第二个谜：怎么把 AM 信号"听出来"

**AM 调制的数学**：

```
uAM(t) = Ac × (1 + ma × cos(2πF×t)) × cos(2πfc×t)

其中：
Ac = 载波幅度
ma = 调幅系数（0.3~1.0）
F = 调制信号频率（1 kHz）
fc = 载频（2 MHz）
```

**这个式子说的其实是**——**'**载波 cos(2πfc×t) 的"幅度"** 被 (1 + ma·cos(2πF×t)) 调制**'**——**幅度从 (1-ma)·Ac 到 (1+ma)·Ac 之间变化**。

**调幅系数 ma**：

```
ma = (Amax - Amin) / (Amax + Amin)
其中 Amax 和 Amin 是 AM 信号的"包络"** 最大值和最小值
```

**'**包络**'** 是什么？**AM 信号"幅度变化的轨迹线"**——**沿着信号顶端连成的曲线**：

```
        ┌──╮  ┌──╮  ┌──╮
       ╱    ╲╱    ╲╱    ╲
      ╱  ╱╲  ╱╲  ╱╲      ╲
     ╱╱╲╱  ╲╱  ╲╱  ╲      ╲   ← 包络（最高点连线）
     ╲╱            ╲      ╱
      ╲             ╲    ╱
       ╲___________  ╲__╱
```

**第一笔账：AM 解调三种方法**

**方法 A：包络检波（最简单）**

```
1. 整流（半波或全波）
2. 低通滤波（截止 = 调制信号频率 5 倍）
3. 减去直流分量
```

**电路实现**——**1 个二极管 + 1 个 RC 低通**——**2 元钱**：

```
uAM ──[二极管]──┬── R = 10kΩ ── 输出 uo
                │
              C = 1nF
                │
              GND
```

**RC 时间常数**：**1nF × 10kΩ = 10μs** → **截止频率 16 kHz** → **能跟上 5 kHz 调制信号 + 滤掉 2 MHz 载波**。

**优点**：**简单、模拟、不耗算力**。  
**缺点**：**直流偏置不稳 + ma 估计精度差**。

**方法 B：数字包络检波**

```c
// 对 ADC 采样数据求包络
for (int i = 0; i < N - 1; i++) {
    envelope[i] = sqrtf(uAM[i]² + uAM[i+1]²);  // 希尔伯特变换近似
}

// 求 Amax 和 Amin
float Amax = max(envelope);
float Amin = min(envelope);

// 算 ma
float ma = (Amax - Amin) / (Amax + Amin);
```

**这段代码说的其实是**——**'**用希尔伯特变换求包络 → 找峰谷 → 算 ma**'**——**精度比模拟方法高 10 倍**。

**国一选择**：**数字包络检波 + 希尔伯特变换**——**ma 精度 ±0.02**——**远超 ±0.1 要求**。

**第二笔账：希尔伯特变换是什么**

**希尔伯特变换（Hilbert Transform）**：**把信号的相位移 90°**——**等于"把 cos 变 sin"**：

```
原信号：x(t) = cos(2πfc×t)
希尔伯特变换后：x_h(t) = sin(2πfc×t)

包络：A(t) = √(x(t)² + x_h(t)²) = 1（恒定，因为 cos² + sin² = 1）
```

**对调制信号**：

```
原信号：x(t) = A(t) × cos(2πfc×t)
希尔伯特变换：x_h(t) = A(t) × sin(2πfc×t)
包络：√(x² + x_h²) = A(t)（精确得到调制信号）
```

**这就是"求包络"** 的精确数学方法**——**远比简单整流精确**。

**FFT 实现希尔伯特**：

```c
// 1. FFT
fft(x, X, N);

// 2. 把负频率分量置零、正频率分量乘 2
for (int k = 0; k < N/2; k++) X[k] *= 2;
for (int k = N/2; k < N; k++) X[k] = 0;

// 3. IFFT 得到"解析信号"
ifft(X, x_analytic, N);

// 4. 包络 = |x_analytic|
for (int i = 0; i < N; i++) envelope[i] = abs(x_analytic[i]);
```

**这段代码说的其实是**——**'**FFT → 削正频 → IFFT → 取模 = 包络**'**——**N log N 复杂度**——**1024 点 1.5ms 完成**。

**第三笔账：ma 估计的精度优化**

**直接用 max / min 求 ma 的问题**：**包络上有噪声 → 单点峰值不可靠**。

**对策**：**多周期平均**：

```c
// 找包络的所有峰值（局部极大）
for (int i = 1; i < N-1; i++) {
    if (envelope[i] > envelope[i-1] && envelope[i] > envelope[i+1]) {
        peaks[peak_count++] = envelope[i];
    }
}
float Amax = mean(peaks);

// 同理找谷值
float Amin = mean(valleys);

float ma = (Amax - Amin) / (Amax + Amin);
```

**'**多个周期平均**'** —— **抑制单点噪声**——**精度 √10 倍提升**。

10 分稳拿。

## 第三个谜：怎么解 FM 调制 + 测最大频偏

**FM 调制的数学**：

```
uFM(t) = Ac × cos(2πfc×t + mf × sin(2πF×t))
       = Ac × cos(2πfc×t + (Δfmax / F) × sin(2πF×t))

其中：
mf = 调频系数 = Δfmax / F
Δfmax = 最大频偏
F = 调制信号频率（5 kHz）
fc = 载频（2 MHz）
```

**'**FM 信号瞬时频率**'**：

```
f_inst(t) = fc + Δfmax × cos(2πF×t)
```

**这个式子说的其实是**——**'**载波频率"上下"** 摆动 ±Δfmax**'**——**最大频偏是 FM 信号的"摆动幅度"**。

**第一笔账：FM 解调三种方法**

**方法 A：微分鉴频**（**经典模拟法**）

```
1. uFM(t) 通过微分电路 → du/dt
2. du/dt 的包络 ∝ 瞬时频率
3. 包络检波 → 解调信号
```

**优点**：**模拟、简单**。  
**缺点**：**精度差 + 噪声敏感**。

**方法 B：PLL 鉴频**

```
1. PLL 锁住 uFM 的瞬时频率
2. PLL 误差信号 ∝ 瞬时频率偏差
3. 误差信号低通滤波 = 解调信号
```

**优点**：**精度高 + 抗噪声强**。  
**缺点**：**电路复杂 + 需要 VCO**。

**方法 C：数字过零法（最经典）**

```
1. 把 FM 信号过零点检测
2. 算每两个过零点的"时间差"** = 1/(2 × f_inst)
3. 反算 f_inst → 解调信号
```

**精度**：**取决于过零点检测的时间分辨率**——**100 MHz 计数器 → 10 ns 精度 → 1 Hz 频率精度**——**远超要求**。

**第二笔账：数字 IQ 解调（国一首选）**

```c
// 1. 用本振信号产生 I/Q 两路
I_local = cos(2π × fc × t);
Q_local = sin(2π × fc × t);

// 2. 混频
I_mix = uFM × I_local;
Q_mix = uFM × Q_local;

// 3. 低通滤波（截止 = 5 × Δfmax）
I = lowpass(I_mix);
Q = lowpass(Q_mix);

// 4. 求瞬时相位
phase = atan2(Q, I);
phase_unwrapped = unwrap(phase);  // 解相位卷绕

// 5. 求瞬时频率（微分相位）
for (int i = 1; i < N; i++) {
    f_inst[i] = (phase_unwrapped[i] - phase_unwrapped[i-1]) / (2π × dt);
}

// 6. 求最大频偏
Δfmax = (max(f_inst) - min(f_inst)) / 2;

// 7. 求 mf = Δfmax / F
mf = Δfmax / F_estimate;
```

**这段代码说的其实是**——**'**IQ 混频 → 求相位 → 求瞬时频率 → 求频偏**'**——**精度 1 Hz**——**远超 ±300 Hz 要求**。

**国一队伍**：**IQ 解调 + 高精度过零检测**——**Δfmax 精度 ±50 Hz**——**满分 15**。

## 第四个谜：怎么自动识别 6 种调制方式

**核心算法**：**特征提取 + 决策树**：

```
特征 1：包络方差 σ_env
        - AM / 2ASK：σ_env > 阈值（包络变化大）
        - FM / CW / 2PSK / 2FSK：σ_env < 阈值（包络恒定）

特征 2：瞬时频率方差 σ_freq
        - FM / 2FSK：σ_freq > 阈值（频率变化）
        - AM / CW / 2PSK / 2ASK：σ_freq ≈ 0

特征 3：平方后频谱
        - 2PSK：平方后载波频率翻倍 + 谱线集中
        - 2FSK：平方后两个谱峰
        - AM / FM：平方后多谱峰
        - CW：平方后单谱峰

特征 4：包络是否"二值化"
        - 2ASK：是（0 或 1）
        - AM：否（连续变化）
```

**决策树**：

```
START
  │
  ├── σ_env > T1 ?
  │       │
  │       ├── YES → σ_env "二值化"** ?
  │       │           ├── YES → 2ASK
  │       │           └── NO → AM
  │       │
  │       └── NO → σ_freq > T2 ?
  │                   │
  │                   ├── YES → 平方频谱"双峰"** ?
  │                   │           ├── YES → 2FSK
  │                   │           └── NO → FM
  │                   │
  │                   └── NO → 平方频谱"翻倍载频"** ?
  │                               ├── YES → 2PSK
  │                               └── NO → CW
```

**这套决策树说的其实是**——**'**4 个特征 + 4 次判断 → 唯一确定 6 种调制类型**'**——**精度 95%+**——**国一标配**。

**第一笔账：识别精度**

| 调制 | 单帧识别率 | 多帧投票后 |
|---|---|---|
| **CW** | 99% | 100% |
| **AM** | 95% | 99% |
| **FM** | 95% | 99% |
| **2ASK** | 90% | 98% |
| **2PSK** | 85% | 96% |
| **2FSK** | 90% | 98% |

**'**5 帧投票**'** 是关键——**每次识别完不直接显示，连续 5 帧一致才显示**——**精度提升 5%**。

**第二笔账：码速率估计**

发挥要求：**估计 2ASK / 2PSK / 2FSK 的码速率（6 / 8 / 10 kbps）**。

**核心算法**：**自相关法**

```c
// 解调出二进制码序列后
for (int lag = 1; lag < MAX_LAG; lag++) {
    autocorr[lag] = 0;
    for (int n = 0; n < N - lag; n++) {
        autocorr[lag] += data[n] * data[n + lag];
    }
}

// 找自相关的"周期峰值"
int peak_lag = find_first_peak(autocorr);
float Tc = peak_lag / fs;  // 码元周期
float Rc = 1 / Tc;          // 码速率
```

**这段代码说的其实是**——**'**自相关函数的"周期峰"** 间距 = 码元周期**'**——**精度 ±100 bps**。

**国一队伍**：**码速率精度 ±50 bps**——**完美命中 6/8/10 kbps**。


## 第五个谜：怎么把解调信号输出 ≥ 1 V

**说明 (4)**：**解调信号 uo 必须单端口输出 + 无明显失真 + 峰峰值 ≥ 1V**。

**问题**：**ADC 采进来的信号 100 mV → 算法解出来的"调制信号"** 还是 100 mV 量级——**直接输出 < 1 V**——**违规**。

**对策**：**MCU 内置 DAC + 后级运放放大**：

```
解调算法输出 → DAC（12 位）→ OPA1612 运放（增益 10 倍）→ BNC 输出
                                          │
                                       100 mV → 1 V 放大
```

**'**OPA1612**'** 是 ADI 的高性能音频运放——**带宽 80 MHz + THD < 0.001%**——**完美适合 1~5 kHz 调制信号**。

### 发挥 (2)：2FSK 识别 + Rc + h（16 分）

**'**移频键控系数 h**'** = **(fc1 - fc0) / Rc**——**两个发射频率的差除以码速率**：

```c
// 找出 2 个发射频率
float fc0 = find_first_peak(spectrum);
float fc1 = find_second_peak(spectrum);

// 算 h
float h = (fc1 - fc0) / Rc;
```

**精度**：**±0.1**——**满足 2~5 范围内的精度**——**满分 16**。

### 发挥 (3)：2PSK 识别 + 码速率（19 分）

**'**2PSK 是最难的**'** —— **包络恒定 + 瞬时频率恒定 + 只有"相位跳变"**——**普通方法识别不出**。

**关键**：**平方法**——**把 2PSK 信号平方后**：

```
原信号：cos(2πfc×t + bn×π)，bn ∈ {0, 1}
平方后：cos²(2πfc×t + bn×π) = (1 + cos(4πfc×t + 2×bn×π)) / 2
                              = (1 + cos(4πfc×t)) / 2  （因为 2×bn×π = 0 或 2π）
```

**这个式子说的其实是**——**'**2PSK 平方后变成了"频率翻倍 + 没有相位跳变"** = 单频信号**'**——**频谱有一根强谱线在 2fc 处 = 4 MHz**——**这是 2PSK 的"金指纹"**。

**FM 平方后频谱有"宽带谱"**——**2FSK 平方后有"两根并行谱"**——**唯独 2PSK 平方后是"单根谱"**——**100% 区分**。

19 分稳拿。
