## 想象一个场景

你是一家深圳代工厂的来料检验员。今天上午到货 5000 颗"国巨 0603 贴片电容"——**标称 22 nF / ±5%**——**单价 0.08 元 / 颗**。**老板要求**：**全数测**——**容值 < 20.9 nF 或 > 23.1 nF 的全部退货 + 测损耗角 tanδ > 0.05 的也退货**。

你打开桌上那台**Keysight E4980AL 精密 LCR 表**——**18 万元的仪器**——**测每颗电容 1 秒**——**5000 颗 = 1.4 小时**——**老板看着秒表催**。

旁边新人小李问：**'**为啥要测损耗角？容值不就够了吗？**'**

你把一颗"看起来 22 nF 但实际损耗角 0.08"** 的电容焊到示波器探头上，让小李看波形——**正弦输入 → 输出居然有"延迟相位 + 失真"** —— **这颗电容里其实混了一些"假电介质"** —— **市面便宜的"二线品牌"** 经常这样——**容值看起来对但功率因数极差**——**装到滤波器里 → 滤波效果差一倍 + 发热严重**。

**这就是"损耗角 tanδ"** 的工业意义——**它告诉你"这颗电容真正多少能量被浪费成热"**：

```
tanδ = ESR / Xc = (R等效串联电阻) / (1 / 2πfC)
```

**这个式子说的其实是**——**'**电容里"无效热"** 占"总能量"** 的比例 = ESR 除以容抗**'**——**tanδ 越小越好**。

| 电容应用 | 典型 tanδ 要求 |
|---|---|
| **高频滤波（5G 基站）** | < 0.0005 |
| **音频（Hi-Fi 功放）** | < 0.005 |
| **电源滤波（普通）** | < 0.05 |
| **储能（铝电解）** | < 0.15 |
| **失效品** | > 0.5 |

**测 tanδ 的仪器叫 LCR 表**——**全球年销 50 万台**——**主流品牌**：**Keysight（美）、HIOKI（日）、Wayne Kerr（英）、罗德与施瓦茨（德）**——**国产替代率 < 30%**——**国内做 LCR 表的有同惠、致远、鼎阳**。**最便宜的入门 LCR 表 1500 元**——**最贵的 30 万元**。

**电赛 2023 C 题让你做的**——**用 200 元成本做出 1500 元 LCR 表的入门版**——**4 天 3 夜里要完成"测电感 + 电容 + Q + tanδ"** 四个量——**这是仪表工程师的"基本功考试"**。

> **小白补课：什么是 Q 和 tanδ**
> - **电感 Q（Quality factor，品质因数）**：**电感能量储存能力 / 损耗能力**——**Q = ωL / R = 2πfL / R_dc**——**'**Q 越高 = 电感越接近"理想元件"**'**——**典型射频电感 Q = 50~200**
> - **电容 tanδ（损耗角正切）**：**电容内部"等效串联电阻 ESR"** 占容抗的比例——**等同于 1/Q**——**'**tanδ 越小 = 电容越纯**'**
> - 一句话：**Q 和 tanδ 是同一个"能量纯度"** 的两种表达方式**——**理想元件 Q = ∞ 或 tanδ = 0**

**第三层意图：阻抗测量的"算法门槛"**

LCR 测量的核心算法叫**'**矢量阻抗法（Vector Impedance Method）**'**——**也叫"四端检测（4-Wire Kelvin Sensing）"** —— **是大学《电路分析》第三章的内容**——**但 90% 学生学完就忘**。

**算法核心**：**给被测元件加正弦电压 V → 测它流过的电流 I → 用 V / I 得复阻抗 Z**：

```
Z = V / I = R + jX
其中：
R = 实部（电阻分量）
X = 虚部（电抗分量）

电感 L = X / (2πf)
电容 C = 1 / (2πf × |X|)
电容 tanδ = R / |X|
电感 Q = |X| / R
```

**这套式子说的其实是**——**'**复阻抗 Z 的实部 / 虚部 + 测量频率 → 反算 L、C、Q、tanδ**'**——**全部都是简单除法和反正切**——**问题在"怎么测精确的 V 和 I"**。

**'**精确测 V 和 I**'** 是 LCR 表 100 年的核心难题——**1 nF 电容在 100 kHz 下容抗 1.6 kΩ**——**给它加 1 V 正弦** = 流过 0.6 mA 电流——**0.6 mA 又分"实部"** 和"虚部"** —— **每部分精度要 < 1 μA**——**这是真正的"高精度模拟测量"**。

把三层意图叠加——**2023 C 是给"模拟 + 算法"** 队伍准备的"仪表工程师入门考"** ——**做出来 = 直接对接 TI / ADI / 同惠 / 鼎阳**——**起薪 25~50 万**。

## 这题在做的事，其实是给电感电容拍一张"复阻抗 X 光片"

**先认识"复阻抗"** 是什么——**这是这道题的灵魂**。

**'**电阻 R**' 是"实数"** = **只是个普通的数字**——**1 Ω 就是 1 Ω**。

**'**电感 L**' 和"电容 C**' 在"交流电路"** 里**不是简单数字**——**而是"复数"**：

```
电感的复阻抗：Z_L = jωL    （纯虚数，j = √-1）
电容的复阻抗：Z_C = 1/(jωC) = -j/(ωC)  （纯虚数）
电阻的复阻抗：Z_R = R  （纯实数）

ω = 2πf 是角频率
```

**'**复阻抗**'** 这个概念让 90% 本科生头疼——但用一个比喻就能讲清楚——**'**电流 = 一群人在跳舞**'**：

> **小白补课**：复阻抗的物理直觉
> - **电阻 R** = **舞池里有一群"懒人"**——**电压拉一下他们才动一下**——**电压和电流"同步舞动"** = 同相
> - **电感 L** = **舞池里有一群"沉重的舞者"**——**电压先动，他们才慢悠悠跟上**——**电流"慢半拍"** = 相位滞后 90°
> - **电容 C** = **舞池里有一群"机灵鬼"**——**还没等电压加上来，他们就"预判"** 提前动——**电流"早半拍"** = 相位超前 90°
> - **复阻抗的"虚部"** = 描述这种"早半拍 / 慢半拍"** —— **数学上用 j = √-1 表示**——**没有"-1 的开方"** 这个数字概念**就没法描述这种"相位移"** 现象**

**所以"测 L、C、tanδ、Q"** 的本质 = **测元件两端"电压相对电流"** 早了多少 / 晚了多少 + 强度比例**。

**核心物理图像**：

```
信号源（正弦 V）─── R_采样 ───被测元件 Z───接地
                       ↑              ↑
                       │              │
                  V_R 测电流          V_Z 测元件电压
                  （电流 I = V_R / R_采样）
```

**用两个 ADC 同时采 V_R 和 V_Z**——**用 FFT 算两者的"幅值比 + 相位差"** —— **就得到了元件的复阻抗**：

```
Z = V_Z / I = V_Z / (V_R / R_采样) = (V_Z / V_R) × R_采样
|Z| = |V_Z| / |V_R| × R_采样
∠Z = ∠V_Z - ∠V_R
```

**这两个式子说的其实是**——**'**幅值之比 × 采样电阻 = 阻抗大小，相位之差 = 阻抗角度**'**——**这就是"矢量阻抗法"**——**LCR 表的灵魂算法**。

**得到 |Z| 和 ∠Z 后**：

```
R = |Z| × cos(∠Z)
X = |Z| × sin(∠Z)
```

**实部 R 是损耗、虚部 X 是储能**——**两者一起就完整描述了元件**。

接下来一层一层揭开三个谜——**怎么生成精确正弦、怎么精确测两个相位、怎么校准误差**。

## 第一个谜：怎么生成 1 kHz~100 kHz 的精确正弦信号源

**矢量阻抗法的第一步**——**给被测元件加"高纯度正弦电压"**——**纯度直接决定测量精度**。

**'**正弦不纯**' 是什么坑**？

设给电容加 1 V 正弦 V_in，但 V_in 实际有 5% 三次谐波——**频谱**：

```
V_in(t) = 1.0 sin(2π × 1000 × t) + 0.05 sin(2π × 3000 × t)
```

**电容对基波的容抗** = **1/(2π × 1000 × C)**  
**电容对三次谐波的容抗** = **1/(2π × 3000 × C) = 基波的 1/3**

**意思是**：**三次谐波分量在电容上感应的电流是基波电流的 3 × 5% = 15%**——**而你的算法只看"1 kHz 那个频点"**——**结果**：

- **测得的 R 多了 15% 误差**
- **测得的 tanδ 多了一倍**

**这就是"信号源谐波"** 的杀伤力——**5% THD 的输入 → 100% tanδ 测量误差**——**远超 5% 要求**。

**对策**：**用"低 THD 正弦发生器"** —— **三种方案**：

**方案 A：DAC + 查表（DDS 软件版）**

```
MCU 内部 SRAM 存 256 点正弦表
DAC 8 位 / 12 位 / 16 位
查表频率 = 输出频率 × 256
```

**TI MSP432 内置 14 位 DAC**——**输出 14 位精度正弦**——**THD 约 -50 dB = 0.3%**——**完全够用**。

**优点**：**便宜（MCU 内置）+ 频率自由调（改查表速率）**。  
**缺点**：**14 位 DAC 在 100 kHz 下纹波大**——**THD 升到 1%**。

**方案 B：DDS 专用 IC**

**ADI AD9833**：**0~12 MHz DDS + 28 位频率分辨率**——**THD = -55 dB**——**8 元 / 颗**——**电赛标配**。

**优点**：**频率超精确（0.1 Hz 分辨率）+ THD 低 + 便宜**。  
**缺点**：**输出幅度小（650 mV 峰峰值）+ 需要后级运放放大**。

**方案 C：精密信号源 IC**

**ADI AD9106**：**4 通道 12 位 180 MSPS DAC + 内嵌正弦发生器**——**THD = -75 dB**——**80 元 / 颗**。

**国一队伍**：**AD9833 + 后级 OPA1612 缓冲**——**THD < 0.1% + 1 V 幅度**——**完美**。

**第一笔账：信号幅度选取**

题目说"测电容 1 nF~100 nF"——**100 kHz 测量频率下**：

```
1 nF 容抗 = 1/(2π × 100k × 1 nF) = 1.6 kΩ
100 nF 容抗 = 1/(2π × 100k × 100 nF) = 16 Ω
```

**容抗范围 16 Ω~1.6 kΩ**——**100 倍**——**信号源输出阻抗必须 < 16 Ω**——**否则电容上电压被分压拉低**。

**对策**：**信号源后级用低输出阻抗运放**（**OPA1612 输出 < 1 Ω**）—— **完美驱动 16 Ω 容抗**。

**第二笔账：测试频率选取**

要求 (3)：**1 kHz~100 kHz 范围内自定一个频率**——**怎么选**？

```
1 kHz：测大电容（100 nF），容抗 1.6 kΩ → 信号大、信噪比好
100 kHz：测小电容（1 nF），容抗 1.6 kΩ → 信号大、信噪比好
10 kHz：折中，全部范围都够测
```

**国一选择**：**10 kHz**——**或者根据被测元件值"自适应频率"** —— **小电容用高频、大电容用低频**——**始终保持容抗 ≈ 1 kΩ**——**信噪比最优**。

## 第二个谜：怎么精确测"幅值比 + 相位差"

**核心问题**：**两路 ADC 同步采 V_R 和 V_Z → 算 |V_Z| / |V_R| 和 ∠V_Z - ∠V_R → 精度多高**？

**第一笔账：理论精度**

设 1 kHz 信号 + 100 kSPS 采样率 + 1024 点 FFT：

```
频率分辨率 = 100 kSPS / 1024 = 97.7 Hz
对应相位精度 = 360° × (97.7 / 1000) = 35° → 不够
```

**'**单纯 FFT 找峰值**'** 精度 35°——**远大于"测 tanδ < 5%"** 需要的 1° 精度**。

**对策**：**整周期采样 + 单频点 DFT**——**精度提升 1000 倍**。

**第二笔账：单频点 DFT**

```
X(f0) = Σ x(n) × exp(-j × 2π × f0 × n / fs)
      = Σ x(n) × cos(2π × f0 × n / fs) - j × Σ x(n) × sin(2π × f0 × n / fs)
      = X_real - j × X_imag

|X(f0)| = √(X_real² + X_imag²)
∠X(f0) = atan2(-X_imag, X_real)
```

**这套式子说的其实是**——**'**只算"被测频率"** 那一个点的 DFT**'** —— **比全谱 FFT 简单 1000 倍**——**且精度极高**。

**关键**：**整周期采样（采样窗口 = 整数个信号周期）**——**消除频谱泄漏**——**精度从 35° 升到 0.01°**。

```c
// 设信号 10 kHz，采样率 1 MSPS → 每周期 100 点
// 采 1024 周期 = 102400 点
const int N = 102400;
const float f0 = 10000.0f;
const float fs = 1000000.0f;

float X_real = 0, X_imag = 0;
for (int n = 0; n < N; n++) {
    float angle = 2 * M_PI * f0 * n / fs;
    X_real += V_Z[n] * cosf(angle);
    X_imag -= V_Z[n] * sinf(angle);
}
float magnitude_VZ = sqrtf(X_real * X_real + X_imag * X_imag);
float phase_VZ = atan2f(-X_imag, X_real);
```

**这段代码说的其实是**——**'**用乘法 + 累加直接算"指定频率的 DFT"**'** —— **精度超 FFT**——**计算量 N 次乘加**——**MSP432 80 MHz 能 1ms 完成**。

**第三笔账：双 ADC 通道一致性**

**两个 ADC 通道同时采 V_R 和 V_Z** —— **必须严格同步**——**否则相位差测错**。

**问题**：**MCU 自带 ADC 一般是"轮询采样"**——**通道 1 采完再采通道 2**——**两通道差 1~10 μs**——**对应 1~10 kHz 信号的相位差 = 0.36°~3.6°**——**这就是 tanδ 测量精度的下限**。

**对策**：**用"同时采样 ADC"** —— **两个独立 ADC 同时启动 + 同步触发**：

| 方案 | 通道间相位误差 | 价格 |
|---|---|---|
| **MSP432 内置 ADC（轮询）** | 0.36° @ 10 kHz | 0 元 |
| **TI ADS131A04（同步 4 通道）** | < 0.001° | 30 元 |
| **TI ADS1294（医疗级 8 通道）** | < 0.0001° | 80 元 |
| **双独立 ADC + 同步触发** | < 0.01° | 50 元 |

**国一队伍**：**ADS131A04**——**24 位 + 同步采样**——**相位误差 < 0.001°**——**完美**。  
**国二**：**MSP432 双 ADC 模块同时触发**——**相位误差 0.05°**——**够用**。  
**国三**：**单 ADC 轮询**——**误差 1°**——**tanδ 测量精度差**。

**第四笔账：相位测量精度对 tanδ 的影响**

```
对于电容 tanδ = 0.005 的元件
∠Z = -90° + arctan(tanδ) = -90° + 0.286°

测得相位差 = -90° + (0.286° ± δφ)
反算 tanδ = tan(0.286° ± δφ)
```

**这个式子说的其实是**——**'**相位测量精度 δφ 必须 < 0.05°，才能保证 tanδ = 0.005 测对 5%**'**。

**国一队伍**（ADS131A04）：**相位精度 0.001°** —— **tanδ 测量精度 0.0005**——**远超要求**。


## 第三个谜：怎么校准系统误差

**LCR 表的"系统误差"** 来自三处：

- **采样电阻 R_采样 不精确**（**5% 普通电阻 → 5% 测量误差**）
- **运放增益不为 1**（**±0.1% 误差累积**）
- **导线杂散电感 + 寄生电容**（**1m 导线 ≈ 1 μH + 30 pF**）

**这三处误差不校准 → 测出来的 L、C 都偏 5%~20%**——**远超要求**。

**第一笔账：开路 / 短路校准（OSL 校准）**

**LCR 表的标准校准流程**：

```
Step 1：开路校准（不接元件）
        理想：Z_open = ∞ → 测得的电流应为 0
        实际：测到杂散电容流过的小电流 I_open
        记录 Y_open = I_open / V_in

Step 2：短路校准（用粗短铜线短接）
        理想：Z_short = 0 → 测得的电压应为 0
        实际：测到导线电阻 + 寄生电感造成的小电压 V_short
        记录 Z_short = V_short / I

Step 3：测量校准（用精密元件 100Ω 0.01% 校准）
        测出装置增益误差 K_gain
```

**校准后的真实阻抗**：

```
Z_actual = (V_measured / I_measured - Z_short) × K_gain
         经过 Y_open 项修正
```

**这一套式子说的其实是**——**'**先测装置自身的"杂散"**——**再测元件时减掉"杂散"** = 真值**'**——**专业 LCR 表的标准做法**。

**第二笔账：自动校准实现**

```c
// 上电后自动校准
void calibration() {
    printf("请保持开路（不接元件）\n");
    wait_for_button();
    measure_open_circuit(&Y_open);
    
    printf("请短接探头\n");
    wait_for_button();
    measure_short_circuit(&Z_short);
    
    printf("请接入 100 Ω 标准电阻\n");
    wait_for_button();
    measure_calibration_resistor(&K_gain);
    
    // 保存校准参数到 Flash
    save_calibration(Y_open, Z_short, K_gain);
}

// 测量时自动应用校准
float measure(float V, float I) {
    Z_raw = V / I;
    Z_corrected = (Z_raw - Z_short) * K_gain;
    Z_corrected /= (1 - Y_open * Z_corrected);
    return Z_corrected;
}
```

**这段代码说的其实是**——**'**首次开机做 3 步校准 → 保存参数 → 之后每次测量自动减掉系统误差**'**——**精度从 ±20% 提升到 ±0.5%**。

**国一队伍**：**OSL 三步校准 + 自动检测**——**精度 ±0.3%**——**远超 5% 要求**——**满分**。

**第三笔账：温度补偿**

LCR 测量精度受温度影响——**采样电阻温度系数 ±100 ppm/℃**——**温度变 10°C → 误差变 0.1%**——**不严重但可补偿**：

```c
float R_sense_temp_compensated = R_sense_25C × (1 + TC × (T - 25));
```

**国一**：**加温度传感器 + 实时补偿**——**精度从 0.5% 提升到 0.1%**。

## 第四个谜：怎么测电感的 Q 值高达 200

**发挥要求 (2)**：**电感 Q 值范围 1~200，精度 ≤ 5%**。

**Q = 200 是什么概念**？

```
Q = ωL / R
设 L = 100 μH，f = 100 kHz
ωL = 2π × 100k × 100μ = 62.8 Ω
要求 Q = 200 → R = 62.8 / 200 = 0.314 Ω
```

**'**电感的等效串联电阻只有 0.3 Ω**'** —— **比导线本身的电阻还小**——**测量极其困难**。

**第一笔账：Q 测量精度**

```
Q = X / R，R 测量精度 ±5% → Q 精度 ±5%
对应 R = 0.314 Ω 时，绝对精度 ±0.016 Ω
```

**'**±0.016 Ω 精度**'** = **几个毫欧**——**接近测量极限**。

**对策**：**4 端开尔文测量（Kelvin Sensing）**

> **小白补课**：什么是 4 端开尔文测量？
> - **2 端测量**（普通万用表）：**电流和电压用同一对探针**——**导线电阻被算进去**
> - **4 端测量**：**电流用一对粗导线、电压用另一对细导线（探针正好接在元件本体）**——**完美隔离导线影响**——**精度提升 100 倍**
> - **应用**：**精密电阻测量、毫欧级测量、电池内阻测试**

**4 端电感测量**：

```
Force +：注入电流（粗线）
Sense +：测元件正极电压（细线，靠近元件）
Sense -：测元件负极电压（细线，靠近元件）
Force -：电流回路（粗线）
```

**国一队伍**：**4 端 Kelvin 探针 + 精密电流源 + 仪表运放**——**Q = 200 测准**——**满分**。

**第二笔账：高 Q 测量的频率选取**

```
Q = ωL / R = 2πfL / R
频率越高 → Q 越大 → 测量越准
```

**对策**：**测高 Q 电感时用高频率**（**100 kHz**）—— **Q = 200 时 R 的相对值 1/200 = 0.5%**——**接近测量精度极限**——**但能测**。

**测低 Q 电感（Q = 1）时用低频率**（**1 kHz**）—— **R 占主导**——**精度好**。

**'**自适应频率**'** 是 LCR 表的常规做法——**国一标配**。

## 把题目逐条翻译一遍

### 任务那段话

> 基于 **TI 公司的 MCU**，设计并制作电感及其品质因数 Q、电容及其损耗角正切 D 的测量装置。**被测元件接入，一键启动后，在规定时间内自动完成测量**。**测量装置要提供专用于监测测试频率的信号输出接口**，用于实时监测装置的测试频率。

任务核心：

- **TI MCU 限定**（**MSP432 / TM4C / 早期 MSPM0**）
- **被测元件 → 一键启动 → 自动测**
- **必须提供"测试频率监测口"**（**给评委用示波器看你用的什么频率**）

**'**测试频率监测口**'** 是隐藏要求——**很多队伍漏做**——**评委要看你的频率是不是稳定**——**没有这个口直接扣分**。

### 基本要求 (1)：电容 1 nF~100 nF ±5%（核心 20 分）

> 电容量测量范围：**1 nF~100 nF**，测量相对误差的绝对值不大于 **5%**。

**'**1 nF~100 nF**'** 是什么范围？

| 容值 | 应用 |
|---|---|
| **1 nF** | 高频滤波、晶振负载 |
| **10 nF** | 信号耦合、PWM 滤波 |
| **100 nF** | 旁路电容、电源去耦 |

**这是电子工程最常用的范围**——**任何 PCB 板上 90% 的小电容都在这里**。

**精度 5%**：**1 nF 元件容差 ±50 pF**——**前面已经讲过 ADS131A04 + DFT + OSL 校准 → 精度 ±0.5%**——**满分稳拿**。

**第一笔账：1 nF 在 1 kHz 下的容抗**

```
Xc = 1 / (2π × 1k × 1n) = 159 kΩ
```

**'**159 kΩ 容抗**'** —— **加 1 V 信号** = 流过 6.3 μA 电流——**对 ADS131A04 的 24 位精度（最小 0.6 μV）来说**——**电流测量分辨率 < 1 nA**——**完全够**。

**第二笔账：100 nF 在 100 kHz 下的容抗**

```
Xc = 1 / (2π × 100k × 100n) = 16 Ω
```

**'**16 Ω 容抗**'** = **接近"短路"** —— **加 1 V 信号** = 流过 60 mA 电流——**采样电阻必须选小（< 5 Ω）**——**否则信号被采样电阻分压**。

**对策**：**自适应采样电阻**——**根据被测元件值切换采样电阻 1 Ω / 100 Ω / 10 kΩ**——**始终保持采样电阻 ≈ 容抗**——**信噪比最优**。

20 分稳拿。

### 基本要求 (2)：tanδ 0.005~1 ±5%（核心 20 分）

> 电容 D 值测量范围：**0.005~1**，测量相对误差的绝对值不大于 **5%**。

**'**0.005~1**'** = **D 值范围 200 倍**——**从"接近理想电容"** 到"几乎是电阻"** —— **覆盖所有"实际电容"** 类型**。

**前面已经讲过相位测量精度 0.05° → tanδ 精度 0.0005**——**满足 5% × 0.005 = 0.00025 极限要求**——**关键是"高精度同步 ADC"**——**满分**。

20 分稳拿。

### 基本要求 (3)：频率自定（5 分）

> 在 1 kHz~100 kHz 范围内，**自定某一固定测量频率**。

**'**自定一个频率**'** = **简单** —— **AD9833 程控 → 选 10 kHz** —— **5 分稳拿**。

### 基本要求 (4)：测量时间 ≤ 1 秒（5 分）

> 测量时间不大于 **1 秒**。

**前面已经讲过 1024 周期 DFT + 80 MHz MCU = 100 ms**——**远低于 1 秒**——**满分**。

5 分稳拿。
