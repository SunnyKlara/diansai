## 想象一个场景

凌晨两点，浙江某座 5G 基站的塔下。**通信运维工程师老周扛着一卷橙色的"同轴电缆"** —— **长度约 50 米**——**正准备爬上 30 米高的塔顶**——**把信号从塔下机房送到塔顶天线**。

但他今晚不爽——**这卷电缆是"二手货"** —— **昨天工地上从一根 100 米的盘子上剪下来的**——**老板没贴标签**——**他不知道这一段是不是"接头处的暗伤"**——**接上去万一信号衰减大 → 5G 信号覆盖不到 → 用户掉网 → 老板罚钱 800 元**。

**怎么办**？老周从工具包里掏出一个**"鞋盒大小的检测仪"**——**一头插同轴电缆 BNC 接头**——**按下"长度"按键**——**1 秒钟后屏幕显示**：

```
长度：5023 cm
终端：开路
反射：正常
判定：合格 ✓
```

**5023 cm = 50.23 米**——**和老板说的"50 米"** 一致——**说明这卷电缆中间没有暗伤**——**老周松一口气**——**爬塔安装**。

**这台"鞋盒"** 在工业上叫**TDR（Time Domain Reflectometry，时域反射仪）**——**全球价格 1500~50000 美元** ——**主流厂商**：**Tektronix（美）、Keysight（美）、Anritsu（日）、致远电子（中）**——**全球年销量约 30 万台**——**5G + 数据中心 + 卫星 + 军工 全部要用**。

**TDR 的工作原理**——**一句话总结**：**'**给电缆发一个尖脉冲，看反射信号回来要多久 + 长什么样**'**。

- **没有反射** → **电缆完美匹配（理想状态）**
- **反射尖峰** → **电缆某处有"突变"（断点 / 接头 / 损伤）**
- **反射的时间** → **告诉你"突变"** 距离始端有多远
- **反射的形状** → **告诉你"突变"** 是开路 / 短路 / 阻抗失配

**这就是 2023 B 题让你做的设备**——**用 200 元成本做出 1500 美元 TDR 的入门版**——**4 天 3 夜里要完成"测电缆长度 + 识别终端负载"** 两件事。

> **小白补课**：什么是同轴电缆？
> - **同轴电缆（Coaxial Cable）**：**中心一根铜芯 + 外面一层屏蔽网编织 + 中间用塑料介质隔离**——**两层金属"同心轴心"** 排列**
> - **特点**：**屏蔽好（外面的金属网挡住电磁干扰）+ 阻抗稳定（典型 50Ω 或 75Ω）+ 高频损耗低**
> - **应用**：**有线电视（75Ω）、5G 基站连线（50Ω）、雷达 / 卫星天线（50Ω）、高频示波器探头（50Ω）**

## 这题在做的事，其实是给电缆"听回声"

把核心物理过程画出来：

```
        ┌─[装置]─┐
        │信号源 │ → 发送一个 1 ns 窄脉冲
        │       │
        │       │      
        │ 始端 ←┼─────────────────[电缆 L = 10 m]──────[终端]
        │       │  脉冲沿电缆传播                         开路 / 电阻 / 电容
        │       │  ↘                                  ↗
        │       │   ↘                              ↗
        │       │    ↘ 50 ns 后到达终端 ↗
        │       │     ↘                        ↗
        │       │      ← 50 ns 后又回到始端 ←
        │ 接收 ←┼─── 总耗时 100 ns
        │       │ 
        └───────┘
```

**'**100 ns 双向时间**'**——**用这个时间反算电缆长度**：

```
长度 L = (双向时间 × v_cable) / 2 = (100 ns × 2 × 10⁸ m/s) / 2 = 10 m
```

**这就是 TDR 的核心数学**——**简单到吓人**——**但工程上要做对**——**3 件事**：

1. **'**1 ns 窄脉冲**'** 怎么生成
2. **'**100 ns 时间**'** 怎么精确测量（精度 ≤ 100 ps）
3. **'**反射形状**'** 怎么识别（开路 / 电阻 / 电容）

**这是 2023 B 的全部考点**——**接下来一层一层揭开**。

## 第一个谜：怎么生成 1 ns 窄脉冲

**1 ns 是什么概念**？

```
1 ns 在电缆中传播 = 2×10⁸ m/s × 10⁻⁹ s = 0.2 m = 20 cm
```

**'**1 ns 脉冲**'** = 信号的"空间长度"** = **20 cm**——**比 1 米电缆短 5 倍**——**才能区分 1m 长度内的细节**。

**第一笔账：脉冲宽度对长度精度的影响**

```
脉冲宽度 1 ns → 空间分辨率 20 cm（不够 100cm 精度）
脉冲宽度 100 ps → 空间分辨率 2 cm（满足 1% × 100cm = 1cm 精度边缘）
脉冲宽度 50 ps → 空间分辨率 1 cm（轻松满足）
```

**'**100 cm 长度 + 1% 精度 = 1 cm**'** 是要求 (3) 的核心——**意味着脉冲必须 < 100 ps**——**这是 GHz 级窄脉冲**——**电赛挑战极限**。

**第二笔账：脉冲生成方案**

**方案 A：NE555 + RC 滤波**（**入门**）

```
NE555 输出 → 高通 RC → 输出窄脉冲
脉冲宽度：约 100 ns
```

**优点**：**便宜**。  
**缺点**：**100 ns 太宽**——**只能测 ≥ 20 米电缆**——**不满足 1m 精度**。

**方案 B：74HC123 单稳态（**入门 +**）

```
脉冲宽度：50 ns ~ 1μs（可调）
```

**仍然太宽**。

**方案 C：FPGA + LVDS 驱动**

```
FPGA Spartan-7：内部时钟 200 MHz → 5 ns 周期
配合 LVDS 高速 IO → 输出 5 ns 窄脉冲
```

**优点**：**5 ns 脉冲 + 灵活可调**。  
**缺点**：**FPGA 成本高 + 学习曲线陡**。

**方案 D：MAX3960 / DS90LV047 高速驱动 IC**

```
MAX3960：输出脉冲宽度 100 ps ~ 1 ns
集成度高 + 低抖动
```

**优点**：**100 ps 级窄脉冲**。  
**缺点**：**贵（80 元 / 颗）+ 难焊**。

**方案 E：阶跃恢复二极管（SRD，Step Recovery Diode）**

**SRD 是高频微波技术的"经典脉冲生成器"** —— **能生成皮秒级（< 100 ps）窄脉冲**：

```
工作原理：SRD 反向截止时存储电荷 → 突然释放 → 100 ps 上升沿
典型 SRD：Aeroflex AGM3408（100 ps 上升沿）
价格：300 元 / 颗
```

**优点**：**100 ps 级脉冲**——**接近商业 TDR 水平**。  
**缺点**：**贵 + 国内难买 + 调试难度高**。

**国一队伍**：**FPGA + LVDS** 或 **SRD**——**满足 100 ps 脉冲**——**满分 20**。  
**国二**：**MAX3960**——**1 ns 脉冲**——**勉强满足 1m 精度边缘**——**18~25 分**。  
**国三**：**NE555**——**100 ns 脉冲**——**只能测 20m 以上电缆**——**0~10 分**。

## 第二个谜：怎么测纳秒级时间差

**核心问题**：**脉冲发出 → 反射回来 → 测精确时间 = 100 ps 精度**。

**4 种主流方案**：

**方案 A：高速 ADC 直采**

```
ADAQ7980（5 GSPS ADC）：每点 200 ps 间隔
数据采集 + 找峰值 → 时间精度 ±50 ps
```

**优点**：**精度高 + 数据全 + 看波形形状**。  
**缺点**：**ADC 贵（500 元 / 颗）+ 数据率高（5GBps）**。

**方案 B：TDC 时间数字转换器**

```
TI TDC7200：单芯片 TDC，精度 55 ps
ams TDC-GPX2：精度 5 ps
```

**TDC 工作原理**：**专用 IC 测两个事件之间的时间**——**类似"高精度计时器"**——**不是"采样波形"**。

**优点**：**直接输出时间数字 + 极高精度**。  
**缺点**：**只能测时间，看不到反射形状**——**不能区分开路 / 电阻**。

**方案 C：FPGA 时延链**

```
Spartan-7 内部时延单元：每级 ~ 50 ps
级联 100 级 = 5 ns 测量范围 + 50 ps 精度
```

**优点**：**便宜 + 精度高 + 灵活**。  
**缺点**：**FPGA 学习曲线陡**。

**方案 D：模拟比较器 + 计数器（最朴素）**

```
比较器（如 ADCMP562）：响应时间 200 ps
触发计数器开始 / 停止 → 测时间
精度：~ 1 ns
```

**精度不够**——**只能做基本要求**。

**国一选择**：**ADC 直采（看反射形状）+ TDC 精测时间**——**双方案融合**。  
**国二**：**FPGA 时延链**——**便宜实用**。  
**国三**：**比较器 + 计数器**——**精度差**。

**第一笔账：时间精度对长度精度的换算**

```
长度 = (时间 × v_cable) / 2

1% 长度误差 + 100 cm 长度 = 1 cm 误差
1 cm / v_cable / 2 = 100 ps 时间误差
```

**'**100 ps 时间精度 = 1 cm 长度精度**'**——**这是发挥 (3) 的硬约束**。

**第二笔账：抗干扰**

100 ps 测量易受干扰：

- **电源噪声 → 时间抖动 ±50 ps**
- **温度漂移 → 时间漂 ±100 ps / ℃**
- **电磁干扰 → 反射信号失真**

**对策**：**多次平均 + 屏蔽 + 温度补偿**：

```c
// 1024 次测量取平均
float total = 0;
for (int i = 0; i < 1024; i++) {
    total += measure_time();
}
time_avg = total / 1024;
// 平均后精度提升 √1024 = 32 倍
```

**'**32 倍**' 提升**——**单次 ±50 ps → 平均后 ±1.5 ps**——**远超需要**。

## 第三个谜：怎么识别"开路 / 电阻 / 电容"

**'**反射波形**'** 是终端类型的"指纹"**：

| 终端 | 反射系数 Γ | 反射波形 |
|---|---|---|
| **开路（Z = ∞）** | Γ = +1 | **完全反射 + 同极性** |
| **短路（Z = 0）** | Γ = -1 | **完全反射 + 反极性** |
| **匹配（Z = Z0 = 50Ω）** | Γ = 0 | **无反射** |
| **小电阻（10~30Ω < Z0）** | Γ < 0 | **部分反射 + 反极性** |
| **大电阻（> Z0）** | Γ > 0 | **部分反射 + 同极性** |
| **电容（100~300pF）** | Γ 时变 | **先短路后开路（充电过程）** |

**'**电容反射波形**'** 是动态的——**电容充电过程**：

```
t = 0：电容相当于短路（Γ = -1）→ 反射尖峰反极性
t → ∞：电容充满，相当于开路（Γ = +1）→ 反射尖峰同极性
中间：指数过渡（时间常数 τ = R × C）
```

**这是电容识别的"金指纹"** —— **看反射的"过渡曲线"** = 算电容值**。

**第一笔账：反射系数公式**

```
Γ = (Zload - Z0) / (Zload + Z0)
反射波幅 = 入射波幅 × Γ
```

**这个式子说的其实是**——**'**反射的振幅 = 入射 × 反射系数**'**——**Z0 = 50Ω 时**：

| Zload | Γ | 反射波幅 / 入射波幅 |
|---|---|---|
| **∞（开路）** | +1.000 | +1.000（满幅同向）|
| **30Ω** | -0.250 | -0.250（25% 反向）|
| **20Ω** | -0.429 | -0.429 |
| **10Ω** | -0.667 | -0.667 |
| **0Ω（短路）** | -1.000 | -1.000（满幅反向）|

**第二笔账：电阻值反算**

```
Zload = Z0 × (1 + Γ) / (1 - Γ)
```

**这个式子说的其实是**——**'**测出反射系数 Γ → 反算负载电阻**'**——**只要测得 Γ 精度 ±5%**——**对应电阻精度 ±10%**——**满足要求**。

**第三笔账：电容值反算**

电容反射的"上升时间"** = RC 时间常数：

```
τ = (Z0 + R_internal) × C
```

**'**Z0 = 50Ω + R_internal = 50Ω**'** = **总阻抗 100Ω**——**100pF 电容对应 τ = 10 ns**。

**测量方法**：**抓反射波形的"指数过渡"** + **拟合 τ → 反算 C**：

```c
// 抓反射波形 → 找 t1（10% 上升点）和 t2（90% 上升点）
float t10 = find_threshold_time(reflected_wave, 0.1);
float t90 = find_threshold_time(reflected_wave, 0.9);
// 计算 τ
float tau = (t90 - t10) / 2.197;  // ln(9) = 2.197
// 反算电容
float capacitance = tau / (Z0 + R_internal);
```

**精度**：**抓 t10 / t90 时间 ±100 ps → τ 精度 ±5%** → **电容精度 ±5%**——**满足 ±10% 要求**。

**国一队伍**：**完美识别开路 / 电阻 / 电容 + 测出参数 ±3%**——**满分 27**。

## 第四个谜：怎么减小测量盲区到 100cm

**要求 (3)：测量长度 ≤ 100cm + 精度 ≤ 1%**——**20 分**——**真正的难点**。

**为什么短电缆难测**？

```
100 cm 电缆 + 双向传播 = 10 ns 总时间
脉冲宽度 1 ns → 反射波和入射波"重叠"** 在时域上
难以分辨
```

**这是 TDR 的"盲区"** —— **类似雷达的"近距盲区"**——**电缆太短 → 反射回得太快 → 跟入射波混在一起**。

**对策 1：脉冲宽度 < 1 ns**

```
脉冲宽度 100 ps → 空间分辨率 2 cm → 100 cm 电缆能分辨
```

**前面已经讲过 SRD / FPGA 方案**——**实现 100 ps 脉冲**——**关键基础**。

**对策 2：差分测量（双探头）**

```
始端 1 个探头测入射波
始端 0.5m 处 1 个探头测反射波
两个探头时间差 = 反射时间
```

**用第二个探头"绕过"** 入射波干扰**——**专门捕获反射**——**精度提升 10 倍**。

**对策 3：算法去卷积**

```c
// 入射波形已知（标定）
incident_known = standard_incident_pulse;
// 实际测得波形
measured = adc_capture();
// 反卷积分离反射
reflected = deconvolve(measured, incident_known);
```

**'**反卷积**'** 能从"重叠波形"** 中分离出反射部分**——**类似"声纹分离"** 算法**。

**国一队伍**：**SRD + 差分测量 + 反卷积**——**100 cm 电缆精度 ±1cm**——**满分 20**。

## 把题目逐条翻译一遍

### 任务那段话

> 设计并制作一个**同轴电缆长度与终端负载检测装置**。

任务核心：**两件事**——**测长度 + 识终端**。

### 基本要求 (1)：显示（8 分）

> 装置能够显示工作状态、电缆长度、负载类型、负载参数。

**LCD 显示 4 行信息**——**简单**——**8 分**。

### 基本要求 (2)：长度 ±5%（30 分）

> 电缆长度 1000cm ≤ L ≤ 2000cm、终端开路，**装置能够检测并显示电缆长度 L，相对误差 ≤ 5%**，**一次检测时间不超过 5s**。

**前面已经讲过 TDR 原理 + 1 ns 脉冲**——**国一 30 分稳拿**。

**5% 精度** = **±100 cm**——**容差大**——**简单方案就能做**。

### 基本要求 (3)：终端识别（12 分）

**前面已经讲过反射系数判断**——**国一 12 分稳拿**。

### 发挥 (1)：长度 ±1%（10 分）

**前面已经讲过 100 ps 脉冲 + TDC**——**国一 10 分稳拿**。

### 发挥 (2)：终端参数 ±10%（15 分）

**前面已经讲过反射波形 + 反卷积 + 时间常数**——**国一 15 分稳拿**。

### 发挥 (3)：盲区 ≤ 100cm（20 分）

**前面已经讲过 SRD + 差分测量 + 反卷积**——**国一 20 分稳拿**。

### 发挥 (4)：其他（5 分）

**5 分自由发挥**：

- **测电缆衰减（dB / 100m）**——**3 分**
- **测特性阻抗（Z0）**——**3 分**
- **测多接头 / 多反射点**——**5 分**
- **手机 APP 显示**——**2 分**

### 说明里的暗坑

**说明 (1)：'**装置应包括信号源和测量处理电路两部分**'**

**意味着**：**信号源（脉冲生成）+ 测量处理（ADC / TDC + MCU）+ 显示**——**三部分集成**。

**说明 (2)：'**至少一根电缆长度不小于 2000cm**'**

**'**自带 20 米电缆**'** —— **测试时拿来测**——**电缆是参赛队自己的**——**算总和长度**。

**说明 (4)：'**电阻、电容的实际值使用 LCR 测试仪测定**'**

**'**真值用 LCR 仪测定**'** —— **不是按你说的标称值**——**意味着评委用专业仪器测**——**你测的值要和它一致**。

**说明 (5)：'**最小长度 L ≤ 100cm 得满分，L ≥ 1000cm 本项不得分**'**

**'**100cm = 满分 20**'** —— **挑战极限**。

**说明 (6)：'**不得使用测距传感器及摄像头**'**

**禁止"作弊"** —— **不能用激光测距代替 TDR**——**必须真做时域反射**。
