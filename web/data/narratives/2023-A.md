## 想象一个场景

你的小区供电只有一台 200kW 的变压器，但小区所有空调全开的高峰时段需要 250kW。**怎么办？**

最简单的办法——**再装一台一样的变压器，两台并联工作**，输出能力翻倍。

这听起来像小学生都能想到的方案。但工程师都知道，**让两台同样的电源并联工作，是电力电子里最难的一类问题之一**。难在哪儿？

设想两个声音稍微不同的人合唱：A 唱 220V/50.000Hz，B 唱 220.1V/50.001Hz。**电压有效值差 0.05%、频率差 0.002%**——看起来可以忽略不计。但放到电力系统里——**两台电源之间会瞬间产生几十安培的环流，几秒钟之内两台机器都被烧穿**。

> 想象一个画面。两个人在唱同一首歌——**一个人慢半拍**，**另一个人立刻能听出来**——但**只听半拍，听不准、跟不上**——**两人节奏越来越乱**——**最后吵架**。两台并联电源就是这两个人，电网就是观众。

本题让你做的，**就是让两台逆变器学会'**完美合唱**'**——电压精确相同、频率精确相同、相位精确相同——然后再让它们一起向同一个负载或电网供电。

## 出题人是怎么想到这道题的

2023 年 A 题选这个方向不是偶然。背景是中国新能源行业一个**真实的工程难题**——**光伏并网逆变器的群组工作**。

一座 100MW 的光伏电站不会用一台 100MW 的大逆变器（造价昂贵、单点故障毁灭性），**而是用 100 台 1MW 的小逆变器并联**——这样任意一台坏了系统还能工作，而且可以分模块分批检修。**但这 100 台逆变器必须协调工作**——电压一致、频率一致、相位一致——**否则它们会互相干架，把电网搅成一锅粥**。

中国 2023 年光伏装机容量 600GW，其中 80% 是 50kW 以下的中小逆变器并联组成——**全国大约 1500 万台逆变器在'**合唱**'**。这个市场规模可怕，对工程师的需求量更可怕。

出题人 2023 年抛这道题，**就是想把电赛选手往'**光伏并网工程师**'**这个方向培养。**做完这一题，你的简历直接被阳光电源、华为数字能源、固德威这些光伏巨头看上**。

而且 2023 A 和 2025 A（能量回馈变流器）是**电力电子的两块最难基石**——**2023 A 是'**多机协调**'**，2025 A 是'**双向能流**'**。两者技术上有 70% 重合度（都是单相 / 三相全桥 + dq 控制 + PLL 锁相），但**视角完全不同**。**做完这两题，你成了'**电力电子全栈工程师**'**。

## 这题在做的事，其实是让两台逆变器学会同步呼吸

把图 1 拆开看：

**两个一模一样的'**变流器 1**'**和'**变流器 2**'**：每台都是单相 H 桥（4 颗 MOS）+ 滤波电感 + DC 母线电容。每台都能独立工作，**输出 24V 有效值 / 2A 有效值的 50Hz 交流电**。

**两个完全独立的直流电源**：DC1 给变流器 1 供电，DC2 给变流器 2 供电——题目说明 (3) 严格规定 **'**各自独立，不得共用**'**。这是为了模拟真实场景——**两台逆变器可能来自不同供应商、用不同电池、用不同地点的市电**——**它们彼此不认识**。

**一个共用的输出回路**：两台变流器的输出汇到一根线上——**一起向电阻负载 RL 供电**（基本要求 1 + 发挥 1）**或经过变压器 T 并入 220V 电网**（发挥 2 + 3）。

整个系统的考验分两类，**对应两种工业上常见的运行模式**：

**离网模式（S2 断开 S1 闭合）**：两台逆变器单独 / 并联向 RL 供电——**它们自己定义 50Hz 的相位、互相对齐**。在野外、海岛、应急电源场景里就是这样——**没有电网**，**两台逆变器自己当老大**。

**并网模式（S1 断开 S2 闭合）**：两台逆变器并入电网——**电网定义相位，它们都要跟着电网相位走**。在城市并网场景里就是这样——**电网是老大，两台逆变器是小弟，必须跟拍子**。

两种模式的同步机制完全不同——**这就是这道题最深的考点**。

> 想象一下两种合唱场景。**离网模式**像两个人在野外即兴合唱——**没有指挥**，他们要互相听对方的声音、调整自己的节奏；**并网模式**像两个人加入合唱团，有一位指挥（电网）拍节奏，**他们都看着指挥跟拍**——**指挥的节奏权威无可置疑**。

代入电力电子的语言：**离网模式叫 'Grid Forming'（构网型逆变器）**，**并网模式叫 'Grid Following'（跟网型逆变器）**。这是 IEEE 在 2010 年代才形成共识的两种范式——**最近 5 年才成为热门话题**。**做完这一题，你已经站在 2020 年代电力电子工程的研究前沿**。

接下来一层一层揭谜。

## 第一个谜：单台逆变器为什么本身就难调

题目基本要求 (1)(2)(3)(4) 全部 50 分都是**只用变流器 1 单独工作**——但分值占了一半。出题人在告诉你：**单机做好就值 50 分**——**它本身已经够你忙 2 天**。

为什么单机就难？

**第一个坑：输出电压精度 ±0.2V（基本要求 1）**

24V ± 0.2V = **±0.83% 误差**。前一篇 2025-A 我们详细推过——开环 SVPWM 受直流母线电压、温度、死区效应影响，**没闭环根本达不到 ±0.83%**。

**这意味着必须做电压闭环 PI**。**电压外环带宽 100Hz、电流内环带宽 1kHz**——**经典的双闭环结构**。

> **小白补课：单机闭环架构**
> - **电压外环**：测输出电压有效值，与目标 24V 比较——**慢回路**（响应几十毫秒），**保证稳态电压精度**
> - **电流内环**：根据外环输出的电流参考值，让 H 桥的瞬时电流跟踪正弦目标——**快回路**（响应 1 毫秒），**保证波形质量**
> - **两者级联**：外环带宽必须比内环慢 10 倍——**这是控制工程的金科玉律**——**否则两个环互相打架，系统失稳**

**第二个坑：THD ≤ 2%（基本要求 2）**

前一篇 2025-A 详细推过 SVPWM 比 SPWM 强 5%——但**那是三相系统**。**单相不是三相**——**单相 SVPWM 不存在**（SVPWM 是三相专属，靠相邻矢量合成）。**单相只能用 SPWM 或 SPWM + 数字预失真**。

单相 SPWM 在 fs=20kHz、调制度 m=0.85 时，**THD 约 3%**——**已经超 2% 要求**。

工程对策三选一：

**对策 A：提高 fs 到 40kHz**

THD 降到 1.5%——但**开关损耗翻倍**——**效率从 88% 掉到 80%**——**和基本要求 (3) 冲突**。**不可行**。

**对策 B：加 LCL 滤波器代替 LC**

三阶滤波代替二阶，**对开关频率衰减 -60dB/decade（LC 是 -40dB/decade）**——**THD 直接降到 1%**——但器件增加 2 颗（多一颗电感）。**国一队伍标配**。

**对策 C：数字预失真补偿**

在 PWM 控制环里加'**三次谐波负反馈**'——**软件层面消除 SPWM 的固有谐波**——**THD 1.5%，效率不掉**。

代码层面（伪代码）：

```c
// 标准 SPWM 调制波
float v_mod_basic = m * sin(omega_t);
// 加入 -1/6 的三次谐波（消除 SPWM 主要谐波）
float v_mod_better = m * sin(omega_t) - (m/6) * sin(3*omega_t);
// 输出 PWM 占空比
duty = 0.5 + v_mod_better / 2;
```

**这个式子说的其实是**——**'**故意在调制波里掺一点三次谐波**'**——**让输出滤波后的总谐波降低**——**听起来反直觉，但实测有效**。

**国一队伍**：**LCL + 数字预失真**——**双保险**——**THD 能压到 0.8%**——**远低于 2% 要求**。

**第三个坑：效率 ≥ 88%（基本要求 3）**

24V × 2A = **48W 输出**。**88% 效率意味着损耗 ≤ 6.5W**。在 H 桥拓扑下：

| 损耗源 | 估算 |
|---|---|
| MOS 开关损耗（4 颗 × fs=20kHz） | 1.2 W |
| MOS 导通损耗（Rds=14mΩ） | 0.5 W |
| 滤波电感铁损 + 铜损 | 1.5 W |
| 直流母线电容 ESR | 0.3 W |
| 栅极驱动 + 辅助电源 | 1.0 W |
| 控制电路 + LCD | 1.0 W |
| **合计** | **5.5 W** ✅ |

**勉强达标**——**6.5W 减 5.5W 余量只有 1W**——**任何一项设计失误都会让你跌出 88%**。

要做到 88%，**辅助电源不能用 LDO**，必须用 Buck 升降压模块——**前一篇 2025-A 详细分析过，这里同样适用**。**LDO 把 48V 降到 12V 损耗 = (48-12)/48 = 75%；Buck 损耗 = 8%**——**单这一项就是 5W vs 0.5W 的差距**。

**第四个坑：负载调整率 ≤ 0.2%（基本要求 4）**

24V × 0.2% = **0.048V**。**比基本要求 (1) 的 ±0.2V 严格 4 倍**。

> **小白补课：负载调整率是什么**
> 负载从 0A 加到 2A 时，输出电压会**下降一些**（电感、电阻、控制器响应都有局限）。**下降的百分比**就是负载调整率：
> ```
> S_I = (U_o1 - U_o2) / U_o1 × 100%
> ```
> 这个式子说的其实是——**电源在负载从轻变重时电压稳不稳定**。0.2% 是**实验室级电源**才能达到的精度。

要让 0.2% 实现，**必须做电流前馈 + 高带宽闭环**：

```c
// 标准 PI 输出
v_pi = Kp * error + Ki * integral;
// 加上电流前馈：补偿电感压降
v_ff = omega * L * i_load;  // 电感感抗压降
// 总输出
v_ref = v_pi + v_ff;
```

**这个式子说的其实是**——**先用前馈算一个'**应该有**'**的电压，再让 PI 修正剩下的小误差**。**前馈是 90% 的功劳，PI 是 10% 的修正**——**效果比纯 PI 好 5 倍**。

**单机 50 分做出来，本身就是一项硬功夫**——**新手做这一项可能花 2 天调试**。

## 第二个谜：两台逆变器一并联会发生什么灾难

发挥要求 (1)：**两台逆变器离网并联给 RL 供电，Io = 4A**。

**第一次接触并联的工程师都会犯一个错误**——以为只要两台逆变器各自调好，并起来就能工作。

**实际上你接通的瞬间会听到一声爆响**——**MOS 击穿、烟雾升起、4 天的工作灰飞烟灭**。

**为什么**？

两台逆变器的输出电压'**应该相同**'——但它们各自由独立的控制器在跑——**PI 参数稍有差异、ADC 校准稍有差异、电网相位检测稍有差异**——它们的输出**实际上有 0.1V 左右的电压差**，加上**几度的相位差**。

电压差 0.1V、两台输出之间的等效阻抗约 0.05Ω（很小的滤波电感 + 走线电阻）：

```
环流 I_c = ΔV / Z = 0.1V / 0.05Ω = 2A
```

**这个式子说的其实是**——**'**两台逆变器之间**有一股 2A 的电流在徒劳循环**'**——**它不输出给负载，纯粹是两台之间的内斗**。

2A 环流——**已经达到额定电流的 50%**。再加上动态扰动（电压瞬态变化 ±5%）——**环流可能瞬时冲到 20A 以上**——**MOS 直接击穿**。

> **小白补课：什么是环流**
> 想象两个水池子高度有微小差异——用一根管子连接。水会从高的池子流向低的池子，**这股水流不属于任何一个池子的'**有效输出**'**——**它只是在两池子之间徒劳地循环**——**这就是环流**。
> 电力上一样：两台并联电源之间的电势差，会产生**徒劳的电流'**内循环**'**——**这股电流不输出给负载、不做任何有用功**——**纯粹消耗 MOS 的功率裕量**。

**所以并联逆变器的核心问题，不是'**让它们一起出力**'，而是'**让它们不要互相挤**'**。

工业上对付环流有三种方案。

**方案 A：主从控制（Master-Slave）**

一台逆变器'**当老大**'**（主机，Master）——**输出固定电压**；**另一台'**当跟班**'**（从机，Slave）——**只跟踪电流目标**——**主机定电压、从机跟主机的电流**。

代码层面：
- 主机：经典电压闭环 PI
- 从机：电流环 PI，目标值 = 主机当前电流 × 比例（通过 CAN 通信传过来）

**优点**：
- 算法简单（200 行 C 代码）
- 效果好（环流 < 0.1A）
- 调试快（电赛 2 天能搞定）

**缺点**：
- **主机故障 = 整个系统挂掉**——**单点故障问题**
- 从机不能独立工作

**方案 B：下垂控制（Droop Control）**

每台逆变器自带'**电压下垂特性**'：**输出电流增大时电压自动微微降低**。**两台逆变器都是'**有弹性**'**的——**电压偏高的那一台会自动'**让贤**'**输出电流，电压偏低的那一台会自动'**接管**'。

数学公式：

```
V_ref = V_nominal - K_d × I_out
```

K_d 是**下垂系数**，典型 0.5V/A。

**这个式子说的其实是**——**'**每多输出 1A，输出电压参考值就降 0.5V**'**——**自动让出电流给对方**。两台逆变器各自跟踪自己的下降参考——**最终自然达到电流均衡**。

**优点**：
- **完全分布式**——两台逆变器之间不需要通信
- **任何一台故障另一台还能工作**——无单点故障

**缺点**：
- **电压精度差一些**（K_d 越大均流越好但电压精度越差）
- **响应慢**（达到稳态需要 10~50ms）

**这是发达国家电网最推崇的方案**——**特别适合分布式光伏系统**。

**方案 C：环流抑制 + 平等控制**

两台逆变器都是平等的——但额外加一个'**环流抑制控制器**'**——它专门测两台之间的环流，并把这股环流送给两台的电流环作负反馈修正。

**这是 2010 年后的工业主流方案**——**性能最好，但代码复杂度最高**——**电赛 4 天调不完，国一队伍 5% 才用**。

**电赛 4 天 3 夜的现实**：

- **国二队伍**选**主从控制 + CAN 通信**——简单粗暴，**能跑通拿基本分**
- **国一队伍**选**下垂控制 + 数字均流补偿**——**分布式 + 精度兼顾**——**满足题目说明 (7)的硬性要求**

题目说明 (7) 是个隐藏的'**约束**'**：

> 逆变器 1 与逆变器 2 各自独立，**不得共用一个控制器**。

这一条**排除了'**用一颗 MCU 控两台逆变器**'**这种偷懒方案——**两台必须各有一颗 MCU**——**你必须做'**分布式控制**'。

但 CAN/UART 通信是允许的——**国一队伍标配两颗 STM32 + CAN 总线**。两颗 MCU 各自跑自己的电压电流环，**通过 CAN 共享'**当前输出电流**'**信息做均流。**通信延迟 1ms 内**——**对 50Hz 系统是可忽略的滞后**。

## 第三个谜：怎么并入 220V 电网

发挥要求 (2)(3)：**断开 S1，闭合 S2**——逆变器输出端通过变压器 T 接到 220V 电网。

题目说明 (9)：

> 逆变器并网时，**应满足并网条件**，确保人员及设备安全。

**'并网条件'是电力电子工程师的硬技能**。要让一台 24V 逆变器并入 220V 电网，必须满足三个条件**完全相等**：

1. **电压相等**：逆变器输出电压 = 电网电压（同一时刻）
2. **频率相等**：逆变器输出频率 = 电网频率
3. **相位相等**：逆变器输出相位 = 电网相位（误差 < 5°）

**任何一项不满足，闭合 S2 的瞬间会发生'**短路冲击**'**——前一篇 2025-A 算过：**相位差 30° 时环流 27A**——**MOS 直接报销**。

> 想象一下并网就像**跳上一辆正在行驶的火车**。火车速度 = 电网频率；火车与你同方向 = 相位对齐；车厢门高度 = 电压幅值匹配。**任意一项不对，你跳上去就摔下来**——**电气上是 MOS 烧穿**。

**电压相等怎么实现**

题目里有变压器 T——它把 24V 变成 220V（变比 1:9.17）。逆变器输出 24V 经变压器变成 220V——**和电网电压有效值匹配**。

但变压器有变比误差（±3%）、有铜损铁损（电压降 1~2V）——**实际并网时电压可能差 5~10V**。这怎么办？

**工程对策**：在合闸前，**用 PLL 锁住电网相位 + 调整逆变器输出电压**——**让逆变器输出电压有效值 = 电网折算到副边的电压（24V ± 0.2V）**——**电压闭环 PI 自动做这件事**。

**频率相等怎么实现**

电网 50Hz 但实际会漂（49.5~50.5Hz）——**逆变器必须实时跟踪电网频率**。

> **小白补课：单相 PLL（锁相环）**
> 三相系统里有 SOGI-PLL、SRF-PLL，相对成熟。**单相系统更难**——只有一根信号线，怎么提取相位？
> 答案是：**构造一个'**虚拟正交相位**'**——**用 SOGI（Second-Order Generalized Integrator，二阶广义积分器）滤波器把单相信号变成两路正交信号（α、β）**——**等效成两相系统**——然后做经典的 dq 变换。
> **SOGI 是 2008 年西班牙工程师发明的**——**专门解决单相 PLL 问题**。

代码（单相 SOGI-PLL 简化版）：

```c
// 输入电网电压 v_grid_in
float v_alpha = v_grid_in;
float v_beta = sogi_filter(v_alpha);  // 90° 滞后

// dq 变换（旋转坐标系）
float v_d = v_alpha * cos(theta_hat) + v_beta * sin(theta_hat);
float v_q = -v_alpha * sin(theta_hat) + v_beta * cos(theta_hat);

// PLL PI 控制器：让 q 轴归零
omega_hat = pi_controller(v_q);
theta_hat = theta_hat + omega_hat * dt;

// theta_hat 就是同步到电网的相位
```

**这段代码说的其实是**——**MCU 在每个时刻'**猜**'**一个电网相位 θ̂——**如果猜对了，dq 变换后 q 轴会归零**——**如果猜错了，q 轴有非零值**——**用 q 轴的偏差做反馈，自动调整 θ̂ 直到猜对**。

锁定后，θ̂ 就是当前电网相位——**逆变器用这个相位作 PWM 调制**——**自然和电网同步**。

**相位对准怎么实现**

PLL 锁住相位之后，**理论上自然就对准了**。但实际有 1~5° 的稳态相位偏差——来自 SOGI 滤波器的固有相位延迟。

**对策**：在 PLL 输出后加'**相位补偿**'——**根据 SOGI 的传递函数计算固有相位偏差，预补偿掉**——**这一招让相位精度从 ±5° 提到 ±0.5°**。

**合闸的标准时序（电力工程师的口诀）**：

```
T0：逆变器空载启动，PWM 输出但 S2 还断开
T1：PLL 锁定电网频率（500ms 内完成）
T2：调整逆变器输出电压有效值 = 电网电压（500ms 内）
T3：在过零点附近相位对齐（±2° 误差内）
T4：合上 S2，逆变器并入电网
T5：电流环开始工作，输出预定电流
```

**T0~T4 总耗时 1~2 秒**——**这就是题目允许的并网时间**——**慢一点没关系，合上去能稳就行**。

**合闸瞬间的工程细节（命门）**：

```c
// 合闸瞬间必须做的 3 件事
if (state == STATE_CLOSING) {
    // 1. 清零电流环 PI 的积分项
    pi_current.integral = 0;
    // 2. 软启动电流目标（不要瞬间满 4A）
    i_target = i_target_final * (t_since_close / 0.5);  // 0.5s 渐进
    // 3. 开启 PWM 输出
    pwm_enable();
}
```

**少了任何一步**——**合闸瞬间就是 BANG**。

## 第四个谜：发挥 (3) 怎么做到电流任意分配

发挥要求 (3)：**两台逆变器并网且电流比 K = Io1 : Io2 在 0.5~2 之间任意设定，误差 ≤ 5%**。

意思是评委说'**让 1 号出 2A、2 号出 4A**'**——**你就要能做到**——**任意比例分配电流**。

**这一步是发挥分的最高考点**——**15 分**。

**怎么实现？**

并网模式下，电网电压固定，**两台逆变器的'**输出**'**本质是各自的'**输出电流**'**。两台的电流目标值各自独立设定，PI 控制器各自跟踪。

代码层面：

```c
// 用户设定 K = Io1/Io2
// 总电流 Io_total = Io1 + Io2 (由用户设定 4A)
float Io1_ref = Io_total * K / (K + 1);
float Io2_ref = Io_total / (K + 1);

// 逆变器 1 跟踪 Io1_ref
// 逆变器 2 跟踪 Io2_ref
```

**这段代码说的其实是**——**给定总电流 4A、比例 K=0.5（1:2）**——**算出 1 号要出 1.33A、2 号要出 2.67A**——**两台各自跟踪自己的目标**。

**听起来简单**。但**电流环精度要做到 5%**——**不容易**：

| 误差源 | 典型值 |
|---|---|
| ADC 采样精度 | ±1% |
| 互感器线性度 | ±2% |
| PI 控制器稳态误差 | ±1% |
| 校准残差 | ±1% |
| **累加** | **5%——勉强达标** |

**国一队伍的做法**：每个测试前**自动校准电流环**——让电流目标 0A → 测实际值，**算出零偏**；让电流目标 4A → 测实际值，**算出增益**——**实时补偿**——**误差能压到 1%**。

**怎么验证**

题目说明 (6) 要求'**实测出的数值**'**对'**设定的数值**'**误差 ≤ 5%。**所以现场测试时，评委**：

1. 设定 K = 0.5（即 Io1:Io2 = 1:2）
2. 你的设备显示 Io1 = 1.33A, Io2 = 2.67A
3. 评委用功率分析仪实测 Io1 = 1.30A, Io2 = 2.70A
4. K_actual = 1.30 / 2.70 = 0.481
5. 误差 |0.481 - 0.5| / 0.5 × 100% = **3.8%** ≤ 5% ✅

**只要你的设备测量准确 + 控制准确，自动达标**——**15 分到手**。

## 把题目逐条翻译一遍

现在你脑子里已经有了全局，是时候回到题目原文，**像工程师那样把每个数字算一遍、每条要求推导一遍**。

### 任务那段话

> 设计并制作由 **2 个单相逆变器组成的并联系统**，逆变器并联后可为电阻负载 RL 供电，**也可通过变压器 T 并入 220V 电网**。

任务的核心是 '**两个**'**——**单台不算完成，必须两台**。

**题目把 220V 电网作为 '**终极考验**'**——前几年 A 题大多是'**孤岛供电**'（不接电网）——**2023 是第一次明确要求并入 220V 电网**——这反映了出题人想把选手往**'**真正的并网工程师**'**方向培养。

### 基本要求 (1)：单机 24V/2A 50Hz

> **断开 S2，闭合 S1，仅用逆变器 1 向 RL 供电**。输出电压有效值 Uo 为 24V±0.2V，频率 fo 为 50Hz±0.2Hz 时，输出电流有效值 Io 为 2A。（10 分）

10 分。这一项是热身——**单机 50W 输出**——前面 "**第一个谜**" 已经详细分析过。

**输出电压 24V 而不是 220V**——为什么？

因为 **220V 直接出输出会触电危险**——出题人选 24V 是个安全且方便测试的中间值。**变压器 T 的存在**就是把这 24V 升到 220V 用于并网测试。**离网模式下用不着变压器，直接 24V 输出给 RL 即可**——**这是题目的安全设计**。

**±0.2V 容差** = ±0.83%——**只能用闭环达到**。**电压外环 PI 是必备**。

**±0.2Hz 容差**——**频率精度依赖晶振 + PLL**。**STM32 内部晶振稳定度 ±50ppm = ±0.0025Hz/50Hz** = **远低于 ±0.2Hz**——**完全够**。

10 分稳拿。

### 基本要求 (2)：THD ≤ 2%

> 输出交流电压总谐波畸变率（THD）**不大于 2%**。（12 分）

12 分。前面 "**第一个谜**" 已经分析过——**LCL + 数字预失真**是国一标准方案。

**这一条是基本要求里最考验软件的项**——**只优化硬件做不到，必须软件配合**。

### 基本要求 (3)：效率 ≥ 88%

> 逆变器 1 的效率 ƞ **不低于 88%**。（14 分）

14 分。前面已经分析过损耗预算 5.5W < 6.5W——**精打细算就能过**。

题目说明 (3) 隐藏的杀手：

> 直流辅助电源的耗能应**计入效率 ƞ 计算中**。

意思是控制电路、栅极驱动、显示器**都算损耗**——**所有耗电 < 6.5W 才算 88%**。

**前一篇 2025-A 已经讲过**——**辅助电源用 LDO 损耗 5W，用 Buck 仅 0.04W**——**这一题同样适用**。

### 基本要求 (4)：负载调整率 ≤ 0.2%

> Io 在 0A~2A 间变化时，负载调整率 SI1 ≤ 0.2%。（14 分）

14 分。前面已经讨论过——**电流前馈 + 闭环 PI**的标准方案。

**0.2% 比基本要求 (1) 的 0.83% 严格 4 倍**——**这是最严苛的稳态精度要求**——**国一硬功夫**。

### 发挥 (1)：双机离网并联

> 逆变器 1 和逆变器 2 **并联**，共同向 RL 供电，Uo=24V，fo=50Hz 时，Io=4A。（15 分）

15 分。**核心是均流**——**两台输出电流尽量相等（理想 2A:2A）**。

**实际不要求严格均流**（题目没说明确指标）——**只要总电流 ≥ 4A、单机不烧 = 通过**。

**国一队伍**会做到 **2A:2A ± 5%**——**分布式下垂控制 + CAN 数字均流补偿**。

### 发挥 (2)：并网，电流任意设定

> 断开 S1，闭合 S2，**逆变器 1 与逆变器 2 并联且能并网**，能在 2A~4A 范围内**按数字设定**输出电流 Io，其误差绝对值应小于设定值的 6%。（15 分）

15 分。**本题真正的核心**。

**'**按数字设定**'** = 用按键 / 旋钮 / 串口命令设定输出电流——**逆变器跟踪这个目标**。

**6% 误差**：2A 时允许 0.12A 误差，4A 时允许 0.24A 误差——**很宽松**。

但这一项的**前提是先并网成功**——前面 "**第三个谜**" 讲的合闸时序是命门。**任何一步不对，并网失败 = 0 分**。

### 发挥 (3)：电流任意比例分配

> Io 在 1A~3A 间变化时，逆变器 1 及逆变器 2 的输出电流比值 K=Io1:Io2 可在指定范围（**0.5~2**）内**按数字设定自动分配**，其相对误差的绝对值不大于 5%。（15 分）

15 分。前面 "**第四个谜**" 已经讲过实现方法。

**K 的范围 0.5~2**：意味着两台逆变器的电流比可以是 1:2 / 1:1 / 2:1 这样的任意值。**完全打破了 '**对称工作**'** 的限制——**这就是工业上 '**主备份切换**'、**'**容量调度**'** 这些场景的需求。

### 说明里的暗坑

**说明 (1)：'**测试过程中不得重新接线**'**

意思是**整个测试 50 分钟里不能换线、不能重启电路**——**前一篇 2025-A 讲过这一坑**——**'**软启动 + 状态机**'** 是命门。

**说明 (3)：'**各自独立 + 直流辅助电源耗能计入**'**

前面已经讨论过——**双 MCU + Buck 辅助电源** = 标准做法。

**说明 (5)：'**低于 1.8A 不得分**'**

题目要求 Io = 2A——**实测 < 1.8A 直接 0 分**。这意味着**你的电流目标不能贴着 2A 设**——**要留 5% 余量设到 2.05A**。

**说明 (7)：'**各自独立的控制器**'**

前面已经讲过——**这一条强制你做 '**分布式控制**'**——**双 STM32 + CAN 总线**是标配。

**说明 (9)：'**并网应满足并网条件，确保人员及设备安全**'**

这是安全条款——**前面合闸时序 T0~T5 必须做对**——**这条就是那个 '**安全**' 两个字的具体要求**。
