## 想象一个场景

你刚搬进新出租屋，房东说：'电费一个月 300。'

你装上一个智能插座（淘宝 30 块那种），开始一件件查家电的耗电——冰箱 80W、电视 50W、微波炉 1100W、电脑 200W、空调 1500W。

加起来一天大概 8 度电，**一个月不应该超过 80 块**。但你的电表却显示用了**260 度**。**钱去哪儿了**？

你可能会怀疑电表坏了。但实际上，**电表没坏，是你的智能插座骗了你**。

那个 30 块的插座只测了一个数字——**功率（W）**。但电力公司算钱用的是**电度（kWh）**，并且对**'功率因数'**有要求。如果你家里大量使用空调、电脑、LED 灯——这些都是**非线性负载**——它们消耗的'**视在功率（VA）**'比'**有功功率（W）**'高出 30~50%。**电力公司按 VA 算钱**（实际上工业户是这样，居民户暂时不严格），你看到的'功率值' = **W** ≠ **真实电费基准 VA**。

这就是为什么工业上，**精密的电力测量仪表卖到 5000~50000 元一台**——它们能区分 W、VA、Var 三种功率，能拆出基波和 2~50 次谐波，能测功率因数和位移因数。

本题让你做的，是把这台 5000 元的仪表压到 **200 元成本，跑在你的本科生焊接水平上**。

## 这题在做的事，其实就把'电'这个概念彻底拆开

打开图 1 的拓扑：

**左半边：墙上插座**——220V 50Hz 工频交流电进来，三根线 L、N、PE。  
**中间：你的功率分析仪**——电压互感器测 u（电压），电流互感器测 i（电流），送到 MCU 处理。  
**右半边：被测负载**——可能是台灯、电吹风、电脑电源、变频空调，**任何一种家电**。

这台分析仪要在**插座和家电之间**'**插一脚'**——不接触强电的情况下，把每一秒钟流过的电流、电压、功率、谐波**一一算出来显示给你看**。

听起来像万用表，**但万用表只能测一个数字**。这台分析仪要同时输出十几个数字：

- **U**（电压有效值）
- **I**（电流有效值）
- **P**（有功功率，单位 W）
- **S**（视在功率，单位 VA）
- **PF**（功率因数 = P/S）
- **THD**（电流总谐波畸变率）
- **H1**（基波电流有效值）
- **H2~H10**（2~10 次谐波有效值各一个）

**'电'这个概念在工程师眼里不是一个数字，是一组关系**。功率分析仪做的事，**就是把这组关系一项一项亮在你面前**。

> **小白补课：U、I、P、S、PF、THD 都是啥**
>
> - **电压 U**：插座上两根线（L、N）之间的电压，**220V 是有效值**，对应峰值 311V。
> - **电流 I**：流过电器的电流大小。**有效值 1A** 表示这股交流电的'热效应'相当于 1A 直流电。
> - **有功功率 P**：被电器'真正用掉'的功率，单位 W（瓦）。**这是变成光、热、动能的部分**。
> - **视在功率 S**：电压有效值 × 电流有效值 = U × I，单位 VA（伏安）。**这是电网'看上去送出去'的功率**——但其中一部分会被反送回去（无功部分）。
> - **功率因数 PF**：P/S，介于 0~1 之间。**1 表示完全有功，0 表示完全无功**。家用电器一般 0.6~0.95。
> - **THD（总谐波畸变率）**：电流波形偏离纯正弦的程度。**0% 是完美正弦，10% 是已经看出来扭曲了**。
> - **H1**：基波电流有效值（50Hz 部分）。
> - **H2~H10**：2~10 次谐波电流有效值（100Hz 到 500Hz 各一个）。

理解这些概念之后，本题的考点就明确了——**怎么从插座上不接触强电的两个传感器读数，算出上面这十几个量**。

接下来一层一层揭谜。

## 第一个谜：为什么必须用互感器，不能直接接 ADC

最简单的'测电压'方法是什么？**两根线接进 ADC**。但本题里你**绝对不能这么干**——会出人命。

为什么？

电网 220V 的电压有'**对地电位**'问题。你家插座的零线 N 是接地的（PE 与 N 在变压器中性点连接），但火线 L 的对地电压是 220V。**如果你的 MCU 板（接 USB / 接电池）和这条 L 线之间没有'**电气隔离**'**，会发生两件事：

1. **MCU 烧毁**：220V 直接把 3.3V 的 ADC 端口击穿
2. **人触电**：你的手摸到 MCU 任何金属部分都可能被电击

题目说明 (2) 写得很重：

> 系统设计和制作必须**符合电气规范**，强电部分电路做好绝缘处理，操作必须符合安全规范，确保**人身安全**；电压和电流传感测量方案**必须选用隔离的方案**。

'**必须**'两个字。**强弱电隔离不是建议，是底线**。不隔离的方案根本评不了——评委一看你的板子直接判不合格。

工程上对付强弱电隔离有四种武器：

**武器 1：电压互感器 PT（测电压用）**

> **小白补课：电压互感器的物理原理**
> 电压互感器（Potential Transformer，PT）是一种'**变压器**'。原边接 220V 高压，副边输出 5V 低压（变比 44:1），**两边线圈互相绝缘**——就像两个不共线的回路'通过磁场隔空对话'。原边电压变 100V，副边自动变 2.27V。**信号传递了，电气却完全隔离**。
> 电赛常用 PT 型号：**ZMPT101B**（南京中旭，常用 1000:1 变比）。原边接 220V 时副边输出几伏。**单价 30 元，电赛标配**。

**武器 2：电流互感器 CT（测电流用）**

CT 的原理和 PT 类似，但'**测的是磁通**'而不是电压。一根载流导线穿过 CT 的环形磁芯，磁芯里就会产生与电流成正比的磁通——磁通在副边线圈里感应出与原边电流成比例的副边电流。

电赛常用 CT 型号：**ZMCT103C**（南京中旭，原副边变比 1000:1，原边 5A 时副边 5mA）。**也是单价 30 元**。

题目说明 (4)：

> 自制系统制作时考虑原方导线**多匝缠绕操作的便利性**。

这一句话的意思是——CT 的原边可以**'多匝缠绕'**：让被测电流的导线在 CT 上**绕几圈**，**等效电流放大几倍**。原边 1A 绕 5 圈 = 等效 5A，**副边输出也放大 5 倍**——**用于测小电流时提高精度**。

**第二笔：互感器输出怎么变成 ADC 输入**

PT 副边输出 5V 时（原边 220V 时），ADC 是 0~3.3V。**需要分压 + 偏置**：

```
PT 副边 (±5V) → 分压电阻 (1:2) → ±2.5V → 加 1.65V 偏置 → 0~3.3V → ADC
```

CT 副边输出更小（mA 级电流），需要**电流-电压转换**：

```
CT 副边 (±5mA) → 100Ω 采样电阻 → ±0.5V → 运放放大 (×3) → ±1.5V → 加 1.65V 偏置 → 0~3.3V → ADC
```

注意运放电源也要从 MCU 供电（隔离侧）——**全程不接触强电**。这就是'电气隔离'的具体含义。

**武器 3：霍尔传感器（更精确）**

**ACS758-50A**（Allegro 公司）：内置霍尔元件，原副边电气隔离 2.1kV，灵敏度 40mV/A。**单价 50 元**。

霍尔比互感器**响应速度快**（DC 到 200kHz），适合测高次谐波。**国一队伍标配 ACS758 + ZMCT103C 双备份**。

**武器 4：隔离运放（最精密）**

**AMC1301**（TI 公司）：精密差分隔离放大器，3kV 隔离电压，0.1% 精度。**单价 150 元**。

适合做超精密测量（**< 0.1% 精度**），但贵。**这一题 1% 精度要求用不到**。

**一句话总结**：**PT + CT 是本题的标配**——成本低、隔离可靠、精度足够。**但要做'CT 多匝缠绕'**——这是题目（1）的硬性要求，不做这一项 20 分丢一半。

## 第二个谜：怎么把波形变成数字

互感器把 220V/几安培变成几伏的低压信号，下一步就是 ADC 采样 → 数字化 → 算各种参数。

**第一笔：采样率怎么定**

题目要求测 2~10 次谐波，**最高 10 次 = 500Hz**。按奈奎斯特定理 **采样率 ≥ 1kHz**。但为了 FFT 频率分辨率高一点，**工程值取 5~20kHz**。

**国一队伍的甜点**：**6.4kHz**（128 点 / 20ms 整周期，50Hz 系统的'魔术数字'）。这意味着 FFT 窗口正好是基波整周期，**没有频率泄漏**——前一篇 2025-B 讲过这个坑。

**第二笔：ADC 精度怎么够**

12 位 ADC 量化精度 1/4096 = 0.024%。**但**测 1% 精度要求的不是 ADC 单点精度，而是**整个测量链的总误差**——包括：

- 互感器误差（±1% 通常）
- 运放误差（±0.1% 通常）
- ADC 量化误差（±0.024%）
- ADC 增益和零偏误差（±0.5% 通常）
- PCB 噪声耦合（±0.1% 通常）

**累加近 1.5%——勉强达标**。

工程对策：**校准消除系统性误差**。

校准方法：**用一台精密功率计（比如 Fluke 175）作标定源**，让你的设备读 1V、5V、10V、50V、100V、200V 时分别记录读数和真值，**算出'增益系数 G + 零偏 O'**：

```
真值 = G × 读数 + O
```

把 G 和 O 写到代码里，每次测量结果**用这两个数线性修正**。**校准后误差能压到 ±0.3%**——离 1% 还有 3 倍余量。

**第三笔：怎么处理交流信号**

互感器输出是±对称的交流信号，但 ADC 只接受 0~3.3V 单极性。中间需要**直流偏置**——**1.65V 居中**。

```
互感器 → 偏置 1.65V → ADC 读 0~3.3V → 软件减去 1.65V → 还原 ±1.65V
```

代码：

```c
uint16_t adc_raw = adc_read();
int16_t adc_centered = (int16_t)adc_raw - 2048;  // 去除直流偏置（4096/2 = 2048）
float voltage_scaled = adc_centered * V_FS / 2048.0f;  // 转换为电压
```

注意一个坑——**1.65V 偏置不准时（运放零偏导致）**会引入直流分量。这个直流分量在 RMS 计算时被'消掉'问题不大（前提是用真 RMS 公式），**但在 FFT 里会变成假的'0Hz 分量'**——影响后面谐波分析的精度。

工程对策：**FFT 之前先减去信号均值**：

```c
float mean = 0;
for (int i = 0; i < N; i++) mean += samples[i];
mean /= N;
for (int i = 0; i < N; i++) samples[i] -= mean;
```

这一步把'**直流分量强制清零**'，让 FFT 能干净地反映 50Hz 基波 + 谐波。

**第四笔：DMA 让 MCU 解放出来**

ADC 单点读取每次几微秒，10000 次/秒就是 100ms CPU 时间——**MCU 几乎全占在 ADC 上**。

工程对策：**用 DMA 让 ADC 自动填缓冲**。MCU 配置完启动，然后睡觉，**DMA 完成中断时来处理整个缓冲**。这是 STM32 / MSP432 / TM4C 上的标准操作：

```c
HAL_ADC_Start_DMA(&hadc1, (uint32_t*)adc_buffer, BUFFER_SIZE);
// 配置完就退出，DMA 自动填 adc_buffer
// 缓冲填满会触发中断 HAL_ADC_ConvCpltCallback
```

**这一步让 MCU 有大量空闲时间做 FFT、做显示、做 LCD 刷新**——**关键的低功耗设计前提**。后面发挥 (4) 50mW 的要求就靠这种结构。

## 第三个谜：怎么算 P、S、PF、THD

ADC 数据有了，现在要算电参数。**每个参数的算法都不一样**。

**算 U_RMS 和 I_RMS（电压电流有效值）**

教科书公式：

```
U_RMS = √(1/T × ∫ u(t)² dt)
```

数字化版本：

```
U_RMS = √(1/N × Σ u_i²)
```

代码 5 行：

```c
float sum_sq = 0;
for (int i = 0; i < N; i++) {
    sum_sq += u_samples[i] * u_samples[i];
}
float u_rms = sqrt(sum_sq / N);
```

这个式子说的其实是：**把每个采样点平方求和，再除以采样点数，再开根号**。背后的物理是——**正弦波的平方是恒正的（cos² 总在 0~1 之间），平均之后再开根，得到的是这个波形的'热效应等价'电压**。

**精度要点**：
- N 必须是 50Hz 整周期数 × 每周期采样点数，否则会有少量误差
- 平方求和必须用 float 或 double（int32 可能溢出）
- 校准后才送显示

**算 P（有功功率）**

教科书公式：

```
P = 1/T × ∫ u(t) × i(t) dt
```

数字化版本：

```
P = 1/N × Σ (u_i × i_i)
```

代码：

```c
float sum_ui = 0;
for (int i = 0; i < N; i++) {
    sum_ui += u_samples[i] * i_samples[i];
}
float p = sum_ui / N;
```

这个式子说的其实是：**把每一时刻的电压电流相乘求和再平均**——也就是'**每一瞬间的瞬时功率取平均**'。

> **小白补课：为什么这就是有功功率**
> 单看一个正弦周期：
> - **如果电流和电压同相**（PF=1，纯阻性负载），u·i 始终非负，平均值就是 (U×I)/2 = U_rms × I_rms。**全是有功**。
> - **如果电流落后电压 90°**（PF=0，纯电感），u·i 在前半周期为正、后半周期为负，平均值 = 0。**全是无功，没干活**。
> - **介于两者之间**，平均值 = U_rms × I_rms × cos(φ)，这就是真实有功 P。

**算 S（视在功率）和 PF**

```
S = U_RMS × I_RMS
PF = P / S
```

S 是'电压电流各自的尺寸大小相乘'，**没有方向感**。PF 把方向感压回来——**有功占视在的比例**。

**算 THD 和谐波**

这一步最重要——**40 分都集中在这里**。

THD 公式：

```
THD = √(I_2² + I_3² + ... + I_10²) / I_1 × 100%
```

要算 THD 必须先做 FFT。FFT 的实现前一篇讲过（CMSIS-DSP 库 1024 点 1.5ms）。这里专门讲'**怎么从 FFT 输出里提取整数次谐波**'。

如果采样率 6.4kHz，FFT 长度 N = 256，频率分辨率 = 6400/256 = 25Hz。  
50Hz 在 FFT 输出的第 **50/25 = 2** 号 bin。  
100Hz（2 次）在第 4 号 bin。  
500Hz（10 次）在第 20 号 bin。

```c
float harmonics[11];  // index 1~10 是基波 / 2~10 次谐波
for (int n = 1; n <= 10; n++) {
    int bin = n * 50 / 25;  // 对应 FFT bin 索引
    harmonics[n] = sqrt(fft_real[bin]² + fft_imag[bin]²) / sqrt(2);  // 转 RMS
}

float sum_sq = 0;
for (int n = 2; n <= 10; n++) {
    sum_sq += harmonics[n] * harmonics[n];
}
float thd = sqrt(sum_sq) / harmonics[1] * 100;
```

**精度要点**：
- 必须**整周期采样**（前面讲过的'6.4kHz × 256 点 = 20ms = 1 周期'魔术）
- 必须**加 Hann 窗减少泄漏**
- 必须**减去信号均值**消除直流分量
- 算出来的 harmonics[n] 单位是'峰值'，要除 √2 转 RMS

**做完这套，THD 误差能压到 1% 以下**——离要求 2% 还有 1 倍余量。

## 第四个谜：50mW 是个什么概念

题目要求 (4)：

> 系统工作时（非休眠状态）系统功耗 ≤ **50mW**。

50mW 是什么概念？

- 一颗 LED 灯珠（白色）：约 60mW
- 一颗 0805 封装电阻（10kΩ，3.3V 电压下）：1.1mW
- 普通示波器探头 USB 接口：500mW
- 你的智能手机电池（待机）：约 200mW
- **本题要求**：**整机不超过 50mW**

50mW = **MCU + LCD + ADC + 互感器 + 运放 + 显示——全部加起来不能超过这个**。

3.3V 电源下，这意味着**总工作电流 ≤ 15mA**。

新手第一次看到这个数字会懵——'**我一颗 STM32 跑 168MHz 就要 50mA，还有什么操作空间**？'

答案是：**MSP430 / MSP432 这些 TI 低功耗 MCU 跑 16MHz 才 1mA**。题目说明 (1) 'TI 公司的 MCU' 把这道题的核心指向了 **TI 的低功耗产品线**。

> **小白补课：MSP430 / MSP432 是什么**
> - **MSP430F471xx**：16 位 MCU，主频 16MHz，**满负载工作功耗约 4mA / 5V**（即 **20mW**）。专为电表设计，自带 24 位 Σ-Δ ADC，**功耗冠军级别**。
> - **MSP432P401R**：32 位 ARM Cortex-M4F MCU，主频 48MHz，**满负载约 80μA/MHz**（即 48MHz 时 4mA = **13mW**）。带 FPU + 14 位 ADC，**性能优秀且省电**。
> - **TM4C123GH6PM**：32 位 ARM Cortex-M4F MCU，主频 80MHz，约 **35mA（115mW）**——**不省电**，不适合本题。

**国一队伍的标配**：**MSP432P401R**——既能跑 FFT，又省电。

**第二项功耗杀手是 LCD 显示器**

普通 ILI9341 TFT LCD（2.4 寸 320×240）背光功耗约 **80mA × 3.3V = 264mW**——**直接超标**。

低功耗替代方案：

- **OLED 1.3 寸（128×64）**：仅依靠 OLED 自身发光，**满显示约 20mA × 3.3V = 66mW**，黑底白字时**仅 5mA = 16mW**。**非常省**。
- **STN 单色 LCD**：背光关掉时几乎不耗电，**1mA 以内**，但需要环境光照才能看清。**最省**。
- **EPaper 电子纸**：刷新瞬间耗电，刷新完后**几乎 0mW**。**超省**但刷新慢（>1 秒）。

**国一队伍的选择**：**1.5 寸 STN 段码 LCD**（如 HT1621 驱动）——**总功耗 < 5mW**，但只能显示数字（不能画波形）。

如果要显示波形——选 **OLED 1.3 寸**，**满显示 < 60mW**。**配合关闭部分像素策略，能压到 30mW**。

**第三项功耗：互感器和运放**

PT、CT 本身基本不耗电（无源器件），但**给运放 + ADC 偏置电路供电**会消耗：

- **运放（如 OPA2333，TI 低功耗运放）**：每路 30μA × 3.3V = 0.1mW，**4 路总共 0.4mW**
- **ADC 参考电压源（TL431 + 滤波）**：约 1mA = 3.3mW
- **偏置电路**：约 0.5mW

**总计辅助电路 < 5mW**——这部分很容易省。

**第四项功耗：MCU 工作模式**

MCU 不需要全速跑——大部分时间在等 ADC 完成采样。**用 DMA + 中断**让 MCU 大部分时间睡眠：

```c
// 主循环
while (1) {
    if (adc_ready) {
        // FFT 计算（耗时 1.5ms）
        compute_harmonics();
        // 更新显示（耗时 0.5ms）
        update_lcd();
        adc_ready = 0;
    }
    // 等下次 ADC 完成
    __WFI();  // Wait For Interrupt，CPU 进入低功耗模式
}
```

`__WFI()` 是 ARM Cortex-M 的低功耗指令——**MCU 时钟暂停，电流降到 1/10**。等到 ADC 完成中断唤醒，才继续工作。

**MCU 占空比 = 工作时间 / 总时间** = 2ms / 20ms = **10%**。  
**等效平均功耗** = 10% × 13mW = **1.3mW**。

**汇总**：

| 模块 | 估算功耗 |
|---|---|
| MCU（MSP432，10% 占空比） | 1.3 mW |
| OLED 1.3 寸（半屏显示） | 25 mW |
| ADC 参考 + 偏置 | 4 mW |
| 4 路低功耗运放 | 0.4 mW |
| LDO 稳压器（3.3V → 1.8V 等） | 5 mW |
| 蓝牙 / 通信（关闭） | 0 mW |
| **总计** | **35 mW** |

**35 mW 距离 50mW 还有 30% 余量**——**做对了就能过**。

**测量功耗的硬件设计**

题目说明 (5)：

> 需在其电路中提供**直流电流表和直流电压表**测量接口，用于测量自制系统的功耗

意思是评委会在你的电源回路里串万用表测电流、并联电压表测电压——P = U × I 算功耗。

工程对策：**在电池正极和系统之间串一个 2-pin 端子**——平时短路（让电流通过），测试时**插上万用表（电流档串入）**测瞬时电流。同样在电池正极上挂一个 4-pin 端子——**测电压用**。

**实战经验**：让万用表的电流量程设到 **100mA 量程**，分辨率 0.01mA——能精确测到 0.1mA 级别的耗电变化，**很容易调试出'哪个模块多耗了多少电'**。

现在你脑子里已经有了全局，是时候回到题目原文，**像工程师那样把每个数字算一遍、每条要求推导一遍**。看完这一节你不仅懂出题人想要什么，更懂自己作为工程师拿到这题时该怎么动笔。

### 任务那段话

> 基于 TI 公司的微控制器（MCU）芯片，设计并制作图 1 所示针对单相交流供电系统的**单相功率分析仪**，**用于标定和比对本自制系统**；系统实现测量用电插座上的负载的**电流、电压、有功功率、功率因数、电流谐波系数（THD）、电流基波及其 2~10 次谐波分量的有效值**等参数，**系统由电池供电**。

任务里几个关键词：

**'单相功率分析仪'**：测一相（不是三相）的电参数。三相分析仪硬件多 3 倍、软件复杂 3 倍，单相是入门版。

**'用于标定和比对本自制系统'**：图中的 PA（市售功率分析仪）是评委用来评分的'**真值源**'——它说测出来 1.0A，你也要测出来 1.0A ± 1%。**说明 (3)** 写明：

> PA 采用市售三相或单相功率分析仪或带谐波系数测量功能的数字功率计作为标定和比对仪器。

意思是评委会用 Fluke 1735 / Hioki 3196 这种几千几万一台的仪表测真值，**你的设备读数和它比**。**所以校准必须做对，不然误差再小都没用**。

**'电池供电'**：限制了功耗（题目要求 (4) 50mW）。**电池电量有限，必须省电**。

**12 个待测参数**：电压、电流、有功、视在（隐含，PF 算出来）、功率因数、THD、H1~H10。**12 个数字同时显示是个 LCD 设计挑战**——要么分 2~3 页显示，要么用大屏幕。

### 任务要求 (1)：电流电压测量，误差 ≤ 1%

> 基于安全要求，电流测量、电压测量采用**电流互感器和电压互感器**的传感方法或其他强弱电隔离的传感方式，**其中的交流电流互感能用原方多匝缠绕的方法提高其灵敏度，并能在系统中设置匝数比**，电流量程为有效值 4A，电压量程为有效值 250V。实现对用电插座上负载的电流和电压的测量，与 PA 读数相比，**相对误差绝对值≤1%**。（20 分）

20 分。'多匝缠绕 + 设置匝数比'是这一项的硬性要求——**新手如果忘了做这个，20 分丢一半**。

**第一笔：什么叫'多匝缠绕'**

CT 的副边电流 = 原边电流 / 匝数比。**如果原边只穿 1 圈，副边电流 5mA / A**；**如果原边穿 5 圈**，等效原边电流变成 5×I，**副边电流变成 25mA/A**——**灵敏度提升 5 倍**。

但有上限——**CT 的磁芯会饱和**。原边总电流（匝数 × 单匝电流）**不能超过 CT 设计的最大值**（一般 30~50A）。

**实现方法**：你的 PCB 上预留一个 CT 的'原边端口'——**两个螺钉**+'**通孔**'。被测导线**自由穿过通孔几圈，然后两端用螺钉固定**。

**第二笔：'设置匝数比'软件实现**

软件里要有一个变量记录'当前的匝数 N'，让用户能修改：

```c
int turn_ratio = 1;  // 默认 1 圈
// 用户按键调整 turn_ratio = 1, 2, 3, 5, 10
float i_actual = i_measured / turn_ratio;
```

**菜单设计**：长按某个按键 2 秒进入设置菜单，显示'匝数比 = 1/2/3/5/10'，**用户选择**。

**第三笔：'电流量程 4A、电压量程 250V'**

CT 选型：**ZMCT103C，5A:5mA 变比**。匝数比 1:1 时直接测 0.5~5A，匝数比 5:1（穿 5 圈）时测 0.1~1A——**覆盖 0.1~5A 的全量程**。

PT 选型：**ZMPT101B，1000:1 变比**。原边接 250V 时副边输出 0.25V——稍微太小，需要**适当放大**。

**4A 和 250V 的'峰值'**：4×√2 = 5.66A 峰值；250×√2 = 354V 峰值。**互感器的耐压必须高于这个**——**ZMPT101B 标称 1500V 峰值**，**ZMCT103C 标称 50A 峰值**，**都有大量余量**。

**第四笔：1% 误差怎么保证**

前面"第二个谜"已经讲过——**校准是关键**。

**校准点选 5 个**：1V、50V、100V、150V、220V（电压侧）；0.1A、0.5A、1A、2A、4A（电流侧）。每个点做 10 次平均，**软件算出'读数 vs 真值'的线性回归参数 G + O**：

```
真值 = G × 读数 + O
```

写到代码常量里。

**校准后的整体误差**：±0.3%（典型值），**远低于要求 1%**。

20 分稳拿。

### 任务要求 (2)：功率和功率因数测量，误差 ≤ 1%

> 实现用电插座上负载的**有功功率、功率因数测量**，与 PA 读数相比，相对误差绝对值≤1%。（25 分）

25 分。这一项考'**乘法运算的精度**'。

**第一笔：P 计算**

```
P = (1/N) × Σ (u_i × i_i)
```

代码层面只有 1 行——但**精度依赖**：
- u_i 和 i_i **必须时间对齐**（同一时刻采样）
- u_i 和 i_i **必须 RMS 校准过**

**ADC 同步采样**很关键。如果 u 和 i 在 ADC 不同通道上轮询采样，**两者之间有 1~2μs 时间差**——这对 50Hz 信号几乎可忽略，但**对 500Hz 的 10 次谐波（周期 2ms）就会引入 0.18° 的相位误差**——大约 0.3% 的功率误差。

工程对策：**两个 ADC 同时启动，DMA 各自独立填缓冲**——**完美同步**。STM32 的 ADC1 + ADC2 双 DMA 模式就是为这种应用设计的。

**第二笔：PF 计算**

```
PF = P / S = P / (U_rms × I_rms)
```

PF 的精度 = P 的精度 + S 的精度 ≈ 1% + 0.3% = **1.3%**。

但 1.3% 仍然超标（要求 1%）。**怎么压到 1% 以内？**

工程对策：**用 P 和 S 是同一组数据算出来的，相关误差会抵消**。具体来说，如果 ADC 增益偏低 0.5%，那么 P 和 S 都偏低 0.5%——**它们的比值 PF 不变**！这就是为什么实际工程中 **PF 比 P 更准**。

实测后 PF 误差能压到 **0.3%**——远低于 1% 要求。

25 分稳拿。

### 任务要求 (3)：THD 和谐波，误差 ≤ 2%

> 实现用电插座上负载的电流**总谐波系数（THD）和谐波电流**的测量和显示，**谐波至少测量至 10 次**，与 PA 读数相比，相对误差绝对值≤2%。（40 分）

40 分。本题最大头。

**'至少测量至 10 次'**：意思是**测出 H2 到 H10 的全部 9 个谐波分量**，每个都要显示具体数值。

**测试时常见负载的谐波特性**（题目说明 (6) 限定 500VA 内）：

| 负载类型 | 主要谐波 | THD 典型 |
|---|---|---|
| **白炽灯**（纯阻性） | 几乎无谐波 | < 1% |
| **电吹风** | 微小谐波 | 2~3% |
| **LED 灯**（开关电源驱动） | 3、5、7 次明显 | 30~80% |
| **变频空调** | 3、5、7、9 次 | 50~150% |
| **电脑电源**（单相整流 + 电容） | 3、5、7 次 | **80~150%** |
| **电吹风调速段**（可控硅） | 偶次 + 奇次都有 | 30~50% |

**测试时评委一般用'电脑电源 + 调速吹风机'**——**THD 50~80%**，谐波丰富。这个工况下你的设备能测准吗？

**测试方案**：

1. 接上电脑电源，PA 读数：U_rms=220V, I_rms=1.5A, THD=72%, H3=55%, H5=20%, H7=8%, ...
2. 你的设备读数应该差不多——**误差 < 2%**

**第一笔：FFT 频率分辨率不够时的怎么办**

之前我们 N=256 / fs=6.4kHz 时分辨率 25Hz。但 H10 在 500Hz，**正好对应 bin 20**。如果电网真实频率是 50.3Hz（不是 50.0Hz），**H10 就在 503Hz**——**bin 20.12**——这个能量泄漏到 bin 20 和 bin 21 之间。

**误差从 0% 跳到 5%+**。

工程对策一：**加 Hann 窗**——把窗口两端衰减为 0，能量泄漏被压平。**误差降到 1%**。

工程对策二：**用 PLL 同步采样**——让 fs 跟着电网频率漂。如果电网 50.3Hz，**让 fs = 6.44 kHz**（动态调整 ADC 触发周期）。**这样 H10 永远在 bin 20**。**误差降到 0.3%**。

**对策二是国一队伍的标配**——锁定电网相位 + 同步采样 + Hann 窗 = **THD 误差 < 1%**。

**第二笔：怎么显示 9 个谐波**

40 分有'**显示**'要求——题目原文'测量和**显示**'。

**显示方案**：

```
H1 (50Hz):    1.234A (100.0%)
H2 (100Hz):   0.012A (1.0%)
H3 (150Hz):   0.678A (54.9%)
H4 (200Hz):   0.005A (0.4%)
H5 (250Hz):   0.246A (19.9%)
H6 (300Hz):   0.003A (0.2%)
H7 (350Hz):   0.099A (8.0%)
H8 (400Hz):   0.001A (0.1%)
H9 (450Hz):   0.039A (3.2%)
H10(500Hz):   0.001A (0.1%)
THD = 71.8%
```

**优秀显示**：用柱状图（横轴次数、纵轴幅值），**一眼看出主要谐波**。

**国一队伍**：用 320×240 LCD，**3 列布局**——左列波形、中列数字、右列谐波柱状图。**酷炫且专业**。

40 分稳拿。

### 任务要求 (4)：低功耗 50mW

> 自制系统采用低功耗电路并进行**功耗管理**设计，系统工作时（**非休眠状态**）系统功耗 ≤ **50mW**。（10 分）

10 分。前面"第四个谜"已经详细分析过——**MSP432 + OLED + DMA + __WFI() = 35mW**——稳拿。

**'非休眠状态'**这个词的特别意义：题目允许你设计'休眠状态'——按键不操作时进入更低功耗模式。**非休眠状态指的是'正在测量和显示'时**。

**休眠模式**（可作为加分项）：

```c
if (no_keypress_for_30s) {
    enter_sleep();  // CPU 关闭、LCD 关闭、ADC 停止
    // 估计休眠功耗 < 1mW（仅 RTC + 唤醒电路）
}
```

**这种'按键操作 → 测量 → 30 秒不动 → 自动休眠'的设计**很'**像产品**'——**评委会留意，可能加 (5) 项的 5 分**。

### 任务要求 (5)：其他，5 分

> 其他。（5 分）

5 分。前面"真正的考点"已经讲了几个加分点。这里再补充：

**加分点 1：宽量程自动切换**

比如电流测量，1A 以下用 5 匝（CT 灵敏度 ×5），1A 以上用 1 匝。**软件自动判断当前电流大小，提示用户切换匝数**。

**加分点 2：自动电网相位同步**

**第三个谜里讲过的 PLL 同步采样**——如果做对了，**所有 1% 精度都变成 0.3%**——**评委一看读数稳定不漂，会刮目相看**。

**加分点 3：温度补偿**

CT、PT 的精度受温度影响。**实时读温度传感器，对读数做温度补偿**——**误差更稳定**。

**加分点 4：USB 数据导出**

可以把测量结果输出到 USB U 盘 / 手机 / PC——**'专业产品'气质**。

5 分难全拿，**做 1~2 个加分点能拿 2~3 分**。

### 说明里的暗坑

**说明 (1)：'必须选用 TI 公司的 MCU'**

和 2024 H 一样的限制。**MSP430 / MSP432 / TM4C / MSPM0 等都可以**。

但有一个允许：

> 可以使用内含其他厂商 MCU 的**一体化的液晶屏**

意思是 LCD 模块（如 ILI9341）内部驱动芯片可以是别家的——**只要主控芯片是 TI 即可**。这给了你**用现成 LCD 模块**的自由。

**说明 (2)：'强电部分电路做好绝缘处理'**

PCB 设计的安全规范：**强电（220V）和弱电（3.3V）之间至少 5mm 间距**。

实现：
- **PT、CT 横跨 PCB 的两侧**，原边在'强电区'，副边在'弱电区'
- 强电区周围用'**安全围栏**'——丝印线 + GND 接地包围
- **强电导线粗 ≥ 1.5mm**，能承受 4A 电流不发热

**评委检查时会拿万用表量测'强弱电之间是否真的隔离'**——**任何疏忽都可能扣分**。

**说明 (5)：'电池不封装在作品中，测试时随身携带'**

意思是评委可能让你**临时换电池**——你的设备必须**支持任何 3.3V~5V 电源**。

工程对策：**电源端加个 LDO + 反向保护二极管**：

```
电池 → 反向保护二极管 → LDO（如 AMS1117-3.3）→ 3.3V 输出
```

这样接错电池极性也不会烧 MCU。**3 元钱的小元件值 5 分稳定性**。

**说明 (6)：'测试负载限定总视在功率在 500VA 以内'**

500VA = 220V × 2.27A——**最大电流 2.27A**。

但题目要求 **电流量程 4A**——**比测试用电流多 1.7 倍余量**。这就是给你预留的'**安全裕量**'，避免量程切换问题。

## 附录 A：单相功率分析仪的'**电力计量**' 全栈深挖

### A.1 为什么'谐波'变成 21 世纪电力计量的核心痛点

20 世纪 80 年代之前——**电网负载几乎都是'**线性负载**'**——**白炽灯、电阻加热器、感应电机**——**电流波形是干净的 50Hz 正弦**——**THD < 5%**——**电网工程师只测 RMS 电压电流就够**。

进入 1990 年代，**'电力电子化'浪潮**席卷全球：

| 时代 | 主流家电 | 谐波特性 |
|---|---|---|
| **1980 年代** | 白炽灯 + 电感日光灯 + 直流电机 | THD 5% |
| **1990 年代** | CRT 电视 + 电脑 + 节能灯 | THD 30% |
| **2000 年代** | LCD 电视 + LED 灯 + 变频空调 | THD 50% |
| **2010 年代** | 手机充电器 + 电动牙刷 + 路由器 | THD 80% |
| **2020 年代** | 电动汽车充电桩 + 储能 + 光伏并网 | **THD 30~150%** |

**问题——为什么电力电子化后 THD 暴涨？**

因为**所有现代电子设备都用'**整流 + 电容滤波**' 拓扑**——

```
220V AC ──[整流桥]── 脉动 DC ──[大电容]── 平滑 DC ──[DC-DC]── 电子电路
```

**整流桥后的电容只在'AC 电压峰值附近的一小段时间'充电**——**充电瞬间电流是脉冲尖峰**——**这个尖峰电流的频谱里全是 3、5、7 次奇次谐波**。

**全国 14 亿人 + 几十亿台'**整流 + 电容**'电器** —— **谐波叠加进电网** —— **电网谐波污染**。

**谐波污染的危害**：

1. **变压器额外发热**——**铜损按 I² 算 + 谐波 I 含量大**——**变压器寿命缩短 50%**
2. **电缆温升异常**——**每年因谐波损耗的电费全国 500 亿元**
3. **保护装置误动作**——**继电保护对高频敏感**——**误跳闸**
4. **电容器爆炸**——**功率因数补偿电容遇谐波谐振**——**全国每年百起爆炸事故**
5. **测量仪表失准**——**普通电表（基于平均整流式 RMS 算法）测谐波严重负载会偏差 20%**

**国家电网 2018 年开始强制要求'**电能质量监测**'**——**全国 35kV 以上变电站必须装电能质量监测仪**——**单台 5~30 万元**——**全国 12000 座变电站 + 10 万台仪器** = **300 亿市场**——**未来 5 年还要扩到 100 万台**。

**这就是为什么电赛 2024 年专门出'谐波分析'题**——**电力计量行业人才缺口 5 万 + 高校年输出 5000 = 10 倍供需差**。

### A.2 IEC 61000-4-7 标准——专业仪器的衡量基准

国际电工委员会 **IEC 61000-4-7** 是'电能质量谐波测量'的国际标准——**所有专业功率分析仪必须达标**。

**标准的核心要求**：

| 项目 | 要求 |
|---|---|
| **基波同步** | **PLL 锁定电网频率 49~51Hz**——精度 ±0.05Hz |
| **采样窗口** | **10 个工频周期 = 200ms**（**比单周期 20ms 更准**）|
| **FFT 长度** | **2048 点**（200ms × 10kHz 采样）|
| **频率分辨率** | **5 Hz**（200ms 倒数）|
| **谐波次数** | **2~50 次**（涵盖 100Hz~2.5kHz）|
| **加窗方式** | **矩形窗（同步采样下不需要加窗）** 或 Hann 窗 |
| **均方根** | **'真有效值（True RMS）'**——**不是平均整流式** |
| **精度** | **基波 ±0.5%，2~50 次谐波 ±5%** |

**电赛要求（要求 (3)）'谐波误差 ≤ 2%'比 IEC 标准还严**——**理论上意味着电赛设备性能要超越部分商用电能质量分析仪**——**听起来夸张**——**但实际上是因为电赛测试场景受控**（**500VA 以内 + 实验室固定负载**）—— **真实电网环境下做到 2% 几乎不可能**。

**国一队伍把'IEC 61000-4-7 全套实现'**——**直接拿满 40 分 + 5 分'其他'**。

### A.3 'PLL 同步采样'——'**频率泄漏**' 的根治方法

前面 '第三个谜' 已经讲过频率分辨率不够的问题——**这里深挖一下国一队伍的 PLL 同步采样实战**。

**问题再现**：

电网频率漂移 ±0.5Hz 是常态——**深圳 50.0Hz、北京 50.3Hz、新疆 49.7Hz** —— **如果你的采样率固定为 6.4kHz / 256 点 = 20ms 窗口**——**实际窗口对应电网周期数 = 20ms × 50.3Hz = 1.006 周期**——**不是整数**——**FFT 输出会出现频率泄漏**。

**'PLL 锁相同步'解决方案**：

```
电网电压 → 过零检测 → 测得电网真实频率 fn ≈ 50.3 Hz
↓
计算所需采样率 fs = N × fn
（N = 整周期采样点数，例如 128）
↓
fs = 128 × 50.3 = 6.438 kHz
↓
动态调整 ADC 触发周期 = 1 / fs = 155.3 us
↓
ADC 在新周期下采样 → FFT 窗口正好 1 个完整电网周期 → 无泄漏
```

**关键代码——电网过零检测**：

```c
volatile uint32_t last_zero_cross_time = 0;
volatile uint32_t period_us = 20000;  // 50Hz 默认 20ms

void TIM_IRQHandler() {
    uint32_t now = HAL_GetTick_us();
    if (zero_cross_detected) {  // 输入电压上升过零
        period_us = now - last_zero_cross_time;
        last_zero_cross_time = now;
        
        // 调整 ADC 采样周期
        uint32_t sample_period = period_us / 128;
        ADC_TIM->ARR = sample_period - 1;
    }
}
```

**这一招让 FFT 在任何电网频率下都'整周期对齐'**——**频率泄漏 < 0.1%**——**THD 精度提升 10 倍**。

**'IEC 61000-4-7 用 200ms（10 周期）窗口而不是 20ms（1 周期）的原因'**：

- **200ms 窗口对应频率分辨率 5 Hz** —— **比 20ms（25Hz）精细 5 倍**
- **能区分'**基波附近的间谐波**'**（如 47Hz、52Hz 这种'非整数次'谐波）
- **抗噪声能力 √10 ≈ 3 倍提升**

**国一队伍标配**：**6.4kHz × 1024 点 = 160ms 窗口** —— **接近 IEC 标准但简化** —— **频率分辨率 6.25Hz** —— **THD 精度 < 0.5%**。

### A.4 互感器的'**频率响应**' 隐藏陷阱

ZMPT101B 电压互感器和 ZMCT103C 电流互感器都是为 50Hz 设计的——**对高频谐波的响应不平**。

**典型频率响应**（实测）：

| 频率 | ZMPT101B 增益 | ZMCT103C 增益 |
|---|---|---|
| 50 Hz（基波） | **1.000**（基准）| 1.000 |
| 100 Hz（2 次） | 0.998 | 0.995 |
| 250 Hz（5 次） | 0.985 | 0.970 |
| 500 Hz（10 次） | 0.950 | **0.890** |
| 1 kHz（20 次） | 0.870 | 0.760 |
| 2.5 kHz（50 次） | 0.620 | **0.500** |

**'高频衰减'**意味着——**你测得的 H10（500Hz）幅值 = 真实 H10 × 0.89**——**少了 11%**——**远超 2% 误差要求**。

**对策——'频率响应补偿'**：

```c
const float ct_compensation[] = {
    1.000, 0.995, 0.985, 0.975, 0.970,  // H1~H5
    0.945, 0.920, 0.910, 0.900, 0.890   // H6~H10
};

for (int n = 1; n <= 10; n++) {
    int bin = n * 50 / freq_resolution;
    float raw_amplitude = sqrt(fft_real[bin]² + fft_imag[bin]²);
    harmonics[n] = raw_amplitude / ct_compensation[n-1] / sqrt(2);
}
```

**频率响应补偿表的来源**——**出厂前用'**精密信号源 + 标准 CT**' 做扫频测量**——**不同频率下输入和输出的幅值比 = 互感器的频响**。

**国一队伍把这个补偿表写进 EEPROM** —— **每次开机加载** —— **测量精度从 ±5% 提升到 ±0.5%**。

### A.5 校准方法学的国一标配——'**两点校准 + 残差查表**'

互感器和 ADC 的'**误差**'分两类：

1. **系统性误差**（**温度漂移、增益偏差**）—— **校准能消除**
2. **随机噪声**（**ADC 量化、电网波动**）—— **多次平均能减小**

**国一队伍的 '两点校准 + 残差查表' 流程**：

**步骤 1：两点校准（基础）**

用'**Fluke 5500A 多功能校准仪**'（实验室借用）输出已知精确值——**1V、220V、0.1A、4A** —— **4 个点**——**算出增益 G + 零偏 O**：

```
真值 = G × 读数 + O
```

**单纯两点校准能把误差从 5% 压到 0.5%**。

**步骤 2：残差查表（精修）**

两点校准后还有'**非线性残差**'（**互感器在不同负载下增益略有变化**）—— **测一组中间值**（**5V、50V、100V、150V、200V、240V** —— **6 个点**）—— **对每个点记录'**校准后读数 vs 真值**' 的差**——**写到 EEPROM**：

```
5V → 校准后读数 5.012V → 残差 -0.012V
50V → 校准后读数 50.08V → 残差 -0.08V
100V → 校准后读数 100.15V → 残差 -0.15V
...
```

**测量时**——**先做基础校准**—— **再用线性插值查表得到残差** —— **从读数减去残差**。

```c
float voltage_corrected = G_voltage * adc_voltage + O_voltage;
float residual = lookup_residual_table(voltage_corrected);
voltage_final = voltage_corrected - residual;
```

**残差查表后误差 < 0.1%**——**远超 1% 要求**——**给后续 PF 和 THD 计算腾出 0.9% 的余量**。

### A.6 低功耗设计的隐藏招——'**ADC 突发模式**'

前面 '第四个谜' 已经讲过 MCU __WFI() + LCD 选型——**这里讲一个'隐藏招'**：

**ADC 突发模式（Burst Mode）**——**不连续采样 + 间歇休眠**。

**问题**：**普通连续 ADC 采样 6.4kSPS** —— **意味着 ADC 持续工作** —— **耗电 5mA × 3.3V = 16.5mW**。

**优化**：**'10 周期采样 + 990 周期休眠' 模式**：

```
工作 200ms（采 1280 点） → 休眠 800ms（关 ADC + DMA + LCD 不刷新）→ 重复
```

**等效 ADC 占空比 20%** —— **平均耗电 = 16.5 × 0.2 = 3.3mW**。

**LCD 也对应'1 秒刷新一次'**——**关闭背光 / 待机 90% 时间** —— **平均功耗 8mW**。

**整机功耗：MCU 1mW + ADC 3.3mW + LCD 8mW + 辅助 5mW = 17mW** —— **远超 50mW 要求 3 倍** —— **国一档案**。

**注意——'**测量精度 vs 测量速度**' 权衡**：

| 模式 | 采样占比 | 功耗 | 测量延迟 | 谐波精度 |
|---|---|---|---|---|
| 连续模式 | 100% | 50mW | 实时 | < 0.5% |
| **20% 突发** | 20% | **17mW** | 1s | < 0.5% |
| 5% 突发 | 5% | 5mW | 4s | < 0.5% |

**5% 突发模式 5mW**——**远超低功耗要求**——**但用户每 4 秒才看到一次更新**——**'像产品但不太像仪器'**。

**国一选 20% 突发 + 1 秒更新**——**功耗 + 实时性平衡最优**。

## 附录 D：调试踩坑实录——国一队伍的 8 大经验

**踩坑 1：互感器副边'**饱和**'**

**现象**：测电流 4A 时副边输出失真——**THD 从应有的 80% 飙到 150%**——**完全测不准**。

**原因**：ZMCT103C 副边接的负载电阻太大（**默认 1kΩ**）——**5mA × 1kΩ = 5V** —— **运放饱和**。

**对策**：副边电阻改 **100Ω**——**5mA × 100Ω = 0.5V** —— **运放线性区**。

**踩坑 2：'强弱电隔离'**评委检查**

**现象**：评委用万用表测'强电火线'和'弱电 GND' 之间的阻抗——**< 1MΩ 直接判不合格**。

**对策**：PCB 设计时**用'狭缝'物理分隔强弱电区域**——**PT 和 CT 跨越狭缝**——**狭缝宽度 ≥ 5mm + 周围铺接地铜**——**实测阻抗 > 100MΩ**。

**踩坑 3：ADC 偏置漂移**

**现象**：放置 30 分钟后 ADC 读数有 0.1% 直流偏移——**RMS 算法被骗**——**误差 0.5%**。

**对策**：**每次测量前先做 100ms '零信号采样'** —— **减去这个直流偏置** —— **消除漂移**。

**踩坑 4：FFT 频率泄漏**

**现象**：电网真实 50.2Hz 时——**FFT 在 50Hz bin 上读 95V**——**少 5V**——**THD 算错**。

**对策**——**前面 A.3 已讲 PLL 同步采样**。

**踩坑 5：低功耗模式 __WFI() 卡死**

**现象**：MCU 进入 __WFI() 后再也不醒——**整机假死**。

**原因**：进入 __WFI() 之前没有正确启用唤醒中断（NVIC）——**没有人来叫醒它**。

**对策**：进入 __WFI() 前**确保 ADC、DMA、TIM 中断都使能** —— **任何一个中断都能唤醒 MCU**。

**踩坑 6：LCD 在低功耗模式下显示乱码**

**现象**：MCU 唤醒后 LCD 内容是上次的'**残影**' + '**新数据**' 重叠。

**对策**：**唤醒后先发送'**LCD reset**' 命令**——**清屏后再写新数据**——**避免残影**。

**踩坑 7：电池电压跌落**

**现象**：18650 电池放电到 3.3V 以下——**LDO 失效** —— **MCU 重启循环**。

**对策**：加'**低电池告警 + 自动关机**'**——**ADC 监测电池电压 < 3.5V 时显示告警 + 进入深度睡眠**。

**踩坑 8：测试时插入 PA 探头干扰自身测量**

**现象**：PA 测试时改变了被测电流路径——**自制设备读数偏 1.5%**——**不是设备本身错，是测试方法错**。

**对策**：**PA 探头和自制设备并联接入** —— **不破坏原电流路径** —— **专业测试规范**。
