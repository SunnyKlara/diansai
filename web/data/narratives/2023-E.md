## 第一个谜：怎么让二维云台精度做到 ±2 cm @ 1m

**'**1m 距离 + ±2cm 精度**'** = **角度精度 ±1.15°**——**简单**——**但要快**——**1 秒内能扫一圈正方形 0.5m**——**云台角速度 ~ 60°/s**——**这是真正的难点**。

**第一笔账：云台角度精度计算**

```
屏幕距激光笔 L = 1 m
要求精度 d = ±2 cm = ±0.02 m
角度精度 θ = arctan(d / L) = arctan(0.02) = 1.15°
```

**这个式子说的其实是**——**'**1m 距离 ±2cm 容差 → 云台角度容差 ±1.15°**'**——**每 1° 误差等于屏幕上 1.7cm 偏差**——**云台角度精度必须 < 1°**。

**第二笔账：电机选型**

| 类型 | 角度精度 | 速度 | 价格 |
|---|---|---|---|
| **SG90 舵机** | ±1° | 60°/s | 6 元 |
| **MG996R 舵机** | ±0.3° | 90°/s | 30 元 |
| **DS3218 数字舵机** | ±0.1° | 120°/s | 60 元 |
| **42 步进电机 + 16 微步驱动** | ±0.018°（0.018° / 步）| 60°/s | 50 元 |
| **42 步进 + DM542 驱动 + 256 微步** | ±0.001° | 60°/s | 80 元 |

**国一选择**：**42 步进电机 + 16 微步细分驱动**——**精度极高 + 无回滞**——**满分**。

**为什么不用普通舵机**？因为**舵机的"内部 PID"** 不可调——**到位前会"超调 + 振荡"** —— **精度差**。

**步进电机的优势**：

- **开环控制 + 没有累计误差**（**每一步精确）
- **没有"过冲 + 振荡"**——**到位即稳定**
- **微步细分技术**：**16 微步 = 1 步分成 16 份 → 0.018° 精度**

**第三笔账：云台机械结构**

```
基座 ──[水平步进电机]──[支架]──[俯仰步进电机]──[激光笔]
```

**水平电机控制方位角 azimuth（±90°）**——**俯仰电机控制仰角 elevation（±30°）**——**两个独立电机 + 独立驱动**——**两个 PWM 通道**。

**国一队伍**：**自己 3D 打印云台外壳 + 42 步进 + DM542 驱动**——**总成本 200 元**——**精度 ±0.05°**。

## 第二个谜：怎么让红色激光"沿 A4 胶带跑"

**基本要求 (3)(4)** 是关键——**'**红色光斑沿 A4 胶带轨迹移动一周**'**：

- 任务 (3)：A4 胶带"位置已知"** —— **简单**
- 任务 (4)：A4 胶带"任意旋转角度"** —— **真正的难点**

**第一笔账：任务 (3) - 已知位置**

A4 纸尺寸：**21 cm × 29.7 cm**——**1.8cm 黑色胶带框**：

```
四角坐标（A4 横放，左下为原点）：
(0, 0), (29.7, 0), (29.7, 21), (0, 21)
```

**激光斑沿这 4 条边走**——**直接编程发送 4 段直线轨迹给云台**：

```c
// 顺时针走一圈
move_laser_to(0, 0);
move_laser_to(29.7, 0);   // 底边
move_laser_to(29.7, 21);  // 右边
move_laser_to(0, 21);     // 顶边
move_laser_to(0, 0);      // 左边
```

**'**move_laser_to**'** 函数怎么实现？——**用云台角度反算**：

```c
void move_laser_to(float x, float y) {
    // 屏幕坐标 (x, y) → 云台角度
    float dx = x - laser_pivot_x;
    float dy = y - laser_pivot_y;
    float dz = SCREEN_DISTANCE;
    
    float azimuth = atan2(dx, dz);
    float elevation = atan2(dy, sqrt(dx*dx + dz*dz));
    
    set_servo_horizontal(azimuth);
    set_servo_vertical(elevation);
}
```

**这段代码说的其实是**——**'**屏幕 (x, y) → 几何反推 → 云台角度**'**——**典型坐标变换**。

15 分稳拿。

**第二笔账：任务 (4) - 任意旋转**

**'**A4 纸任意旋转 30°、60°、85° 贴在屏幕**'** —— **激光不知道纸放哪里 → 必须先识别**。

**核心算法**：**摄像头看屏幕 → 识别黑色矩形 → 算 4 个顶点 → 沿顶点连线移动**：

```python
# OpenMV 代码（装在红色激光附近的摄像头）
img = sensor.snapshot()

# 1. 二值化（黑色胶带）
binary = img.binary([(0, 80)])  # 黑色阈值

# 2. 找轮廓
contours = binary.find_blobs([(0, 0)])

# 3. 找最大矩形轮廓
rect = max(contours, key=lambda b: b.area())

# 4. 找 4 个顶点（用 Hough 直线检测 + 交点）
lines = img.find_lines(threshold=1000, theta_margin=25)
corners = compute_intersections(lines)

# 5. 把 4 个顶点发给主控
uart.write(f"{corners}\n")
```

**主控收到 4 个顶点 → 控制激光沿 4 边移动**——**即使纸旋转任意角度也能跑对**。

**第三笔账：摄像头标定（坐标系对齐）**

**问题**：**摄像头看到的"图像坐标"** ≠ "屏幕物理坐标"** —— **必须标定转换矩阵**。

**'**透视变换矩阵**'**（**Homography Matrix**）：**4 个对应点（图像 4 个角 ↔ 屏幕 4 个角）→ 求 3×3 变换矩阵**：

```python
# OpenCV 标定（PC 上一次性做好）
src_points = [(0, 0), (640, 0), (640, 480), (0, 480)]  # 图像 4 个角
dst_points = [(-0.3, 0.3), (0.3, 0.3), (0.3, -0.3), (-0.3, -0.3)]  # 屏幕物理坐标

H, _ = cv2.findHomography(src_points, dst_points)
# 之后每次：物理坐标 = H × 图像坐标
```

**国一队伍**：**赛前用屏幕角点标定一次 + 实时套用**——**任意旋转的 A4 纸都能跟上**——**满分**。

## 第三个谜：绿色激光怎么追上红色激光（视觉伺服）

**发挥要求**：**绿激光只能"看"红激光**——**不能通信 + 必须 2 秒内追上 + 距离 ≤ 3cm**。

**核心算法**：**Image-Based Visual Servoing（IBVS, 图像视觉伺服）**：

```
绿色激光摄像头看屏幕 → 找红色光斑位置 (ux, uy) 
                       找绿色光斑位置 (gx, gy)
                       误差 (ex, ey) = (ux - gx, uy - gy)
                       
                       PID → 云台速度命令
                       云台调整 → 绿斑往红斑方向走
                       
                       直到误差 < 3 cm
```

**第一笔账：双色激光识别**

OpenMV 在 HSV 颜色空间区分红绿：

```python
# 红色激光（H ~ 0° 或 360°）
red_threshold = (50, 100, 30, 127, -10, 30)

# 绿色激光（H ~ 120°）
green_threshold = (50, 100, -50, -10, 0, 30)

img = sensor.snapshot()
red_blobs = img.find_blobs([red_threshold])
green_blobs = img.find_blobs([green_threshold])

if red_blobs and green_blobs:
    red_pos = (red_blobs[0].cx(), red_blobs[0].cy())
    green_pos = (green_blobs[0].cx(), green_blobs[0].cy())
    error = (red_pos[0] - green_pos[0], red_pos[1] - green_pos[1])
```

**这段代码说的其实是**——**'**摄像头同时找红绿两个光斑 → 算误差**'**——**OpenMV 25 fps 处理 → 40ms 一帧**。

**坑**：**激光太亮 → 摄像头过曝 → 都看成白色**——**HSV 失效**。

**对策**：

- **降低摄像头曝光**（**手动模式 + 短曝光**）
- **加红色 / 绿色滤光片**（**只让对应颜色光通过**）
- **激光功率调小**（**用串电阻降亮度**）

**国一队伍**：**带滤光片 + 手动曝光 + 多帧平均**——**红绿识别率 100%**。

**第二笔账：视觉伺服 PID**

```c
// 主控接收 OpenMV 数据
float error_x = red_x - green_x;  // 像素单位
float error_y = red_y - green_y;

// 像素 → 云台角度（用透视矩阵）
float angle_error_x = pixel_to_angle(error_x);
float angle_error_y = pixel_to_angle(error_y);

// PID 控制
float servo_vel_x = Kp * angle_error_x + Kd * (angle_error_x - angle_error_x_prev);
float servo_vel_y = Kp * angle_error_y + Kd * (angle_error_y - angle_error_y_prev);

// 限速
servo_vel_x = clamp(servo_vel_x, -MAX_VEL, MAX_VEL);

// 移动云台
move_servo(servo_vel_x, servo_vel_y);
```

**这段代码说的其实是**——**'**用图像误差驱动云台速度**'**——**典型 IBVS 控制**。

**第三笔账：2 秒锁定时间**

**'**2 秒内追上**'** = 云台从任意初始位置 → 红斑位置 → 误差 < 3 cm。

**云台最大角速度**：**60~120°/s**——**最大角度差 90° → 0.75~1.5 秒到达**——**剩 0.5~1.25 秒 PID 收敛**。

**国一**：**预测 + 高速电机 + 高刷新摄像头 → 1 秒锁定**——**满分 10**。

**第四笔账：实时跟踪（红斑动）**

**发挥 (2) 35 分**——**红色激光在 A4 胶带轨迹上跑**——**绿色激光必须始终跟上 ≤ 3cm**——**红斑速度约 0.1 m/s**——**云台必须实时跟**。

**核心**：**用线性预测算法**：

```c
// 预测红斑下 100ms 后位置
red_vx = (red_x - red_x_prev) / dt;
red_vy = (red_y - red_y_prev) / dt;
red_x_predicted = red_x + red_vx * 100ms;
red_y_predicted = red_y + red_vy * 100ms;

// 让绿斑追"预测位置"
move_to(red_x_predicted, red_y_predicted);
```

**这段代码说的其实是**——**'**预测红斑未来位置 → 提前转动云台**'**——**抵消 100ms 反应时间**。

## 第四个谜：A4 胶带"任意角度"** 的轨迹规划

**任务 (4)** 的难点——**纸旋转 30°、60°、85° 任意角度** —— **激光必须沿胶带走**。

**第一笔账：怎么"找到任意角度的矩形"**

**OpenMV 代码**：

```python
img = sensor.snapshot()

# 1. 找黑色像素（胶带）
binary = img.binary([(0, 80)])

# 2. 形态学闭运算（连接断点）
binary = binary.dilate(2).erode(1)

# 3. 找最大轮廓
blobs = binary.find_blobs([(0, 0)])
biggest = max(blobs, key=lambda b: b.area())

# 4. 用 minAreaRect 找最小外接矩形（旋转矩形）
rect = biggest.min_corners()  # 4 个顶点

# 5. 检查是否接近 A4 比例（210:297）
ratio = compute_ratio(rect)
if 0.65 < ratio < 0.78:
    # 是 A4
    send_corners(rect)
```

**'**min_corners**'** 返回 4 个顶点（无论旋转角度）—— **Open MV 自带函数**——**直接用**。

**第二笔账：4 顶点排序**

**问题**：**4 个顶点是任意顺序的**——**激光要"顺时针"** 跑——**必须排序**。

**算法**：**找质心 + 用极角排序**：

```python
def sort_corners_clockwise(corners):
    cx = mean([p[0] for p in corners])
    cy = mean([p[1] for p in corners])
    
    def angle(p):
        return math.atan2(p[1] - cy, p[0] - cx)
    
    sorted_corners = sorted(corners, key=angle)
    return sorted_corners
```

**这段代码说的其实是**——**'**4 个顶点按"极角"** 排序 = 顺时针顺序**'**——**简单**。

**第三笔账：激光沿 4 边平滑移动**

```c
for (int side = 0; side < 4; side++) {
    int from = side;
    int to = (side + 1) % 4;
    
    float steps = 100;
    for (int i = 0; i <= steps; i++) {
        float t = i / steps;
        float x = corners[from].x * (1 - t) + corners[to].x * t;
        float y = corners[from].y * (1 - t) + corners[to].y * t;
        
        move_laser_to(x, y);
        delay(75);  // 30 秒 ÷ (4 边 × 100 步) = 75 ms
    }
}
```

**这段代码说的其实是**——**'**4 边各 100 步线性插值 + 75 ms 一步 = 30 秒一圈**'**——**满足要求**。
