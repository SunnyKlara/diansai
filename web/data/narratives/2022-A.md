## 第一个谜：前级 PFC 怎么"模拟电阻"

**模拟电阻** —— **最简单**——**让"电流和电压同相 + 同形（正弦）"** —— **就是 2021 B 讲过的标准 PFC**。

**控制目标**：

```
i_in(t) = (P_demand / V_RMS²) × v_in(t)
```

**这个式子说的其实是**——**'**电流参考 = 功率需求 / 电压有效值² × 瞬时电压**'**——**电流和电压完全同步**。

**对 2021 B 做过 PFC 的人**：**这一步的代码就是 2021 B 的代码**——**复用率 100%**。

**实操参数**（**U1 = 30V，I1 = 2A**）：

```
P_demand = U1 × I1 = 30 × 2 = 60 W
V_RMS = 30 V
I_amplitude = (P_demand / V_RMS²) × V_peak
            = (60 / 900) × 42.4
            = 2.83 A（峰值）
```

**这个式子说的其实是**——**'**电流幅值 2.83A 峰值 = 2A RMS**'**——**和题目要求一致**。

**实操**：**电流环带宽 3kHz、电压环带宽 30Hz、PFC 电感 1mH（前面 2021 B 详细讲过电感设计）**——**复用**。

**15 分稳拿**。

## 第二个谜：怎么"模拟电感"——把电流相位往后拨

**模拟电感** —— **电流要"滞后电压"** —— **比如 PF = 0.5 对应"滞后 60°"**：

```
v_in(t) = V_peak × sin(ωt)
i_in(t) = I_peak × sin(ωt - 60°)  ← 电流晚 60°
```

**对应的功率因数**：

```
PF = cos(60°) = 0.5
```

**怎么实现"电流晚 60°"** ？

**核心思想**：**让电流参考的相位偏移 60°**——**和 2021 B 发挥要求 (3) "PF 可调"** 完全一样。

**第一笔账：相位偏移的代码**

```c
// 1. 测量电网相位（PLL 锁相环）
phase_voltage = pll_get_phase();  // [0, 2π]

// 2. 加相位偏移（滞后）
phase_current = phase_voltage - phi;  // phi = 60°（弧度 π/3）

// 3. 生成电流参考
i_ref = i_amplitude * sinf(phase_current);

// 4. 电流环跟踪
pwm_duty = current_pi(i_ref - i_actual);
```

**这段代码说的其实是**——**'**让电流参考相位比电压晚 60°，PFC 电流环就把电流推到滞后状态**'**——**实现"模拟电感"**。

**第二笔账：相位偏移精度**

PF = 0.5 对应相位差 60°——**怎么保证 PF 精度 ±2%**（**典型工程要求**）？

```
ΔPF = sin(φ) × Δφ
0.02 = sin(60°) × Δφ
Δφ = 0.02 / 0.866 = 0.023 rad = 1.32°
```

**这个式子说的其实是**——**'**相位精度 ±1.32°，对应 PF 精度 ±2%**'**——**要求 PLL 精度 ≤ 1°**。

**SOGI-PLL 精度 0.1°**——**远超要求**——**满分**。

**第三笔账：50Hz 怎么变成 1.32° 相位精度**

50Hz 周期 20ms——**1.32° = 73μs**——**MCU 时钟 80MHz 完全够用**。

```
1.32° / 360° × 20ms = 73 μs
73 μs × 80 MHz = 5840 个时钟周期
```

**这个式子说的其实是**——**'**73μs 对 80MHz MCU 是 5840 个周期，能精确控制**'**——**完全没问题**。

**第四笔账：电感模拟 vs 真电感的差别**

真电感 = 储能元件——**它能把能量"暂存 + 释放"**。  
模拟电感 = 控制器 —— **它通过"电流相位偏移"** 让"看上去像电感"**——**但内部并不储能**。

**外部观察**：**两者电流、电压、功率因数都一样**——**无法区分**。  
**内部本质**：**真电感的能量在磁场储存，模拟电感的能量在 DC 母线储存**。

**这就是"等效电路"** 的工程哲学——**只要外部端口行为一致，内部结构无所谓**——**这是控制理论的核心思想之一**。

> **小白补课**：什么是"等效电路"？
> - **意大利物理学家伏打**早在 1800 年就提出"等效电路"概念——**把复杂物理系统简化为几个理想元件（电阻 / 电感 / 电容 / 电源）的组合**。
> - **黑盒思想**：**端口电压、电流、功率因数一致 = 等效**——**内部怎么实现都行**。
> - **这就是为什么"电子负载能完美伪装电阻"**——**只要端口看起来像电阻就够了**。

## 第三个谜：怎么"模拟电容"——把电流相位往前推

**模拟电容** —— **电流要"超前电压"** —— **PF = 0.5 对应"超前 60°"**：

```
v_in(t) = V_peak × sin(ωt)
i_in(t) = I_peak × sin(ωt + 60°)  ← 电流早 60°
```

**'**超前 60°**'** 是怎么实现的？**和"滞后 60°"** 完全对称——**只是相位偏移符号反过来**：

```c
phase_current = phase_voltage + phi;  // phi = 60°，符号变正
```

**这段代码说的其实是**——**'**滞后改成超前，相位偏移加而不是减**'**——**对称性极强**。

**第一笔账：电感 vs 电容的对称性**

| 特性 | 模拟电感 | 模拟电容 |
|---|---|---|
| **电流相位** | 滞后电压 | 超前电压 |
| **PF 公式** | cos(-φ) = cos(φ) | cos(+φ) = cos(φ) |
| **无功类型** | 感性无功（吸收）| 容性无功（释放）|
| **代码差异** | phase - φ | phase + φ |

**完全对称的两种模式**——**代码量增加 0 行**——**只是"数字设定"** 时换一个符号**。

**第二笔账：PF 设定怎么数字化**

题目要求**"根据数字设定自动调整"** —— **意思是用户输入一个 PF 值**——**装置自动调到对应相位**。

```c
// 用户通过编码器 / 触摸屏设定 PF
float PF_set = 0.86;  // 用户设定

// 选择电感性还是电容性
bool is_inductive = true;

// 计算相位偏移
float phi = acosf(PF_set);  // 30.7°（弧度 0.536）

// 加符号
if (is_inductive) {
    phase_offset = -phi;  // 滞后
} else {
    phase_offset = +phi;  // 超前
}

// 应用到电流参考
phase_current = phase_voltage + phase_offset;
```

**这段代码说的其实是**——**'**用户输入 PF 数字，代码自动换算成相位偏移，控制器自动调整电流相位**'**——**用户体验类似数字电源**。

**第三笔账：测试时怎么验证 PF**

测试时用**功率分析仪**（**如横河 WT500**）测输入侧 PF：

| 设定 PF | 实测 PF | 误差 |
|---|---|---|
| 1.00 | 0.998 | 0.002 |
| 0.86 | 0.857 | 0.003 |
| 0.71 | 0.708 | 0.002 |
| 0.50 | 0.495 | 0.005 |

**全部误差 < ±0.02**——**远超工程要求**——**满分**。

**国一队伍**：**PF 误差 < ±0.005**——**比工业产品（±0.01）还好**。  
**国二队伍**：**PF 误差 ±0.01~0.02**——**勉强达标**。  
**国三队伍**：**PF 误差 > ±0.05**——**0 分**。

## 第四个谜：后级并网逆变怎么做

**后级逆变器** —— **把 DC 母线（70V）的能量转换成 50Hz 交流**——**送到回馈侧的电阻负载**。

**核心难点**：**逆变器输出"电压、频率、相位"** 都要和"参考电网"** 同步。

**第一笔账：单相逆变器拓扑**

经典两种：

**拓扑 A：H 桥逆变器（4 个 MOSFET）**

```
DC+ ──[Q1]──┬──[Q3]── DC+
            │        │
       [负载]│        │[负载]
            │        │
DC- ──[Q4]──┴──[Q2]── DC-
```

**4 个 MOSFET 控制**：

- 半周期 Q1 + Q2 导通——**输出正半周**
- 另半周期 Q3 + Q4 导通——**输出负半周**

**用 SPWM（正弦脉宽调制）**：**让输出"平均值"** 跟随正弦参考——**输出经过 LC 滤波后变成纯正弦**。

**拓扑 B：半桥逆变器（2 个 MOSFET）**

只用 2 个 MOSFET——**但需要"分裂电源"**（**+35V / -35V**）——**布线复杂**。

**国一选择**：**H 桥**——**简单稳定 + 全桥推挽**。

**第二笔账：SPWM 调制**

```c
// 50Hz 正弦参考（0~1）
float sin_ref = sinf(2 * PI * 50 * t);

// 三角载波（开关频率 20kHz，0~1）
float triangle_carrier = (counter % 100) / 100.0;

// 比较生成 PWM
if (sin_ref > triangle_carrier) {
    pwm_high = 1;  // Q1/Q2 开
} else {
    pwm_high = 0;  // Q3/Q4 开
}
```

**这段代码说的其实是**——**'**正弦参考与三角波比较，生成 PWM 占空比**'**——**输出"平均值"** 是正弦——**经过 LC 滤波 = 纯正弦交流**。

**第三笔账：电网同步（关键）**

逆变器输出必须和"参考电源"** 同步——**频率、相位、幅值都要一致**。

**'**参考电源**'** 在哪里？——**说明 (3)"交流电子负载仅由图 1 中的交流电源供电"** —— **意味着前后两个交流电源是"同一个 50Hz 电网"** ——**或者后侧电源就是从前侧电源采样得到的**。

**对策**：**前级 PFC 已经锁住了前侧电网的相位（SOGI-PLL）**——**后级逆变器直接复用同一个相位参考**——**自动同步**：

```c
// 前级和后级共享同一个 PLL
float phase_grid = pll_get_phase();

// 前级电流参考
i_in_ref = i_in_amplitude * sin(phase_grid + phase_offset_in);

// 后级电压参考
v_out_ref = v_out_amplitude * sin(phase_grid + phase_offset_out);
```

**'**共享 PLL**'** 是 Back-to-Back 拓扑的标配——**两级用同一个相位**——**前级 + 后级 = 同步运行**。

## 第五个谜：怎么把 ΔP 压到最小（回馈效率最大化）

**回馈效率 = P2 / P1**——**ΔP = P1 - P2** —— **越小越好**。

**ΔP 的来源**：

```
ΔP = P_前级损耗 + P_后级损耗 + P_母线电容损耗
   = P_前级_MOSFET + P_前级_电感 + P_前级_二极管
   + P_后级_MOSFET + P_后级_电感 + P_后级_二极管
   + P_控制电路 + P_母线电容ESR损耗
```

**前后两级都是 PFC 拓扑**——**总损耗 = 2 × 单级损耗**。

**单级 PFC 95% 效率** = **5% 损耗**——**双级串联**：

```
η_total = η_前级 × η_后级 = 0.95 × 0.95 = 90.25%
ΔP = (1 - 0.9025) × 60W = 5.85W
```

**这个式子说的其实是**——**'**双级串联效率约 90%，ΔP 约 6W**'**——**这是"标准方案"**。

**怎么把 ΔP 进一步降到 4W 以内**（**即效率 93%+**）？

**对策 1：SiC MOSFET（前面 2021 B 讲过）**

**单级效率从 95% 升到 97%**——**双级 0.97 × 0.97 = 94.09%**——**ΔP = 3.55W**。

**对策 2：软开关（Soft-Switching）**

**普通 PWM 是"硬开关"**——**MOSFET 在"有电流时关断"** —— **开关损耗大**。  
**软开关**：**让 MOSFET 在"零电压 / 零电流时切换"** —— **开关损耗趋零**。

**两种软开关技术**：

- **ZVS（Zero Voltage Switching）**：**零电压开关**——**适合 Buck-Boost / 谐振变换器**
- **ZCS（Zero Current Switching）**：**零电流开关**——**适合 LLC 谐振 / 准谐振**

**软开关的代价**：**电路复杂度增加 + 控制更难**——**国一队伍才会做**。

**对策 3：母线电容 ESR 优化**

母线电容 470μF 通常用电解电容——**ESR 200~500mΩ**——**每秒损耗 1~2W**。

**改用薄膜电容**（**ESR < 10mΩ**）—— **单价从 5 元升到 50 元**——**但损耗降到 0.05W**——**省 1.5W**。

**国一队伍**：**SiC + 薄膜电容**——**效率 95%+**——**ΔP < 3W**——**满分 25 分**。  
**国二队伍**：**普通 Si + 电解电容**——**效率 88%~90%**——**ΔP = 6~7W**——**18~22 分**。  
**国三队伍**：**效率 75%**——**ΔP = 15W**——**5~10 分**。

## 第六个谜：实战硬件清单与"坑"——别让设计胎死实验室

前面五个谜把"算法 + 拓扑 + 控制"都推完了。但**电力电子题真正翻车的地方往往不是算法，而是硬件**——**MOSFET 选错型号炸机、驱动死区不够拉弧、采样电阻烫坏、PCB 布局走线串扰**——**这些 90% 不会出现在课本里**。这一节把"血泪经验"摊开。

**第一笔账：MOSFET 选型 — 不要省 30 元**

题目 P1 = 60W，前级 PFC + 后级逆变 各需要主管。**主管电流应力**：

```
I_peak = √2 × I_RMS = √2 × 2A = 2.83 A
开关瞬态电流（开通尖峰）= 2 × I_peak = 5.66 A
```

**这个式子说的其实是**——**'**MOSFET 通流能力至少要选 6A 以上**'**——**4A 管子在尖峰瞬间会发烫甚至炸**。

**电压应力**：

```
DC 母线电压 ≈ V_peak + 余量 = 42.4 + 30 = 72 V
开关关断瞬态尖峰 = 1.5 × V_DC = 108 V
```

**意味着 MOSFET 击穿电压必须 ≥ 150V（留 50% 余量）**。

**对比候选**：

| 型号 | Vds | Id | Rds(on) | 价格 | 评价 |
|---|---|---|---|---|---|
| **IRF540N**（Si） | 100V | 33A | 44mΩ | 4 元 | **击穿不足，不能用** |
| **IRFB4115**（Si） | 150V | 104A | 9.3mΩ | 8 元 | **国二常用** |
| **IPP60R190P6**（Si） | 600V | 20.2A | 190mΩ | 12 元 | **冗余足，国一备选** |
| **C3M0120090D**（SiC） | 900V | 23A | 120mΩ | 35 元 | **国一首选** |

**'**IRFB4115**'** 是性价比之选——**8 元 / 颗 × 4 颗（H 桥）+ 4 颗（PFC）= 64 元**——**双级总成本可控**。

**'**SiC C3M0120090D**'** 是效率之选——**35 元 / 颗 × 8 = 280 元**——**贵一档但效率提升 3%**——**直接拿满 ΔP 25 分**。

**第二笔账：驱动 — 死区时间不能省**

H 桥的"上下管"** 不能同时导通——**否则瞬间短路 + 炸机**。**死区时间（Dead Time）** 在两管切换之间留一段"两管都关断"** 的时间：

```
死区时间 = 上管关断时间 + 下管开通时间 + 安全余量
       = 50ns + 50ns + 100ns = 200 ns
```

**这个式子说的其实是**——**'**MOSFET 关断不是瞬间完成的，需要预留 200ns 缓冲**'**——**否则上下管"重叠导通"** = **"直通"** = **炸机**。

**驱动 IC 选型**：

| 型号 | 通道 | 死区可调 | 价格 | 用途 |
|---|---|---|---|---|
| **IR2104** | 半桥 | 否（固定 540ns）| 6 元 | 入门 |
| **TI UCC27211** | 半桥 | 否 | 12 元 | 中级 |
| **TI UCC21330** | 隔离半桥 | 是 | 35 元 | **国一首选** |
| **Allegro A4915** | 三相 | 是 | 50 元 | 三相专用 |

**'**UCC21330**'** 自带"可编程死区"—— **能设到 200ns 精度** —— **国一队伍的标配**。

**坑**：**新手忘记接 Bootstrap 电容（10nF~100nF）**——**上管驱动失效**——**电路不工作**。**这是 H 桥调试 90% 翻车的原因**。

**第三笔账：电流采样 — 0.05Ω 还是 LEM 传感器**

PFC 必须实时测电流——**采样精度直接决定 PF 控制精度**。

**两种采样方案**：

**方案 A：低值电阻采样（Shunt）**

```
采样电阻 R = 50 mΩ（康铜线绕电阻 1W）
最大压降 = R × I_peak = 0.05 × 2.83 = 141 mV
功耗 = R × I_RMS² = 0.05 × 4 = 0.2 W
```

**这个式子说的其实是**——**'**50mΩ 采样电阻在 2A 电流下压降 141mV，功耗 0.2W**'**——**用差分运放（如 OPA2188）放大到 ADC 量程**。

**优点**：**便宜（5 元）+ 高带宽**。  
**缺点**：**没有电气隔离**——**采样电路和功率电路共地**——**容易引入干扰**。

**方案 B：LEM 霍尔传感器**

```
LEM HXS 20-NP：50A/50A 霍尔传感器，灵敏度 50 mV/A
2A 电流对应输出 100 mV
```

**优点**：**电气隔离 + 抗干扰**。  
**缺点**：**贵（80 元 / 颗）+ 带宽较低（50kHz）**。

**国一选择**：**LEM HXS 20-NP**——**抗干扰强**——**适合实验室环境多干扰场景**。  
**国二**：**0.05Ω + OPA2188**——**便宜实用**——**如果走线 careful 也能用**。

**第四笔账：PCB 布局 — 高频回路最短**

PFC 工作在 50kHz~100kHz 高频——**电流回路的"环路面积"** 直接决定 EMI 噪声**：

```
高频电流环路：MOSFET → 电感 → 二极管 → 母线电容 → MOSFET
环路面积 ≤ 1 cm²（关键参数）
```

**'**环路面积 1cm²**'** 是高频电源 PCB 设计的"金标准"——**面积越小，辐射干扰越小**——**EMI 测试越容易过**。

**布局技巧**：

- **MOSFET 漏极、电感、母线电容紧挨着放**——**走线不超过 2 cm**
- **铺地平面在第二层（双层板）或内层（4 层板）**——**降低回流路径阻抗**
- **电源走线用"星型分布"** —— **避免共阻抗耦合**
- **采样信号走差分对**——**抗共模干扰**

**国一队伍**：**4 层 PCB（信号 / 电源 / 地 / 信号）**——**EMI 优化做到 30dBμV 以下**——**轻松通过 EMI 测试**。  
**国二**：**2 层 PCB**——**EMI 50dBμV 边缘合格**——**比赛时偶尔受外界干扰**。  
**国三**：**手工焊万能板**——**EMI 80dBμV+**——**90% 受干扰**——**控制不稳**。

**第五笔账：母线电容选型**

母线电容承担"两级解耦 + 储能 + 滤波"** 三重任务：

```
所需电容值 = P / (2 × π × f_grid × V_DC × ΔV_DC)
           = 60 / (2 × 3.14 × 50 × 70 × 7)
           = 390 μF
```

**'**ΔV_DC = 7V（10% 母线电压纹波）**'** 是工业级要求——**算出 390μF**——**实际取 470μF**。

**电容种类对比**：

| 类型 | 470μF/100V 价格 | ESR | 寿命 | 适合 |
|---|---|---|---|---|
| **铝电解** | 5 元 | 200 mΩ | 5000 小时 | 入门 |
| **固态电解** | 25 元 | 30 mΩ | 30000 小时 | 国二 |
| **薄膜电容** | 50 元 | 5 mΩ | 100000 小时 | **国一** |

**薄膜电容的损耗**（**ΔP 贡献**）：

```
P_ESR = I² × ESR = 2² × 0.005 = 0.02 W
```

**远低于电解电容的 0.8W**——**ΔP 优化 0.78W = 1.3% 效率提升**——**直接帮 ΔP 拿 25 分**。

**第六笔账：调试节奏 — 先空载后带载**

**新手最大坑**：**直接 30V 输入 + 60W 负载上电** = **保险丝瞬间烧 + MOSFET 炸 + PCB 冒烟**。

**正确节奏**：

1. **空载上电**：**PFC 输入 0V，慢慢升到 5V** —— **看 PWM 波形是否正常**
2. **轻载测试**：**输入 10V，负载 5W** —— **看电流环是否稳定**
3. **半载测试**：**输入 20V，负载 30W** —— **看 PF 控制是否准**
4. **满载测试**：**输入 30V，负载 60W** —— **测全部参数**
5. **长时间老化**：**满载跑 1 小时** —— **测温度、效率漂移**

**国一队伍**：**用调压器慢慢加压**——**每次加压前测温度 + 测电流**——**0 炸机**。  
**国二**：**先 220V 直接上**——**经常炸 1~2 颗 MOSFET**——**多备 5 颗管子**。  
**国三**：**直接 380V 上**——**炸到不可控**——**第二天电路重新焊**——**4 天没了**。
