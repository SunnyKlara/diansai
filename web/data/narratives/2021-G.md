## 想象一个场景

下午四点，新疆昌吉的一片棉花地。**500 亩平地**——往一个方向看过去，地平线被棉花顶起来一片白。

地里站着一位 40 岁的农场主老李。他手里捏着遥控器，看着头顶那架黑色的四旋翼无人机——**翼展 2 米、起飞重量 25 公斤、载药 16 升**——正在以**每秒 5 米**的速度往前推进。无人机肚子下面的喷头**每分钟雾化 5 升农药**——形成一道宽 6 米、距离地面 2 米的"药雾走廊"——**走过去的棉花叶面均匀挂满了一层薄薄的吡虫啉**。

**500 亩地，老李用这一架无人机，1 小时打完**。

**做完这一题，你已经摸到了"植保无人机算法工程师"的入门钥匙**——**这个赛道未来 5 年缺人 1 万**——**起薪 30 万**——**头部岗位（大疆、极飞、亿航）50~80 万**。

## 第一个谜：室内 4m × 5m 怎么定位

**4m × 5m 场地 + 50cm 区块定位精度**——**意味着定位精度 ≤ 25cm**——**这是真正的难点**。

**室外无人机用 GPS-RTK**——**厘米级精度**——**但室内 GPS 信号弱到没法用**——**必须用其他定位手段**。

**4 种主流室内定位方案**：

**方案 A：UWB（超宽带）定位**

**4 个 UWB 锚点 + 1 个 UWB 标签** = **三角定位**——**精度 10cm**：

| 模块 | 价格 | 精度 | 缺点 |
|---|---|---|---|
| **DW1000 UWB 模块** | 80 元 / 个 | 10cm | 需要预先布置 4 个锚点 |
| **DWM1001** | 200 元 / 个 | 10cm | 同上 |
| **海康 UWB** | 500 元 / 个 | 5cm | 价格高 |

**UWB 优点**：**抗光照、抗遮挡、精度稳定**。  
**缺点**：**需要预先布置 4 个锚点**——**电赛场地无法预置**——**只能自己带去赛场布置**。

**国一队伍**：**自带 UWB 模块**——**比赛前 30 分钟布置好**——**精度稳定 10cm**。

**方案 B：光流 + 激光高度计**

**飞控板自带的"光流摄像头"** + **TF-Mini 激光高度计**：

- **光流**：**测水平位置变化**（**类似鼠标光流**）——**精度 ±5cm**
- **激光高度计**：**测垂直高度**（**测量距离**）——**精度 ±2cm**

**优点**：**便宜（200 元）+ 不需要预置基站**。  
**缺点**：**累计漂移**——**飞 30 秒位置漂 50cm**——**不够本题精度**。

**对策**：**结合视觉标记修正漂移**——**每飞一段就看一次"标记"** 校准。

**方案 C：视觉定位（T265 / 双目相机）**

**Intel T265 视觉惯性传感器**——**自带"视觉惯性里程计（VIO）"** 算法——**输出相机的 6 自由度位姿**：

```
T265 输出：
- x, y, z 位置（cm 级精度）
- roll, pitch, yaw 姿态（0.1° 精度）
- 频率 200 Hz
```

**优点**：**精度高（±5cm）+ 无需预置基站 + 即插即用**。  
**缺点**：**单价 1300 元**——**贵**——**且对纹理要求高（白墙效果差）**。

**国一队伍**：**T265 + 飞控融合**——**精度稳定 5cm**——**满足 25cm 要求**——**有大余量**。

**方案 D：激光 SLAM**

**单线激光雷达（YDLIDAR / Slamtec RPLIDAR）扫描墙体** + **SLAM 算法**：

- **YDLIDAR X4**：500 元——**10m 范围、6Hz 扫描**
- **RPLIDAR A1**：800 元——**12m 范围、10Hz 扫描**

**优点**：**精度 ±3cm**——**最高精度**。  
**缺点**：**需要墙体特征明显**——**电赛场地是开放安全网**——**没有墙**——**不适合**。

**国一选择**：**T265 视觉**——**便携 + 高精度**——**适合电赛室内场地**。

**第一笔账：定位精度对成绩的影响**

```
飞行器位置精度 ±10cm
激光笔垂直向下 → 投影精度 = 飞行器精度
区块尺寸 50cm × 50cm
"打中区块中心" 容差 = ±25cm
精度余量 = 25 - 10 = 15cm（60% 余量）
```

**这个式子说的其实是**——**'**T265 精度 10cm 远好于 25cm 要求**'**——**满分稳拿**。

**第二笔账：定位频率**

飞行器以 0.5 m/s 速度移动——**每 100ms 走 5cm**——**定位频率 ≥ 10Hz 才能"实时跟踪"**。

| 方案 | 频率 |
|---|---|
| **UWB** | 10~50 Hz |
| **光流** | 100~200 Hz |
| **T265** | 200 Hz |
| **激光雷达** | 6~10 Hz |

**T265 的 200 Hz 是顶级配置**——**飞行器响应非常快**。

> **小白补课**：什么是 SLAM？
> - **SLAM（Simultaneous Localization And Mapping，同步定位与建图）**：**机器人一边走、一边画地图、一边知道自己在哪**——**听起来矛盾，但是用"图优化"算法可以同时做到**。
> - **应用**：**扫地机器人、自动驾驶、AR/VR、无人机**。
> - **本题不用全 SLAM**——**只用其中的"定位"部分**——**称为 VIO（视觉惯性里程计）**。

## 第二个谜：四旋翼飞控怎么调

**四旋翼飞控的核心 = 姿态环 + 位置环 + 高度环**——**三个独立闭环 + 互相耦合**。

**第一笔账：姿态环（Inner Loop）**

控制输入：**期望姿态角 φ（roll）、θ（pitch）、ψ（yaw）**  
控制输出：**4 个电机的转速差**

```
PID 控制：
torque_x = Kp_x × (φ_ref - φ) + Kd_x × (φ̇_ref - φ̇) + Ki_x × ∫(φ_ref - φ) dt
torque_y = Kp_y × (θ_ref - θ) + Kd_y × (θ̇_ref - θ̇) + Ki_y × ∫(θ_ref - θ) dt
torque_z = Kp_z × (ψ_ref - ψ) + Kd_z × (ψ̇_ref - ψ̇) + Ki_z × ∫(ψ_ref - ψ) dt
```

**这个式子说的其实是**——**'**根据期望姿态和当前姿态的差，算出 3 轴扭矩**'**——**再通过电机分配矩阵转成 4 个电机转速**。

**'**电机分配矩阵**'** 是怎么来的？四旋翼物理：

```
电机 1（前右）：增加 → roll 右、pitch 前、yaw 顺
电机 2（后左）：增加 → roll 左、pitch 后、yaw 顺
电机 3（前左）：增加 → roll 左、pitch 前、yaw 逆
电机 4（后右）：增加 → roll 右、pitch 后、yaw 逆

矩阵表达：
[motor_1]   [+1  +1  -1  +1]   [thrust]
[motor_2] = [-1  -1  -1  +1] × [torque_x]
[motor_3]   [-1  +1  +1  +1]   [torque_y]
[motor_4]   [+1  -1  +1  +1]   [torque_z]
```

**这段矩阵说的其实是**——**'**4 个电机的转速 = 总推力 ± 三轴扭矩**'**——**电机分配矩阵把"想要的扭矩"** 翻译成"每个电机转多快"**。

**姿态环带宽**：**100~200 Hz**——**最快的环**——**响应飞机扰动（风、振动）**。

**第二笔账：位置环（Middle Loop）**

控制输入：**期望位置 (x_ref, y_ref)**  
控制输出：**期望姿态 (φ_ref, θ_ref)**

```
v_x_ref = Kp × (x_ref - x) + Kd × (ẋ_ref - ẋ)
v_y_ref = Kp × (y_ref - y) + Kd × (ẏ_ref - ẏ)

φ_ref = arctan(v_y_ref / g)  // 期望 roll
θ_ref = -arctan(v_x_ref / g) // 期望 pitch
```

**这段代码说的其实是**——**'**位置环把"想去哪里"翻译成"飞机往哪倾斜"**'**——**飞机倾斜 → 推力分量产生水平加速度**。

**位置环带宽**：**1~10 Hz**——**慢于姿态环 10~100 倍**——**两环解耦**。

**第三笔账：高度环（Vertical Loop）**

控制输入：**期望高度 z_ref**  
控制输出：**总推力 thrust**

```
thrust = Kp × (z_ref - z) + Kd × (ż_ref - ż) + Ki × ∫(z_ref - z) dt + g × m
```

**'**+ g × m**'** 是重力前馈——**直接补偿重力**——**让 PID 只需要应对干扰**。

**高度环带宽**：**5~20 Hz**。

**第四笔账：PID 参数怎么调**

四旋翼 PID 调参是"玄学"——**初值 + 经验 + 实验**：

| 参数 | 典型值（500g 四旋翼）| 调参方向 |
|---|---|---|
| **roll/pitch Kp** | 6.0 | 振荡降，不响应升 |
| **roll/pitch Kd** | 0.15 | 高频抖动降，反应迟钝升 |
| **roll/pitch Ki** | 0.05 | 稳态误差降，过冲升 |
| **yaw Kp** | 2.5 | 偏航响应 |
| **height Kp** | 1.5 | 高度跟踪 |
| **position Kp** | 1.0 | 水平位置 |

**调参流程**：

1. **先调姿态环**（**roll → pitch → yaw**）：**让飞机能稳住**
2. **再调位置环**（**xy → z**）：**让飞机能定点悬停**
3. **最后调任务环**（**航线 → 速度 → 高度变化**）：**让飞机能完成任务**

**'**先内环后外环**'** 是控制理论的铁律——**反过来调内环会被外环干扰**——**永远调不出来**。

**国一队伍**：**直接用 PX4 默认参数 + 微调**——**1 天调通**。  
**国二队伍**：**自己从零调**——**3 天才能稳住**。

## 第三个谜：全覆盖航线规划

**'**全覆盖**'** 意味着——**每个绿色区块都要飞到 + 不能漏 + 不能重复**——**这是经典的"覆盖路径规划（CPP, Coverage Path Planning）"** 问题。

**朴素方案：弓字形扫描**

```
路径：从 A（21）开始
    │
    ↓ 行 1：21 → 20 → 19 → 18 → 17
    │
    ← 行 2：12 → 13 → 14 → 15 → 16
    │
    ↓ 行 3：6 → 7 → 8 → 9 → 10
    │
    ← 行 4：5 → 4 → 3 → 2 → 1
```

**优点**：**简单、易实现**——**新手就能写**。  
**缺点**：**不能处理"非播撒区"**——**飞机会飞过灰色区块（白白浪费时间）**。

**进阶方案：BFS / 节点图覆盖**

把整个 28 个区块建模为"图"——**节点 = 区块，边 = 邻居**——**用 BFS 遍历**：

```python
# 简化伪代码
def coverage_path(start_node, green_nodes):
    path = [start_node]
    visited = {start_node}
    queue = [start_node]
    
    while green_nodes - visited:
        # 优先选距离最近的未访问绿色节点
        next_node = find_nearest_unvisited(path[-1], green_nodes - visited)
        # 从当前节点走到 next_node（可能经过非播撒区）
        sub_path = bfs(path[-1], next_node)
        path.extend(sub_path)
        visited.update(sub_path)
    
    return path
```

**这段伪代码说的其实是**——**'**贪心式选最近的未播撒区，BFS 找路径**'**——**适合"分散绿色区块"** 场景。

**国一方案：TSP 路径优化**

把"必须访问的区块"** 看作"旅行商问题（TSP）的城市"** ——**求最短遍历路径**：

```python
from python_tsp import solve_tsp_dynamic_programming

# 距离矩阵
distance_matrix = compute_distances(green_nodes)
# 求最短路径
path, total_distance = solve_tsp_dynamic_programming(distance_matrix)
```

**优点**：**最短路径、最快完成时间**。  
**缺点**：**计算量大（28 个区块的 TSP）**——**赛前预先计算，飞行时直接执行**。

**国一队伍**：**TSP 优化路径**——**比贪心快 15~30%**——**关键时候多得 5 分**。

**第一笔账：弓字形 vs TSP**

| 路径 | 总长度 | 飞行时间（0.3 m/s）|
|---|---|---|
| **弓字形（含灰色）** | 14 m | 47 秒 |
| **贪心 BFS** | 12 m | 40 秒 |
| **TSP 优化** | 10 m | 33 秒 |

**TSP 比弓字形快 30%**——**节省 14 秒**——**直接保证 360 秒内完成**。

## 第四个谜：激光笔精确开关时机

**'**激光笔光点闪烁周期 1~2s**'**——**意味着每个区块要"开 → 关 → 开 → 关 → 开"** 1~3 次**——**对时序的精确度要求很高**。

**坑 1：飞机晃动**

飞机悬停时——**重心晃动 ±5cm**——**激光点跟着抖**——**可能从一个区块"晃到"** 邻居区块——**误判"重复播撒"**。

**对策**：**只在"飞机稳定"时开激光**

```c
bool is_stable() {
    static int stable_count = 0;
    if (fabsf(vx) < 0.05 && fabsf(vy) < 0.05 && fabsf(yaw_rate) < 0.05) {
        stable_count++;
        if (stable_count > 50) {  // 50ms 稳定
            return true;
        }
    } else {
        stable_count = 0;
    }
    return false;
}

// 主循环
if (in_target_block() && is_stable()) {
    if (laser_blink_count < 2) {
        laser_blink();  // 闪一下
        laser_blink_count++;
    } else {
        move_to_next_block();  // 完成此区块
    }
}
```

**这段代码说的其实是**——**'**只在'**位置准 + 速度小**' 时开激光**'**——**避免误判**。

**坑 2：区块边界识别**

飞机不知道"自己在哪个区块"——**只知道 (x, y) 坐标**——**需要把坐标映射到区块编号**：

```c
int get_block_id(float x, float y) {
    int col = (int)(x / 50);  // 0~7（4m/50cm = 8 列）
    int row = (int)(y / 50);  // 0~9（5m/50cm = 10 行）
    return row * 8 + col + 1;
}
```

**这段代码说的其实是**——**'**把 (x, y) 坐标除以 50cm，得到行列号，再算出区块编号**'**。

**坑 3：闪烁次数控制**

题目要求**1~3 次**闪烁——**新手会闪 2 次（保险）**——**但 2 次 × 14 个绿区块 = 28 次**——**每次 1.5 秒** = **42 秒**——**占用大量时间**。

**对策**：**闪 1 次（紧贴下限）+ 多帧确认**

```c
// 每个区块只闪 1 次（500ms 长闪）
// 同时确认稳定 → 评委判定"成功"

delay(500);
laser_off();
move_to_next();
```

**1 次 × 14 个区块 = 14 次 × 0.5 秒 = 7 秒**——**省 35 秒**——**关键时刻多 35 秒可用**。

**国一方案**：**激光闪烁与飞行同步**——**飞过区块中心时闪 1 次**——**最高效**。

**法律风险**——**起飞重量 < 250g 免实名 / 250g~7kg 需实名 + 250m 以下飞行**——**电赛飞机 < 1kg 在室内 = 合规**。

**说明 (2.5)：'**起飞可手动一键启动，起飞后整个飞行过程中不得人为干预**'**

**全自动飞行**——**和小车题一样的"一键启动"** —— **任何人为干预 = 失败**。

**说明 (3.4)：'**触地后 5 秒内不能自行恢复飞行视为失败**'**

**炸鸡保护**——**飞机轻微触地后还能自动起飞继续 → 不算失败**——**但 5 秒不能自动起飞 = 失败**。

**对策**：**实现"触地检测 + 自动恢复"** —— **加分项**。

**说明 (3.5)：'**全程不能在 360 秒内完成的不记录成绩**'**

**360 秒是硬上限**——**超时 = 整项 0 分**——**TSP 路径优化是关键**。
