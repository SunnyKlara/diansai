## 怎么用（别照搬）

**先读我们自己的借鉴分析**：[`workbench/天猛星主板平台/对标分析_已收口/车题上层控制栈_借鉴2024H实战.md`](../../../../workbench/天猛星主板平台/对标分析_已收口/车题上层控制栈_借鉴2024H实战.md) —— 那里写了我们缺哪几层、每层该抄什么思路、以及**不该抄什么**。

硬件差异（决定了不能直接编译进我们的工程）：

| | 他们 | 我们 |
|---|---|---|
| 电机驱动 | TB6612 | 板载 DRV8231 ×2（+电磁槽） |
| 灰度 | 74HC4051 八通道 MUX + 单 ADC | **没有**（清单里有光电，方案待定） |
| IMU | ICM-45686（I2C） | ICM42688（**SPI1，与 LCD 共享**） |
| 屏 | ST7735S | 板载 GC9A01 |
| 编码器解码 | 左轮硬件 QEI + 右轮 GPIO 边沿中断 | **两路软件定时采样 4x 正交解码**（我们这样是因为电机 EMI 把边沿中断打成中断风暴，见坑库——这点我们的做法更抗扰，别倒过来学） |
| 工程/构建 | CCS Theia 工程 + `tools/build.ps1` | GCC + `gcc/makefile` + `mingw32-make` |

引脚一律以我们自己的 `工程事实SSOT.md §B` 为准，**不要用他们 `docs/hardware_*.md` 里的引脚**。
