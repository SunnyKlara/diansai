**什么是融合**
是的，就是在循迹过程中加入陀螺仪辅助，但三种传感器各管一件事：

- 灰度：黑线在车身左边还是右边，负责“不离开轨迹”。
- 陀螺仪：车身当前转得多快、累计转了多少度。
- 编码器：左右轮实际速度和行驶距离。

不能直接把三者数值相加，因为它们测量的是不同物理量。

**现有控制**
当前 `followarc` 大致是：

```text
灰度位置误差
    ↓
PD + 固定弯道 bias
    ↓
左右轮目标速度
    ↓
编码器速度 PI
    ↓
电机
```

代码中的核心相当于：

```text
desired_turn = curve_bias + Kp * line_error + Kd * line_derivative
```

另外还用左右编码器速度差做了转动阻尼。但编码器只能通过“左右轮差速”推测车身旋转，轮胎打滑、轮径误差都会影响它。

**加入陀螺仪**
比较合理的是级联控制：

```text
灰度误差 ──> 期望转弯速度
                 ↓
          与陀螺仪 Z 轴角速度比较
                 ↓
          修正左右轮差速
                 ↓
            轮速度 PI
```

可写成概念公式：

```text
期望角速度 = 弯道前馈 + 灰度位置修正
角速度误差 = 期望角速度 - 陀螺仪实际角速度
最终差速   = 灰度控制输出 + Krate * 角速度误差
```

例如车应该以 `+23°/s` 左转，但陀螺仪只测到 `+17°/s`，控制器就稍微增大右轮速度、减小左轮速度。若车转得太猛，则反向压住。这会直接抑制你之前看到的“偏了、猛地拉回、再走直线”的离散摆动。

**Yaw 角的用途**
角速度负责稳定转弯过程，累计 `yaw` 更适合管理整段路径：

1. 进入半圆弧时执行 `yaw zero`。
2. 左半圆目标设为约 `+180°`，右半圆设为约 `-180°`。
3. 循迹过程中灰度仍是主控制，yaw 只做较弱的方向约束。
4. 离开黑线时检查是否确实接近 180°。
5. 进入没有黑线的直线后，锁定该航向，用 yaw 角闭环保持直行。
6. 编码器负责判断直线距离是否走够。

直线无黑线时的控制可以是：

```text
航向误差 = 目标 yaw - 当前 yaw
差速修正 = Kp_heading * 航向误差 - Kd_heading * Z轴角速度
```

这正好解决“虽然跑完圆弧，但出弯车头没有对准下一段”的问题。

**推荐实施顺序**
1. 先只记录一次完整半圆的 `yaw`、Z 轴角速度、灰度误差和左右轮速度。
2. 测出当前 `followarc 12 -2` 的平均角速度和最终角度。
3. 加很弱的陀螺仪角速度阻尼，暂时不改原来的灰度 PD。
4. 对比摆动幅度、最终 yaw 和出弯朝向。
5. 稳定后再加入“半圆目标 180°”和无黑线直线航向保持。

这种做法风险最低：灰度永远负责贴线，陀螺仪负责让转动更连续，yaw 负责保证最终朝向。

## 269. `2026-07-11 07:42:42`

是两层串级闭环，不是单纯让编码器速度相同。

```text
IMU 航向 PD 外环
        ↓ 产生左右轮差速目标
编码器轮速 PI 内环
        ↓
      电机 PWM
```

具体周期：

- 系统基础 tick：`1 ms`
- ICM-45686 采样和 yaw 积分：`5 ms`，即 200 Hz
- 航向 PD：`10 ms`，即 100 Hz
- 编码器测速窗口：`10 ms`
- 左右轮速度 PI：`10 ms`
- 电机 PWM 载波：`10 kHz`

直线时，IMU 外环使用：

```text
航向误差 = 目标 yaw - 当前 yaw
差速修正 = 航向误差 P项 + Z轴角速度 D项
```

它没有积分项，本质是航向 PD。当前限制最大修正为 `±3.50 count/10ms`。

编码器内环分别控制左右轮：

```text
轮速误差 = 目标计数 - 10ms内编码器计数
PWM = 前馈 + P + I
```

当前轮速参数：

```text
Kp = 3.00
Ki = 0.10 / 10ms
前馈 = 8.50 PWM/(count/10ms)
```

A→C 基础目标速度为：

```text
12 count/10ms
```

启动时以每个 10 ms 增加 `0.25 count/10ms` 的速度软启动，避免左右电机启动特性不同导致突然偏转。

之所以不用 1 ms 编码器速度 PID，是因为 1 ms 内编码器计数通常只有 0、1 或少量脉冲，量化噪声非常大。10 ms 测速窗口在响应速度和计数分辨率之间更合适。1 ms 定时器只是调度基准。
