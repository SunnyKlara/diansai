# 控制与智能车方向专用物资清单

> **主控/驱动/视觉/通信已升级到 2026 实物套件**（天猛星 MSPM0G3507 + K230 + ICM42688 + DRV8231 + ESP-01S + 自制电源板）。下表相应行已更新；集成/接线/打板见 `workbench/天猛星主板平台/`，全套件见 `通用物资清单.md` 顶部"实物套件"块。
