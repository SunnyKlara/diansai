# 外部参考仓库镜像 · 总索引（vendor_ref）

> **这个目录是什么**：30 个外部开源仓库的本地浅克隆，**按用途编排**，为的是**赛场没网也能查**。
> 评估分析在 [`../通用能力/TI_MSPM0开发/MSPM0电赛开源项目清单_2026.md`](../通用能力/TI_MSPM0开发/MSPM0电赛开源项目清单_2026.md)；**本文是"东西在哪、什么时候翻它"的导航**。
>
> **入库规则**：只有 `00_INDEX.md` + `_refresh.ps1` + 四个桶的 `README.md` 进 git，**1.38 GB 第三方代码本体全部 `.gitignore`**。
> 合规不是洁癖 —— 下表 22 个仓库**没有 LICENSE 文件**，我们仓库公开，无权替他们再分发。本地留副本读思路是合规的。
>
> **重建镜像**（换机器 / 清过盘 / 队友要同一份）：
> ```powershell
> cd library/vendor_ref
> .\_refresh.ps1                 # 缺的克隆，已有的更新
> .\_refresh.ps1 -SkipExisting   # 只补缺的（上次部分失败后用这个）
> .\_refresh.ps1 -Only other/    # 只处理某个桶
> ```
>
> **诚实边界**：`commit` / `日期` / `许可` / `体积` 是**本机实测**（`git rev-parse` + 读 LICENSE 首行 + 递归统计）。
> 但 **30 个仓库一个都没编译、没上板、没复现任何指标** —— 能力声明一律是作者自述。**别把任何一条当"已验证"往我们文档里抄。**

## 5. 踩过的坑（都已在 `_refresh.ps1` 里做成机制）

1. **PS 5.1 把无 BOM 的 UTF-8 脚本当 GBK 读** → 脚本里写中文注释会把解析器炸掉（第一版就这么死的）。**`_refresh.ps1` 永久保持纯 ASCII**，中文说明放本文与各桶 README。
2. **一口气 30 个 clone 会大批失败**：首轮 19 成 11 败，而失败的 URL 紧接着 `git ls-remote` **全部可达** ⇒ **瞬时网络重置，不是仓库不存在**。已加 3 次重试 + 退避。**别看一次失败就下"仓库没了"的结论。**
3. **一个卡住的仓库会堵死整个队列**：`zuoliangyu/NUEDC_TOPIC` 在第 3 次重试上挂住（不报错、纯等），后面 15 个全排不上。已设 `GIT_HTTP_LOW_SPEED_LIMIT=1000` / `GIT_HTTP_LOW_SPEED_TIME=30`，**低速 30 秒自己中断**而不是无限等。
4. **许可列不能信别人的元数据**：清单文档写 ZLC 库"无 LICENSE"，实测**它是 GPL-3.0**（传染性许可，性质完全不同）。**判"能不能抄"就 clone 下来读 LICENSE 首行。**
5. **过滤参数匹配到 0 项时别覆盖既有产物**：跑了一次 `-Only zzz_none` 做语法自检，脚本照流程把 30 行结果 CSV **覆盖成空**。已加 `if ($results.Count -gt 0)` 保护。
6. **路径预算是硬约束**：`car/periph_ex` 最深文件 254 字符 / MAX_PATH 260。第一版按 `t1_/t2_` 分组时它是 259（只剩 1 格），重排成短桶名后反而降到 254。`_refresh.ps1` 跑完自动报这个数、≥250 打 WARN。
