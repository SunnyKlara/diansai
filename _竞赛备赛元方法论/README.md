# 竞赛备赛元方法论（Meta Playbook）

> 把"电赛备赛仓库"这套打法抽成竞赛无关的模板，下一次开新比赛仓库时复制本目录即可。

## 这套方法论解决什么

任何"赛前长期训练 + 赛中短时高压交付"的竞赛都共享同一类痛点：

- 资料散在 PDF / 群文件 / 学长硬盘，开赛找不到
- 队员各自发力，重复造轮子，到赛场才发现没对齐
- 平时刷题没结构，看了等于没看
- AI 协作时反复来回确认，效率低于手搓

本方法论用**仓库结构 + 文档契约 + AI 自主执行铁律**三件套统一上述问题。

## 怎么用（30 秒上手）

1. `cp -r _竞赛备赛元方法论 <新比赛仓库>/`
2. 选一个适配文件（03/04/05）作为骨架
3. 把 `01_steering模板.md` 里的占位符替换成你这个比赛的关键词，存到 `.kiro/steering/<比赛名>规范.md`
4. 跑 `02_目录结构模板.md` 里的脚本生成空骨架
5. 让 AI 按 steering 自主刷题，你只验收成果
