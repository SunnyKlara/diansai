# 适配 · 全国大学生智能车竞赛

> 卓大大智能车 / 恩智浦智能车系列。从电赛仓库迁移过来的差异点和补充约定。

---

## 1. 与电赛的核心差异

| 维度 | 电赛 | 智能车 |
|---|---|---|
| 周期 | 4 天 3 夜 | 半年（3 月报名 → 8 月决赛） |
| 题目 | 公布后再做 | 赛题提前公布，全程优化 |
| 主控 | 多种（STM32/MSPM0/...） | 限定（RT1064/CH32/MCX 等） |
| 关键指标 | 误差、精度、响应 | **单圈圈速 + 通过率** |
| 报告 | 设计报告（4 天写完） | 技术报告（半年迭代版） |
| 实物 | 原型板 | 整车（车模 + 电路 + 算法） |
| 协作 | 2~3 人 | 通常 3 人（电控/视觉/机械） |

## 4. 量化指标体系（替换电赛的"误差/精度"）

智能车评分 = **完赛圈数 × 单圈得分 / 总用时**，所以核心指标只有两个：

| 指标 | 目标 | 测量方法 |
|---|---|---|
| 单圈圈速 | < 25s（参考省一水平） | 秒表 + 摄像头打点，跑 5 圈取平均 |
| 通过率 | > 90% | 连续 10 圈不出赛道 |
| 元素识别准确率 | > 95% | 离线视频回放 + 标注 |
| 速度档位切换平稳性 | 加速度 < 5m/s² | IMU 录制 + matlab 分析 |
| 系统启动时间 | < 3s | 上电到可下场 |

## 5. AI 协作的智能车特化指令

把下面这段加到 steering 末尾：

```markdown
## 智能车特化规则

- 摄像头组所有图像处理算法都要先在 PC 上跑通（用 OpenCV + 录制赛道视频），**再移植到主控**
- 电磁组阈值参数全部进 `config.h`，禁止散落代码各处
- 圈速实测必须有视频证据存到 `04_调试记录/圈速视频/<日期>.mp4`（git lfs 或外链）
- 每次大改算法前先打 git tag `v<赛季>-<次数>`，方便回滚
```
