# 适配 · ICPC / CCPC / 蓝桥 / 算法竞赛

> 算法比赛跟硬件比赛差异最大，但"以题为单元 + 模板沉淀 + 复盘"的内核完全一致。
> 本文是把电赛六件套压缩到算法场景的最小可用版本。

---

## 1. 与电赛的核心差异

| 维度 | 电赛 | ICPC |
|---|---|---|
| 题量 | 1 题 / 4 天 | 12 题 / 5 小时 |
| 输出物 | 实物 + 报告 | 通过的代码 |
| 评测 | 仪器 + 人工 | OJ 自动判 |
| 关键能力 | 工程整合 | 题感 + 模板熟练度 |
| 队伍 | 2~3 人 | 3 人 1 机 |

差异虽然大，但**"赛后题解 + 个人模板库 + 训练计划"**是上岸的关键，恰好可以套本框架。

## 3. 一场比赛的"必备六件套"（精简版）

```
2024_ICPC济南/
├── 00_题目原件/             # 13 道题原题
│   ├── A.md ~ M.md
├── 00_赛后复盘.md           # 替代"00_深度审题"，含：实际开题顺序、卡题点、应该开但没开的题
├── 01_代码/
│   ├── A_solution.cpp       # 每题独立文件
│   ├── B_solution.cpp
│   └── ...
├── 03_题解/
│   ├── A_题解.md ~ M_题解.md
│   └── 整场题解汇总.md
└── 04_经验总结.md           # 这场学到的东西，去重后归并到模板库
```

省掉了 `02_硬件`（不需要）和 `04_调试记录/调试检查清单`（OJ 不需要）。

## 4. 单题题解模板（`A_题解.md`）

```markdown

## 数据范围
- n ≤ 10^5
- 1 ≤ a_i ≤ 10^9
- 时限 1s / 空间 256MB

## 思路
1. 关键观察：xxx
2. 转化为：xxx
3. 用 xxx 算法解决

## 复杂度
- 时间：O(n log n)
- 空间：O(n)

## 关键代码
​```cpp
// 核心 30 行
​```

## 踩坑
- WA 1 次：忘记处理 a_i = 0 的边界
- TLE 1 次：cin 没关 sync_with_stdio

## 同类题
- CF Round 900 B
- AtCoder ABC 320 D
```

## 5. 个人模板库的组织（核心资产）

```
C_通用能力/模板库/
├── README.md              # 索引 + 每个模板的复杂度和适用场景
├── 数据结构/
│   ├── DSU.cpp            # 并查集（含按秩合并 + 路径压缩）
│   ├── SegTree_Lazy.cpp   # 线段树带懒标记
│   ├── Treap.cpp
│   └── ...
├── 图论/
│   ├── Dijkstra.cpp
│   ├── Tarjan_SCC.cpp
│   └── ...
├── 数学/
│   ├── 快速幂.cpp
│   ├── 中国剩余定理.cpp
│   └── ...
├── 字符串/
│   ├── KMP.cpp
│   ├── SA.cpp
│   └── ...
└── 几何/
    └── 二维几何全家桶.cpp
```

**铁律**：

- 每个模板**赛前打印一次**，赛中可纸质参考（很多比赛允许带纸质模板）
- 每个模板必须包含：复杂度、调用示例、已通过的题号（≥3 题）
- 用过一次没通过的模板必须立即修复或废弃，不留半成品

## 6. 量化指标（替代电赛"误差/精度"）

| 指标 | 目标 | 测量方法 |
|---|---|---|
| 中位数 AC 数 | ≥ 6/12 | 训练赛取近 10 场 |
| 平均开题速度（前 3 题） | < 60 min | 赛后秒表回顾 |
| 模板出错率 | < 5% | 复盘时统计 |
| 罚时占总分比 | < 10% | 直接 OJ 数据 |
| 卡题超 30 min 切题率 | > 70% | 复盘统计 |

## 7. AI 协作的算法比赛特化指令

加到 steering：

```markdown
## ICPC 特化规则

- 每场赛后 24 小时内必须补完 12 道题题解（不会的看官方/其他队解）
- 题解写完后，AI 自动从中抽取通用模板补到 `C_通用能力/模板库/`，并去重
- 训练赛代码默认放 `B_比赛实战/<场次>/01_代码/`，不污染日常练习
- 涉及具体题目原文时**只放截图或官方链接**，不直接复制题面（避免版权问题）
- AI 不允许在比赛中实时辅助（违反规则），只用于赛后训练和总结
```

## 8. 复用现有资产

| 来自电赛仓库 | ICPC 用法 |
|---|---|
| 必备六件套结构 | 简化为四件套（去掉硬件、调试清单） |
| AI 自主执行铁律 | 完全适用（赛后批量补题解） |
| 进度看板 | 改成"训练赛积分榜"+"模板库覆盖度" |
| `算法层PC验证方法论` | 不直接用，但启发"对拍 + 数据生成器"思路 |
| commit 规范 | 完全适用 |
