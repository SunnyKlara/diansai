# 开源项目参考与简化控制方案（悬浮球定高）

> 目的：你反馈"闭门造车一直搞不出来、也调不出来"。本文档调研了 3 个**同类**开源项目，
> 用它们的**可工作实现**反推我们当前控制器卡在哪，并给出一套**砍掉冗余、照搬已验证结构**的简化方案。
> 核心结论先说：**问题不是 PID 算不出来，是我们把控制器做成了 8 个互相打架的旋钮，没法整定。**

## 二、David 的可工作实现（同款硬件，逐行拆解）

> 来源文件：`LevitatorPID-FixedSetpoint.ino`（MIT 许可）。下面是**改写后的等价伪代码 + 关键参数**，非逐字复制。

**硬件**：ESP32 + VL53L0X(连续模式) + 风机(PWM 100Hz, 8bit)。距离单位 cm。

**控制器结构（全部）**：
```
误差   e        = distance - set_point          // 注意符号：球离传感器越远(球越低) e 越大 -> 加大风力
积分   I        = I_prev + (dt/2)*(e + e_prev)   // 梯形积分(比矩形更准)
微分   D        = (e - e_prev)/dt                // 误差微分(他没滤波,因为 20Hz+增益不大,够用)
pwm_control     = Kp*e + Ki*I + Kd*D            // 一句话,就这
pwm             = constrain(pwm_control, 0,1023) // 限幅
输出            = map(pwm,0,1023,0,255)          // 映射到执行器量程
```

**他的整定值**：`Kp=170, Ki=15, Kd=17`（对 cm 误差、输出 0~1023 标度）。
**采样**：`delay(50)` → 20Hz（受 VL53L0X 限制，和我们 50Hz 同量级）。

**他做对、而我们漏掉的 3 件关键小事**：
1. **控制器启动前先让风机空转 4 秒**（`delay(4000)`）。→ 直接解决了我们反复踩的"四线风扇冷启动死区 + 静摩擦 + 3s 惯性"。我们一直想用 `PWM_RUN_MIN` 怠速地板硬扛，David 直接"先转起来再闭环"，更干净。
2. **测量野值过滤极简且只有两条**：① 距离 > 量程上限当垃圾丢弃，用上一帧值顶替；② 相邻跳变 > 20cm 丢弃。**没有 median、没有 EMA、没有 jump-reject 计数器**。
3. **整个控制律就一行**，没有前馈、没有串级、没有 boost 两段式、没有 slew 限速、没有 D 钳位、没有软目标 ramp。

## 三、为什么我们"调不出来"——根因诊断

把我们 `Control_Update()` 和 David 的实现并排看，问题一目了然：**我们有 8 个互相耦合的旋钮，David 只有 3 个。**

| 旋钮 | 我们当前 | David | 评价 |
|---|---|---|---|
| Kp / Ki / Kd | ✅ | ✅ | 必需，保留 |
| 悬停前馈 u_hover | ✅ `uh` | ❌(用大Ki自由积分代替) | **保留！见下方"重要更正"**：对不稳定直筒，前馈到工作点是正确做法；David 没用它是因为他的 Ki 自由无限幅积分能长出悬停量，我们积分限幅小则不行。 |
| 软目标 ramp (`r`) | ✅ | ❌ | 锦上添花，调参阶段先关 |
| 球速 EMA 系数 (`f` alpha=0.4) | ✅ | ❌(裸微分) | 多一层相位滞后，调 Kd 时看不清因果，调参先关 |
| PWM 斜率限速 (`l` slew=800) | ✅ | ❌ | 会把 D 项的快速制动也削掉 → 越界后拉不回，调参先关 |
| D 项钳位 (`c` dmax=1500) | ✅ | ❌ | 超声波时代防假跳变用的；换激光后干净反馈，调参先关 |
| 怠速地板/天花板 (`n`/`x`) | ✅ | ❌ | 保留地板(配合预热)；天花板防窜顶 |
| boost 两段式 | 残留(仅显示) | ❌ | bang-bang 天生极限环，已退役只剩显示，无害 |
| **风机预热** | ❌→**已加** | ✅(4s) | **关键缺失，已补**：闭环前先空转越过冷启动死区 |

> ### ⚠ 重要更正（仔细读了代码后修订前一版结论）
> 前一版本文说"删掉 u_hover"。**仔细核对代码后这是错的，会把球压在管底。** 原因：
> - 我们的积分权限 = `Ki × PID_INTEGRAL_LIMIT`（如 2×200=400 PWM），悬停需要 ~3600 PWM。
> - 删了 u_hover，P+I+D **永远到不了悬停 PWM** → 球趴底（正是 06-10 日志"P≈380 托不起球"的现象）。
> - David 能不用前馈，是因为他的积分**自由无限幅winding**(Ki=15)，能自己积到悬停量；我们积分限幅小，不行。
>
> **正确结论**：对悬浮球这种不稳定平衡对象，**前馈到工作点(u_hover)是正确工程做法，应保留**。
> 我们控制律 `u = u_hover + Kp*e - Kd*v + Ki*I`（条件抗饱和 + 微分作用在测量）本身已是教科书级正确，甚至比 David 严谨。
>
> **真正的根因不是 u_hover，而是**：① 缺风机预热（冷启动死区把人骗成"PID 不稳"）；
> ② 调参时 5 个补丁旋钮(ramp/EMA/slew/Dclamp 等)同时开着，分不清因果；③ 缺"先 D 后 P 最后 I"的整定纪律。
> **闭门造车的本质 = 在多维耦合空间手动搜参 + 冷启动干扰 + 没有定量纪律。** 修法：补预热 + 调参时关补丁 + 按序整定。

## 四、参考设计：保留正确内核 + 砍掉调参干扰 + 补预热

### 4.1 控制律（保持现有，已是正确结构）

```
e   = set_point - height                 // 球低于目标 e>0 加力
P   = Kp * e
I   = I + Ki * e * dt                     // 条件抗饱和：仅当总输出未顶限时才累加
D   = -Kd * velocity                      // 微分作用在测量(球速)，避免目标突变微分踢
u   = u_hover + P + I + D                 // 前馈到工作点 + PID 修正(不稳定对象的正解)
u   = constrain(u, U_MIN, U_MAX)          // U_MIN=怠速地板(风机不停转), U_MAX=防窜顶
```

**这套控制律本身不用改**——它已包含前馈、条件抗饱和、微分作用在测量，是教科书级写法。
要动的只有两处：**①补风机预热（已做）；②调参时把干扰旋钮关掉（串口操作，见 §5）。**

### 4.2 已实施的代码改动（本次）
1. **风机预热**（`config.h: FAN_PREHEAT_MS=3000` + `main.c` 使能上升沿状态机）：
   闭环从停机使能时，风机先在 `g_pwm_min` 空转 3s 越过冷启动死区/静摩擦/转速爬升，再投入闭环并 `PID_Reset()` 以当前球位为基准干净接管。手动模式(风机已转)免预热。心跳新增 `PRE:1/0` 指示是否预热中。
2. **u_hover 保留**（更正前一版"删除"的错误结论，理由见 §3 更正框）。

### 4.3 三个旋钮的物理含义（背下来，调参时对症）
- **Kp（刚度）**：球偏离目标多远就用多大力拉回。太小→拉不回/软塌塌；太大→过冲、来回荡。
- **Kd（阻尼）**：盯球速，球冲得快就提前刹车。**直筒悬浮是不稳定对象，Kd 是能不能稳的关键**，先调它。太小→发散冲顶落底；太大→高频抖。
- **Ki（消静差）**：慢慢补掉"球总停在目标下方/上方"的固定偏差。太大→慢振荡/积分过冲。
- **u_hover（前馈）**：球速、误差都为 0 时维持悬停的 PWM。先用 CALIB 手动扫出来设好，PID 只需修正残差。

## 五、整定流程（照搬 David 顺序，用串口在线调，禁止靠眼睛）

> 前提：①传感器支架已固定刚性（调试日志强调过，否则零点漂）；②几何标定好，球在底 H≈0、管口 H≈43；③`serial_tx.ps1` 能发命令收数据。

0. **预热验证**：`g` 启动，确认风机先空转 ~3s（心跳 `PRE:1`）再进闭环（`PRE:0`），不再有冷启动顿挫。
1. **设好前馈 + 关掉补丁**：先用 CALIB 手动扫出悬停 PWM 设 `uh<该值>`（球大致不快升不快降的"刀刃点"）；再 `f0`(裸微分) `l9600`(关 slew) `c9600`(关 D 钳) `r0`(关 ramp) `ki0`(先不积分)。此时 `u = u_hover + Kp*e - Kd*v`。
2. **先调 Kd（找阻尼）**：`kp0 ki0`，`kd` 从小往大加。现象：球应从"发散冲顶/落底"逐渐变成"晃但不发散"。调到肉眼球速被明显压住、不再撞顶撞底。
3. **再调 Kp（找刚度）**：逐步加 `kp`，球开始能回到目标附近。加到"刚开始来回过冲"就退一档。此时应已能稳在目标 ±2cm（基本分到手）。
4. **加弱 Ki（消静差）**：`ki` 给小值。若 u_hover 标得准残差很小，Ki 只需轻补；球总停在目标下方就加 Ki 顶上去。**Ki 过大会慢振荡**——出现慢摆就减半，必要时抬 `PID_INTEGRAL_LIMIT`。
5. **按需微调滤波**：若末端高频抖，`f` 加一点点 EMA（0.2~0.4）压抖；若加 EMA 后又发散，说明相位滞后过大，退回去靠 Kd。
6. **达标后**：阶跃测试 `t10`→`t20` 看调节时间(<5s)、超调；需要时开 `r`(ramp 8~12cm/s) 平滑大阶跃。记录 10/15/20cm 三点参数回填 `config.h`。

**看板字段**：串口 `D`=球速(判阻尼是否够)、`E`=误差(判静差)、`P`=PWM(判饱和/到地板天花板)、`PRE`=是否预热中。

### 参数比例参考（David 的比值，绝对值因执行器不同需自标）
- David：`Kp : Ki : Kd = 170 : 15 : 17 ≈ 10 : 0.9 : 1`，即 **Kp 与 Kd 同量级、Ki 约为 Kp 的 1/10**。
- 我们 06-11 实测可稳的 `kp20 kd45`（D 比 P 重）也合理——直筒不稳定对象偏爱大阻尼。两种比例都可，**关键是先 D 后 P 最后 I 的顺序**，别同时拧。
- 绝对值不要照抄 David（他是 brushed 风机 8bit/100Hz，我们是四线 25kHz/9600 标度，执行器增益完全不同），**只抄结构、比例和顺序**。

## 六、可选进阶：串级（内环转速）——但不是必需

调试日志已搭好 tach 测速(TIM3_CH1)。串级的价值：**用转速内环线性化风机非线性 + 吸收冷启动滞后**，外环高度只管给定转速。
- Khaled 的项目证明：先 sysID 拿到传递函数，再设计 PID，是报告"理论分析"拿分的标准做法。
- **但 David 证明：单环 + 4s 预热就能稳定任意定高。** 所以串级当"发挥部分/鲁棒性加分项"，**不要在拿到基本分之前上**，否则又回到多旋钮打架。

**优先级**：先用 §4/§5 的单环把基本分(定高±2cm)和进阶(±1cm)拿到手 → 再考虑串级冲发挥分。
