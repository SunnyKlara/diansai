# ADRC 自抗扰控制方案与实施（冲 ±1cm + 抗干扰）

> 目标：在已达标的 ±2cm 单环 PID 基础上，用**线性自抗扰控制(LADRC)**冲进阶 ±1cm 与发挥部分抗干扰。
> 本文是写代码前的设计冻结：数学结构、参数取值、固件改法、协作流程、整定 SOP、风险回退。
> 关联：模型来自 `调试日志.md`(sysid 实测)；工具 `sysid.ps1/pidcalc.ps1/tune_step.ps1`。

---

## 0. 一句话方案

把"悬停点漂移 + 对象增益随高度变 + 外部扰动(拨球/吹气)"统一当作**一个总扰动 f**，用**扩展状态观测器(ESO)实时估计 f 并直接抵消**。这样 ±1cm(抗内部漂移)和抗干扰(抗外部扰动)是**同一套机制一次解决**。

---

## 1. 为什么是 ADRC（对着我们的残差选的）

实测残差 = 0.13cm/s 慢漂 + ~2s 振荡，外环增益治不了。本质是**缓变总扰动**，不是增益不对。
- 普通 PID 积分能消静差，但跟不上"持续缓变的扰动"(积分慢、大了又振荡)。
- ADRC 的 ESO 把 f 当一个**额外状态实时估出来**，控制律里**直接减掉**，不靠积分硬扛。
- 外部扰动(评委拨球)进来 → f 突变 → ESO 几拍内估到 → 抵消 → 快速恢复。**这就是发挥分的抗扰能力。**

**我们恰好具备 ADRC 的前提**：对象阶数已知(2)、b0 已测(0.333)、传感器快而干净(42Hz/0.26cm)、有回退基线。

---

## 2. 数学结构（2 阶 LADRC，离散实现）

被控对象近似： `y'' = b0 * u + f`
- `y` = 球高(cm)，`u` = 控制量(PWM 等效)，`b0` = 输入增益(实测 g≈0.333 cm/s²/计数)，`f` = 总扰动(重力配平残差 + 悬停漂 + g(h) 变化 + 外部扰动 + 未建模项)。

### 2.1 扩展状态观测器 ESO（3 阶）
状态：`z1≈y`(位置)、`z2≈y'`(速度)、`z3≈f`(总扰动)。
```
e  = z1 - y
z1 += dt * (z2 - b1*e)
z2 += dt * (z3 + b0*u - b2*e)
z3 += dt * (-b3*e)
```
观测器增益(把 ESO 三极点都配到 -ωo)：
```
b1 = 3*ωo ,  b2 = 3*ωo² ,  b3 = ωo³
```
`ωo` = 观测器带宽，**唯一的核心调节旋钮**：越大估扰动越快，但越放大测量噪声。

### 2.2 控制律
```
u0 = Kp*(r - z1) - Kd*z2          // 基于估计状态的 PD
u  = u_hover + (u0 - z3) / b0     // 减掉估计的总扰动 z3
```
- `Kp = ωc²`、`Kd = 2*ωc`(把闭环双极点配到 -ωc)。`ωc` = 控制器带宽。
- 保留 `u_hover` 作偏置 → ESO 只需估"漂移量"(z3 动态范围小、更准)，而非整个悬停推力。
- `r` 用软目标(对目标做跟踪微分/限速)避免阶跃冲击；跟踪微分器可选(先用现有 ramp 思路)。

### 2.3 离散与抗饱和
- `dt` 用事件驱动真实间隔(同现 PID)。
- 输出夹 `[g_pwm_min, g_pwm_max]`；饱和时**冻结 z3 积分**(防 ESO 把饱和误差当扰动越积越偏)。

## 3. 参数取值（算出来，不是猜）

| 参数 | 初值 | 来源/公式 | 备注 |
|---|---|---|---|
| `b0` | 0.333 | sysid 实测 g | ADRC 对其不敏感(±50%可) |
| `ωc` | 3.0 | 4/ts, ts≈1.3s；对齐极点配置 wn2.67 | 控制器带宽 |
| `ωo` | 12 | 3~5×ωc | 观测器带宽，**主调旋钮** |
| `Kp` | =ωc²≈9 | ωc² | 自动随 ωc |
| `Kd` | =2ωc≈6 | 2ωc | 自动随 ωc |
| `u_hover` | 3420 | 实测 | 偏置 |

约束：`ωo` 远低于采样 Nyquist(42Hz→~131 rad/s)，12 很安全；噪声大就降 ωo。

---

## 4. 要不要新做实验？（协作的关键差别）

**基本不用重型 sysID** —— ADRC 只要 b0 和阶数，都已有。新增工作只有：
1. **(可选)复测一次 b0**：再跑一次干净阶跃用 pidcalc 反算，确认 g≈0.333(差也没关系，ESO 吸收)。
2. **上板看 `f̂`(=z3) 遥测**：这是**唯一新增的关键诊断**。看 ESO 估的扰动是否跟得上实际漂移——跟得上=这条路通；跟不上=升 ωo 或这是噪声天花板。**几分钟就能证伪。**
3. 之后只在线调 `ωo`(先)和 `ωc`(后)两个旋钮。

## 5. 固件落地（改法 + 回退）

- **新增 `Control_Update` 的 ADRC 分支**，由 `config.h` 的 `CTRL_MODE`(0=PID 现状 / 1=LADRC)切换；**默认 0**，不破坏已锁基线。串口 `Z1/Z0` 在线切换。
- 新增全局：`adrc_z1/z2/z3`、`g_b0/g_wc/g_wo`(由 ωo 算 b1/b2/b3)。
- `PID_Reset` 同步重置 ESO：`z1=current_height, z2=0, z3=0`。
- **串口在线整定旋钮**(纯新增，不动 PID 旋钮)：
  - `Z1/Z0` 开关 ADRC
  - `wcN.N` 设 ωc、`woN.N` 设 ωo、`b0N.NNN` 设 b0
  - `q` 打印 ADRC 参数
- **遥测新增** `z3`(=f̂) 字段进心跳 —— 调参就看它。可选把 z3 画到曲线界面(答辩展示"系统看见扰动")。

## 7. 整定 SOP（分阶段，单变量，定量裁决）

- **P0 反馈门**：TST:0 / A<150 / F~42，球底 RAW 稳。不绿不往下。
- **P1 ESO 健康(核心证伪点)**：`Z1` 开 ADRC，球稳在 15。**看 `f̂`(z3)**：应平滑收敛到一个稳定值(≈悬停残差)，拨球时 f̂ 应跟着跳。f̂ 乱跳/发散 → ωo 太大降之；f̂ 太钝跟不上漂 → ωo 太小升之。
- **P2 调 ωo**：从 12 起，`tune_step` 看 std + f̂ 质量。升 ωo 到 std 不再降或开始抖为止。
- **P3 调 ωc**：升 ωc 收紧响应，看 std/超调。过头则球抖、退一点。
- **P4 多高度**：10/15/20 各测，确认 ADRC 把 g(h) 变化吸收(应比 PID 更不需要分高度调)。
- **P5 动态跟踪**：t10↔t20 测 settle，应比 PID 更干净(ESO 抵消瞬态扰动)。
- **P6 抗扰**：拨球/吹气，测恢复时间 + 最大偏移，记报告。

每阶段达标参数回填 config.h；失败回退 `Z0`(PID)不丢基础分。

## 8. 抗干扰测试协议（发挥分硬证据）

1. 球稳在 15cm。
2. ① 手指快速拨球(横向/纵向) ② 管口吹气 ③ 突然部分挡风，各 3 次，我喊"现在"你做。
3. 串口/脚本自动算：**恢复时间(回 ±1cm 带)、最大偏移、是否发散**。
4. 答辩展示：曲线界面叠加 `f̂` 曲线 —— "扰动一来，ESO 立刻估到并抵消"，直观有力。

## 9. 风险与回退

| 风险 | 应对 |
|---|---|
| ωo 过大放大噪声→抖 | 降 ωo；ESO 输入可加轻滤波 |
| ESO 在饱和时积偏 | 饱和冻结 z3 |
| b0 估偏 | ADRC 容忍；必要时 `b0` 在线调 |
| ±1cm 仍差(噪声/气流天花板) | 守住改善后的结果 + 抗扰分 + 报告分；PID 一键回退保基础分 |
| 串口 EMI 掉线(已知) | sysid 已加重连；短事务采集 |

**底线**：ADRC 是新增分支，默认关，调不出不影响任何已锁基础分。
