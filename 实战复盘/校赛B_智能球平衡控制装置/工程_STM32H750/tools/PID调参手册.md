# PID 调参手册（悬浮球定高 · 串口在线整定）

> 配套分析见 `../../04_调试记录/开源项目参考与简化控制方案.md`。
> 核心思想（来自同款开源项目 davidoises/AirLevitatorPIDControl 实测）：
> **先砍到最小三参数(Kp/Kd/Ki)，按"先D后P最后I"的顺序、一次只拧一个，禁止靠眼睛、全程串口抓数。**

---

## 0. 串口命令速查

| 命令 | 作用 | 调参建议 |
|---|---|---|
| `kpNN` / `kiNN` / `kdNN` | 设 Kp / Ki / Kd | 主旋钮 |
| `uhNNNN` | 悬停前馈 u_hover | **保留**：先用 CALIB 扫出悬停 PWM 设好，PID 只修残差 |
| `fN.N` | 球速 EMA 系数 alpha | 调参先 `f0`(裸微分)，末端抖再加 0.2~0.4 |
| `lNNNN` | PWM 每拍斜率限速 | 调参先 `l9600`(等于关) |
| `cNNNN` | D 项钳位 | 激光干净，调参先 `c9600`(等于关) |
| `rNN` | 目标 ramp 速率 cm/s | 调参先 `r0`(关)，达标后开 8~12 |
| `mNNN` / `+` / `-` / `a` | 手动 PWM / 微调 / 回自动 | 标定升力曲线用 |
| `tNN` | 设目标高度 cm | 阶跃测试 |
| `g` / `s` | 启动 / 停机 | |
| `y1` / `y0` | 串级内环(转速闭环) 开 / 关 | 默认关=单环；标定 A/B 后再开 |
| `yaN` / `ybN` | 内环 PWM→RPM 前馈映射 A / B | 由 `sweep_rpm.ps1` 拟合得出 |
| `ypN` / `yiN` | 内环转速 PI：Kp_rpm / Ki_rpm | 先 yp 小值，末端再加 yi |
| `q` | 查询当前参数 | 每步前后查一次 |

**心跳看板字段**：`H`=当前高度 `T`=目标 `E`=误差 `P`=PWM输出 `D`=球速 `R`=转速(tach) `RAW`=原始测距 `A`=反馈停滞ms `F`=测高帧率Hz `PRE`=预热中 `CAS`=串级使能 `RS`=内环目标转速。

## 1. 调参前置检查（不过关别调，否则全是无用功）

1. **传感器支架刚性固定**：晃支架零点就漂，每次重烧 TOF_ZERO 都变。先用热熔胶/螺丝固死。
2. **几何标定**：球静止管底 RAW≈47cm → `TOF_ZERO_CM=47`，确认 H≈0@底、H≈43@管口。
3. **反馈可信**：手持球上下移动，串口 `RAW`/`H` 应平滑跟随、无冻结无大跳。（06-11 已验 50Hz 假跳变 0%）
4. **风机预热**：`g` 启动后风机应先空转 ~3s（心跳 `PRE:1`）再进闭环（`PRE:0`），解决冷启动死区/静摩擦。**已在代码实现**（`FAN_PREHEAT_MS=3000`）。

## 2. 整定流程（照此顺序，逐参数）

### Step 0 — 设好前馈 + 关掉补丁，回到"干净 PID"
先用 CALIB 手动扫出悬停 PWM（球不快升不快降的"刀刃点"），`uh<该值>` 设好前馈；再：
```
f0    l9600    c9600    r0    ki0
```
此时控制律 = `u = u_hover + Kp*e - Kd*v`（**保留 u_hover 前馈**：悬浮球是不稳定对象，
前馈到工作点是正解；删了它积分供不上悬停量，球会趴底——见参考方案 §3 更正框）。

### Step 1 — 调 Kd（阻尼，最先调，决定能不能稳）
- `kp0 ki0`，`kd` 从小到大：如 `kd10` → `kd20` → `kd40` ...
- **看现象**：球从"发散冲顶/落底" → "晃但不发散" → 球速被压住。
- **判据**：`D` 字段(球速)峰值明显变小、球不再撞顶撞底。
- 太大 `kd` → 高频抖(`D` 来回快速变号)，退一档。

### Step 2 — 调 Kp（刚度，把球拉回目标）
- 保持 Step1 的 kd，`kp` 逐步加：`kp5` → `kp10` → `kp20` ...
- **看现象**：球开始能回到目标附近，`E`(误差) 变小。
- **判据**：稳在目标 **±2cm**（基本分到手）。
- 加到"刚开始来回过冲"就退一档。

### Step 3 — 加弱 Ki（消静差 + 长出悬停量）
- `ki` 给小值：`ki1` → `ki2`（David 比例约 Ki≈Kp/10）。
- **看现象**：球原本停在目标下方/上方的固定偏差被慢慢顶到目标线。
- 太大 → 慢振荡(球缓慢大幅摆)，减半；必要时抬 `PID_INTEGRAL_LIMIT`。
- **判据**：稳态误差进 **±1cm**（进阶分）。

### Step 4 — 末端微调滤波（按需）
- 若末端高频抖：`f0.2`~`f0.4` 加点 EMA 压抖。
- 若加 EMA 后变发散：相位滞后过大，退回 `f0`，靠 Kd。

### Step 5 — 动态跟踪 + 软启动
- 阶跃 `t10`→`t20`、`t20`→`t10`：测调节时间(<5s)、超调。
- 大阶跃超调大 → 开 `r8`~`r12`(ramp) 平滑目标。
- 末端来回过冲 → 退一点 Kp 或加一点 Kd。

## 3.5 误差缩减进阶：串级转速(RPM)内环

> 单环把残余压到 ±1cm 后旋钮收益递减。根因是**四线风扇执行器非线性**（冷区/静摩擦/
> 供电下垂/温漂）：同一 PWM 在不同工况转速并不相同，高度环只能"事后"被动补。串级内环
> 用 tach 实测转速把风机线性化，从根上压住浮动。代码已实现，**默认关闭**（`config.h`
> `CASCADE_RPM_DEFAULT=0`），不影响已验证的单环。

控制结构：
```
外环(高度PID, 输出 = PWM等效推力需求 u) ──► 期望转速 rpm_sp = A*u + B
内环(转速PI)  pwm = u + Kp_rpm*(rpm_sp - rpm_meas) + Ki_rpm*∫(rpm误差)
```
执行器理想时 `rpm_err≈0`、`pwm≈u`，与单环完全一致（零风险）；执行器发懒时内环自动补
PWM 把转速顶回"被要求的速度"。

**整定步骤（务必先把单环调好再开内环）**：
1. **先验 tach**：`q` 看 `R:` 字段在风机转时是否给出合理 RPM（满速约 9000+）。读 0 先查
   PC6 接线 / `TACH_ENABLE`，别带病开内环。
2. **扫 PWM→RPM 映射**：
   ```bash
   powershell -ExecutionPolicy Bypass -File tools/sweep_rpm.ps1 -From 1500 -To 6000 -Step 250
   ```
   脚本会线性拟合并直接打印 `ya<A>` / `yb<B>` 两条命令，粘到串口设好前馈。
3. **开内环**：`y1`。此时 `pwm≈u`，行为应与单环几乎一致（前馈已抵掉大部分）。
4. **加内环比例**：`yp` 从小到大（如 `yp0.05`→`yp0.1`→`yp0.2`），看心跳 `R:` 是否更贴
   `RS:`（目标转速），高度 `std` 是否下降。抖了就退一档。
5. **按需加内环积分**：`yi` 给小值消除转速静差（如 `yi0.02`）。
6. **抓长数据对比**：开/关内环各跑一次长采集，比 `std` / `drift` / `oscillation`：
   ```bash
   powershell -ExecutionPolicy Bypass -File tools/tune_step.ps1 -Target 15 -CaptureS 30
   ```
   达标后把 `A/B/Kp_rpm/Ki_rpm` 回填 `config.h`，并把 `CASCADE_RPM_DEFAULT` 置 1。

## 3.6 数据采集工具（长采集 + CSV，便于离线分析）
- `tools/tune_step.ps1`：一次性"开环预热→闭环→采集→停机→分析"。默认采 **30s**，每个样本
  落 `tools/logs/run_*.csv`（已 gitignore），分析输出含 **稳态 std / 漂移斜率 / 残余振荡周期 /
  RPM 统计 / 反馈健康度**。`-CaptureS` 调时长、`-TailFrac` 调稳态窗口、`-CsvOut` 指定文件。
- `tools/sweep_rpm.ps1`：PWM→RPM 执行器特性扫描（串级内环前馈标定，见 §3.5）。
- **建议**：调参先用 `tune_step.ps1` 抓 30s 长数据，比"看屏感觉"可靠得多；关键几条 CSV
  手动归档到 `04_调试记录/`。

## 5. 常见坑速查
| 现象 | 大概率原因 | 处理 |
|---|---|---|
| 球大幅上下荡不收敛 | Kd 太小 / 有 bang-bang 残留 | 先只调 Kd；删 boost 两段式 |
| 球稳但总停在目标下方 | Ki=0(纯 PD 抗重力必留静差) | 加弱 Ki |
| 球缓慢大幅摆 | Ki 太大 / 积分饱和 | Ki 减半，查抗饱和 |
| 越界后拉不回 | slew 限速削掉了 D 的快速制动 | 调参期 `l9600` 关掉 |
| 偶发瞬间窜飞 | 假球速喂出大 D（超声波时代）| 激光下应消失；否则 `c` 钳位 |
| 闭环 PWM 卡住不动 | 事件驱动下反馈拒帧→不更新 | 看门狗超时保持 u_hover(见调试日志 06-11) |
