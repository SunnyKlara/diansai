# 2026 校赛 B 智能球平衡控制装置 —— 深度审题与方案论证

> **本题为本校 2026 校赛真题**，用于检验"最高标准刷题工作流"在一道全新控制题上的实战可用性。
> 方法论沿用系统标杆题（2024F 磁悬浮 / 2024H 自动行驶小车）：五层深度审题 → 误差预算 → 多方案打分选型 → 软件架构 → 硬件难点 → 风险登记 → 评分预估。
> 题目原件见同目录 `00_题目原件.md`。练手固件工程见 `工程_STM32H750/`（STM32H750,唯一真机工程）。

## 〇、本质判定（30 秒结论）

这是一道 **单输入单输出（SISO）、非线性、欠阻尼的悬浮定高控制题**，与系统里 **2024F 磁悬浮**同属一类：被控量是位置，执行器是单一连续量（风机 PWM ↔ 磁铁电流），核心是**带前馈的 PID + 抗振荡 + 设定值平滑跟踪**。

与磁悬浮的关键区别：

| 维度 | 2024F 磁悬浮 | 本题 球平衡 |
|---|---|---|
| 开环稳定性 | **开环不稳定**（Earnshaw，必须高带宽闭环）| **开环临界稳定/弱阻尼**（存在自然平衡点，但振荡大）|
| 执行器带宽 | 电磁铁电流 ~kHz，极快 | 风机转速 + 气柱传输，**慢且有大滞后**（百 ms 级）|
| 主要矛盾 | 采样率 / 控制带宽要足够高 | **大滞后 + 强非线性 + 气流湍流噪声** |
| 控制律 | PD 微分先行（不用 I）| **前馈 + PID（D 抑振 + 弱 I 消静差）** |

> **一句话**：磁悬浮难在"快"，球平衡难在"滞后大、非线性强、噪声脏"。能拿满分的队靠的是**好的传感器滤波 + 合理的前馈工作点 + 微分抑振**，而不是把 Kp 拉大。

### 隐含约束（评委不会明说但必扣分）

- **约束 1｜"启动 ≤5s 进入正常工作"**：上电后必须在 5s 内完成传感器自检 + 风机软启 + 球体起浮稳定。→ 风机不能从 0 猛冲（球弹到顶），需 **软启 ramp + 快速到前馈工作点**。
- **约束 2｜"不可人为干预风道"**：全自动闭环，禁止手扶。→ 必须真闭环，不能靠开环定占空比碰运气。
- **约束 3｜测量误差 ≤±1cm 直接决定 10 分**（基本(1)）且是进阶(1) ≤±1cm 的**前提**：传感器测不准，控制再好也锁不进 ±1cm。→ **传感器精度是全题地基**，误差预算必须先做。
- **约束 4｜"无明显振荡"是主观项**：评委肉眼看球抖不抖。→ 宁可慢一点（4s 到位）也不要冲过头来回荡，**D 项 + 设定值 ramp** 是关键。
- **约束 5｜曲线"坐标清晰 + 同时显示参考线"占 10 分**：不是随便描点，要有刻度轴 + 目标水平虚线。→ 显示屏分辨率与刷新策略要提前定。
- **约束 6｜导管自制、透明**：管径/管长/出风口形状直接决定气流-高度特性曲线，**机械是隐性控制变量**。管径建议 ≈ 球径 +3~5mm（45mm 内径配 40mm 球），太松球贴壁、太紧摩擦大。

## 第二层：物理建模 + 误差预算

### 2.1 物理本质：阻力-重力平衡（非线性 + 弱阻尼）

球在竖直气流中受力：

```
m·ẍ = F_drag − m·g
F_drag = ½·ρ·Cd·A·(v_air(x) − ẋ)²
```

- ρ≈1.2 kg/m³（空气密度），Cd≈0.47（球体），A≈1.26×10⁻³ m²。
- 悬浮平衡（ẋ=0, ẍ=0）需 F_drag = mg = 2.7e-3 × 9.8 ≈ **26.5 mN**。
- 反解所需气流速度：v = √(2mg / (ρ·Cd·A)) = √(2×0.0265 / (1.2×0.47×1.26e-3)) ≈ **8.6 m/s**。

**为什么会自然悬浮在某高度**：风机出口气流速度随高度衰减（射流扩散 + 管壁损耗），存在唯一高度使 v_air(x)=8.6m/s 达到平衡。这意味着系统**开环存在平衡点（临界稳定）**，但：

- 阻尼仅来自相对速度项 (v_air−ẋ)，**阻尼比很小 → 球上下大幅振荡**（典型自然振荡 0.5~2 Hz）。
- 非线性：F_drag ∝ v²，工作点附近增益随高度/风速变化 → **定增益 PID 在全行程不一致**。

> **建模结论**：
> ① 振荡频率低（≤2 Hz）→ 控制采样 **50 Hz 足够**（≥10× 余量），不需要磁悬浮的 2kHz。
> ② 必须有 **微分阻尼 D** 来压制固有振荡。
> ③ 必须有 **前馈工作点 u_ff**（悬浮基准占空比），PID 只做小幅修正，避免大增益。
> ④ 非线性 → 可选 **增益调度**（不同目标高度用不同 Kp）或工作点线性化，作为发挥加分项。

### 2.2 高度测量误差预算（决定基本(1) 10 分 + 进阶(1) 前提）

目标：总测量误差 ≤±1cm（RSS 留 1.5 倍裕量 → 设计目标 ≤±0.6cm）。

| 误差源 | 量级（未处理）| 处理对策 | 处理后 |
|---|---|---|---|
| 声速温漂（超声）| 0.6 m/s/℃ → 10℃≈1.7% → @40cm 6.8mm | 板载测温 + 声速补偿 c=331.4+0.6T | ≤2mm |
| 波束扩散打到管壁/非球顶（超声 15°锥角）| 可达 ±10mm | 传感器装管口正上方对准轴线 + 中值滤波 | ≤3mm |
| 小目标弱回波抖动（40mm 球）| ±3~5mm 跳变 | 5 点中值 + 限幅（剔除 >3cm/帧 跳变）| ≤3mm |
| 量化/时基 | <1mm | — | <1mm |
| 安装基准标定误差 | 系统性 | 上电用已知高度标定零点 | ≤1mm |
| **RSS 合计** | | | **√(2²+3²+3²+1²+1²)≈4.9mm < 6mm ✓** |

> **结论**：超声方案在"装好位置 + 温补 + 中值滤波"后**可以压到 ±0.5cm**，满足 ±1cm。但**裕量不大**，且小目标回波是最大不确定性 → 这是**选型论证要重点权衡**的点（见第三层）。

### 2.3 控制性能预算（决定基本(3) 20分 + 进阶 15分）

| 指标 | 要求 | 设计目标 | 实现手段 |
|---|---|---|---|

## 第三层：选型论证（传感器 + MCU + 风机 + 显示）

### 3.1 高度传感器（全题地基，重点论证）

5 维加权打分（精度×0.35 + 刷新率×0.2 + 抗扰×0.2 + 成本易用×0.15 + 量程匹配×0.1）：

| 方案 | 精度 | 刷新率 | 抗气流/光扰 | 成本易用 | 量程匹配 | 加权 |
|---|---|---|---|---|---|---|
| HC-SR04 超声 | 3（±1cm 临界）| 3（~40Hz）| 3（湍流声噪/小目标弱回波）| 5 | 3（盲区2cm，3cm 临界）| **3.4** |
| **VL53L1X TOF 激光** | **5（±1~3mm）** | **5（>50Hz）** | 4（透明管反光需挡光）| 4 | 5（4cm~4m）| **4.55** ✅ |
| GP2Y0A 红外测距 | 2（非线性、±cm 级差）| 4 | 2（环境光敏感）| 4 | 2（量程窄）| 2.7 |

**决策**：

- **主选 VL53L1X（TOF 激光）**：精度直接达 ±3mm，刷新率 >50Hz，I²C 接口，对 ±1cm（进阶满分）和"动态跟踪 ≤5s"最稳。这是把进阶分锁死的关键升级。
- **保底 HC-SR04（手头已有，已写好驱动）**：经温补 + 中值滤波可达 ±0.5~1cm，满足基本要求。**先用它把闭环跑通**（练手工程已实现测距），再换 TOF 冲进阶。
- **被否红外**：非线性严重、环境光敏感，不适合 ±1cm。

> **工程节奏**：Day1 用 HC-SR04 跑通定高（拿基本 50 分）；Day2 换 VL53L1X 冲进阶 ±1cm + 动态跟踪（再拿 25 分）。**双传感器抽象成统一 `height_sensor_read()` 接口**，切换零改控制层。

### 3.2 MCU：沿用 STM32H750（练手工程）

| 候选 | 主频 | 适合度 | 理由 |
|---|---|---|---|
| **STM32H750**（手头）| 480MHz | ✅ 直接用 | 已配 ADC/DAC/TIM PWM/TIM 输入捕获/OLED，外设绰绰有余；控制只需 50Hz，性能过剩但省去重建工程 |
| STM32F103/G4 | 72/170MHz | △ | 够用，但要重搭工程 |
| ESP32 | 240MHz | △ | 带 WiFi 可做发挥（手机看曲线），但 ADC 差 |

**决策**：**沿用 STM32H750**，零迁移成本，把精力放控制与传感器。

### 3.3 风机驱动

- 推荐 **12V/24V 涵道无刷风机（EDF）** 或 **大风量直流鼓风机**，风量足、响应不能太慢。
- 驱动：无刷需 **电调（ESC）**；有刷鼓风机用 **MOS 大电流 PWM 驱动**（手头 TIM8 PWM 2kHz 适配）。
- **死区/非线性**：标定 **u_min（球开始起浮的占空比）** 作前馈基准，PID 在 [u_min, u_max] 区间工作。
- 电源：风机电流大（数 A），**风机电源与控制板分开供电、单点共地**，避免风机启停拉低 MCU 复位。

### 3.4 显示：OLED（手头）够用，TFT 更优

- OLED 128×64（手头 SSD1306）**可做**曲线：留 ~100×40 像素绘图区，纵轴映射 3~40cm，横轴滚动 ~10s，目标画水平虚线。
- 曲线占 10 分，**2.4" TFT(ILI9341)** 视觉分更高。**先 OLED 跑通，有时间换 TFT**。

## 第四层：软件架构

### 4.1 分层（Drivers / Algorithm / Core）

```
Core/        main.c  状态机 + 50Hz 控制节拍 + 按键/显示任务
Drivers/     height_sensor.c (HC-SR04 / VL53L1X 统一接口)
             fan_pwm.c        (占空比 → TIM PWM，带限幅/软启)
             key.c            (目标高度设定 10/15/20/任意)
             display.c        (OLED/TFT：数值区 + 曲线区)
Algorithm/   pid.c            (位置式 PID + 微分先行 + 抗积分饱和)
             ball_ctrl.c      (前馈 u_ff + PID + 设定值 ramp + 增益调度)
             config.h         (Kp/Kd/Ki/采样率/限幅/ramp 集中)
```

> **强制**：Algorithm 层不依赖 HAL，可在 PC 端用 Python 金标准（复用 `library/通用能力/算法层PC验证方法论/`）先仿真前馈+PID，达标再上板。

### 4.2 控制律（核心）

```
u(k) = u_ff(setpoint)                         // 前馈：该目标高度的悬浮基准占空比
     + Kp·e(k)                                 // 比例
     + Ki·Σe   (抗饱和，仅死区外积分)            // 弱积分消静差
     − Kd·(y(k)−y(k−1))/Ts                     // 微分先行（对测量微分，避免设定值突变踢腿）
e(k) = setpoint_ramped(k) − y(k)
u(k) = clamp(u(k), u_min, u_max)               // 限幅在风机有效区
```

要点：① 前馈 u_ff 使 PID 只小范围修正 → 增益小、振荡小；② 微分先行避免目标突变冲击；③ 设定值 ramp 满足"单次≤3cm""无明显振荡"；④ 抗积分饱和；⑤ 增益调度（发挥项）应对 v² 非线性。

### 4.3 状态机

```
ST_INIT ──传感器自检/标定──→ ST_SOFTSTART ──风机ramp到u_ff──→ ST_HOLD（定高）
                                                                  │
                            目标变更 ──→ ST_TRACK（ramp跟踪）─────┘
                                                                  │
          传感器丢失/球出量程 ≥1s ──→ ST_FAULT（风机降安全值 + 报警）
```

显示状态字："INIT / 起浮 / 定高 / 跟踪 / 异常" 对应基本(4) 的"控制状态"。

### 4.4 时序预算（50Hz 主节拍，Ts=20ms）

| 任务 | 周期 | 说明 |
|---|---|---|
| 传感器读取 | 20ms | TOF I²C 连续模式 / 超声非阻塞中断捕获（**禁止阻塞等待**）|
| 滤波 + 控制 | 20ms | 中值 + PID，<1ms |
| PWM 更新 | 20ms | 写 CCR |
| 显示刷新 | 100ms | 数值 5Hz；曲线每帧描点 |
| 按键扫描 | 20ms | 消抖 |

> **练手代码硬伤**：`chaoshenbo()` 用 `while(...30ms)` **阻塞主循环**、100ms 才测一次 → 闭环采样太慢有大延迟。**必须改成非阻塞 50Hz**（详见 04_调试记录）。

## 第五层：硬件 / 机械难点

1. **导管几何（隐性控制变量）**：内径 ≈45mm，管长 ≥50cm；出风口加**整流格栅/蜂窝**把湍流变层流 → 球更稳，比狂调 PID 有效；传感器装管顶正中向下打，避开风机湍流区。
2. **风机非线性 + 大滞后**：标定 u_min 死区；转速变化到气流到达球位有百 ms 滞后 → 不能用大 Kp，靠 D + 前馈。
3. **超声小目标弱回波**（若用 HC-SR04）：中值滤波 + 限幅剔跳变，必要时换 TOF。
4. **风机电流冲击拉垮 MCU 供电**：分电源、单点共地、大电容。
5. **透明管对 TOF 反光**：传感器贴管口/开窗 + ROI + 距离窗门限。
