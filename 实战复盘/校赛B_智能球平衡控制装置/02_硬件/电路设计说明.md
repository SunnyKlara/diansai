# 校赛B 智能球平衡控制装置 — 电路设计说明

> 与 `01_代码/config.h`、固件实际接线一一对应。标 ✅ 为真机已验证，标 ⚠ 为待接/待验。
> 原理图源文件见 `../工程_STM32H750/SCH_Schematic1_2026-06-08.pdf`。

---

## 1. 系统电路总览

```
12V 电池 ──┬── 风机 0420 (12V/0.6A) ←── PWM(PI6,25kHz)
           │                          └── TACH(PC6) → 转速
           └── DC-DC 降压 → 3.3V ── STM32H750XBH6
                                       ├─ SPI1 → GC9A01 圆形彩屏
                                       ├─ TIM4_CH1 ← HY-SRF05 回波
                                       ├─ GPIO → HY-SRF05 触发
                                       └─ GPIO ← 4 按键
                          USART1(115200) ↔ CH340 ↔ 上位机/串口桥
```

## 2. 供电

| 项 | 方案 | 说明 |
|---|---|---|
| 输入 | 12V 电池 | 直供风机 |
| 逻辑电源 | DC-DC 降压 3.3V | 供 MCU、传感器、显示屏 |
| 注意 | 风机与 MCU 共地 | 大电流回路与信号地单点汇接，避免 PWM 噪声窜入测距 |

> ⚠ 电池跌压会影响风机升力（抗扰测试项），后续风速串级闭环可借 TACH 补偿。

## 3. 主控

- **型号**：STM32H750XBH6（Cortex-M7，480 MHz，FPU，大容量 SRAM）。✅
- 工程：Keil MDK + ARM Compiler 6（armclang），SWD 烧录。
- 时钟：HSE 25 MHz → PLL → SYSCLK 480 MHz；pll1_q=240 MHz 供 SPI1。

## 4. 高度测量（HY-SRF05 超声波）✅

| 信号 | MCU 引脚 | 说明 |
|---|---|---|
| TRIG | PD11 | GPIO 输出，>10µs 触发脉冲 |
| ECHO | PD12 | TIM4_CH1 输入捕获（1 MHz 计数，1µs/计数）|

- 距离换算：`d(cm) = 回波(µs) / 58`。
- 触发间隔 ≥ 60 ms（取 80 ms）；回波超时 10 ms 复位。
- 滤波：3 点中值 → 滑动平均（窗口 3）→ 跳变 >10cm 剔除。

## 5. 气流执行（0420 四线 PWM 风机）

| 信号 | MCU 引脚 | 说明 |
|---|---|---|
| PWM | PI6 | TIM8_CH2，25 kHz，占空比 0~9600 ✅ |
| TACH | PC6 | TIM3_CH1（AF2），10kΩ 上拉 3.3V，2 脉冲/转 ✅ |
| +12V / GND | — | 12V 直供 |

- 风机规格：40×40×20 mm，12V/0.6A。
- 转速：满速实测约 9520 r/min（示波器验干净 3.3V 方波，~317 Hz）。✅
- **25 kHz 改造原因**：1 kHz 时占空比→转速强非线性，升力挤在约 10 个计数内；25 kHz 后分辨率提升约 10 倍。✅

## 6. 显示（GC9A01 1.28" 圆形彩屏）✅

硬件 SPI1 寄存器级直驱（本工程不含 HAL SPI 库）。

| GC9A01 | MCU 引脚 | 功能 |
|---|---|---|
| SCL | PB3 | SPI1_SCK（AF5）|
| SDA | PB5 | SPI1_MOSI（AF5）|
| DC | PG13 | GPIO 输出 |
| CS | PE6 | GPIO 输出 |
| RST | PG14 | GPIO 输出 |
| VCC/GND | 3.3V/GND | 模块常亮背光 |

> 坑（已解）：DC/CS/RST 物理脚曾与代码宏错位致黑屏；SPI1 寄存器初始化需先置 SSI 再置 MASTER，否则 MODF 清 MASTER。详见 `04_调试记录/独到经验总结.md`。

## 7. 人机交互（4 按键）✅

| 按键 | MCU 引脚 | 键义 |
|---|---|---|
| K1 | PC8 | 上 / 加 |
| K2 | PC12 | 进入 / 切换 |
| K3 | PC11 | 返回 |
| K4 | PC9 | 下 / 减 |

- 上拉输入，按下接 GND；8 ms 扫描 + 长按连发。

## 8. 通信 / 调试 ✅

- USART1 @115200，经 CH340 转 USB（COM8）。
- 串口心跳（80 ms）：`H:当前 T:目标 E:误差 P:PWM M:模式 D:球速 R:转速`。
- 在线整定命令：`kp/ki/kd/uh`、`m/+/-/a/t/s/g`，无需重新烧录即可调参与标定。

## 10. 机械结构（导管）

- 透明直筒导管，内径约 45 mm，标准 40 mm 乒乓球。
- 风机置于底部送风，传感器置于顶部向下测距。
