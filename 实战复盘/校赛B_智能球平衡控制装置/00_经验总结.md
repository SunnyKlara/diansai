# 校赛B 经验总结（唯一实战真题 · 全仓库最值钱的一份 · 后续做题的参考基准）

> 校赛B(智能球平衡控制装置)是我们**唯一真机实战做完**的题:上过真板子、踩了几十个坑、把控制器榨到物理极限。
> 成绩 3-5cm(目标 ±1cm;彩排 std 0.37-0.75cm),未达预期——**但真经验全在这**。
> 本文把可迁移到**任何后续题**的教训提炼成铁律。**后续每道题动手前先过一遍;这也是本仓库文档体系的参考样板。**

---

## 0. 元教训:文档漂亮 ≠ 能做出来

校赛B 用真板子证明了一件事:**离线写得再全的代码/报告/BOM,没上板跑过都是零。**
这是本役最贵的一课,也是我们**清掉旧 24 题纸上谈兵骨架**的根本原因——它们制造"已完成"的假象,误导判断。
**真实 > 齐全。没验证的一律标"待验证",绝不自欺。**

## 1. 方法论铁律（调试 / 协作 —— 任何真机问题都适用）

| # | 铁律 | 一句话 | 出处 |
|---|---|---|---|
| **M1 盲调止损** | 同方向连猜 2 次没中 → 立刻改"测量"(读寄存器/上探头/加遥测),别再猜。猜是线性烧时间,测量是 O(1) 命中。 | SPI 黑屏猜了 3 版时钟全跑偏,读一次寄存器 dump(`SPISR=0x200 MODF`)10 秒命中。 | 独到经验总结 §2 |
| **M2 先证固件是新的** | "改了没效果"第一步:加版本标签/新打印,确认板上跑的就是刚烧的。缺新遥测行/数据不新鲜 = 旧 hex/烧错工程,先修链路再谈逻辑。 | 曾读到旧会话缓存 + dump 行缺失,才发现改的固件根本没跑。 | 独到经验总结 §2-B |
| **M3 单变量 + 定量裁决** | 一次只改一个参数,每轮出 avg/std/ptp 和上轮对账;禁止"感觉好像好点"。 | 同时改带宽+Kd 就分不清谁的效果。 | AI协作调试方法论(steering) |
| **M4 对标开源砍旋钮** | 闭门造车调不出时,找**同款开源项目**反推卡在哪。往往病根不是"算法算不出",而是"把控制器做成 N 个互相打架的旋钮,没法整定"。**只抄结构/比例/顺序,不抄绝对值**(执行器增益不同)。 | 对标 davidoises/AirLevitator(同款激光+风机悬浮):它一行 PID + 预热就稳,我们 8 个旋钮打架。砍到 3 个核心旋钮才调得动。 | 开源项目参考 §三/五 |

## 2. 控制工程铁律（控制 / 悬浮 / 小车类题直接复用）

| # | 铁律 | 一句话 |
|---|---|---|
| **C1 整定顺序** | **先 D(阻尼)→再 P(刚度)→最后弱 I(消静差)**,一次只拧一个。不稳定对象尤其如此。 |
| **C2 前馈到工作点** | 不稳定平衡对象(悬浮球)恒定输出守不住任何点。控制律 `u = u_hover + Kp·e − Kd·v + Ki·I`:前馈 uh 扛住工作点,PID 只修残差。**积分限幅小就必须有前馈,别学"大Ki自由积分"的开源写法删 uh。** |
| **C3 Kd 有甜区** | Kd 不是越大越稳:`Kd×球速峰值` 会超过悬停带 → D 项自己撞满量程 → 高频抖/bang-bang。**越加越差 = 方向反了,立刻砍。** 最终 `Kp30 Ki0.5 Kd53`。 |
| **C4 执行器先预热/线性化** | 风机/电机有冷启动死区+静摩擦+转速爬升(本案 ~6s)。**闭环前先空转预热**越过死区,别用"怠速地板"硬扛。进阶可上转速串级(内环锁 RPM)线性化非线性 + 对电压漂免疫。 |
| **C5 微分作用在测量** | D 项对"测量(球速)"求导,不对误差——避免目标突变时的微分踢。配条件抗饱和(仅未饱和时积分)。 |
| **C6 总扰动观测(ADRC)** | 把"悬停漂移+增益随高度变+外部扰动"统一当**一个总扰动 f**,用扩展状态观测器 ESO 实时估 f 并在控制律里**直接减掉**。这样"抗内部漂(±1cm)"和"抗外部扰(发挥分)"是**同一套机制一次解决**。核心旋钮就 ωo(观测带宽)、ωc(控制带宽)。 |

## 3. 工程化 / 现场铁律（最痛的教训,决定彩排好却场上崩）

| # | 铁律 | 一句话 |
|---|---|---|
| **E1 鲁棒方案=默认上场态** | 抗扰/抗电压漂那套(如转速串级)**必须设成 default 上场**,别留在可选开关后面。**本役最痛:解药做出来了却没在场上启用。** |
| **E2 选题先看物理地板** | 动手前估"控制器完美时误差极限是多少"。本题 std≈0.85cm 的底来自气动悬崖+激光 0.3cm 固有跳变——±1cm 贴着物理墙,任何小扰动都顶穿。**指标贴物理极限就早换打法,别在墙上磨几天。** |
| **E3 现场清单 > 算法** | 电池电压/支架拧紧/零点标定/模式确认/暖机——这些**非算法项**才是"彩排 sub-cm、场上 3-5cm"的真凶。进场前过一遍硬 checklist。 |
| **E4 信号完整性** | 飞线上高速 SPI/OLED(>10MHz)会花屏/雪花 → 降速(本案 15→7.5MHz)。上 PCB/缩线再提速。 |

## 4. 报告 / 答辩拿分经验

- **基于模型的设计叙事**:sysID 辨识 → 极点配置 PID → ADRC,一条完整的"基于模型的控制设计"链,理论分析扎实(报告 20 分的采分点)。
- **鲁棒性可视化**:把扰动估计 `f̂`(ESO 的 z3)画到曲线界面,答辩时"扰动一来,系统立刻估到并抵消"——创新性+鲁棒性的硬证据(发挥 25 分)。
- **量化抗扰测试**:拨球/吹气/挡风各 3 次,量恢复时间+最大偏移,写进报告。
- **诚实叙事**:定量指标 + 承认边界(如动态跟踪受气动带宽限),比吹牛更得评委信任。

## 5. 技术硬结论（可直接查用）

- **STM32H7 SPIv2 屏黑屏根因**:软件 NSS 下"先置 MASTER 后拉 SSI"顺序错 → MODF 自动清 MASTER → 永不产生时钟。**修:先 SSI 后 MASTER**(读 SR + 写 CFG2 清 MODF)。
- **悬浮球对象**:不稳定平衡 + 极陡升力曲线(~200 PWM 计数跨全程)。最终 `Kp30 Ki0.5 Kd53 uh3400`,15cm std≈1.25cm。
- **电压是主控变量**:风机真实功率=占空比×电压,电池掉压则悬停 PWM 漂(12V≈3420 / 8.87V≈4240);**但离地转速恒≈6700RPM 与电压无关 → 转速串级对电池放电免疫**。
- **测量地板**:VL53L0X 在 47cm 远处固有 0.3cm 跳变(峰值 1.1cm),是 ±1cm 的硬底 → α-β 观测器/卡尔曼从噪声抠位置。

## 8. 给后续每道题的行动清单（把教训变动作）

1. **动手前**:估物理地板(E2)、列现场清单(E3)、查有没有同款开源可对标(M4)。
2. **写码**:算法层可 PC 单独验证;控制律用前馈+微分作测量(C2/C5);鲁棒方案设为默认(E1)。
3. **上板**:先证固件是新的(M2);执行器先预热(C4);调不通先测量别猜(M1);单变量定量裁决(M3)。
4. **控制题整定**:先 D 后 P 最后 I(C1);Kd 别过头(C3);调参时关掉所有补丁旋钮只留核心 3 个(M4)。
5. **报告答辩**:走"基于模型的设计"叙事 + 鲁棒性可视化拿分。
6. **全程**:没验证的标"待验证",绝不当成品(元教训)。
