# index/ —— 题型图谱（系统脊柱）

> 让系统从"文件柜"变"会推理"的那一层。把**题型**映射到**方法 / 复用积木 / 相似案例 / 高频坑**。

## 它解决什么

- **对内（AI 做题）**：拿到一道新题 → 先查 `题型图谱.json` 判定题型 → 立刻得到"该用什么方法 + 复用哪个案例/积木 + 要避哪些坑" → **不从零开始**。
  - 例：校赛 B（智能球平衡）→ 判定为"悬浮定高控制" → 直接拿 2024F 磁悬浮的 PD 微分先行 + `library/通用能力/PID控制/` + 已知坑"阻塞采样致发散"。
- **对外（网页展示）**：可据此渲染"这题 ↔ 相似题 ↔ 用到的积木 ↔ 踩过的坑"的关系网，点着学。

## 怎么用（AI 协作时）

1. 读题 → 对照 `题型图谱.json` 的 `判别特征` 定位题型。
2. 取该题型的 `推荐方法` 作控制律/算法起点。
3. 按 `复用积木` 路径调现成零件，按 `相似案例` 路径抄结构与经验。
4. 把 `高频坑` 逐条作为设计/调试 checklist。

## 维护规则

- **每新解一道题** → 归入对应题型的 `适用题`，并把它的新经验补进 `高频坑`、新模块补进 `复用积木`。
- **出现全新题型** → 新增一个 `题型` 条目。
- 图谱是"活的"：解的题越多，连接越密，系统越聪明（自增强）。
