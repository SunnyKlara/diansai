## 想象一个场景

你家里有 30 件电器：洗衣机、电视、冰箱、电脑、LED 灯、手机充电器、空调、热水壶……每一件单独看都没问题。可是当它们同时开机的时候，**电网会变得很'脏'**。

什么叫'脏'？

你拿一台示波器去看墙上插座那 220V 交流电的波形——理论上应该是一条标准的正弦波，每秒 50 个圈。但实际上你看到的是一条**长着锯齿、扭曲变形的'伪正弦波'**，顶端有平台、底端有尖刺，像被人用小刀划过一样。

这条扭曲的波形会让变压器嗡嗡响、让电机过热、让电脑突然死机、让你家电费**多出 5%~15%**。在工厂里，**重型电机的轴承会因为这种'脏电'提前一年报废**；在数据中心，**服务器集群的故障率会增加 3 倍**。

这就是**谐波污染**——本题要让你做的，是给这条扭曲的波形'刮一次脸'，让它变回干净的正弦波。

## 出题人是怎么想到这道题的

去年 2024 年的电赛 B 题是'单相功率分析仪'——让你**测量**电网谐波。今年 2025 年的 B 题是'单相有源电力滤波'——让你**消除**电网谐波。

**这是一个连续命题策略**。出题人在告诉你：电力电子工程师的成长路径是'**先看懂问题，再解决问题**'。**测量是诊断，滤波是治疗**。掌握了这两步，你就成了电网医生。

那为什么把这道题选成 2025 年的电赛主菜之一？答案在产业里。

中国'双碳目标'要求 2060 年前实现碳中和。**电网清洁化的最大障碍不是发电端**（光伏、风电技术都成熟了），**而是用电端**——大量非线性负载（你家里的开关电源、变频空调、LED 驱动器、手机充电器）会向电网注入谐波，**让发电端不得不多发 5%~15% 的电去填补这部分'被浪费'的能量**。

> **小白补课：什么是谐波，什么是非线性负载**
> - 一个'**线性负载**'就是电压翻倍电流也翻倍——比如纯电阻、纯电感。它们的电流波形和电压波形形状一样，都是干净的正弦波。
> - 一个'**非线性负载**'就是电压翻倍电流不一定翻倍——比如二极管整流器（电压低时不导通、超过某个阈值才导通）。它们的电流波形被'削顶'或'抽尖'，**不再是正弦**。
> - 任何非正弦周期波形，按数学家**傅里叶**1822 年的发现，都可以分解成基波（50Hz）+ 一系列谐波（100Hz、150Hz、250Hz……）的叠加。**非正弦的电流就是带谐波的电流**。

工业上对付谐波有两种武器：

**第一代：无源滤波器（LC 滤波器）**——最简单，几个电感和电容串并联，专门吸收某次谐波。**问题是它'认死理'**：你设计成滤 5 次谐波（250Hz），来 7 次谐波（350Hz）就废了；电网频率从 50Hz 漂到 50.5Hz，谐振点就跑了。**这是 1970 年代的老方案**。

**第二代：有源电力滤波器（APF, Active Power Filter）**——用一台变流器**主动产生'反向谐波电流'**注入电网，**两股电流相加为零**，谐波就被'抵消'了。它能动态适应任意谐波次数、任意频率漂移。**这是 1990 年代以后兴起、目前的主流方案**。

本题要你做的就是**第二代 APF 的简化版**。Mtech、ABB、施耐德这些电力厂商有商用 APF 产品，单机售价从几万到几百万，**国内市场 2024 年规模 80 亿、增速 20%**。这就是出题人埋的彩蛋——做完这一题，**你的工业可雇佣度直接拉满一档**。

而且 B 题往往比 A 题更适合'电控背景'选手——A 题硬件多、烧 MOS 多；**B 题软件多、调控制算法多**。如果你队里有人擅长写 C 代码，B 题是更好的选择。

## 这题在做的事，其实就两步

把图 1 拆成两块：

**左半边：非线性负载**——一台 24V 副边变压器接一组二极管 + 电容，画出来就是你手机充电器内部的简化版。这就是'**坏人**'：它会从电网吸 2A 电流，但**吸的方式不规矩**，造成谐波污染。

**右半边：APF 有源电力滤波器**——一个 H 桥（4 个 MOS 搭成单相全桥）+ 电感 LF + 一颗 DC 母线电容。它的工作是**实时产生一股电流 iF 注入电网，专门用来抵消负载产生的谐波**。这就是'**警察**'。

中间一根线接到了'电网'（变压器副边 24V/AC）。这根线上的电流叫 **iS（网侧电流）**——它是 iL（负载电流）和 iF（APF 注入电流）的代数和：

```
iS = iL - iF
```

(注意正方向定义不同符号会变，但物理含义一致：网侧电流 = 负载需求 - APF 补偿)

题目要做的事情用一句话讲完：**让 iS 尽可能干净，最好是纯 50Hz 正弦**。

办法是：**测出 iL 里有哪些谐波、APF 就生成相反的 iF**。**iL 把它的谐波全'抛'到 iS 上，APF 把它的谐波全'吸'回来**——两者抵消，**iS 看到的只剩基波**。

> 想象一个画面。一辆卡车在土路上跑，扬起一股向后的尘土。一辆扫地车跟在它后面，**朝同样的方向以同样的速度喷一股向前的气流**——两股气流互相抵消，路面上看不到尘土。卡车 = 非线性负载，尘土 = 谐波，扫地车 = APF。

听起来简单——'测谐波 + 反相注入'。但**让 APF 的输出电流跟踪一个高频变化的目标**（150Hz、250Hz、350Hz……都要跟住），**这是控制工程的高阶问题**。所以本题真正考的是**电流环的速度和精度**。

接下来一层一层揭谜。

## 第一个谜：怎么从一团扭曲电流里挖出谐波

要消除谐波，第一步是**知道谐波长什么样**。

题目给的负载电路（图 2）由两组开关 KD、KC 切换出 4 种工作模式：

| KD | KC | 负载类型 | 谐波特征 |
|---|---|---|---|
| 断开 | 断开 | 半波整流 + 纯电阻 | **2 次谐波**为主（100Hz） |
| 断开 | 闭合 | 半波整流 + 电容滤波 | 2 次为主，**3、4 次也明显** |
| 闭合 | 断开 | 桥式整流 + 纯电阻 | **3 次谐波**为主（150Hz） |
| 闭合 | 闭合 | 桥式整流 + 电容滤波 | 3 次为主，**5、7 次叠加** |

> **小白补课：为什么半波整流以 2 次为主，桥式以 3 次为主**
> - **半波整流**：只有半个正弦周期有电流流过，另外半个周期电流为零。这种'**砍掉一半**'的波形展开成傅里叶级数后，**主要分量是基波 + 直流分量 + 偶次谐波**——其中 2 次最大。
> - **桥式整流**：两个半周期都有电流流过，但电流方向被'**翻折**'成单向。这种波形是个**双倍频脉冲串**，傅里叶展开后**主要含基波 + 奇次谐波**——3、5、7 次依次递减。
> - 加上电容滤波之后，电流不再是平缓的'削顶'波，而是**只在每个周期峰值附近持续 2~3ms 的窄脉冲**——脉冲越窄，傅里叶展开的高次谐波越多。**电容越大，脉冲越窄，谐波越凶**。

这就是题目要求 IO=2A、电容 1000~10000μF 的用意——**让谐波幅值大到足以测量**。如果只测 0.1A 的谐波，被 ADC 的 1mA 量化误差淹没，就什么都看不到了。

那么，**给你一段 iL 的电流波形（每秒采样几千次的数据数组），怎么算出它的 H2、H3、H4、H5（2~5 次谐波含有率）**？

工程师有三个武器。

**武器 1：傅里叶变换 FFT（最直观）**

> **小白补课：FFT 是什么**
> 傅里叶变换是数学家**约瑟夫·傅里叶**1822 年发明的工具。他证明了一件惊人的事：**任何周期函数都可以分解成正弦波的叠加**。FFT（Fast Fourier Transform，快速傅里叶变换）是这个分解过程的高效算法，1965 年发明。
> 给 FFT 输入 N 个时域采样点（一段电流波形），它输出 N 个频域分量（每个频率上的能量）。**算法复杂度 O(N·logN)**，1024 点 FFT 在 STM32 上 5 毫秒能算完。

要测 2~5 次谐波（即 100Hz、150Hz、200Hz、250Hz），采样率要满足**奈奎斯特定理**——**采样率 ≥ 2 × 最高频率**。本题最高 5 次谐波 = 250Hz，**采样率 ≥ 500Hz** 就够。但工程上一般取 10 倍以上，**4kHz~20kHz 是合理范围**。

采多少点合适？**频率分辨率 = 采样率 / N**。要分清 50Hz 和 100Hz（间隔 50Hz），分辨率应优于 5Hz——**N ≥ 800**。但 FFT 喜欢 2 的幂，常用 **N = 1024 或 2048**。

代入：采样率 4096Hz，N = 1024 → 采样窗口 0.25 秒（恰好 12.5 个基波周期），频率分辨率 4Hz。**可以清晰分辨 50/100/150/200/250Hz**。

谐波含有率公式：

```
H_i = I_iRMS / I_1RMS × 100%
```

这个式子说的其实是：**i 次谐波的有效值，相对于基波有效值的比例**。

代码大概长这样（伪代码）：

```c
float i_samples[1024];     // 采集 1024 点电流
adc_capture(i_samples);    // ADC 采样
float fft_real[1024], fft_imag[1024];
fft_compute(i_samples, fft_real, fft_imag);

// 找出每次谐波的幅值
float I1_rms = sqrt(fft_real[12]*fft_real[12] + fft_imag[12]*fft_imag[12]) / sqrt(2);
// (50Hz 在 1024 点 / 4096Hz 采样下对应 bin 12.5，实际取 12)
float I2_rms = sqrt(fft_real[25]*fft_real[25] + fft_imag[25]*fft_imag[25]) / sqrt(2);
// ...
float H2 = I2_rms / I1_rms * 100;
```

**FFT 的优点**：直观、通用、能同时给出所有谐波。  
**FFT 的缺点**：计算量大、有'**频率泄漏**'（如果采样窗口不是整周期会出现假谐波）。

工业级 APF 不用 FFT 做实时控制（**FFT 输出延迟 0.25 秒，对 APF 来说太慢**），FFT 主要用在**显示与测量**。题目里基本要求 (3) 显示 H2~H5 用 FFT 是最方便的；**APF 实时控制用下面两种方法**。

**武器 2：dq 变换（同步坐标系，最经典）**

> **小白补课：dq 变换是什么**
> 三相系统里有一个工具叫 Park 变换（dq 变换），把三相 abc 信号变成两个直流量 d 轴和 q 轴。**单相系统也能用类似的'虚拟正交'方法**——构造一个比当前信号超前 90° 的'虚拟相'，凑出一个'伪两相'系统，然后做 dq 变换。
> 这种方法叫**单相 SOGI-PLL**（二阶广义积分锁相环），1990 年代发明。把单相波形丢进去，能输出'**和电网同步旋转的 dq 坐标系下的直流量**'。

为什么要这样？因为如果电流 iL 在 dq 坐标系下被分解成：
- **d 轴直流分量** = 基波有功电流
- **q 轴直流分量** = 基波无功电流  
- **d/q 轴交流分量** = 谐波（在 dq 系下都不是直流）

这意味着 **'谐波 = dq 系下的非直流部分'**。把 dq 系信号通过一个**低通滤波器**（截止频率 30Hz 左右）就能保留基波（直流），剔除所有谐波。然后**原始电流减去这个'纯基波部分'**——剩下的就是**完整的谐波信号**！

```
i_harmonic = i_L - i_L_fundamental
```

这个式子说的其实是：**'谐波部分 = 原始电流 - 基波部分'**。一减就出谐波。

dq 法的优点：**实时性极佳**（延迟 1~2 个基波周期，约 20~40ms），**适合做 APF 实时控制**。  
dq 法的缺点：**单相 dq 需要构造虚拟正交相**，实现比三相复杂。

**武器 3：瞬时功率理论（pq 法）**

把电流信号在 αβ 坐标系下计算瞬时有功功率 p 和瞬时无功功率 q，**'有用'的功率是直流部分，'谐波'对应交流部分**。和 dq 法本质类似，方法稍有差异。

**国一队伍最常用的组合**：dq 法做 APF 控制 + FFT 做 LCD 显示。**两套算法并行跑**——dq 法响应快用于 APF 闭环控制，FFT 输出准确数字显示给评委看。

## 第二个谜：怎么生成想要的电流波形

知道谐波长什么样，下一步是**让 APF 输出一股反向的电流**——iF 必须实时跟踪 -i_harmonic。

但你的 APF 不是一台'电流源'——你只能控制 4 个 MOS 开关的开/关。**怎么用开关控出连续的电流**？

**关键器件：滤波电感 LF**

H 桥的输出端不是直接接到电网，而是先经过一颗电感 LF。**这颗电感是 APF 的灵魂**。

H 桥输出端有 4 种电压状态：+V_dc、0、0、-V_dc（取决于 4 个 MOS 的开关组合）。这是**离散电压**。但加上电感之后，**电感对电流变化有'反抗'作用**——根据电感方程：

```
V_L = L × (di/dt)
```

这个式子说的其实是：**电感两端电压等于电流变化率乘以电感值**。换句话说：**只要给电感两端加合适的电压，就能精确控制电流的变化方向和速度**。

打个比方：H 桥就像水龙头，**电感就是一段橡皮水管**——水龙头开/关切换得很快（几千次每秒），但水管里的水流不会突变，**水管里的水流随时间平滑变化**。这就是 PWM 输出'看起来像连续电流'的物理原理。

电流环控制公式（连续时间域）：

```
V_pwm = L × (di_ref/dt) + R × i + V_grid + V_PI(error)
```

**逐项翻译**：
- **L × di_ref/dt**：前馈项——根据目标电流变化率算出需要多大电压
- **R × i**：电阻补偿——克服电感和导线的等效电阻
- **V_grid**：电网电压前馈——抵消电网电压对电流的扰动
- **V_PI(error)**：PI 反馈——修正前面三项算不准的部分

这就是所谓的**电流环 deadbeat 控制 + 前馈解耦**——工业 APF 的标配方案。

**第二个关键参数：开关频率 fs**

APF 要能跟踪 250Hz（5 次谐波），开关频率 fs 必须高得多。工程经验：**fs ≥ 30 × f_target**——250Hz × 30 = 7.5kHz 起步。

但 fs 越高，开关损耗越大（前面 2025-A 题讲过）。**国一队伍的甜点是 fs = 20kHz**——既能跟踪到 7 次谐波（350Hz × 30 = 10.5kHz < 20kHz），又控制开关损耗。

**第三个关键参数：DC 母线电压 V_dc**

APF 要往电网注入电流，H 桥输出电压必须**比电网电压峰值高出一截**——这样电感才有正向电压驱动电流变化。

电网 24V AC（有效值）→ 峰值 24√2 ≈ 34V。  
APF DC 母线 V_dc 至少 1.5 倍峰值 = 50V，工程上取 60~80V。

题目说明 (2) 给的是 48V 直流电源——**勉强够用**。这意味着你必须设计一个**升压电路**把 48V 升到 60~80V，或者**直接用 48V 凑合**（输出能力受限）。这是题目埋的暗坑——后面"说明里的暗坑"会专门讲。

## 第三个谜：电流环为什么这么难调

直线段 PID、温度 PID、电压 PID 都不难。但**电流环的 PID 是电力电子里最难调的环**——为什么？

**理由 1：目标值是高频时变量**

温度环的目标是 50℃ 这种'静止值'，PID 慢慢追就行。**APF 电流环的目标是 250Hz 的'快速振荡值'**——每 4ms 就要从 +1A 变到 -1A 再回来。**这要求控制器响应时间 < 0.4ms**（10 倍快于目标变化），即**控制带宽 ≥ 2.5kHz**。

要做到 2.5kHz 带宽，PI 控制器的 Kp 得拉得很高。但 Kp 一高就容易震荡——

**理由 2：电感小则响应快但纹波大；电感大则响应慢但纹波小**

电感 LF 的选择充满矛盾：

```
电流变化率 di/dt = (V_pwm - V_grid) / L
PWM 纹波 ΔI = V_dc / (4 × L × fs)
```

**第一个式子**：电感越小，电流变化越快，**APF 跟踪谐波的能力越强**。  
**第二个式子**：电感越小，PWM 开关纹波越大，**输出电流越脏**。

代入数据：V_dc = 48V, fs = 20kHz, 要求纹波 ΔI < 0.05A：
```
L > 48 / (4 × 0.05 × 20000) = 12 mH
```

但要跟踪 5 次谐波（250Hz, 峰值约 0.5A），di/dt 峰值 = 0.5 × 2π × 250 = 785 A/s：
```
V_drive = L × di/dt = 0.012 × 785 = 9.4V
```

加上电网电压补偿 34V，PWM 输出需要 43V——**距离 V_dc=48V 只剩 5V 余量**。**电感再大就饱和**，电感再小就纹波超标。

**12mH 电感是这道题的甜点**。再小（如 5mH）需要 V_dc 升到 80V 才稳；再大（如 20mH）就跟不上 7 次谐波。

**理由 3：'谐波目标值'本身有滞后**

dq 法测出 i_harmonic 需要至少 1 个基波周期（20ms）的滞后。然后控制器算出 PWM、PWM 控制 MOS、MOS 驱动电流——这条链条又有 1 个开关周期（50μs）的滞后。**总滞后约 20ms**。

20ms 后再让 APF 注入电流，**那时候 iL 的谐波早变了**。所以 APF 的输出和真实需要的电流之间永远有相位差。**消除谐波就不彻底**。

工程对策：**重复控制器（Repetitive Controller）**——一种**周期化 PID**，记住上一个基波周期的误差，下一个周期主动**预补偿**。配合传统 PI 形成 'PI + 重复控制' 的复合结构。**国一队伍的标配**。

**理由 4：电网电压本身不干净**

电网电压 uS 不是完美 50Hz 正弦——它已经被千万家邻居的非线性负载污染了。**uS 里含有微量谐波**（你测出来 THD 可能 2%~5%）。如果你用未滤波的 uS 做电压前馈，**这些谐波会被前馈进 APF 输出**，反而恶化补偿效果。

工程对策：**对 uS 做一个数字 LPF（低通滤波）**，截止频率 60Hz，只保留基波。**然后用滤波后的'纯基波 uS'做前馈**。

**控制环路图（简化版）**

```
i_L → [谐波提取(dq 法)] → -i_harmonic_target
                                  ↓
                                  + ─────→ [PI + 重复控制] → V_PI
i_F (反馈)                        ↑                            │
   ↑                              │   电压前馈 V_grid_filtered  │
   │                              │       │                    │
   │                              │       ▼                    ▼
   │                              └──────[+]──────►[+]──── V_pwm_ref
   │                                                  │           │
   │                                                  ▼           ▼
   └────────────────────────[ 电感 LF ]◄── [ H 桥 PWM ]◄── [ SPWM/HBPWM ]
```

整个环路涉及：
- **数字滤波器（IIR）**：1 阶/2 阶 LPF
- **PLL（锁相环）**：跟踪电网相位
- **dq 变换**：实时算谐波
- **PI + 重复控制**：电流闭环
- **PWM 调制**：H 桥开关

**这就是电力电子控制工程的'软件版图'**。每一个模块都是 1980~2010 年间发表的专门论文。**做完这一题，你完整摸过了这个领域 30 年的技术积累**。

## 第四个谜：怎么验证 APF 真的在工作

调试 APF 最大的困难不是写代码，是**验证**——你怎么知道你的输出真的在抵消谐波？

**误区**：用示波器看 iF 波形——'好像有点像谐波的样子'，就以为做对了。

**真相**：单看 iF 波形完全不够。**核心检验是看 iS 波形**——网侧电流应该接近正弦（基波 + 极少谐波）。

工业上的标准测量工具：**电能质量分析仪（Power Quality Analyzer）**。比如 Fluke 1736、Hioki PW3198。它能：
- 实时显示 uS、iS、iL 三路波形
- 实时计算 THD、单次谐波含有率 H1~H50
- 输出图表和数字报告

**题目说明 (6) 写得清清楚楚**：

> 基本要求 (3) 以电能质量分析仪的读数作为 HmL 的真实值计算装置的测量误差，电流测量应使用电流钳；发挥部分各项电流及其谐波也都使用电能质量分析仪测量。

**这意味着评委会拿一台电能质量分析仪现场测**。你自己测的数据没用——评委的数据为准。

工程对策：**自带一台电能质量分析仪做训练校准**。如果学校实验室没有，**至少要有一台 Fluke 175 万用表**（带 RMS 真有效值测量）+ **一台 1G 带宽示波器**（自带 FFT 功能）。这是基本装备。

**第二层验证**：跑遍 4 种 KD/KC 组合，**每种都要测 H1~H7 + THD**。建立一张完整的'真值表'：

| KD | KC | 不接 APF 时 H_m^L | 接 APF 后 H_m^S | THD_S |
|---|---|---|---|---|
| 0 | 0 | 38% (2 次) | < 5% ? | < 5% ? |
| 0 | 1 | 50%+ (2 次) | < 5% ? | < 5% ? |
| 1 | 0 | 25% (3 次) | < 5% ? | < 5% ? |
| 1 | 1 | 60%+ (3 次) | < 5% ? | < 5% ? |

**KD=1, KC=1（带电容滤波桥式整流）的谐波最厉害**——这是发挥 (3)(4) 的'终极考点'。如果你的 APF 在这个极端工况下还能把 H3 压到 5% 以下、THD 压到 5% 以下，**16 分稳拿**。

**第三层验证**：'**鲁棒性测试**'

国一队伍最后一天会做这套测试：
- 突然切换 KD/KC 状态——APF 能在 100ms 内重新跟上吗？
- 突然加重负载（IO 从 1A → 3A）——APF 会过流跳闸吗？
- 输入电压波动 ±10%——APF 还能稳定补偿吗？

**鲁棒性强的设计 = 工业级产品**。这部分通常体现在'其他' 4 分，但更重要的是测试时不会因为意外失败而丢分。

## 真正的考点：发挥 (4) 比的是综合调优

基本要求 50 分（送分给做出来的队伍）。发挥 (1)(2)(3) 各 10 分（按工况依次叠加难度）。**发挥 (4) 16 分 + 其他 4 分共 20 分**——这一项是排名分。

发挥 (4) 的要求：

> 在 KD、KC **闭合**条件下（最严苛工况：桥式整流 + 电容滤波），要求 iS 的总谐波畸变率 **THD 不高于 5%**。

为什么 5% 是个魔术数字？因为这是**国家电网对电力客户的入网标准**——GB/T 14549《电能质量 公用电网谐波》对低压用户的 THD 上限就是 5%。**做到这一项 = 你的 APF 已经达到工业入网标准**。

THD 5% 比单一次谐波 5% 难得多。THD 是**所有谐波的能量平方和开根**：

```
THD = √(H2² + H3² + H4² + ... + Hn²)
```

把每次谐波都压到 5% 以下还不够——**它们叠加起来可能 10%+**。要让 THD < 5%，**每次谐波都要压到 2~3% 以下**。

**怎么做到？**

**第一招：把 PI 的 Kp 拉满**

电流环 PI 的 Kp 越大，**跟踪误差越小**，对应谐波抑制越强。但 Kp 太大会震荡，导致整体不稳定。**调试方法**：从 Kp = 0.5 开始，每次加倍，**直到看到 PWM 输出有微弱的开关频率附近的振荡**——这个临界值的 60% 就是工程值。

**第二招：加重复控制器**

PI 单独跑能压到 THD 8~10%，加重复控制后能进一步压到 **THD 4~5%**。

重复控制的核心是：**保留一个基波周期长度（20ms）的'误差缓冲区'**，每个新周期开始时，**用上周期的误差去预补偿**。代码：

```c
#define REPEAT_BUFFER_LEN 400  // 20ms / 50us = 400 点
float repeat_error[REPEAT_BUFFER_LEN];
int repeat_index = 0;

float compute_pwm(float i_target, float i_actual) {
    float error = i_target - i_actual;
    
    // PI 项
    float pi_out = Kp * error + Ki * integral;
    integral += error * dt;
    
    // 重复项：取上周期同一位置的误差
    int idx_last = (repeat_index + 1) % REPEAT_BUFFER_LEN;
    float repeat_out = K_repeat * repeat_error[idx_last];
    
    // 更新缓冲区
    repeat_error[repeat_index] = error;
    repeat_index = (repeat_index + 1) % REPEAT_BUFFER_LEN;
    
    return pi_out + repeat_out;
}
```

**重复控制要花 1~2 个周期才'收敛'**——开始 40ms 内还没生效，所以**测试时要让 APF 先空跑 200ms 稳定**。

**第三招：升压到 80V V_dc**

48V 母线在重负载下会饱和（前面"第二个谜"算过）。**外加一个 Boost 升压电路把 48V 升到 80V**——APF 输出余量充足，跟踪能力大增。

升压电路本身要 4 颗器件：电感 + MOS + 二极管 + 电容。**会让总成本和复杂度增加 30%**——但 THD 从 8% 降到 4% 的回报是 16 分。**绝对值得**。

**第四招：DC 母线电容大些**

H 桥的 DC 母线电容要承担**百赫兹纹波**（100Hz、200Hz 等谐波瞬时功率波动）。电容越大，纹波越小，电流环越稳：

```
ΔV_dc = ΔP / (V_dc × ω × C)
```

代入 ΔP = 50W（瞬时谐波功率波动），V_dc = 80V，ω = 2π × 100，要求 ΔV_dc < 2V：

```
C > 50 / (80 × 2π × 100 × 2) ≈ 500 μF
```

工程上常用 **1000μF / 100V 电解电容**，余量充足。

**THD 5% 的实战分布**

根据往年类似题目（2018 H 题、2021 B 题）的获奖数据：
- **THD ≤ 3%**：前 5%（满分 16 分）
- **THD 3~5%**：前 30%（满分 16 分）
- **THD 5~8%**：前 60%（部分得分 8~12 分）
- **THD > 8%**：失败（0 分）

**THD ≤ 5% 是个全有或全无的门槛**——做到就稳拿 16 分，做不到就 0 分。**全场拿走这 16 分的队伍大约只占 30%**。

### 任务那段话

> 设计并制作如图 1 所示**单相有源电力滤波实验装置**，**检测并显示**非线性负载电流 iL 及其谐波成分与含量，**控制有源电力滤波器（APF）产生补偿电流 iF**，降低网侧电流 iS 中谐波含量。

任务里隐藏着两个独立功能：

**功能 1：检测与显示**——这是基本要求 (2)(3) 考的。即使没有 APF，**只要能正确测出 iL 的谐波**，你就能拿到基本要求 50 分中的 42 分（只丢基本要求 (1) 的 8 分，但这一分太基础不会丢）。

**功能 2：APF 控制**——这是发挥部分考的。即使 APF 跑不起来，**只要做完检测与显示也能拿基础分**。

这是出题人留的'保底机制'——**APF 太难，万一失败也别空手而归**。

**24V 副边变压器 + 48V 直流电源**

题目说明 (2)：

> 使用 **48V**、额定输出电流不小于 **3A** 的成品直流电源为装置供电

48V × 3A = 144W。考虑 APF 损耗 + 检测与显示模块功耗，**真正能给负载用的有效功率约 100W**。题目要求 IO = 2A、负载电压约 24V × 0.7（半波/桥式平均）= 17V，**负载吸收功率约 34W**——余量充足。

但 48V 电源给 APF 供电，**就只有 48V 母线**。前面分析过，**APF 跟踪 5 次以上谐波会饱和**。如果你想拿满分，**必须自己加 Boost 升压**——题目允许使用 48V 电源做主输入，但**没有限制你能否在内部升压**。这是题目埋的一个隐藏关卡。

### 基本要求 (1)：非线性负载本身要做出来

> 设计并制作如图 2 所示非线性负载电路，要求 KD、KC **不同状态下**的输出直流电流 IO 的最大值均**不小于 2A**。（8 分）

这一条是热身。但'**不同状态下都要 2A**'是有讲究的。

**4 种状态分析**：

| KD | KC | 等效电路 | IO 最大值 |
|---|---|---|---|
| 断开 | 断开 | 半波 + 20Ω 电阻 | (24×√2) / (π × 20) ≈ 0.54A ❌ |
| 断开 | 闭合 | 半波 + 20Ω + 电容 | 24 × √2 / 20 ≈ 1.7A ❌ |
| 闭合 | 断开 | 桥式 + 20Ω | 2 × 24 × √2 / (π × 20) ≈ 1.08A ❌ |
| 闭合 | 闭合 | 桥式 + 5Ω // 20Ω + 电容 | √(24²+...) / 5Ω ≈ 4A+ ✅ |

(题目电路里 KC 闭合时把 5Ω 也并进去了，电流大幅提升)

意思是：**只有 KD=1 KC=1 时 IO 自然能到 2A**，其他三种状态需要**调整 RL 电阻**来达到 2A。

**工程上怎么做**？

题目里 RL 是个变量。**让 RL 是可调电阻箱**——根据 KD/KC 状态切换 RL 阻值，保证每个状态下 IO 都能调到 2A。

实际上一般做法：**RL 默认 5Ω**（KD=1 KC=1 状态下 IO 就 2A 多）。其他状态下电流不到 2A 也能测——**题目要求'最大值不小于 2A'，意思是负载有能力达到 2A，不是每次测试都强制 2A**。

但**基本要求 (2)(3) 测试时调整 IO=2A**——所以测试时只测 KD=1 KC=1 这一种状态？

**不**。题目原文'调整 IO=2A'意味着**通过调整 RL 让每种状态下 IO 都到 2A**。所以你的电路必须有能力让每种状态都达到 2A——**这才是 8 分的真正考点**。

**8 分的具体设计**：

- 副边 24V 变压器：选 **30V/3A 隔离变压器**（淘宝单价 80 元），副边电压余量充足
- 二极管 D1~D4：**选 1N5408（3A/1000V）4 颗 + 1N4007（1A/1000V）2 颗**（构成图 2 中的 D1 桥式 + D 半波）
- 电容 C1, C2：**两个并接端口**，常用 1000μF/100V 电解电容 + 4700μF/100V 备用
- 电阻 RL：**5Ω/50W 大功率水泥电阻 + 20Ω/30W 滑动变阻器**（按 KD/KC 状态切换）
- 开关 KD/KC：**3.5mm 跳线 + 拨码开关**

整个负载电路 BOM 不超过 200 元。**8 分稳拿**，关键是**接线整洁、跳线规整**——评委见过太多杂乱的电路，整洁度是隐性加分项。

### 基本要求 (2)：检测 uS 和 iL，测 ILRMS 误差 ≤ 5%

> 装置能够检测变压器副边电压 uS 及 KD、KC 不同状态下的负载电流 iL，并**同步显示** uS 和 iL 的波形。装置能够测量并显示 iL 的有效值 ILRMS，**测量相对误差的绝对值不大于 5%**。（22 分）

**22 分**——基本要求里最大的一项。这条考'**测量电路 + 显示**'。

**第一笔：电压检测电路**

uS 是变压器副边电压（24V AC）。要送到 MCU 的 ADC 上——**ADC 只能测 0~3.3V**。需要分压 + 偏置。

经典电路：

```
uS (peak ±34V) → 100kΩ 分压 → 1.65V 偏置 → ADC 输入
分压比 = 1.5V / 34V ≈ 1/22.7
```

```
R1 (100kΩ from uS) ──┐
                     ├── 1.65V (来自 3.3V/2)
R2 (4.7kΩ to GND) ───┘
```

更好的方案：**用 LV25-P 隔离电压传感器**（LEM 公司产品，电赛常用）——一边接 24V 高压，另一边输出隔离的 0~5V 信号。**安全 + 精度高**。

但 LV25-P 单价 200 元，有点贵。**国二队伍用电阻分压 + 隔离运放（如 ISO124）**，节省 150 元。

**第二笔：电流检测电路**

iL 是负载电流（最大 2A 峰值约 3A）。常用方案：

**方案 A：精密电流采样电阻（最便宜）**

串一颗 0.1Ω 5W 电阻（如 Vishay WSL2512），3A 峰值时压降 0.3V，**送差分运放放大 5 倍**到 1.5V 给 ADC。**总成本 < 5 元**。

但电阻发热（峰值时 0.9W）、**没有电气隔离**——共模电压可能干扰运放。

**方案 B：霍尔电流传感器（精度更高，更安全）**

**ACS712-20A**（Allegro 公司）：单价 20 元，灵敏度 100mV/A，输出 0.5~4.5V（中心 2.5V）。**带电气隔离 + 直接给 ADC**。

**方案 C：电流互感器 CT（精度最高）**

**ZMCT103C**（南京中旭）：1mA / 1mA 比，需要外接负载电阻 + 运放。带电气隔离，频响 0~10kHz（足够测谐波）。**国一队伍标配**。

**第三笔：ADC 采样率与精度**

要测 5 次谐波（250Hz）的含有率，采样率 ≥ 5kHz（10 倍奈奎斯特）。STM32F4/F7 的内置 ADC 12 位，最大采样率 2.4MSPS——**绰绰有余**。

但 12 位 ADC 的精度天花板：**1/4096 = 0.024%**——理论上能测出 0.1% 的谐波。实际上由于噪声 + 量化误差，**5% 的精度要求很轻松**。

**第四笔：'同步显示 uS 和 iL'怎么实现？**

显示器选 **3.5 寸 TFT LCD（320×240）** 或 **OLED 1.3 寸 (128×64)**。

**TFT LCD 优势**：分辨率高，能同时显示波形 + 数字 + 表格。  
**OLED 优势**：低功耗、显示清晰、响应快。

**同步显示的关键**：uS 和 iL 必须**采样时间对齐**。MCU 只有一个 ADC，多通道扫描时，通道间有 1~2 微秒延迟——**对 250Hz 谐波来说可忽略**（一个周期 4ms = 4000μs）。

但要画出'**同步'**的视觉效果，**两个波形要画在同一时间轴上**。代码里建议用**双缓冲采样**：

```c
uint16_t adc_buffer[2][1024];  // 双缓冲
int active_buffer = 0;

ISR_ADC_DMA_Complete() {
    active_buffer = 1 - active_buffer;  // 切换缓冲
    process_buffer(adc_buffer[1 - active_buffer]);  // 处理刚填满的缓冲
}
```

DMA 自动把 ADC 数据填到缓冲里，主循环慢慢处理。这是**STM32 跑实时信号处理的标准模式**。

**第五笔：ILRMS 怎么算 5% 精度**

```
ILRMS = √(Σ i_n² / N)
```

直接对 1024 点平方求平均开根。整数运算就能搞定，**精度由 ADC 决定**——12 位 ADC 自带 0.024% 精度。**5% 误差很轻松**。

但有个**隐藏坑**：**校准 ADC 的零偏 + 增益**。出厂时 ADC 可能有 ±10mV 偏移、±0.5% 增益误差。**未校准的话 RMS 误差可能到 2~3%**——还在 5% 内，但留的余量小。

**校准方法**：用 Fluke 175 万用表测真实 RMS 值（如 1.50A），调整代码里的乘法系数让显示读数对齐。**这一步不能省**。

22 分稳拿。这是 B 题的'保底分'——**只要测量电路做对、显示美观、RMS 计算无误**。

### 基本要求 (3)：H2~H5 显示，HmL 误差 ≤ 3%

> 装置能够测量 KD、KC 不同状态下的负载电流 iL 中谐波含有率 Hi，**显示 H2~H5（保留小数点后一位）**，其中**含量最高的谐波含有率（HmL）测量误差的绝对值不大于 3%**。（20 分）

20 分——再大头一项。

3% 误差比基本要求 (2) 的 5% 严格——**FFT 必须做对**。

**FFT 实现的几个坑**：

**坑 1：采样窗口必须是基波整周期**

电网 50Hz → 周期 20ms。FFT 窗口建议 **40ms（2 个周期）或 80ms（4 个周期）**——必须是 20ms 的整数倍。

**为什么**？如果窗口不是整周期，FFT 会出现**频率泄漏**：50Hz 的能量泄漏到 49Hz、51Hz 等附近 bin，**测出来的 H1 偏小，H2~H5 偏大**——误差可能到 5%+。

代码里：**用 PLL 锁定电网相位**，让 FFT 触发在过零点附近，**确保窗口是整周期**。

**坑 2：加窗函数（Hann / Hamming）**

即使是整周期采样，由于电网频率会漂移（50Hz ± 0.5Hz）、采样时钟也有微小误差，**实际窗口可能差几个采样点**——还是会泄漏。

工程对策：**乘 Hann 窗或 Hamming 窗**，把窗口两端的样本'渐变到 0'，减少泄漏。代码里：

```c
for (int i = 0; i < N; i++) {
    samples[i] *= 0.5 * (1 - cos(2 * PI * i / (N - 1)));  // Hann 窗
}
fft_compute(samples, ...);
```

加窗后**主瓣变宽，副瓣变低**——FFT 频谱更干净。**这一步让 H_m 误差从 4% 降到 1%**。

**坑 3：FFT 库的选择**

STM32 上常用的 FFT 库：
- **CMSIS-DSP**（ARM 官方）：最快，1024 点约 1.5ms（F7@216MHz）。**国一队伍标配**。
- **KissFFT**（开源 C 库）：最简洁，2048 点约 5ms。**新手友好**。
- **手写 FFT**：性能差但代码透明。**不推荐**。

`arm_rfft_fast_f32` 是 CMSIS-DSP 的实数 FFT 函数，**自带 Bit-Reversal + 复用对称性**，速度比通用 FFT 快 2 倍。

**坑 4：HmL 最大值识别**

题目要求'**含量最高的谐波**'——可能是 2 次、3 次、4 次、5 次中的任意一个。代码里要**比较 H2/H3/H4/H5，取最大值作为 HmL**：

```c
float H[6] = {0, 1.0f, H2, H3, H4, H5};  // index 1 是基波
float HmL = 0;
int Hm_index = 0;
for (int i = 2; i <= 5; i++) {
    if (H[i] > HmL) {
        HmL = H[i];
        Hm_index = i;
    }
}
```

**Hm_index** 是后面 APF 要跟踪的目标频率（150Hz、200Hz、250Hz 之一）——这个变量是发挥部分的关键。

20 分到手。基本要求 50 分齐了——**做完这步，APF 一行代码不写也有 50 分稳拿**。

### 发挥 (1)：APF 输出对的频率，IFRMS ≥ 0.1A

> APF 上电，KF1、KF2 保持断开，KLF 闭合。要求在 KD、KC 不同状态下，iF 的有效值 IFRMS **均不小于 0.1A**；要求 iF 的频率 fF 与 iL 中含量最高的谐波的频率 fm **偏差的绝对值不大于 1Hz**，即 |fF - fm| ≤ 1Hz。（10 分）

**这一项 10 分是发挥部分的'敲门砖'**——做不到这一项，**发挥 (2)~(4) 都不予测试**（说明 (7) 写得很清楚）。

任务'拆解'：
- APF 接到了 H 桥输出，但还没接入电网（KF1、KF2 断开），KLF 闭合所以 iL 直接走原回路
- APF 自己输出一股电流 iF，**频率必须等于 iL 里最大谐波的频率**
- IFRMS ≥ 0.1A：**至少能输出**这么大的电流（说明 H 桥能干活）

**第一笔：怎么让 APF 单独输出电流**

KF1、KF2 断开 = APF 没接入网侧，**它的输出端通过 KLF 接到一颗 10Ω 的'测试负载电阻'上**。

APF 输出电流 IFRMS = V_pwm_RMS / 10Ω。要 IFRMS ≥ 0.1A，需要 **V_pwm 输出 ≥ 1V RMS**。

H 桥能输出的最大基波电压 = V_dc / √2 ≈ 48 / 1.414 = 34V RMS（理论极限）。**输出 1V 简直 trivial**——只要 APF 的电流环工作了，1V 输出根本不是问题。

**所以重点是'频率对'**。

**第二笔：怎么让 fF 和 fm 一致**

代码里你已经识别出 Hm_index = 2/3/4/5（基本要求 (3) 已经做完）。然后让 APF 的电流给定值是：

```c
i_target_F = AMPLITUDE * sin(Hm_index * omega_grid * t + phase_offset);
```

其中：
- `omega_grid` 是电网角频率（来自 PLL 锁相）
- `Hm_index * omega_grid` 自动是 fm（n 次谐波频率）
- AMPLITUDE 取 0.2A 左右（保证 IFRMS = 0.1A）
- phase_offset 在这一项里可以是 0（**这一项不要求精确补偿，只要求频率对**）

**第三笔：±1Hz 偏差怎么保证**

电网频率本身会在 49.5~50.5Hz 漂移，**所以 'fm = n × f_grid' 也会漂**。

如果 PLL 跟踪到了真实 f_grid，**fF = n × f_grid 也会跟着漂**——**永远跟踪在 ±0.1Hz 内**。这就是 PLL 的功劳。

但如果你不用 PLL（用 50Hz 硬编码），电网漂到 50.5Hz 时 fm = 5×50.5 = 252.5Hz，但你的 fF 还是 250Hz——**偏差 2.5Hz，超标**。

**所以这一项隐式要求 PLL 必须做对**。

10 分到手。**只要 APF 电流环工作 + PLL 工作 + 频率识别正确**——三个独立的子系统都对了，就过关。

### 发挥 (2)(3)：APF 接入电网，HmS ≤ 5%

> (2)：合上 KF1、KF2，断开 KLF，接入 APF。在 KD、KC **断开**条件下，要求 iS 中对应 iL 含量最高的谐波的含有率 HmS **下降至不高于 5%**。（10 分）
>
> (3)：合上 KF1、KF2，断开 KLF，接入 APF。在 KD、KC **闭合**条件下，要求 iS 中对应 iL 含量最高的谐波的含有率 HmS **下降至不高于 5%**。（10 分）

发挥 (2) 是'**简单工况**'——半波整流 + 纯电阻，谐波相对单一（2 次为主）。  
发挥 (3) 是'**复杂工况**'——桥式 + 电容滤波，3 次谐波很大、5、7 次叠加。

**两者的核心都是'让 APF 真正抵消谐波'**。这就要求电流环 + 重复控制都跑对。

**关键参数：补偿电流的振幅 + 相位**

补偿电流 iF 必须满足：

```
|iF| = |i_harmonic|       (振幅相等)
angle(iF) = angle(i_harmonic) + 180°  (反向)
```

代码：

```c
// dq 法已经提取出 i_harmonic（包含了振幅和相位）
i_target_F = -i_harmonic;  // 反相
// 然后这个目标值送给电流环
pwm_value = current_pid(i_target_F, i_actual_F);
```

听起来简单。但**实际跑起来**会发现：**APF 输出和 i_harmonic 之间永远差 5~20ms**（控制延迟）——这就让 HmS 压不到 5% 以下。**重复控制器是必备**，前面已经讲过。

**怎么测 HmS**：

题目说明 (6)：

> 发挥部分各项电流及其谐波也都使用**电能质量分析仪**测量。

意思是评委用电能质量分析仪测 iS 的谐波。**你自己测的不算**。但你训练时也要会测——**借同学的、租实验室的**。

这条 10 分 + 10 分 = 20 分，**做出来一个就稳拿一个**。如果你的 APF 在简单工况下成功了但复杂工况失败了，发挥 (2) 拿 10 分、发挥 (3) 拿 0 分——这是常见情况。

### 发挥 (4)：KD/KC 都闭合时 THD ≤ 5%

> 合上 KF1、KF2，断开 KLF，接入 APF。在 KD、KC **闭合**条件下，要求 iS 的总谐波畸变率 **THD 不高于 5%**。（16 分）

**16 分** + 其他 4 分 = 20 分——这是发挥部分最大的一项，**也是这道题的胜负手**。

前面"真正的考点"那一节已经讲了 4 招（拉 Kp、加重复、升压、加大母线电容）。这里专门讲**测试现场的实战要点**。

**实战要点 1：测试时间限制 10 秒**

题目说明 (8)：

> 各项测试设置完成后，**一键启动装置进行测试，期间不允许人工干预，每项测试时间不超过 10s**。

10 秒里要：
- APF 启动 + PLL 锁相（200ms）
- dq 解算 + 谐波识别（1 个基波周期 = 20ms）
- 电流环投入工作（5~10 个基波周期 = 100~200ms）
- 重复控制收敛（2~3 个基波周期 = 40~60ms）
- **稳态运行**（剩余 9 秒）

**关键是稳定时间 < 0.5 秒**——剩 9.5 秒做评测。

**实战要点 2：突变工况下不能掉链子**

发挥部分各项可能连续测试。每一项测试间评委会切换 KD/KC 状态——**APF 必须能在 0.5 秒内重新跟上新工况**。

工程对策：**用一个'状态切换检测器'**。监测 iL 的 RMS 在 100ms 内的变化，超过 30% 就触发'**重新锁谐**'：

```c
if (fabsf(iL_rms - last_iL_rms) > 0.3 * last_iL_rms) {
    state = STATE_RELOCK;  // 进入重新锁谐状态
    // 重置 dq 法的内部积分器
    // 等 100ms 后才重新激活电流环
}
```

**这一步让 APF 像活的一样'适应'工况切换**。新手不做这一步，工况切换时 APF 会瞬间过流。

**实战要点 3：电流采样精度**

要测 THD ≤ 5%，**iS 的采样精度必须远高于 5%**——**至少 0.5%**。

12 位 ADC 的量化精度 0.024% 理论上够，但实际由于：
- ADC 输入端的运放噪声
- 电源纹波耦合到 ADC 参考电压
- 走线耦合的开关噪声

**实测精度可能只有 0.5~1%**——勉强够用。

**国一队伍的招数**：
- ADC 参考电压用 **TL431 + 滤波**（3.3V 标称，纹波 < 1mV）
- ADC 输入端加 **RC 抗混叠滤波**（截止频率 5kHz）
- PCB 上 **数字地和模拟地分开**，单点连接
- **ADC 多采样平均**（10 次平均，等效精度 +1.5 位）

**实战要点 4：硬件保护**

THD 5% 的极限调试中，**常见故障**：
- PI Kp 过大 → 电流环震荡 → 母线电压瞬升 → MOS 击穿
- 重复控制不收敛 → 误差累积 → 电流逐渐增大 → 过流
- 工况突变 → APF 输出突变 → di/dt 过大 → 电感饱和

工程对策：**在 PWM 输出端加硬件保护**：
- **过流保护**：电流采样信号送比较器，超过 5A 立刻关闭 PWM
- **过压保护**：母线电压采样，超过 90V 立刻关闭
- **欠压保护**：母线电压低于 30V 立刻关闭（防止电流环饱和）

这些保护通过比较器 + 与门连到 PWM 使能引脚——**无需 MCU 介入，硬件直接保护**。**MCU 故障时器件还活着**——这是工业产品的基本要求。

### '其他' 4 分

> （5） 其他。

这是评委给你'**惊艳作品**'的加分项。常见加分点：

- **THD ≤ 3%**（远超要求 5%）：'**这队人功底深**'
- **优秀的人机界面**：4.3 寸 LCD 实时显示 6 路波形 + 谐波柱状图
- **多保护机制**：过流 / 过压 / 过温 / 欠压齐全，**测试时各种异常都不'崩'**
- **工程化设计**：PCB 层叠合理、接线整洁、外壳美观
- **创新功能**：**自动识别工况、自适应调整 PI 参数**——AI 不仅识别 fm，还能根据负载特性动态优化 Kp

**4 分不多，但是排名分**——前 5% 队伍才能拿满。

### 说明里的暗坑

**说明 (2)：'除此以外，检测与显示模块、APF 不准再使用其他电源'**

这一句话斩断了'**外接 USB 电源给单片机供电**'这种偷懒做法。**所有逻辑、传感器、显示器、PWM 驱动、栅极驱动**——全部从 48V 母线取电。

工程对策：**分级降压**：
- 48V → Buck → 12V（栅极驱动）
- 12V → Buck → 5V（运放、显示器）
- 5V → LDO → 3.3V（MCU、ADC）

每级用 Buck 而不是 LDO，**保证整体效率**。

**'电源功耗预算'**：
- MCU + ADC：**0.5W**
- LCD 显示：**0.5~2W**（看屏幕大小）
- 5 路运放 + 传感器：**0.5W**
- 栅极驱动：**1W**
- 总计：**3W**

48V 电源 3A = 144W 容量，**辅助电源 3W 占 2%**——可忽略。

**说明 (3)：'两个滤波电容端口，方便测试时更换、并接不同容值的电容'**

这是评委要测试**不同电容下的谐波特性**。你的非线性负载 PCB 上必须**预留两个易于更换的电容焊盘**——3.5mm 跳线、香蕉头、螺钉端子都可以。**绝对不能焊死电容**，否则评委没法换。

**国一队伍**：用 **Micro-Fit 3.0 双排针端子**——电容用插拔的方式连接，10 秒内能换 1000μF / 4700μF / 10000μF 之间的任意电容。**专业感拉满**。

**说明 (7)：'本题要求采用 APF，不允许采用投入电感、电容的方法抑制谐波'**

不允许**无源 LC 滤波器**——**只能用主动控制**。

这就排除了'**给电网串一颗 10mH 电感**'这种作弊方案。出题人坚持你用真正的有源滤波技术。**这是题目的灵魂**。

**说明 (8)：'一键启动装置进行测试'**

10 秒测试 + 一键启动 = **不允许测试中途人工干预**。

工程对策：**总状态机**

```
STATE_IDLE → 等待按键
STATE_INIT → 初始化（500ms）
STATE_PLL_LOCK → 等 PLL 锁定（最多 200ms）
STATE_HARMONIC_DETECT → 测量谐波（200ms）
STATE_APF_RAMPUP → APF 软启动（300ms）
STATE_RUNNING → 稳态运行（剩余 8 秒）
STATE_DONE → 测试完成
```

**整套流程不需要人触发**——按下启动键后自动跑完。**这一步代码量约 200 行**。

但有一个隐藏的'坑'——**软启动**。如果 APF 一上来就满功率输出，**会瞬时过流**（电感 LF 没有储能，电流跃变剧烈）。**软启动**是把 PWM 占空比从 0 渐进升到目标值（300ms 内）。**少了这一步，第一次测试就 BOOM**。
