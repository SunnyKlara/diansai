## 想象一个场景

凌晨两点，深圳一家做工业逆变器的小厂车间。出厂前最后一个 QA 工位，质检员小陈把示波器探头夹到一台 5kW 逆变器的输出端——屏幕上跳出一条波形——**他要在 5 秒内做出三个判断**：

1. **这是不是一条正弦波**？（**逆变器要输出正弦，否则不能并网**）
2. **频率是不是 50.0Hz**？（**电网要求 49.5~50.5Hz，超了卡脖**）
3. **峰峰值是不是 311V**？（**对应 220V RMS，电压低了用电器跑不动**）

如果是熟手——**3 秒看眼**——**没问题就贴绿标签放行**。但小陈是新人——**他瞄半天还不敢拍板**——**因为示波器屏幕上"看起来像正弦"** 的波形还可能是"叠了 5% 三次谐波的伪正弦"** —— **凭眼睛分不出**。

**怎么办**？车间老师傅给他指了一台躺在角落里的"**自动波形识别仪**"——**长得像一个鞋盒**——**前面板上一个 BNC 输入口、一块 LCD 屏**——**把探头插进去 1 秒后**：

```
┌──────────────────────┐
│  类型: 正弦 ✓         │
│  频率: 50.02 Hz       │
│  Vpp:  311.4 V        │
│  THD:  1.8%           │
│  状态: 合格 ✓         │
└──────────────────────┘
```

**1 秒识别 + 量化指标 + 自动判定**——**新人也能做出"老师傅水准"** 的判断——**这台鞋盒就是 2021 J 题让你做的设备**：**周期信号波形识别及参数测量装置**。

工业现场为什么需要这种设备？

- **逆变器 / UPS / 变频器 出厂检测**：**每秒检测一台**——**人工跟不上**
- **电网监测**：**每个变电站布 100 个测点**——**实时识别异常波形**
- **音频功放质检**：**正弦输入 → 看输出有没有"被削顶"** 变成方波
- **EMI 测试**：**自动识别"干扰是脉冲噪声还是连续噪声"**

**全球波形识别仪市场约 30 亿美元**——**国产替代率不到 30%**——**主流厂商有 Tektronix、Keysight、Rohde & Schwarz、横河**——**国内有鼎阳、普源、固纬**。**做这一题等于摸到这个赛道的入门钥匙**。

> **小白补课**：示波器和"波形识别仪"的区别？
> - **示波器**：**画出波形让人看**——**人眼判断**——**慢、主观、依赖经验**
> - **波形识别仪**：**自动识别 + 自动量化 + 自动判定**——**毫秒级、客观、不依赖人**

## 这题在做的事，其实是教 MCU 学会"看波形"

把任务拆成三步：

**Step 1：采样**——**把模拟波形变成数字数组**  
**Step 2：分析**——**判断"这是哪种波形"** + **算出关键参数**  
**Step 3：显示**——**LCD 显示类型 + 频率 + Vpp**

**核心难点都在 Step 2**——**怎么用一段算法分清"正弦 / 三角 / 矩形"**？

**答案有三种思路**——**每种都对应一种"工程师味道"**：

**思路 A：时域统计法**

看波形的"统计特征"——**正弦 / 三角 / 矩形 各有不同的"指纹"**：

| 特征 | 正弦 | 三角 | 矩形 |
|---|---|---|---|
| **峰值因子（Vp / Vrms）** | 1.414 | 1.732 | 1.000 |
| **形状因子（Vrms / Vavg）** | 1.111 | 1.155 | 1.000 |
| **斜率分布** | 连续变化 | 两段恒定 | 阶跃 |
| **过零率** | 2 / 周期 | 2 / 周期 | 2 / 周期 |

**这个表说的其实是**——**'**每种波形的峰值因子和形状因子是固定的**'**——**算出来对照查表 = 识别成功**。

**思路 B：频域 FFT 法**

看波形的"频谱"——**每种波形的谐波分布不同**：

| 波形 | 谐波分布 |
|---|---|
| **正弦** | 只有基波 H1，无谐波 |
| **三角** | H1 + 1/9·H3 + 1/25·H5 + ...（仅奇次，1/n²） |
| **矩形（占空比 50%）** | H1 + 1/3·H3 + 1/5·H5 + ...（仅奇次，1/n） |
| **锯齿** | H1 + 1/2·H2 + 1/3·H3 + ...（全谐波，1/n） |

**这个表说的其实是**——**'**FFT 后看二次谐波 / 三次谐波 / 五次谐波的相对幅值，能反查出波形类型**'**。

**思路 C：神经网络法**

把"波形数组"** 喂给神经网络——**让网络自己学习"哪个特征代表哪种波形"**——**端到端识别**。

**优点**：**精度最高（99.9%+）**——**能识别 10 种以上波形**。  
**缺点**：**训练数据量大**——**MCU 算力消耗大**——**不适合电赛 4 天**。

**国一队伍的选择**：**思路 A + 思路 B 组合**——**先用统计特征粗判，再用 FFT 精判**——**99.5% 识别率**。  
**国二队伍**：**纯思路 A**——**90% 识别率**——**勉强**。  
**国三队伍**：**只看峰峰值不识别波形**——**直接 0 分**。

## 第一个谜：怎么用统计特征认出"波形指纹"

**先看最简单的"过零率"**——**所有周期波形过零率都是 2 / 周期**——**没用**。

**再看"峰值因子"** —— **公式**：

```
峰值因子 CF = Vp / Vrms

正弦波：Vp = √2 · Vrms → CF = √2 = 1.414
三角波：Vp = √3 · Vrms → CF = √3 = 1.732
矩形波：Vp = Vrms → CF = 1.000
```

**这个式子说的其实是**——**'**算出 Vp 和 Vrms，相除，对照查表**'**——**简单**。

**怎么算 Vp 和 Vrms**？

```c
// Vp = max - min
float vp = (max(samples) - min(samples)) / 2;

// Vrms = sqrt(均方)
float sum_squared = 0;
for (int i = 0; i < N; i++) {
    sum_squared += samples[i] * samples[i];
}
float vrms = sqrt(sum_squared / N);

// 峰值因子
float crest_factor = vp / vrms;
```

**这段代码说的其实是**——**'**1024 点采样 → 算 max/min/RMS → 比值**'**——**3ms 完成**。

**判断逻辑**：

```c
if (crest_factor < 1.1) {
    waveform = SQUARE;     // 矩形 1.0
} else if (crest_factor < 1.55) {
    waveform = SINE;       // 正弦 1.414
} else if (crest_factor < 1.9) {
    waveform = TRIANGLE;   // 三角 1.732
} else {
    waveform = UNKNOWN;
}
```

**精度**：**单次识别 90~95%**——**多次平均 99%+**。

**坑 1：噪声让峰值因子飘**

实测时 ADC 噪声让 Vp 偏大、Vrms 偏小——**峰值因子比理论值高 5%**。

**对策**：**去除野点 + 滤波**

```c
// 去除前 5% 和后 5% 的极值（避免噪声尖峰）
sort(samples);
float vp = (samples[N*0.95] - samples[N*0.05]) / 2;
```

**'**截尾处理**'** 把噪声尖峰过滤掉——**Vp 估计精度提升 3~5%**。

**坑 2：信号幅值不同时识别不稳**

50mV 的信号 + 12 位 ADC → **信号占满 5% 量程** → **信噪比差** → **峰值因子误差大**。

**对策**：**PGA 自动增益（前面 2021 A 讲过）**——**让信号始终占满量程**。

## 第二个谜：FFT 法的"谐波指纹"

**FFT 法是更稳的识别方法**——**因为它看"频谱"** 而不是"时域统计"** —— **抗噪声更强**。

**第一笔账：FFT 后的频谱长什么样**

正弦波（1kHz）的 FFT：

```
H1（1kHz）：100%
H2（2kHz）：< 0.1%
H3（3kHz）：< 0.1%
... 全谐波 < 0.1%
```

**纯净到只有 H1**——**典型"正弦指纹"**。

三角波（1kHz）的 FFT：

```
H1（1kHz）：100%
H3（3kHz）：11.1%   ← 1/9 = 11.1%
H5（5kHz）：4.0%    ← 1/25 = 4.0%
H7（7kHz）：2.0%    ← 1/49 = 2.0%
H2/H4/H6 = 0
```

**'**奇次 + 1/n² 衰减**'** 是三角波的"指纹"**。

矩形波（1kHz，50% 占空比）的 FFT：

```
H1（1kHz）：100%
H3（3kHz）：33.3%   ← 1/3 = 33.3%
H5（5kHz）：20.0%   ← 1/5 = 20.0%
H7（7kHz）：14.3%   ← 1/7 = 14.3%
H2/H4/H6 = 0
```

**'**奇次 + 1/n 衰减**'** 是 50% 占空比矩形波的"指纹"**。

**第二笔账：识别算法**

```c
// FFT 后取归一化幅值
float h1 = abs_spectrum[1];  // 基波
float h3 = abs_spectrum[3] / h1;  // 三次谐波归一化
float h2 = abs_spectrum[2] / h1;  // 二次谐波归一化

// 判断
if (h3 < 0.05 && h2 < 0.05) {
    waveform = SINE;        // 几乎无谐波
} else if (h3 > 0.08 && h3 < 0.15 && h2 < 0.05) {
    waveform = TRIANGLE;    // H3 ≈ 11%
} else if (h3 > 0.25 && h3 < 0.40 && h2 < 0.05) {
    waveform = SQUARE;      // H3 ≈ 33%
} else if (h2 > 0.30) {
    waveform = SAWTOOTH;    // 有偶次谐波
}
```

**这段代码说的其实是**——**'**根据 H2 / H3 的归一化幅值，对照标准值，识别波形**'**——**精度 99%+**。

**第三笔账：占空比测量（基本要求 4）**

题目要求**矩形波占空比 D，范围 20%~80%，误差 ≤ 2%**——**这是 J 题的特色**。

**怎么算占空比**？

**方法 A：时域过阈值法**

```c
// 1. 算阈值（信号中点）
float threshold = (max + min) / 2;

// 2. 找上升沿和下降沿
int rise_count = 0, fall_count = 0;
int high_count = 0;
for (int i = 1; i < N; i++) {
    if (samples[i-1] < threshold && samples[i] >= threshold) {
        rise_indices[rise_count++] = i;
    }
    if (samples[i] >= threshold) high_count++;
}

// 3. 占空比
float duty = (float)high_count / N;
```

**这段代码说的其实是**——**'**信号高于中点的时间占比 = 占空比**'**——**简单直接**。

**精度**：**1024 点采样 + 1 周期信号 = 时间分辨率 1/1024 = 0.1%**——**远超 ±2% 要求**。

**国一队伍**：**多周期平均 + 上升 / 下降沿对齐**——**精度 0.1%**——**满分稳拿**。

## 第三个谜：50mV~10V × 1Hz~50kHz 的大动态范围

发挥要求 (1) 把量程拉到：

- **电压**：**50mV~10V**（**200 倍范围**）
- **频率**：**1Hz~50kHz**（**50,000 倍范围**）

**这是 J 题真正的难点**——**和 2021 A 一样难**。

**第一笔账：电压范围 200 倍怎么覆盖**

12 位 ADC + 3.3V 输入 → **量化精度 0.8mV**——**50mV 占 60 个量化级别**——**精度差**。

**对策**：**PGA 自动增益（前面 2021 A 详细讲过）**

```c
// 输入信号范围
if (vpp_estimate > 5V)       gain = 1;
else if (vpp_estimate > 1V)  gain = 4;
else if (vpp_estimate > 0.2V) gain = 20;
else if (vpp_estimate > 0.05V) gain = 100;
else                          gain = 200;

set_pga_gain(gain);
```

**这段代码说的其实是**——**'**根据估测幅值选最佳增益**'**——**让 ADC 始终满量程工作**。

**第二笔账：频率范围 5 万倍怎么覆盖**

**1Hz**：周期 1 秒——**采 1024 点要 1 秒**——**慢**  
**50kHz**：周期 20μs——**采 1024 点要 1.024 ms**——**快**

**采样率必须自适应**：

```c
// 先粗扫描估测频率
fs = 100000;  // 100kSPS 默认
adc_capture(buf, 1024, fs);
float coarse_freq = fft_find_peak(buf);

// 选最佳采样率
if (coarse_freq < 100) fs = coarse_freq * 1024;     // 整周期
else if (coarse_freq < 1000) fs = coarse_freq * 256;
else if (coarse_freq < 10000) fs = coarse_freq * 64;
else fs = 1000000;  // 1MSPS for 50kHz
```

**这段代码说的其实是**——**'**先粗扫频率，再选最佳采样率，做整周期采样**'**——**和 2021 A 同一思路**。

**第三笔账：1Hz 信号怎么测**

1Hz 信号周期 1 秒——**采样 1024 点要 1 秒**——**违反"反应时间 < 3 秒"** 要求 (发挥 2)。

**对策**：**多采样率混合**

```c
// 1Hz 信号采 256 点（4 秒/4 = 1 秒）
fs = 256;  // 256SPS
adc_capture(buf, 256, fs);

// FFT 256 点 + 加窗
fft_compute(buf, spectrum, 256);
```

**256 点 FFT 的频率分辨率**：

```
分辨率 = 256 SPS / 256 = 1 Hz
```

**1 Hz 分辨率刚好能分辨基波**——**够用**。

**国一队伍**：**1Hz 信号 1.5 秒识别完成**——**远低于 3 秒**——**满分**。

## 第四个谜：反应时间 < 3 秒怎么压

发挥 (2) 要求：**识别 + 所有参数同时显示，反应时间 < 3 秒**。

**反应时间 = ADC 采样时间 + FFT 计算时间 + 显示更新时间**：

| 步骤 | 1Hz 信号 | 50kHz 信号 |
|---|---|---|
| **ADC 采样** | 1 秒（256 点） | 1.024 ms（1024 点） |
| **FFT 计算** | 0.5 ms（256 点） | 1.5 ms（1024 点） |
| **波形识别** | 0.1 ms | 0.1 ms |
| **参数计算** | 0.1 ms | 0.1 ms |
| **LCD 更新** | 30 ms | 30 ms |
| **合计** | **1031 ms** | **33 ms** |

**1Hz 信号最慢 1.03 秒**——**远低于 3 秒**——**满分**。

**国一队伍**：**1Hz 信号 0.8 秒识别完成（用半周期 FFT 优化）**——**最快**。

## 把题目逐条翻译一遍

### 任务那段话

> 设计一个周期信号的波形识别及参数测量装置，该装置能够**识别出给定信号的波形类型**，并**测量信号的参数**。

任务定义里两个动作：**识别 + 测量**——**前者输出"类型"** —— **后者输出"数字"**。

### 基本要求 (1)：识别三种波（21 分）

> 能够识别 **1V≤VPP≤5V、100Hz≤f≤10kHz** 范围内的**正弦波、三角波和矩形波**信号，并显示类型。（21 分）

**21 分** —— **基本要求最大头**——**核心是"能不能正确识别"**。

**前面已经讲过**——**统计特征 + FFT 谐波分析**——**99% 识别率**——**满分**。

### 基本要求 (2)：频率 ±1%（12 分）

> 能够测量并显示信号的**频率 f**，相对误差的绝对值**不大于 1%**。

**±1% 频率精度** —— **整周期 FFT + 抛物线插值** —— **能压到 ±0.05%**：

```
插值频率 f_精 = f_粗 + (k-1)/2 × Δf  
其中 k = (s[m+1] - s[m-1]) / (2·s[m] - s[m-1] - s[m+1])
```

**这个式子说的其实是**——**'**用峰值附近 3 个 FFT bin 的幅值，二次插值精确定位频率**'**——**精度比单纯找最大 bin 高 100 倍**。

12 分稳拿。

### 基本要求 (3)：Vpp ±1%（12 分）

> 能够测量并显示信号的**峰峰值 VPP**，相对误差的绝对值**不大于 1%**。

**±1% Vpp 精度** —— **去野点 + 校准** —— **能压到 ±0.3%**。

12 分稳拿。

### 基本要求 (4)：占空比 ±2%（5 分）

> 能够测量并显示**矩形波信号的占空比 D**，D 的范围为 **20%~80%**，绝对误差的绝对值**不大于 2%**。

**前面已经讲过过阈值法**——**精度 0.1%**——**满分**。

### 发挥 (1)：扩量程 50mV~10V/1Hz~50kHz（30 分）

> 能够识别 **50mV≤VPP≤10V、1Hz≤f≤50kHz** 范围内的正弦波、三角波和矩形波信号。（30 分）

**前面已经讲过 PGA + 自适应采样率**——**国一 30 分稳拿**。

### 发挥 (2)：反应时间 < 3 秒（9 分）

**前面已经讲过 1.03 秒最慢**——**满分**。

### 发挥 (3)：增加 3 种波形 + 3 个参数（6 分）

**前面已经讲过锯齿 / 梯形 / 半正弦 / THD / DC offset / RMS**——**满分**。

### 发挥 (4)：其他（5 分）

**5 分自由发挥**：

- **触摸屏交互**——**2 分**
- **历史数据存储**——**3 分**
- **远程通信（蓝牙 / WiFi）**——**3 分**
- **自动校准**——**5 分**

**国一队伍**：**做 2~3 项**——**5 分稳拿**。

### 说明里的暗坑

> **被测信号由函数发生器产生**。**测量精度以函数发生器输出显示为基准**，测试时**函数发生器自带**。**反应时间从函数发生器输出信号至装置时开始计时**。

三个关键约束：

1. **必须自带函数发生器**（**Tektronix / Rigol / Siglent 都行**）
2. **以函数发生器读数为真值**（**校准时要把函数发生器的精度也考虑进去**）
3. **反应时间从信号到达开始算**——**意味着必须有"信号检测启动"** 机制——**接到信号后立即开始采样**

**对策**：**ADC 一直跑、检测到信号 > 阈值时启动识别**：

```c
while (true) {
    if (signal_detected(adc_buffer)) {
        timestamp_start = get_time();
        recognize_and_measure();
        display_results();
        timestamp_end = get_time();
        reaction_time = timestamp_end - timestamp_start;
    }
}
```
