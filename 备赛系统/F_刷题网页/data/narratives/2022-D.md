## 想象一个场景

夏天傍晚，你在阳台上点了一支烟。**烟从烟头升起一瞬——直直一根白烟柱**——**升到 30 厘米高时**——**烟柱开始扭曲**——**先是慢慢左右晃**——**晃到 60 厘米**——**突然"散花"**——**变成一团乱七八糟的烟雾**——**完全看不出规律**。

**这是混沌**。

**烟柱前 30 厘米的"直线"**——**是确定性的层流**——**完全可预测**。  
**60 厘米后的"散花"**——**仍然是确定性的物理（牛顿方程描述）**——**但人类已经无法预测**——**这就是"混沌"**——**确定性系统产生的不可预测行为**。

**生活中处处都是混沌**：

- **天气**：**蝴蝶在巴西扇翅膀 → 美国一个月后下大雨**——**蝴蝶效应的"原型"**
- **股市**：**1929 年大萧条、2008 年次贷危机、2020 年熔断**——**所有"系统"** 突然崩盘
- **心律失常**：**正常心电图突然变成"颤动"**——**心室颤动是混沌**
- **激光器输出**：**普通激光是稳定单频，半导体激光高功率时输出混沌**
- **电网谐波**：**整流器在临界点的"分岔"** —— **谐波突然爆增**

**为什么要研究混沌**？

- **加密通信**：**用混沌信号当"载波"** —— **没有钥匙的人解码不了**——**保密强度比 RSA 还高**
- **混沌雷达**：**敌方无法识别"混沌雷达"** 的发射波形——**军用反隐身**
- **疾病预警**：**心电图开始"分岔"** = **心室颤动前兆**
- **金融预警**：**指数突然进入"混沌"** = **崩盘前兆**

**全球混沌科学产业大约 50 亿美元**——**中国有"南京大学吴可教授团队"** 在做混沌通信芯片**——**未来 10 年市场翻 10 倍**。

> **小白补课**：什么是"涡旋（Scroll / Vortex）"？
> - **数学上**：**相空间（X-Y 平面）中信号绕着一个"焦点"** 旋转——**不是完美闭合的圆**——**而是螺旋形向外或向内**

## 这题在做的事，其实是把数学方程变成实物电路

混沌的数学起源是一个**三阶非线性常微分方程组**：

```
dx/dt = α [y - x - f(x)]
dy/dt = x - y + z
dz/dt = -β y - γ z

其中 f(x) 是非线性函数（蔡氏二极管特性）：
f(x) = m1·x + (1/2)(m0 - m1)(|x + Bp| - |x - Bp|)
```

**这个方程组说的其实是**——**'**三个变量 x、y、z 互相影响、+ 一个非线性元件 f(x)**'**——**只要参数 α、β、γ、m0、m1、Bp 选得对**——**信号就会从"稳定振荡"** 变成"混沌"**。

**'**怎么把这个方程变成实物电路**'**？**用积分器 + 加法器 + 非线性元件**：

```
变量 x → 电容 C1 上的电压 v1
变量 y → 电容 C2 上的电压 v2  
变量 z → 电感 L 中的电流 iL（或回转器代替）

dx/dt → 电容 C1 上的电流 iC1
dy/dt → 电容 C2 上的电流 iC2
dz/dt → 电感 L 上的电压 vL

非线性 f(x) → 蔡氏二极管（两个反向并联的二极管 + 运放折线）
```

**这个对应说的其实是**——**'**数学变量 = 电路变量**'**——**积分器 = 电容、加法器 = 运放、非线性 = 二极管折线**——**任何方程都能变成电路**。

**这就是"电路理论 = 微分方程"** 的精髓——**模拟电路本质上是"用电子元件求解微分方程"**——**比数字电路（用 MCU 求解）便宜 100 倍**。

**全题难点**：

| 模块 | 难度 | 核心技术 |
|---|---|---|
| **稳定周期相图（单 / 双 / 三倍）** | ★★ | 调电阻参数 |
| **单 / 双涡旋混沌** | ★★★ | 调到混沌临界点 |
| **40 MHz 带宽** | ★★★★★ | 高速运放 + PCB |
| **不用电感（回转器）** | ★★★★ | 运放模拟电感 |
| **运放 ≤ 6 个** | ★★★★ | 电路压缩 |

接下来一层一层揭开它的谜。

## 第一个谜：蔡氏电路最朴素的接法

**经典蔡氏电路**：**3 个储能元件（C1、C2、L）+ 2 个电阻（R、R0）+ 1 个非线性元件（蔡氏二极管 NR）**：

```
        ┌──[R]──┐
        │       │
      ┌─┴─┐   ┌─┴─┐
      │C1 │   │C2 │
      │   │   │   │
      │   │   │   │
      └─┬─┘   └─┬─┘
        │       │
        ▼       ▼
        ▶ NR   ▶─[R0]─[L]── 接地
       （蔡氏
       二极管）
```

**这是最简朴的版本**——**1983 年蔡少棠的原始电路**——**6 个元件就能产生混沌**。

**'**蔡氏二极管**'** 是什么？**两个反向并联的肖特基二极管 + 运放折线特性**——**一段三段式电压电流曲线**：

```
i = f(v)：

       i
       │
       │     ╱
       │    ╱     ← 斜率 m1（正区）
       │___╱
       │  ╱│
       │ ╱ │      ← 斜率 m0（中区，负斜率！）
   ────┼───┼──── v
       │   ╱
       │  ╱│      ← 斜率 m1（负区）
       │ ╱ │
       │╱
```

**'**中区斜率 m0 < 0**'** 是关键——**意味着"电压增加电流减少"** —— **这就是"负电阻"** —— **混沌产生的源头**。

**怎么用运放做"负电阻"**？

**经典电路**——**两个运放 + 6 个电阻**：

```
         ─[R3]─┐
        │      │
        ▼      │
    +───────────┐
    │   OPA1   │
    │     ────│──[R5]──┐
    └─────────┘         │
         │              │
        [R4]           [R7]
         │              │
         └──[R6]── OPA2 ┴── v_out
```

**这是 1990 年代电赛模拟工程师的"基本功"** —— **运放折线生成器** —— **任何模拟电路工程师都该会**。

**第一笔账：参数选取**

经典蔡氏参数（标准教科书）：

```
C1 = 10 nF
C2 = 100 nF
L = 18 mH
R = 1.5~2 kΩ（可调，控制振荡 / 混沌切换）
R0 = 0
m0 = -0.76 mS（负斜率）
m1 = -0.41 mS（正斜率）
Bp = 1.0 V（折线断点）
```

**通过调 R**：**1.5kΩ → 单倍周期，1.7kΩ → 双倍，1.85kΩ → 双涡旋混沌**。

**这就是"分岔"** ——**参数缓慢变化时**，**系统从单周期 → 双周期 → 四周期 → 混沌**——**这是非线性动力学的"周期倍增分岔"**。

**第二笔账：振荡频率**

蔡氏电路的振荡频率：

```
f = 1 / (2π × √(L × C2))
  = 1 / (2π × √(0.018 × 100e-9))
  = 1 / (2π × 4.24e-5)
  ≈ 3.75 kHz
```

**'**3.75 kHz**'** 是经典蔡氏电路的工作频率——**音频范围**——**普通运放（带宽 1MHz）完全够用**。

**国一队伍**：**经典蔡氏 + LM358 运放（0.5 元 / 个）**——**6 个元件 + 2 个运放**——**做出 5 种相图**——**34 分稳拿**。

## 第二个谜：怎么把带宽提到 40 MHz

要求 2：**双涡旋混沌信号带宽 ≥ 40 MHz**——**30 分**——**真正的难点**。

**40 MHz 是什么概念**？

**经典蔡氏电路工作在 3.75 kHz**——**40 MHz 是它的 10000 倍**——**意味着**：

```
所有储能元件的值要除以 10000：
C1: 10 nF → 1 pF
C2: 100 nF → 10 pF
L: 18 mH → 1.8 μH

工作频率：
f = 1 / (2π × √(1.8e-6 × 10e-12)) ≈ 37.5 MHz ✓
```

**'**1 pF 电容**'** 是什么概念？——**比 PCB 走线本身的"杂散电容"** 还小——**几乎做不出**。

**对策**：**把目标频率定在 30~40 MHz 之间**——**用 5 pF 电容 + 较小电感**——**勉强可行**。

**第一笔账：高速运放选型**

工作频率 40 MHz——**运放的"单位增益带宽"** 必须 ≥ 100 MHz（**留 2~3 倍余量**）：

| 运放 | 带宽 | 价格 | 评价 |
|---|---|---|---|
| **LM358** | 1 MHz | 0.5 元 | **40 MHz 完全不行** |
| **NE5532** | 10 MHz | 2 元 | **不够** |
| **LM6172**（单运放）| 100 MHz | 15 元 | 边缘可用 |
| **AD8055** | 300 MHz | 30 元 | **国二常用** |
| **LMH6628** | 220 MHz | 35 元 | 高速版 |
| **THS3491** | 900 MHz | 80 元 | **国一首选** |

**国一队伍**：**THS3491**（**900 MHz BW**）—— **40 MHz 工作完全无压力**——**有大余量**。

**坑**：**LM358 在 40 MHz 工作下"发瓷"——输出严重失真——双涡旋变形——直接 0 分**。

**第二笔账：PCB 高速布局**

40 MHz 信号的"波长"** 在空气中是 7.5 米——**在 FR4 PCB 中约 4 米**——**只要 PCB 走线 < 40 cm 就不需要传输线设计**——**电赛尺寸完全够**。

**但是 EMI 问题严重**：

- **走线交叉 → 串扰**——**双涡旋"花掉"** 看不出来
- **地平面不完整 → 共模噪声**——**"噪声涡旋"覆盖真实信号
- **运放电源去耦 → 自激振荡**——**信号变成"啸叫"**

**对策**：

- **4 层 PCB**（**信号 / 地 / 地 / 信号**）—— **完整地平面**
- **运放电源每路加 0.1μF + 10μF 双重去耦**
- **关键信号走差分对**——**抗噪声**
- **shortest path 原则**——**电容 + 运放 + 二极管尽量挨近**

**国一队伍**：**4 层 PCB + 高速运放 + 仔细布局**——**40 MHz 双涡旋清晰**——**满分 30**。  
**国二**：**双层 PCB + AD8055**——**30 MHz 边缘**——**18~25 分**。  
**国三**：**万能板手工焊 + LM358**——**信号变形 + 0 分**。

## 第三个谜：怎么"不用电感"——回转器（Gyrator）

**要求 3：仅用电阻、电容、运算放大器，不使用电感**——**20 分**。

**为什么要"不用电感"**？

- **电感占空间大**（**比电容大 5~10 倍**）
- **电感不可调**（**电容能调电压**）
- **电感容易引入磁场干扰**（**和电源 / 电机互扰**）
- **电感不便于集成**（**IC 无法集成电感**）

**真实工业场景**：**所有"芯片化"的电路都不用电感**——**用"有源电感"** 替代——**这是 IC 设计的基本功**。

**'**有源电感（Active Inductor）**'** 怎么做？

**核心电路**——**回转器（Gyrator）**：**用 2 个运放 + 4 个电阻 + 1 个电容**——**等效成一个电感**：

```
等效电感值：L = R1 × R2 × C / R3
```

**这个公式说的其实是**——**'**电容值 + 电阻比例 = 电感值**'**——**通过调电阻就能调"电感"**——**远比真电感方便**。

**回转器的电路图**（Tow-Thomas 拓扑）：

```
v_in ──[R1]──┐                    
              ▼              
        ┌─OP1─┐              
        │     │ ──[R2]──┐    
        └─────┘          ▼    
                    ┌─OP2─┐ ──[R3]── v_out
                    │     │
                    └──┬──┘
                       │
                      [C]
                       │
                      GND
```

**这是 1965 年发明的经典电路**——**任何模拟电路教材都有**——**至今广泛用于"芯片化滤波器"**。

**第一笔账：回转器替代电感的精度**

| 频率 | 真实电感（18mH 电感）| 回转器（等效 18mH）|
|---|---|---|
| 1 kHz | Q = 100，损耗低 | Q = 50，损耗中等 |
| 10 kHz | Q = 80 | Q = 30 |
| 100 kHz | Q = 50 | Q = 20 |
| 1 MHz | Q = 30 | Q = 5（运放带宽不够）|
| 40 MHz | Q = 10 | **几乎不能用** |

**'**回转器的高频性能受运放带宽限制**'** —— **40 MHz 对运放要求极高**——**用 THS3491 这种 900 MHz 运放才能勉强工作**。

**国一队伍**：**THS3491 × 2 个运放 + 4 个电阻 + 1 个电容 = 等效电感**——**40 MHz 双涡旋仍然能做**——**20 分稳拿**。

**第二笔账：回转器对蔡氏电路的影响**

**用回转器替换电感后**，蔡氏电路变成**纯运放 + RC** 实现：

```
原始：1 个电感 + 蔡氏二极管（4 个运放）= 4 个运放
新版：回转器（2 个运放）+ 蔡氏二极管（4 个运放）= 6 个运放
```

**'**6 个运放**'** 正好等于要求 4 的"上限"——**精确匹配**。

## 第四个谜：怎么把运放压到 6 个以内

**要求 4：运放总数 ≤ 6 个**——**10 分**。

**经典实现**：**蔡氏二极管（4 运放）+ 回转器（2 运放）= 6 运放**——**正好 10 分**。

**怎么进一步压缩**？

**对策 1：用单个运放实现折线（蔡氏二极管简化版）**

```
单运放 + 2 个二极管 + 4 个电阻 = "折线生成器"
```

**精度比 4 运放版差 5%**——**但运放数量从 4 降到 1**——**省 3 个**。

**对策 2：三运放回转器（更高性能但占运放）**

不推荐——**运放更多**。

**对策 3：用单个运放同时做"加法 + 积分"**

```
单运放 + 2 个电容 + 4 个电阻 = "积分器 + 加法器"
```

**这是"运放复用"** 的高级技巧——**模拟工程师的"绝技"**。

**国一队伍最终方案**：**4 运放（蔡氏二极管）+ 2 运放（回转器）= 6 运放**——**满分 10**。  
**或者**：**2 运放（简化二极管）+ 2 运放（回转器）+ 1 运放（缓冲）= 5 运放**——**满分 10 + 加印象分**。


## 第五个谜：怎么调出 5 种不同相图

**要求 1：依次产生 5 种相图**——**34 分**——**核心**。

**5 种相图的本质**——**同一个电路、不同参数、不同行为**：

| 相图类型 | 调谁 | 典型 R 值（蔡氏电路）|
|---|---|---|
| **单倍周期** | 调 R 接近振荡临界 | R = 1.40 kΩ |
| **双倍周期** | R 进一步增大 | R = 1.65 kΩ |
| **三倍周期** | R 进一步增大 | R = 1.78 kΩ |
| **单涡旋混沌** | R 在分岔区 | R = 1.85 kΩ |
| **双涡旋混沌** | R 跨过临界 | R = 2.00 kΩ |

**这就是"周期倍增分岔到混沌"** 的经典路径——**蔡氏电路的"教科书演示"**。

**'**编程设置或开关选择**'** 怎么做？

**方案 A：电子开关（CD4051）切换不同电阻**

```
单片机 → CD4051 → 5 个不同电阻
        通过选通信号选不同 R 值 → 不同相图
```

**简单可靠**——**但单片机要负责切换 + 电赛允许（题目说"编程设置或开关选择"）**。

**方案 B：数字电位器（MCP41010）**

```
单片机 → SPI → MCP41010（256 级电阻）→ 蔡氏电路
        编程设置任意阻值 → 任意相图
```

**精细可调**——**适合做实验时找最佳混沌点**。

**方案 C：纯硬件开关（拨码开关）**

```
拨码开关 → 选 1 / 2 / 3 / 4 / 5 → 选不同电阻
```

**最简单**——**不用 MCU**——**但不够"高级"**。

**国一选择**：**方案 A 或 B**——**MCU + 电子开关**——**自动切换 5 种相图**——**满分 34**。

**第一笔账：示波器 X-Y 模式显示相图**

**'**相图**'** = **X-Y 模式**——**不是普通的"电压随时间变化"** 图——**而是"v1 横轴 + v2 纵轴"** 的"轨迹图"**。

```
普通示波器 Y-T 模式：横轴时间，纵轴电压
X-Y 模式：横轴 = v1，纵轴 = v2，没有时间
```

**测试现场**：**评委用示波器 X-Y 模式接你的电路**——**看屏幕上的"相图"** 是什么样**。

**正确连法**：

```
通道 1（X 输入）→ 电容 C1 上的电压 v1
通道 2（Y 输入）→ 电容 C2 上的电压 v2
示波器模式 → X-Y 模式
```

**坑**：**说明 (3) 强调"接入示波器进行相图显示时，不得影响信号产生电路的工作状态"**——**意味着不能直接接示波器探头（探头有 1MΩ 输入阻抗 + 几 pF 电容**——**会影响 40 MHz 高频电路**）。

**对策**：**加一级"缓冲放大器"** —— **运放跟随器**——**让示波器看到"信号副本"** 而不是直接负载电路：

```
v1 ──[运放跟随器 OPA1]── 示波器 X
v2 ──[运放跟随器 OPA2]── 示波器 Y
```

**'**运放跟随器**' 输入阻抗高（>1 MΩ）+ 输出阻抗低（<10Ω）**——**完美隔离**——**示波器看到信号但不影响电路**。

**这两个跟随器要算在"运放总数"** 里——**6 - 2 = 4 个运放给主电路**——**进一步压缩了空间**。

## 把题目逐条翻译一遍

### 任务那段话

> 使用**电阻、电容、电感和运算放大器**设计一个能生成稳定周期信号和混沌信号的信号产生实验装置，**装置采用单电源供电**。

任务核心：

- **元件限制**：**只能用 R、C、L、运放**——**不允许 MCU 主导信号生成**（**MCU 只能切换参数**）
- **单电源供电**：**比双电源（±12V）难一档**——**需要做"虚拟地"** —— **运放工程师常用技巧
- **多种信号**：**周期 + 单涡旋 + 双涡旋**——**通过参数切换实现**

### 要求 1：5 种相图（34 分）

> 通过编程设置或开关选择，控制实验装置产生稳定周期信号和混沌信号，**依次生成下列相图信号**。

**前面已经讲过 R 值切换 + CD4051 / 数字电位器**——**国一 34 分稳拿**。
