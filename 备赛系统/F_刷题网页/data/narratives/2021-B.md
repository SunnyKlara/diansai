## 想象一个场景

夏天最热那几天，下午三点，城市电网压力达到峰值。这一刻，你家附近的小区供电变压器正在散发烫手的热量——10kV 高压送进来，380V/220V 三相低压送出去。**这种场景每秒钟都在发生在中国 800 万台分布式变压器上**。

把镜头拉近——拉到楼下小卖部冰柜的角落。冰柜里有一台 200W 的小型不间断电源（UPS），它的'**输入端**'插在 220V 墙插上，'**输出端**'接着冰柜的压缩机。**这台 UPS 此刻的功率因数是 0.6**——意思是说，**它从电网吸 200W 真实功率的同时，还吸了 270W 的'**无功功率**'**——这部分无功功率根本不做功，**只是在 UPS 和电网之间来回'**振荡**'**——但电网的铜线、变压器的铁芯，**都得为这部分'**无效能量**' 付出热量代价**。

整个城市每个角落都有这种'**功率因数低**'的设备——空调、冰柜、节能灯、充电器、电脑电源、电梯——**它们集体让电网每年浪费的电能高达 8000 亿度**——**相当于三峡水电站全年发电量的 8 倍**。

**电网公司怎么办**？两个办法：**罚款 + 强制改造**。

国标 GB/T 14549-93 规定：**任何接入公网的设备，功率因数必须 ≥ 0.9**——**低于 0.85 罚款 5%~10%**——**低于 0.7 直接断电**。这意味着任何'**普通 AC-DC 整流器**'——包括最便宜的 380V 工业电源——**都必须'**主动**'把功率因数拉到 0.9 以上**——**否则没法卖**。

**怎么把'**普通整流器**' 变成'**高功率因数整流器**'**？这就是 2021 B 题让你做的事——**做一台三相 AC-DC 变换电路，把功率因数从'**典型值 0.5**' 拉到'**电网友好的 0.99**'**——**同时还要把效率从'**普通 75%**' 拉到'**国一级别的 95%**'**。

这一题做完，你就摸到了**电力电子工程师入门最深的那道槛**——**'**功率因数校正（PFC）**'**——**这个技术撑起了从快充头到数据中心机房的整个工业产业链**。

> **小白补课：功率因数到底是什么**
> - 把电网想象成水管。**真实功率（P）** 是真正从你家流出去做功的水（开洗衣机、烧热水）；**无功功率（Q）** 是水管里来回振荡但没出去的水（被电感、电容来回吸收和释放）；**视在功率（S）** 是水管承担的总流量（包含两种水）。
> - **功率因数（PF）= P / S = cosφ**——**φ 是电压和电流的相位差**。
> - **PF = 1 时**，电压电流同相位，**全部能量做功，电网最舒服**。
> - **PF = 0.6 时**，电压电流相位差 53°，**只有 60% 能量做功，剩下 40% 在'**振荡**'**。
> - 工业空调常见 PF = 0.7，节能灯常见 PF = 0.5，**电网公司见到这种设备就头疼**。

## 这题在做的事，其实是把电网的'**坏脾气**' 治好

把图 1 简化一下：

```
三相 AC 输入（线电压 28V）
    ┌─── A 相 ───┐
    ├─── B 相 ───┤
    └─── C 相 ───┘
            │
            ▼
    [三相调压变压器 + 隔离变压器]
            │
            ▼
    [AC-DC 变换电路]  ←── PFC 控制器
            │
            ▼
    直流输出（36V / 2A）
            │
            ▼
        负载（电阻）
```

**输入端**：三相调压变压器（输入 380V，可调输出 28V 线电压）+ 三相隔离变压器（隔离原副边，保安全）。**这两台设备由学校提供 / 实验室自带**——**不算在你的作品里**。

**核心装置**：**AC-DC 变换电路** + **PFC 控制器** + **直流辅助电源**——**这是你要做的部分**。

**输出端**：负载电阻（**36V / 2A = 72W 功率**——**18Ω 大功率电阻**——**实验室常用 50W~100W 水泥电阻**）。

**你的作品要做到三件事**：

**事情 1：稳定输出 36V / 2A**——**不管输入电压（23~33V）和负载电流（0.1~2A）怎么变，输出都死死锁在 36V**——**这是稳压能力**。

**事情 2：从电网吸的电流是干净的正弦**——**功率因数 ≥ 0.99**——**这意味着输入电流必须**：

- **波形是纯正弦**（不能是方波或者锯齿波）
- **相位和电压相同**（不能滞后或超前）
- **没有高次谐波**（THD < 5%）

**事情 3：能量损耗少**——**95% 的电能要送到负载**，**只有 5% 允许变成热**——**这是效率要求**。

**为什么这三件事这么难**？

因为'**最简单的三相整流器**'（三相不控整流桥）**只能做到**：

- 输出电压：跟随输入波动，不稳
- 功率因数：典型 0.5~0.7（电流是脉冲状）
- 效率：85%~88%（二极管压降 + 变压器损耗）

**要让它'**稳压 + PFC + 高效**'**——**必须把'**不控整流**' 升级成'**有源整流**'**——**这就是 PFC 整流器**。

> **小白补课：什么是 PFC 整流器**
> - **不控整流**（被动）：6 个二极管搭一个桥，**电流被动地跟随电压**——**电流波形是脉冲状（上升时充电、下降时不导通）**——**功率因数低**。
> - **PFC 整流**（主动）：在二极管桥后加 **MOSFET 高频开关 + 电感**——**通过 PWM 调制让电流波形主动跟随电压波形**——**功率因数能拉到 0.99+**。
> - 一句话：**PFC = 让电流'**主动模仿**' 电压**——**所以也叫'**有源功率因数校正**'**。

**这道题在做的事，用一句话讲完**——**做一台'**会主动模仿电压波形**' 的整流器**——**让电网公司不再头疼**。

接下来一层一层揭开它的谜。

## 第一个谜：为什么不控整流的功率因数只有 0.5

**最最最简单的'**三相 AC-DC**' 怎么做**？——**6 个二极管搭一个桥**——**学过《电力电子》第一章的人都会**。

```
A 相 ──[D1]──┐         ┌──[D4]── A 相
             │         │
B 相 ──[D2]──┤  Uo +  ├──[D5]── B 相
             │         │
C 相 ──[D3]──┘    -    └──[D6]── C 相
```

**这就是三相不控整流桥**——**输出端接电容 C + 负载 R**。

**问题来了——为什么这种最简单的整流器功率因数只有 0.5**？

**答案藏在'**电流波形**' 里**。

**正常情况**——**整流桥的负载是纯电阻 R**——**电流和电压同相、波形相同**——**功率因数应该接近 1**。

**但是实际负载是'**电容 C + 电阻 R**'**（**电容滤波让输出电压平滑**）——**问题就出在这个 C 上**。

电容工作机理：

- **电压上升时**——**C 充电 → 电网必须供大量电流 → 电流脉冲尖**
- **电压下降时**——**C 放电给负载 → 电网不供电 → 电流为 0**

**电网看到的电流波形**——**不是正弦**——**是一个个尖锐的'**充电脉冲**'**——**像图：**

```
    电压（正弦）    ───╱╲───╱╲───╱╲───
                       
    电流（脉冲）   ─┐ ┌─┐ ┌─┐ ┌─┐ ┌─
                   │ │ │ │ │ │ │ │
                   ┘ └─┘ └─┘ └─┘ └─
```

**这种'**脉冲电流**'** 用傅里叶分解一下，**含有大量奇次谐波**（**3 次、5 次、7 次……**）。

按 IEC 61000-3-2 标准计算，这种电流波形对应的**功率因数 PF ≈ 0.5~0.65**——**THD 高达 80%~120%**——**电网公司一看就皱眉**。

**第一笔账：功率因数 0.5 意味着什么**

```
PF = P / S = 0.5
S = P / 0.5 = 2P
```

**这个式子说的其实是**——**'**要给负载送 1kW 真实功率，电网必须供 2kVA 视在功率**'**——**电网铜线和变压器要按 2kVA 选型**——**成本增加一倍**。

**举个具体例子**：你家小卖部冰柜功率 200W，PF = 0.5——**电网必须按 400VA 给你供电**——**铜线粗一倍、变压器贵一倍**——**电网公司当然要罚款**。

**第二笔账：PF 高怎么办？答案是 PFC**

**PFC（Power Factor Correction，功率因数校正）的核心思想**——**强行让电流跟随电压**——**让电流波形从'**脉冲**' 变回'**正弦**'**：

```
    电压        ───╱╲───╱╲───╱╲───
                      ↓ 跟随
    电流（PFC）  ───╱╲───╱╲───╱╲───  ← 干净正弦
```

**怎么做到**？**核心三件套**：

1. **MOSFET 高频开关**（50kHz~200kHz）——**让电流可以被'**主动塑形**'**
2. **PFC 升压电感 L**——**储能元件，把脉冲电流'**摊平**'**
3. **PFC 控制器**（数字或模拟）——**实时计算 PWM 占空比**

**控制目标**：

```
电流参考 i_ref(t) = (P_demand / V_ac_RMS²) × v_ac(t)
                ↑                            ↑
           '**幅值**'                  '**形状（正弦）**'
```

**这个式子说的其实是**——**'**电流参考 = 功率需求 / 电压有效值² × 瞬时电压**'**——**这样电流就和电压同相同形**——**功率因数 = 1**。

> **小白补课**：
> - **MOSFET（金属氧化物半导体场效应管）**：高频开关器件，**能在 1μs 内开关 100A 大电流**——**PFC 的'**心脏**'**。
> - **升压电感**：把电流'**储能 + 释放**'，让电流波形可控。**电感越大，电流越平滑，但响应越慢**——**典型 1mH（适合 100kHz 开关频率）**。
> - **占空比（Duty Cycle）**：MOSFET 一个开关周期里'**导通时间**' 的占比。**占空比变 → 升压比变 → 输入电流变**。

## 第二个谜：三相 PFC 拓扑怎么选

**三相 PFC 整流器有 4 种主流拓扑**——**每种都有自己的脾气**。**作为电赛队伍，你必须从中选一种**——**这是真正的胜负手**。

**拓扑 1：三个独立 Boost PFC（最简单）**

每相一个独立的 Boost PFC，三个 PFC 并联：

```
A 相 ──[D]──[L]──[Q]──┬── DC+
B 相 ──[D]──[L]──[Q]──┤
C 相 ──[D]──[L]──[Q]──┴── DC-
```

**优点**：**控制简单**——**每相独立控制**——**不需要复杂的三相同步算法**。

**缺点**：**需要 3 个独立电感 + 3 个独立 MOSFET + 3 套独立驱动**——**成本高**——**效率较低（每相都有独立的开关损耗）**。

**适合**：**电赛入门队伍**——**4 天能调通**。**典型效率 88%~91%**。

**拓扑 2：三相六开关 PWM 整流（VSR，Voltage Source Rectifier）**

最经典的三相 PFC——**6 个 MOSFET 搭成 H 桥**：

```
       ┌───[Q1]───┬───[Q3]───┬───[Q5]───┐
       │          │          │          │
A ─────┤    L1    │    L2    │    L3    │── DC+
B ─────┤          │          │          │
C ─────┤          │          │          │
       │          │          │          │── DC-
       └───[Q4]───┴───[Q6]───┴───[Q2]───┘
```

**优点**：**双向能流**（**整流 + 逆变都能做**）——**控制成熟**——**效率 92%~94%**。

**缺点**：**控制复杂（需要 SVPWM 调制 + dq 坐标变换）**——**6 个 MOSFET 同步驱动难度高**。

**适合**：**电赛中级队伍**——**有过 STM32 + SVPWM 经验的队伍**。**典型效率 92%**。

**拓扑 3：Vienna 整流器（三电平）**

**Vienna 是三相 PFC 的'**明星拓扑**'**——**只用 3 个 MOSFET + 6 个二极管**——**比六开关少用一半 MOSFET**：

```
       ┌──[D1]──┐                  ┌──[D2]──┐
       │        │                  │        │
A ─────┤   L    ├──[Q]──┬─[D]─┐    │        │
B ─────┤        │       │     ├────┤        │
C ─────┤        │       │     │    │        │
       └──[D3]──┘       │     │    └──[D4]──┘
                        │     │
                       DC+   DC-
```

**优点**：

- **MOSFET 只有 3 个，效率最高（94%~97%）**
- **三电平输出，电感纹波小（电感小一半）**
- **共模电压低，EMI 友好**
- **没有'**直通风险**'（六开关有上下管短路风险）**

**缺点**：

- **二极管多，反向恢复损耗大**
- **控制相对复杂（电感电流不连续模式）**
- **不能逆变（单向能流）**

**适合**：**电赛国一队伍**——**有过 PFC 实操经验**。**典型效率 95%**——**完美匹配本题 95% 效率要求**。

**拓扑 4：T 型三电平整流**

把 Vienna 升级——**用 3 个双向开关替代二极管**：

```
A ──[L]──┬──[Q1+]──[D1]──┬── DC+
         ├──[Q1-/Q2-]────┤── 中点
B ──[L]──┼──[Q2+]──[D2]──┤
         │               │── DC-
C ──[L]──┴──[Q3+]──[D3]──┘
```

**优点**：**最高效率 96%~97.5%（减少二极管损耗）**——**双向能流**——**适合 380V 高压**。

**缺点**：**控制最复杂**——**需要专用 IC（如 TI UCC28630）**——**成本高**。

**适合**：**电赛顶级队伍**——**有过工业 PFC 经验**——**或者电源工程师子女**。

**国一队伍的选型决策树**：

```
电赛要求 PF ≥ 0.99 + 效率 ≥ 95% ?
  ├── 是 → Vienna 整流（最佳性价比）
  └── 否 → 三个独立 Boost（简单稳）
```

**国二队伍**通常选**'**三个独立 Boost**' + 软件 PFC**——**效率 88%~91%**——**功率因数 0.95~0.98**——**勉强满足基本要求 + 部分发挥分**。

**国一队伍**几乎都选 **Vienna**——**效率 95%+**——**功率因数 0.99+**——**满分**。

## 第三个谜：升压电感怎么算

**Vienna PFC 的核心元件**——**升压电感 L**——**它决定了**：

- **开关频率**（频率越高，电感越小）
- **电流纹波**（电感越大，纹波越小）
- **效率**（电感损耗占总损耗 10%~20%）

**怎么算 L 的合适值**？

**第一笔账：基本公式**

```
L = (Vin × D) / (fs × ΔIL)
```

**这个式子说的其实是**——**'**电感值 = 输入电压 × 占空比 / (开关频率 × 电流纹波)**'**。

各参数取值：

- **Vin = 28V × √2 / √3 = 22.86V**（**线电压 28V → 相电压峰值**）
- **D = 1 - Vin/Vout = 1 - 22.86/72 = 0.683**（**Vout = 36V × 2 = 72V**——**Vienna 是三电平输出**）
- **fs = 50kHz**（**典型 PFC 开关频率**）
- **ΔIL = 30% × Iin = 30% × 4A = 1.2A**（**纹波 30% 是工程经验**）

代入计算：

```
L = (22.86 × 0.683) / (50000 × 1.2)
  = 15.61 / 60000
  = 0.26 mH
  = 260 μH
```

**这个式子说的其实是**——**'**为了让电流纹波控制在 30% 以内，电感至少 260μH**'**——**实际取 1mH 留余量**。

> **小白补课**：
> - **'**纹波 30%**' 是什么意思**：**电感电流不是恒定的，会有上下波动 ΔIL**——**'**纹波 = ΔIL / Iin**' = 30% 是工业 PFC 的经验值**——**纹波过大会让 EMI 严重，纹波过小则电感太大太贵**。
> - **'**Vienna 三电平输出**'**：Vienna 整流器输出端有'**正轨 + 中点 + 负轨**'——**三个电平**——**所以 Vout 是 72V（正负轨之间）而不是 36V**。

**第二笔账：电感的物理设计**

电感 L = 1mH，电流 5A，**要选什么材料**？

**磁芯选型**：

| 材料 | 饱和磁通密度 | 损耗 | 适合频率 | 价格 |
|---|---|---|---|---|
| **硅钢** | 1.5T | 高 | < 1kHz | 便宜 |
| **铁氧体** | 0.4T | 低 | 50kHz~1MHz | 中 |
| **铁粉芯（MPP）** | 0.7T | 中 | 50kHz~100kHz | **PFC 首选** |
| **非晶 / 纳米晶** | 1.2T | 极低 | 50kHz~500kHz | 贵 |

**Vienna PFC 50kHz**——**铁粉芯（MPP / 高磁通密度铁粉芯）是首选**——**饱和磁通 0.7T、损耗低、价格适中**。

**绕线计算**：

```
N = (L × Imax) / (Bsat × Ae)
  = (0.001 × 6) / (0.5 × 0.0001)
  = 120 匝
```

**这个式子说的其实是**——**'**N = LI / BA**'**——**1mH 电感配 6A 峰值电流，需要 120 匝绕线**。

**铜线选型**：

```
导线截面 = Imax_RMS / 电流密度
        = 4A / 4 A/mm²
        = 1 mm²
```

对应**线径 1.13mm 单股漆包线** 或 **0.6mm × 4 股利兹线**（**抑制趋肤效应**）。

**'**利兹线**' 是什么**？——**多股细线编织绞在一起**——**抑制高频电流的'**趋肤效应**'**——**让电感损耗降低 30%**——**国一队伍的标配**。

**第三笔账：饱和余量**

电感设计完后必须验证**饱和余量**：

```
B_max = (L × Imax) / (N × Ae)
      = (0.001 × 6) / (120 × 0.0001)
      = 0.5 T
```

**0.5T < 0.7T 饱和**——**有 40% 余量**——**安全**。

**如果余量不足**——**电感会在大电流时'**饱和**'**——**电感值急剧下降**——**电流尖峰冲击 MOSFET**——**炸机**。

**国一队伍的做法**——**饱和余量留 50%**——**永不炸机**。


## 第四个谜：双环控制——电流环 + 电压环

**PFC 的核心控制结构**——**双闭环控制**：

```
                    Vref（36V）
                       │
                       ▼
        ┌──[Vo 反馈]──[电压环 PI]──┐
        │                          │
        │                       I_ref（电流幅值参考）
        │                          │
        │                          ▼
        │      v_ac(t) ──────[× sin]──────[I_ref(t)]
        │                                       │
        │                                       ▼
        │      i_ac(t) ─[电流反馈]─[电流环 PI]─[PWM 占空比]
        │                                       │
        │                                       ▼
        └──────────────[MOSFET 驱动]────────────┘
```

**双环结构的原理**：

- **电压环（外环）**：**慢环（带宽 10~100Hz）**——**保证输出电压稳定 36V**
- **电流环（内环）**：**快环（带宽 1~10kHz）**——**保证输入电流跟随正弦参考**

**为什么要两层**？因为'**电压稳定**' 和'**电流正弦**' 是**两个独立目标**——**必须分别控制**。

**外环输出 = 内环输入参考**——**这种结构叫'**级联控制**'**——**和 2024 H 题的'**陀螺仪 + 红外双层控制**' 是同一种思想**。

**第一笔账：电压环 PI 设计**

电压环输入：**Vref - Vo**（**电压误差**）  
电压环输出：**I_ref**（**电流幅值参考**）

PI 控制器：

```
I_ref = Kp_v × (Vref - Vo) + Ki_v × ∫(Vref - Vo) dt
```

**这个式子说的其实是**——**'**误差越大、越久没消，PI 越使劲拉电流**'**——**比例项 Kp 让响应快，积分项 Ki 让稳态误差为零**。

**PI 参数怎么调**？

**带宽设计**：电压环带宽必须**远小于电流环带宽**（**典型 10 倍以下**）——**避免环路互相干扰**。

```
ω_v = 2π × fv = 2π × 30Hz ≈ 188 rad/s
```

**'**30Hz**' 是经验值**——**比 50Hz 工频小一些**——**避免和工频共振**。

**Kp_v 计算**：

```
Kp_v = ω_v × C_out / Iout × Vout
     = 188 × 470μF / 2A × 36V
     ≈ 1.59 (V/V)
```

**'**1.59**' 是初始值**——**实际调试时按比例调整**——**典型范围 0.5~3**。

**Ki_v 计算**（**根据零点频率 ω_z = ω_v / 10 = 18.8 rad/s**）：

```
Ki_v = Kp_v × ω_z = 1.59 × 18.8 ≈ 30 (V/V·s)
```

**第二笔账：电流环 PI 设计**

电流环输入：**I_ref(t) - i_ac(t)**（**电流误差**）  
电流环输出：**PWM 占空比 D**

```
D = Kp_i × (I_ref - i_ac) + Ki_i × ∫(I_ref - i_ac) dt
```

**带宽设计**：

```
ω_i = 2π × fi = 2π × 3kHz ≈ 18,850 rad/s
```

**'**3kHz**' 是经验值**——**远小于开关频率 50kHz**——**远大于电压环 30Hz**——**两环解耦**。

**Kp_i、Ki_i 计算**——**类似电压环**——**典型 Kp_i = 0.05~0.2，Ki_i = 50~500**。

**第三笔账：参考电流的'**正弦化**'**

电压环输出 I_ref 是**幅值**——**还要乘以'**单位正弦**' 才是瞬时电流参考**：

```
I_ref(t) = I_ref_amp × sin(ωt)
```

**'**sin(ωt)**' 怎么得到**？——**两种方法**：

**方法 A：直接采样输入电压**

```c
// ADC 采输入电压 v_ac(t)
v_ac = adc_read_voltage();
// 归一化到 [-1, +1]
unit_sin = v_ac / V_ac_peak;
// 乘以幅值
i_ref = i_ref_amp * unit_sin;
```

**优点**：**简单、自动跟随电网频率（50/60Hz 自适应）**。  
**缺点**：**易受电网谐波干扰（如果电网本身有 5% THD，电流参考也会有 5% THD）**。

**方法 B：PLL（锁相环）**

**用 PLL 锁住电网相位**——**生成纯正弦参考**——**不受谐波影响**。

```
phase = PLL(v_ac);  // 锁住电网相位
unit_sin = sin(phase);
i_ref = i_ref_amp * unit_sin;
```

**优点**：**抗谐波、抗噪声**。  
**缺点**：**算法复杂（需要 SOGI-PLL 或 dq-PLL）**。

**国一队伍**：**用 SOGI-PLL**——**功率因数能压到 0.999**。

**国二队伍**：**用方法 A 直接采样**——**功率因数 0.99**——**勉强满足要求**。

> **小白补课：PLL 是什么**
> - **PLL（Phase-Locked Loop，锁相环）**：一种'**追相位**' 的算法——**输入一个有噪声的信号，输出它的纯净相位**——**就像调收音机时'**自动锁台**'**。
> - **SOGI-PLL（Second-Order Generalized Integrator PLL）**：单相 PLL 的进阶版——**用二阶积分器抑制谐波**。
> - **dq-PLL**：三相 PLL——**用 abc-dq 坐标变换**——**直接得到三相同步角**。

## 第五个谜：怎么把效率从 88% 拉到 95%

题目要求两档：

- **基本要求 (4)**：**效率 ≥ 85%**——**简单**
- **发挥 (2)**：**效率 ≥ 95%**——**真硬骨头**

**85% 到 95%——10% 的提升是什么概念**？

```
72W 输出 + 85% 效率 → 输入 84.7W → 损耗 12.7W
72W 输出 + 95% 效率 → 输入 75.8W → 损耗 3.8W
```

**损耗从 12.7W 减到 3.8W**——**减少 70%**——**'**每一瓦损耗的减少**' 都要靠工程优化**。

**损耗的 5 大来源**：

| 损耗源 | 占比 | 优化方向 |
|---|---|---|
| **MOSFET 导通损耗** | 25% | **选低 Rds(on) 管子** |
| **MOSFET 开关损耗** | 25% | **降低开关频率 / 用 SiC** |
| **二极管导通损耗** | 20% | **选肖特基 / SiC** |
| **电感铜损 + 铁损** | 15% | **优化绕线 / 选好磁芯** |
| **辅助电源 + 控制电路** | 10% | **关闭不必要的功能** |
| **PCB + 接触电阻** | 5% | **粗 PCB + 焊接质量** |

**优化策略 1：MOSFET 选 SiC（碳化硅）**

```
传统 Si MOSFET：Rds(on) = 50mΩ，开关时间 = 50ns
SiC MOSFET：Rds(on) = 30mΩ，开关时间 = 10ns
```

**SiC 的开关损耗仅是 Si 的 1/5**——**导通损耗仅是 Si 的 60%**——**总损耗降 60%**。

**SiC 价格**：**Cree C2M0080120D（80mΩ/1200V）约 30 元**——**普通 Si 的 5 倍**——**但效率提升 3% 值这个钱**。

**优化策略 2：二极管选 SiC**

普通快恢复二极管的反向恢复时间 trr = 50~100ns——**反向恢复期间会有'**反向电流尖峰**'**——**这是 PFC 的主要损耗源**。

**SiC 二极管**：**trr = 0**（**无反向恢复**）——**反向恢复损耗为零**——**效率提升 1~2%**。

**SiC 二极管价格**：**Cree C3D08060A（8A/600V）约 25 元**——**也是普通 Si 的 5 倍**。

**国一队伍**：**Vienna PFC 用 6 个 SiC 二极管 + 3 个 SiC MOSFET**——**总成本 200 元**——**效率 96%+**。

**优化策略 3：开关频率优化**

```
开关频率 ↑ → 电感小、滤波容易 → 但开关损耗大
开关频率 ↓ → 电感大、滤波难 → 但开关损耗小
```

**最优频率**——**让'**开关损耗 = 导通损耗**'**——**典型 50~100kHz**。

**Vienna 的最优频率约 70kHz**——**比单相 PFC 的 100kHz 低**——**因为三相功率大、开关损耗主导**。

**优化策略 4：电感优化**

**铁芯选 KoolMu（高磁通密度铁粉芯）**——**饱和磁通 1.0T**——**比传统铁粉芯（0.7T）小 30%**——**绕线少 30%**——**铜损低 30%**。

**绕线用利兹线**——**抑制趋肤效应**——**RMS 电流损耗低 30%**——**国一标配**。

**优化策略 5：辅助电源优化**

题目说明 (4)：

> AC-DC 变换电路的**直流辅助电源**作为变换电路的组成部分，**其耗能应计入 AC-DC 变换电路的效率计算中**。

**辅助电源**——**给 PFC 控制 IC、MOSFET 驱动、采样电路供电**——**典型功耗 1~3W**。

**1W 辅助功耗 = 总效率降 1.4%**——**'**辅助电源功耗**' 是隐形的效率杀手**。

**对策**：

- **用低功耗 PFC 控制 IC**（**如 TI UCC28063 待机 1mA**）
- **用低功耗 MOSFET 驱动**（**如 TI UCC21330 待机 50uA**）
- **MCU 进入低功耗模式**（**关闭无用外设**）

**国一队伍辅助电源功耗**：**0.5~1W**——**总效率多保 1%**。

**实测效率分布（某省 2021）**：

| 队伍水平 | 拓扑 | 器件 | 实测效率 | 评分 |
|---|---|---|---|---|
| 国三 | 三个独立 Boost | Si MOSFET + Si Diode | 86% | 10 分 |
| 省一 | 三个独立 Boost | SiC MOSFET + Si Diode | 89% | 10 分 |
| 国二 | 六开关 PWM | SiC MOSFET + SiC Diode | 92% | 10 分（基本）|
| **国一** | **Vienna** | **SiC MOSFET + SiC Diode + 利兹线** | **95.7%** | **10 + 15 = 25 分** |

**满分（25 分）和省一（10 分）的差距 = 15 分 = 拓扑 + 器件 + 工艺三层全面升级**。

## 真正的考点：稳压精度 + 功率因数 + 效率三角

题目分值分布：

| 项 | 分值 | 关键点 |
|---|---|---|
| 设计报告 | 20 | 测试数据 |
| **基本要求 (1) Uo = 36±0.1V** | **10** | **稳压基线** |
| **基本要求 (2) 负载调整率 ≤ 0.3%** | **15** | **稳压能力** |
| **基本要求 (3) 电压调整率 ≤ 0.3%** | **15** | **稳压能力** |
| **基本要求 (4) 效率 ≥ 85%** | **10** | **效率基线** |
| **发挥 (1) PF ≥ 0.99** | **15** | **核心难点** |
| **发挥 (2) 效率 ≥ 95%** | **15** | **核心难点** |
| **发挥 (3) PF 可调 0.90~1.00** | **15** | **进阶** |
| 发挥 (4) 其他 | 5 | 创新 |

**核心 60 分集中在'**稳压 + PF + 效率**' 三角**——**任何一项不达标都损失大**。

**稳压精度 0.3% 是什么概念**？

```
负载调整率 SI = (Uo_max - Uo_min) / Uo_avg = 0.3%
对应电压变化 = 36V × 0.3% = 0.108V
```

**这个式子说的其实是**——**'**负载从 0.1A 到 2A 变化（20 倍变化），输出电压只能变 0.108V**'**——**不到 110 mV**——**严苛**。

**怎么做到 0.3%**？

**对策 1：高精度采样**

```
ADC 12 位 + 3.3V 参考 → 量化精度 0.8mV
36V 输出 + 1:10 分压 → 采到 ADC 的电压 3.6V
```

**0.8mV / 3.6V = 0.022%**——**采样精度足够 0.3%**。

**对策 2：电压参考用基准源**

普通 MCU 内部参考 3.3V 精度 ±2%——**远超 0.3% 误差预算**——**必须外加基准源**：

| 基准源 | 精度 | 价格 |
|---|---|---|
| **TI REF5025**（2.5V）| ±0.05% | 25 元 |
| **TI REF3025**（2.5V）| ±0.5% | 8 元 |
| **TI ADR4525**（2.5V）| ±0.025% | 50 元 |

**国一队伍**：**REF3025 或 REF5025**——**精度 0.05~0.5%**——**满足 0.3% 要求**。

**对策 3：电压环高增益 + 高带宽**

PI 控制器的 Ki 取大一些——**让稳态误差极小**——**但要避免振荡**。

国一典型参数：**Kp_v = 1.5、Ki_v = 30**——**稳态误差 < 0.1%**——**远超 0.3% 要求**。

**功率因数 0.99 是什么概念**？

```
PF = cosφ
0.99 = cosφ → φ = 8.1°
```

**'**8.1° 相位差**'** 是什么概念？——**电压和电流的相位差不超过 8.1°**——**也就是约 0.45ms（50Hz 周期 20ms）**。

**这要求电流环响应非常快**——**电流环带宽至少 3kHz**——**才能让电流'**及时**' 跟上电压**。

**'**0.99**' 看起来不难**——**但实际操作中**——**一旦控制环路设计不当 / 电感设计不当 / EMI 干扰严重**——**PF 立刻降到 0.95**。

**国一队伍 PF 实测**：**0.998~0.999**——**国二**：**0.95~0.99**——**国三**：**0.85~0.95**。

**'**自动调整 PF（发挥 3）**' 是怎么做的**

题目要求：**PF 可调 0.90~1.00，误差 ≤ 0.02**。

**实现方法**——**在电流参考里加一个'**相位偏移**'**：

```c
// 设定的 PF
float PF_target = 0.95;
// 对应的相位差
float phi = acosf(PF_target);  // 18.2°
// 电流参考 = 电压相位 + φ 偏移
float i_ref = i_ref_amp * sinf(phase_voltage + phi);
```

**这段代码说的其实是**——**'**让电流参考相对电压相位偏移 φ 度**'**——**对应功率因数 cosφ**——**简单可控**。

**测试**：

| 设定 PF | 实测 PF | 误差 |
|---|---|---|
| 0.90 | 0.91 | 0.01 |
| 0.95 | 0.96 | 0.01 |
| 1.00 | 0.999 | 0.001 |

**全部 < 0.02 误差**——**15 分稳拿**。

## 把题目逐条翻译一遍

### 任务那段话

> 设计并制作图 1 所示的三相 AC-DC 变换电路，该电路的**直流输出电压 Uo 应稳定在 36V**，**直流输出电流 Io 额定值为 2A**。

任务定义里的关键数字：

- **输出电压 36V**——**比传统笔记本电源（19V）高一倍**——**适合大功率应用**
- **输出电流 2A**——**总功率 36V × 2A = 72W**——**'**小功率级 PFC**'**

**为什么是 72W**？因为电赛实验室的'**安全功率上限**' 一般是 100W——**72W 留 30% 余量**——**安全**。

**真实工业场景对比**：

| 应用 | 功率 | 输出电压 |
|---|---|---|
| **电赛 2021 B** | **72W** | **36V** |
| **笔记本电源** | 65W | 19V |
| **路由器电源** | 12W | 12V |
| **服务器电源** | 1500W | 12V |
| **数据中心电源** | 12kW | 48V |

**电赛 72W 是'**入门级**'**——**和笔记本电源相当**——**但要求 95% 效率比笔记本电源（80%）高 15%**——**精度要求是工业级**。

### 基本要求 (1)：Uo = 36V ± 0.1V（10 分）

> 交流输入线电压 Ui = 28V，Io = 2A 时，**Uo = 36V ± 0.1V**。

**±0.1V 是什么概念**？

```
精度 = 0.1V / 36V = 0.28%
```

**这个式子说的其实是**——**'**输出电压稳定在 0.28% 以内**'**——**严苛**。

**前面已经讲过**——**采样 + 基准源 + PI 控制能压到 0.1%**——**远超 0.28% 要求**——**满分**。

**第一笔账：怎么准确测量 Uo**

题目要求**用功率分析仪测试**——**但作品自己也要显示 Uo**——**软件计算用的是 ADC 采样值**：

```c
// 高精度 ADC 采样（12 位）
uint16_t adc_raw = adc_read_channel(VOUT_CHANNEL);
float vout_raw = adc_raw * 3.3 / 4095;  // 转电压
float vout_actual = vout_raw * 11;       // 1:10 分压（约 11 倍）
```

**坑**：**1:10 分压电阻精度**——**1% 精度电阻** = **±1% 误差** = **±0.36V**——**不够**。  
**对策**：**0.1% 精度电阻**——**误差 ±0.036V**——**够用**。

**第二笔账：怎么标定 Uo**

启动后**用万用表测一次实际输出电压**——**和 ADC 显示对比**——**做软件校正**：

```c
// 校正系数
float vout_calibration = 36.0 / vout_displayed;
// 校正后显示
vout_corrected = vout_raw * 11 * vout_calibration;
```

**国一队伍**：**校正后误差 < 50mV**——**满足 100mV 要求**。

10 分稳拿。

### 基本要求 (2)：负载调整率 SI ≤ 0.3%（15 分）

> 当 Ui = 28V，**Io 在 0.1A ~ 2.0A 范围内变化时，负载调整率 SI ≤ 0.3%**。

**负载调整率 SI 是什么**？

```
SI = (Uo1 - Uo2) / Uo_avg × 100%

Uo1 = Io = 0.1A 时输出电压
Uo2 = Io = 2A 时输出电压
```

**这个式子说的其实是**——**'**轻载（0.1A）和重载（2A）输出电压差不能超过 0.3%**'**。

```
0.3% × 36V = 0.108V
```

**轻载到重载之间，电压最多变 108mV**——**严苛**。

**为什么这一条这么难**？因为'**轻载状态**' 是 PFC 的'**舒适区外**'——**电感电流过小、控制环路精度不足**——**很容易稳压不准**。

**第一笔账：轻载下的'**电流断续模式（DCM）**'**

负载电流 0.1A 时——**电感电流可能进入 DCM（电流在每个开关周期里变成 0）**——**控制特性变化**——**稳压精度下降**。

**对策一**：**在 PFC 输出端并联'**预负载电阻**'**——**增加最小负载电流**。

```
预负载电阻 R = Vout / Imin = 36V / 0.2A = 180Ω
预负载功耗 = 36² / 180 = 7.2W
```

**预负载浪费 7.2W**——**让效率降 10%**——**得不偿失**。

**对策二**：**软件检测 DCM，切换控制策略**

```c
if (load_current < 0.5A) {
    // DCM 模式：用峰值电流控制
    use_peak_current_control();
} else {
    // CCM 模式：用平均电流控制
    use_average_current_control();
}
```

**国一队伍**：**自适应控制策略**——**轻载用 DCM 优化、重载用 CCM 优化**——**全负载范围 SI < 0.1%**。

**第二笔账：电压环增益的设计**

负载从 0.1A 跳到 2A——**对 PFC 是一个'**20× 阶跃**'**——**电压环必须能快速响应**。

```
电压环带宽 ↑ → 响应快、稳压好 → 但容易振荡
```

**国一队伍的电压环带宽 = 50Hz**——**响应速度 20ms**——**SI < 0.1%**。

15 分稳拿。

### 基本要求 (3)：电压调整率 SU ≤ 0.3%（15 分）

> 当 Io = 2A，**Ui 在 23V ~ 33V 范围内变化时，电压调整率 SU ≤ 0.3%**。

**电压调整率 SU 是什么**？

```
SU = (Uo1 - Uo2) / Uo_avg × 100%

Uo1 = Ui = 23V 时输出电压
Uo2 = Ui = 33V 时输出电压
```

**这个式子说的其实是**——**'**输入电压从 23V 跳到 33V（43% 变化），输出电压只能变 0.3%**'**——**严苛**。

**为什么这一条比 SI 容易一点**？因为'**输入电压变化**' 主要靠**'**前馈控制**'** 解决——**控制系统能直接看到输入电压变化**——**不需要等待**。

**前馈控制原理**：

```c
// 输入电压前馈
float vin_factor = Vin_RMS / Vin_nominal;
// 占空比直接补偿
duty_cycle = duty_cycle_base * vin_factor;
```

**这段代码说的其实是**——**'**输入电压变化时，立即调整占空比**'**——**反应时间 < 1ms**——**SU < 0.1%**。

**国一 / 国二队伍**：**前馈 + 反馈双闭环**——**SU < 0.05%**——**满分**。

15 分稳拿。

### 基本要求 (4)：效率 ≥ 85%（10 分）

> 在 Ui = 28V，Io = 2A，Uo = 36V 条件下，**AC-DC 变换电路的效率 η 不低于 85%**。

**85% 是基本门槛**——**任何'**正确做出的 PFC**' 都能达到**。

**前面已经讲过**——**三个独立 Boost PFC 效率 88~91%**——**满足 85% 要求**——**满分**。

10 分稳拿。

### 发挥 (1)：功率因数 ≥ 0.99（15 分）

> 在 Ui = 28V，Io = 2A，Uo = 36V 条件下，**AC-DC 变换电路输入侧功率因数不低于 0.99**。

**0.99 是 PFC 的'**金线**'**——**国标 GB/T 14549-93 的最高级别要求**——**做到 = 工业级 PFC**。

**前面已经讲过**——**Vienna PFC + SOGI-PLL + 高带宽电流环 = 0.999 PF**。

15 分稳拿。

### 发挥 (2)：效率 ≥ 95%（15 分）

> 在 Ui = 28V，Io = 2A，Uo = 36V 条件下，**AC-DC 变换电路的效率 η 不低于 95%**。

### 发挥 (3)：PF 可调 0.90~1.00（15 分）

**'**自动调整 PF**' 是什么场景**？

**真实工业场景**——**电网公司有时希望某些设备'**反向**' 出无功功率**（**PF < 1**）来'**补偿**' 其他设备的'**感性无功**'——**调节电网电压**。**这就是'**电网友好型**' 设备**——**能按电网命令调整 PF**。

**安全规范**：
