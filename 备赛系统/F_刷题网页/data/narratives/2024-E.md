## 这题在做的事，其实是 '**手 + 眼 + 脑**' 三合一的机器人

把题目压缩成一句话——**'**让一台 4 自由度机械臂在一块 9 格棋盘上和人下三子棋——人能动棋它也能动棋——人不能赢它**'**。

**三大子系统**：

```
眼（摄像头 + 视觉算法）        脑（MCU + minimax）           手（机械臂 + 运动控制）
   ↓                              ↓                              ↓
读棋盘当前状态：              算下一步最优 move：              拿棋子放到目标格：
8种棋型 × 9 格 = 72 状态        8 步全搜索 < 1ms            机械臂 IK + 路径规划
   ↓                              ↓                              ↓
  state[3][3]                    next_move (i, j)               servo_control(...)
```

**三个子系统的物理隔离**：
- **眼**：摄像头（OpenMV 或 USB 摄像头）+ 视觉处理（树莓派 / Python）
- **脑**：决策 MCU（STM32 或 ESP32）+ 状态机
- **手**：机械臂（MyCobot / 自制 4 舵机）+ 运动 MCU

**三个子系统的通信**：眼的 board[3][3] → 脑判决 → 脑的 (i, j) → 手执行 → 完成。

**通信简单**——**只有两个数据流**：

```
眼 ──[board 状态 9 个字符]──► 脑
脑 ──[目标格号 1 字符 + 棋色 1 字符]──► 手
```

**整套系统跨越机械、视觉、AI、控制**——**任何一块差就拿不到分**——**但只要分模块设计 + 简单接口**——**4 天能完成**。

**接下来的 5 个谜，把每个子系统里关键工程点拆开讲**。

## 第一个谜：机械臂怎么选——4 自由度还是 3 自由度

**4 自由度机械臂能做什么？**——**让末端执行器（夹爪）能到达 3D 空间任意点 + 任意姿态**——**精度 ±1mm**。

**3 自由度只能保证位置 + 不能保证姿态**——**'**夹爪角度可能歪**'**——**对三子棋'**正放棋子**' 够用**。

**3 种主流方案对比**：

**方案 A：商用 4 自由度机械臂**

| 厂商 | 型号 | 单价 | 精度 | 工作范围 |
|---|---|---|---|---|
| **Dobot** | Magician | 8000 元 | ±0.2mm | 320mm 半径 |
| **MyCobot** | Cobot 280 | 5500 元 | ±1mm | 280mm 半径 |
| **uArm** | Swift Pro | 3500 元 | ±0.2mm | 320mm 半径 |
| **元创 Aaiot** | AT-SCARA | 4000 元 | ±0.5mm | 400mm 半径 |
| **ROBOTIS** | Bioloid 4DOF | 4500 元 | ±2mm | 250mm 半径 |

**优点**：**精度好、SDK 成熟、4 天能调通**。  
**缺点**：**贵 + 不能完全'自主开发'扣分**。

**方案 B：自制 4 关节舵机臂（推荐）**

```
基座（旋转）─┐
             [底舵机 MG996R + 滚珠轴承]
                          │
                          [大臂 - 3D 打印 + MG996R]
                                       │
                                       [小臂 - 3D 打印 + MG996R]
                                                │
                                                [腕部 - SG90]
                                                         │
                                                         [夹爪 - SG90]
```

**舵机选型**：

| 舵机 | 扭矩 | 速度 | 单价 | 用途 |
|---|---|---|---|---|
| **MG996R**（标准）| 11 kg·cm | 0.17s/60° | 30 元 | 底舵 + 大小臂 |
| **DS3218**（数字）| 20 kg·cm | 0.16s/60° | 80 元 | 重负载关节 |
| **SG90**（小型）| 1.8 kg·cm | 0.12s/60° | 5 元 | 夹爪 |

**自制 4 关节臂总成本**：

```
4 颗 MG996R × 30 = 120 元
2 颗 SG90 × 5 = 10 元
3D 打印件 = 80 元
轴承 + 螺丝 + 滑块 = 50 元
PCB + 控制板 + STM32 = 80 元
合计：340 元
```

**优点**：**便宜 + 完全'自主设计'报告分高**。  
**缺点**：**精度 ±5mm**——**临界值**——**调试时间长**。

**方案 C：XY 龙门 + Z 升降（最简单）**

```
[X 滑轨]──┬──[Y 滑轨]
          │
        [电磁铁吸取 / 真空吸盘]
          │
        [Z 升降机构]
```

**适合棋子是磁性铁片或扁平塑料**——**电磁铁吸取最简单**。

**精度 ±0.5mm**——**优秀**——**国一队伍最爱**。

**国一队伍的最优选**：**XY 龙门 + 电磁铁**——**单价 600 元**——**精度 ±0.5mm**——**速度快**——**4 天能调通**。

**但 XY 龙门有一个'**致命缺陷**'**——**不能旋转夹爪**——**棋子放下去时姿态固定**——**对要求 (3) '棋盘旋转 ±45°' 仍然适用**——**但夹爪需要也跟着转 ±45°**——**需要 Z 轴下方加一个旋转关节**。

**完整 XY 龙门 + 旋转 + 升降的最优配置**：

```
X 滑轨（500mm 行程）+ Y 滑轨（300mm 行程）
+ Z 升降（80mm 行程）
+ 旋转关节（±90°）
+ 电磁铁吸取
合计成本：约 700 元
精度：±0.5mm
```

**国一标配**——**4 天能调通 + 报告分高**。

> **小白补课：什么叫'机械臂的精度'？**  
>  
> **'重复定位精度（Repeatability）'**：**多次让机械臂去同一个目标点 → 测量实际到达位置的离散度**。  
>  
> **MyCobot 280 = ±1mm 重复精度**——**每次放棋子的位置可能差 1mm**。  
>  
> **三子棋方格 30mm × 30mm + 棋子直径 22mm**——**棋子在格子里有 4mm 余量**——**±1mm 完全够**。  
>  
> **±5mm 的自制方案有时压线**——**需要软件做'**机械误差补偿**'**：每次到达后用摄像头测实际位置 → 算补偿量 → 修正下一次。

## 第二个谜：怎么用摄像头识别棋盘——从'拍照'到 board[3][3]

**视觉识别的完整流程**——**5 步法**：

```
1. 摄像头拍照              （硬件）
2. 边缘检测                （Canny + Hough）
3. 棋盘定位                （4 角检测）
4. 透视校正                （warpPerspective）
5. 9 格分类                （颜色阈值 / CNN）
   → 输出 board[3][3]
```

**'**5 步法**' 详细展开**：

**步骤 1：摄像头硬件选型**

| 选项 | 单价 | 分辨率 | 帧率 | 适合 |
|---|---|---|---|---|
| **OpenMV H7（标配）** | 600 元 | **640×480** | 30fps | **入门** |
| **OpenMV H7 Plus** | 1200 元 | 1280×720 | 30fps | 进阶 |
| **USB 摄像头 + 树莓派 4B** | 800 元 | 1920×1080 | 30fps | **国一标配** |
| **手机摄像头（DroidCam）** | 0 元 | 1080P | 30fps | 调试用 |

**国一标配——树莓派 4B + USB 摄像头**——**1080P + Python OpenCV 全套**——**算法移植容易**。

**摄像头位置——'垂直俯视'**：

```
摄像头位置：棋盘正上方 30~50cm
拍摄方向：垂直俯视（90°）
```

**为什么要垂直俯视？**——**最小化透视失真**——**让 9 格在图像中正好是 3×3 网格**——**简化算法**。

**步骤 2：Canny 边缘检测**

```python
import cv2
import numpy as np

img = cv2.imread('board.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 高斯滤波降噪
blurred = cv2.GaussianBlur(gray, (5, 5), 0)

# Canny 边缘检测
edges = cv2.Canny(blurred, 50, 150)

# Hough 直线检测
lines = cv2.HoughLines(edges, 1, np.pi/180, threshold=100)
```

**Canny 算法步骤**：
1. 高斯滤波平滑
2. Sobel 算子算梯度
3. 非极大值抑制
4. 双阈值 + 边缘连接

**输出**——**纯白色边缘 + 黑色背景的二值图**——**棋盘 4 条边和 9 格内的 8 条小线**全部清晰可见**。

**步骤 3：棋盘 4 角定位**

```python
# 找出图像中的所有直线
horizontal_lines = []
vertical_lines = []

for line in lines:
    rho, theta = line[0]
    if abs(theta) < np.pi/4 or abs(theta - np.pi) < np.pi/4:
        vertical_lines.append((rho, theta))
    elif abs(theta - np.pi/2) < np.pi/4:
        horizontal_lines.append((rho, theta))

# 找最外圈的 4 条边
top_line = min(horizontal_lines, key=lambda x: x[0])
bottom_line = max(horizontal_lines, key=lambda x: x[0])
left_line = min(vertical_lines, key=lambda x: x[0])
right_line = max(vertical_lines, key=lambda x: x[0])

# 算 4 个角点（4 条直线的两两交点）
corners = compute_intersections([top_line, bottom_line, left_line, right_line])
```

**4 个角点**——**用于下一步透视校正**。

**步骤 4：透视校正（核心）**

```python
# 4 个目标角点（标准 300×300 方形）
dst_corners = np.array([[0, 0], [300, 0], [300, 300], [0, 300]], dtype='float32')

# 计算透视矩阵
M = cv2.getPerspectiveTransform(np.array(corners, dtype='float32'), dst_corners)

# 应用透视变换
warped = cv2.warpPerspective(img, M, (300, 300))
```

**透视校正后**——**任意角度拍摄的棋盘 → 标准正方形俯视图**——**棋盘绕中心 ±45° 旋转的影响被消除**——**'**SLAM 思想**' 的最简单实现**。

> **小白补课：'**透视变换**' 的数学本质**  
>  
> 摄像头从某个角度看一个平面 → 平面上的每个点投影到图像平面 → **这是个 3×3 矩阵的线性变换**：  
>  
> ```
> [x']   [a b c] [x]
> [y'] = [d e f] [y]
> [w']   [g h 1] [1]
> ```  
>  
> **8 个未知参数（a~h）** → **需要 4 个对应点对（每个点对提供 2 个方程）**——**8 个方程 8 个未知数 → 可解**。  
>  
> OpenCV 的 `getPerspectiveTransform` 就是封装了这个过程——**1 行代码搞定**——**这就是开源库的力量**。  
>  
> **应用**：**车牌识别、文档扫描、AR 增强现实**——**全都用透视变换**。

**步骤 5：9 格分类（识别每格的棋子）**

```python
def detect_pieces(warped):
    board = [['.' for _ in range(3)] for _ in range(3)]
    
    for i in range(3):
        for j in range(3):
            # 截取每个 100×100 的格子
            cell = warped[i*100:(i+1)*100, j*100:(j+1)*100]
            
            # 转 HSV 色彩空间
            hsv = cv2.cvtColor(cell, cv2.COLOR_BGR2HSV)
            
            # 计算中心区域的平均亮度（V 通道）
            center = hsv[30:70, 30:70]
            avg_v = np.mean(center[:, :, 2])
            
            if avg_v < 50:
                board[i][j] = 'B'  # 黑棋
            elif avg_v > 200:
                board[i][j] = 'W'  # 白棋
            else:
                board[i][j] = '.'  # 空
    
    return board
```

**这段代码说的其实是**——**'每格中心 40×40 像素的 HSV V 通道平均亮度** —— **黑棋 < 50（深暗）**——**白棋 > 200（很亮）**——**空格在中间'**。

```python
    bg = np.mean([cell[10:20, 10:20], cell[80:90, 10:20], 
                  cell[10:20, 80:90], cell[80:90, 80:90]])
    
    # 中心区域亮度
    center = np.mean(cell[30:70, 30:70])
    
    # 中心 vs 背景的对比

    if contrast < 0.5: return 'B'  # 中心比背景暗 50% → 黑棋
```

## 第三个谜：怎么写'**永不输**' 的 AI——minimax 算法

要求 (5)：**人执黑棋先行，装置能正确放置白棋子以保持不输棋**——**这是这道题的核心**——**也是 AI 算法的最大考点**。

**三子棋的'**完美策略**'**——**1952 年数学家已经证明**——**双方都最优时**——**结果一定是平局**——**任何一方走错就会输**。

**'让 AI 永不输'的核心**——**写一个'最优'的玩家**——**永远选'对自己最好'的一步**。

**这就是 minimax 算法**：

```c
// 评估当前棋盘对 AI（白棋）的'好坏'
int evaluate(int board[3][3]) {
    // 检查 8 种连线
    for (int i = 0; i < 3; i++) {
        // 行
        if (board[i][0] == board[i][1] && board[i][1] == board[i][2] && board[i][0] != 0) {
            return board[i][0] == WHITE ? +10 : -10;
        }
        // 列
        if (board[0][i] == board[1][i] && board[1][i] == board[2][i] && board[0][i] != 0) {
            return board[0][i] == WHITE ? +10 : -10;
        }
    }
    // 主对角线
    if (board[0][0] == board[1][1] && board[1][1] == board[2][2] && board[0][0] != 0) {
        return board[0][0] == WHITE ? +10 : -10;
    }
    // 副对角线
    if (board[0][2] == board[1][1] && board[1][1] == board[2][0] && board[0][2] != 0) {
        return board[0][2] == WHITE ? +10 : -10;
    }
    return 0;  // 还没有人赢
}

// minimax 算法（递归搜索）
int minimax(int board[3][3], int depth, bool isMaximizing) {
    int score = evaluate(board);
    
    // 终止条件
    if (score == 10) return score - depth;     // AI 赢，越早越好
    if (score == -10) return score + depth;    // 人赢，越晚越好
    if (is_full(board)) return 0;              // 平局
    
    if (isMaximizing) {
        int best = -1000;
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                if (board[i][j] == 0) {
                    board[i][j] = WHITE;       // AI 试下
                    int val = minimax(board, depth + 1, false);
                    board[i][j] = 0;            // 撤销
                    best = max(best, val);
                }
            }
        }
        return best;
    } else {
        int best = +1000;
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                if (board[i][j] == 0) {
                    board[i][j] = BLACK;       // 人试下
                    int val = minimax(board, depth + 1, true);
                    board[i][j] = 0;
                    best = min(best, val);
                }
            }
        }
        return best;
    }
}

// 找最优 move
void find_best_move(int board[3][3], int *best_i, int *best_j) {
    int best_val = -1000;
    *best_i = -1;
    *best_j = -1;
    
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            if (board[i][j] == 0) {
                board[i][j] = WHITE;
                int val = minimax(board, 0, false);
                board[i][j] = 0;
                
                if (val > best_val) {
                    best_val = val;
                    *best_i = i;
                    *best_j = j;
                }
            }
        }
    }
}
```

**这段代码说的其实是**——**'AI 模拟所有可能的 move → 假设对手也最优 → 选出对自己最好的 move'**——**博弈论的标准做法**。

**搜索空间分析**：

```
三子棋空棋盘开始：9 个空位 × 8 × 7 × ... × 1 = 9! = 362880 个完整对局
但很多是对称等价的：去除对称 ≈ 5478 个不同状态
每个状态搜索一次：5478 × 9 状态评估 ≈ 50000 次评估
STM32F4 每次评估 1us → 总耗时 50ms
```

**STM32F4 上 50ms 完成完整 minimax 搜索** —— **远低于题目 15 秒限制**——**完全可行**。

**'AI 永不输' 的数学保证**：

| 玩家 | 第一步 | 数学结论 |
|---|---|---|
| 中心（5 号格） | 完美策略 | **永不输** |

## 第五个谜：要求 (6) '**人移动棋子**' 怎么应对

要求 (6)：**人将装置下过的 1 颗棋子变动位置**——**装置自动发现并放回**——**10 分**。

**核心算法——'**对比当前棋盘 vs 上次记录**'**——**找差异**：

```c
typedef struct { int i, j; int piece; } CellChange_t;

CellChange_t detect_changes(int last[3][3], int current[3][3]) {
    CellChange_t change = {-1, -1, 0};
    
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            if (last[i][j] != current[i][j]) {
                change.i = i;
                change.j = j;
                change.piece = last[i][j];  // 应该是什么棋子
                break;
            }
        }
    }
    return change;
}

void handle_human_move(int last[3][3], int current[3][3]) {
    CellChange_t move = detect_changes(last, current);
    
    if (move.i < 0) {
        // 没有变化 → 异常
        return;
    }
    
    // 检查是否是合法的'下新棋'
    if (last[move.i][move.j] == 0 && current[move.i][move.j] == BLACK) {
        // 合法：人下了一步新棋
        memcpy(last, current, sizeof(last));
        return;
    }
    
    // 检查是否是'人移动了已有棋子'（异常）
    int old_pos_count = count_pieces(last);
    int new_pos_count = count_pieces(current);
    if (old_pos_count == new_pos_count) {
        // 棋子总数没变 → 有人移动了棋子
        // 找到被移到新位置的棋子
        // ...
        // 把它放回原来的位置
        execute_move_back();
        return;
    }
    
    // 检查是否是'缺失了某颗棋子'（异常）
    if (new_pos_count < old_pos_count) {
        // 棋子总数减少 → 有人拿走了棋子
        // 把它放回原来的位置
        execute_move_back();
    }
}
```

**这段代码说的其实是**——**'**对比上一次记忆的棋盘 vs 当前看到的棋盘 → 找差异 → 判断是合法 move 还是作弊 → 作弊就放回**'**——**异常检测的入门**。

### 要求 (3)：棋盘旋转 ±45° - 20 分

题目原文（第 23 行）：

**核心 - 把'图像坐标'转成'机械臂坐标'**：

```c
// 棋盘的 4 个角在图像中的像素坐标（已知，由视觉识别）
Point2D corners_pixel[4] = {(...), (...), (...), (...)};

// 棋盘的 4 个角在世界坐标（机械臂坐标系）的真实位置（已知，由摄像头校准）
Point2D corners_world[4] = {(...), (...), (...), (...)};

// 求一个 3×3 透视矩阵 M
Matrix3x3 M = compute_perspective(corners_pixel, corners_world);

// 用 M 把 9 个格子的中心从图像坐标转到世界坐标
Point2D cell_world[9];
for (int i = 0; i < 9; i++) {
    Point2D cell_pixel = compute_cell_pixel(i);
    cell_world[i] = M * cell_pixel;
}

// 机械臂按 cell_world[i] 移动放棋子
move_to(cell_world[i].x, cell_world[i].y, board_z);
```

**这段代码说的其实是**——**'**摄像头看到棋盘 4 角的像素位置 → 算出像素到世界的映射矩阵 → 把每格中心从像素映射到世界 → 机械臂按世界坐标放置**'**——**'**视觉伺服**' 的简化版**。

**精度链**：

```

棋盘 → 世界换算误差：±0.5mm
机械臂重复精度：±1mm

```
