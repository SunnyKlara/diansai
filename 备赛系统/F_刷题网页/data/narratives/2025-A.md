## 想象一个场景

你在测试一台 1kW 的逆变器，需要给它接上 1kW 的负载来验证性能。最朴素的办法是接一组电阻——电流流过电阻，全变成热，散热片烫手，房间像桑拿房。**这种白白烧掉的电费**，就是工厂工程师每天在交的'测试税'。

本题让你做的，就是干掉这笔税。

你去搜'再生式电子负载'，会发现 Chroma、艾德克斯、致茂这些电源测试仪表大厂每家都有产品线，单台售价从几万到几十万。它们的客户是：电源厂研发部门、新能源车 BMS 测试线、风光储产线下线检测。**这是一个上百亿规模的细分市场。**

出题人选这个题材，意图是双重的：一方面让选手接触到真实工业产品的核心拓扑（不是教科书里的玩具电路），另一方面把'三相变流 + 锁相 + 双向能流 + 闭环效率优化'这几个电源类的高阶技能压成一道题。**做完这一题，你的电力电子能力直接从本科生提升到初级工程师**——这是出题人埋的彩蛋。

而且 2025 年是电赛'电源题大年'：A、B 两道都是电源题，A 偏拓扑硬功夫，B 偏控制软功夫。这背后其实有个判断——**国内新能源行业人才缺口巨大**，电赛要往这个方向引导。

## 这题在做的事，其实就两个变流器在玩传球

图 1 里画了两个方块面对面站着。我先帮你认识它们。

左边那个方块，标着 'DC-AC'，叫'变流器 1'。它的工作是：**接进来直流电（一根正一根负），吐出来交流电（三根线，互相错 120°）**。这个动作叫'逆变'，做这个动作的设备叫'逆变器'。家里光伏发电系统、电动汽车驱动电机、所有把电池能量变成交流的场合都用它。

右边那个方块，标着 'AC-DC'，叫'变流器 2'。它做的是反过来的事：**进三相交流，出直流**。这个动作叫'整流'，最简单的整流器是 4 个二极管搭成的整流桥（你充电器里就有）。但本题里它远比二极管复杂，后面会讲为什么。

现在好玩的来了。题目要求把变流器 2 的直流输出接回到变流器 1 的直流电源那一端。

你脑子里画一下：电从直流电源出发 → 进变流器 1 变成交流 → 电流跑了一圈 → 进变流器 2 又变回直流 → 回到电源。**这个回路是闭合的**。

这就叫'能量回馈'。变流器 1 输出 100W，变流器 2 收回 90W 还给电源（中间总有点损耗），那直流电源**实际上只需要补充那 10W 的损耗**。

> 想象两个人玩传球。A 把球扔给 B，B 把球扔回给 A。如果两人都不漏球，球永远在空中，A 和 B 都不需要新球。但人手会有点累，所以偶尔需要补一个球进来——这点'累'就是损耗，那个补球的人就是直流电源。

看明白这一层，你就理解了'能量回馈'四个字。**剩下所有内容，都是在讨论怎么把这个传球游戏玩稳、玩省**。

## 第一个谜：为什么变流器 2 不能用普通整流桥

刚才说变流器 2 是 'AC→DC'，是整流器。你脑子里第一个反应肯定是：那不就是 4 个二极管吗，初中物理课就讲过的。

如果你这么做，**这道题你最多拿 50 分**——基本要求做出来，发挥部分一分都没有。

为什么？

二极管有个性格：电只能从正极流向负极，反向就关门了。这意味着一个二极管整流器**只允许电流从交流侧流向直流侧，不允许反过来**。

但是！变流器 1 工作的时候，电感里会储存能量。每个开关周期里，电感会有大约一半时间在'放能'——这时候电流方向是从直流回流到交流的。如果二极管挡住了这条路，电感能量没地方去，电压瞬间飙起来，**MOS 管一秒钟内就被打穿**。

所以变流器 2 不能用二极管，它必须是**用 MOS 管搭起来的整流器**——MOS 管可以双向导通（不像二极管），电流爱怎么流怎么流。这种东西叫**PWM 整流器**，或者**主动整流器**。

它和变流器 1 长得几乎一模一样——都是 6 个 MOS 管搭成三相全桥。**唯一区别只是控制策略**：变流器 1 想把直流变成 50Hz 正弦交流，所以 PWM 信号像正弦波；变流器 2 想把交流稳定成直流，所以 PWM 信号要跟着电网相位精确翻转。

听到这里你应该有个直觉了：**这道题硬件最终就是两组一模一样的三相全桥，区别全在软件**。出题人选这种结构的原因也清楚了——既考你拓扑认知（不能想当然用二极管），又简化了硬件设计（两块板一样，可以并行打样），剩下的精力全给软件。

## 第二个谜：交流电怎么和直流电做闭环

现在硬件你画好了，要写代码了。第一个问题是：怎么让变流器 1 输出稳定的 50Hz 三相正弦？

你的第一反应可能是 PID 闭环：测一下输出电压，比一下目标电压，差多少调多少。这是初中物理课你就懂的'反馈调节'。

但 PID 这个东西有个隐藏前提——**它最擅长跟踪不动的直流目标**。比如让温度稳定在 50℃，PID 会工作得很好。可你现在的目标是 50Hz 正弦波，**目标值每秒钟自己在变化 50 次**，PID 跟得手忙脚乱。它的积分项在正负之间反复横跳，永远凑不出'稳态'。

这是电力电子工程师在 1980 年代就遇到的难题。他们后来想出一个聪明办法：**既然 PID 擅长跟直流，那我把交流变成直流再 PID**。

这个变换叫**Park 变换**，发明者 Robert Park。它把三相 abc 信号（三个 120° 错相的正弦波）通过一组旋转坐标变成两个直流量，分别叫 d 轴和 q 轴。

比喻一下：你站在地面看一个旋转木马，木马上的小马上下起伏，是个正弦运动。但如果你也跟着木马一起转，**你看那匹小马就是不动的**——它和木马同步旋转。Park 变换就是让你的'坐标系'跟着电网相位一起转，转起来之后**正弦量在你眼里就成了静止的直流量**。

这下 PID 就能上场了。一个 PID 控制 d 轴，一个 PID 控制 q 轴，两个直流目标，**两个独立的 PID 各自做到稳态无差**。

但 Park 变换需要一个前提——**你必须时时刻刻知道木马转到哪儿了**。也就是说，你要知道电网当前的相位角度。

这就引出了第三个谜。

## 第三个谜：相位是怎么'锁'住的

相位听起来抽象，给你个具体的画面：50Hz 正弦波每 20ms 走一圈 360°。'相位 0°'是这一圈的起点，'相位 180°'是中间。**你必须告诉单片机：现在这一刻，电网走到了 30° 还是 60°？**

最朴素的办法是过零检测——电压穿过 0 那一瞬间就是 0°，开始计时，到 5ms 时刚好 90°，到 10ms 时是 180°。听起来完美。

但电网总是不干净的：有杂波、有干扰、有谐波。你以为是过零的那一瞬间，**信号在 0 上下来回穿了 5 次**，单片机一脸懵。

工程师又发明了一个东西，叫**锁相环（PLL，Phase-Locked Loop）**。

这玩意原理像追火车：你站在站台上拿个秒表，每次火车经过你这里你按一下，对比你心里默念的节拍——如果火车比你快，你就调快默念速度；如果慢了，你就调慢。一段时间之后，**你心里的节拍就和火车精确同步了**。

三相系统里这个 PLL 有个具体名字叫 **SRF-PLL**（Synchronous Reference Frame PLL，同步旋转坐标 PLL）。它的实现很优雅：**你假设一个相位 θ̂，用这个 θ̂ 做 Park 变换。如果你猜对了，q 轴会归零；如果猜错了，q 轴就有非零值**。把 q 轴误差送进一个 PI 控制器，让它去调 θ̂，让 q 轴归零。一旦 q 轴稳定在 0，**你猜的 θ̂ 就是真实相位**。

这套机制只用了大概 50 行 C 代码，但**第一次接触的人通常会卡两天**。因为它把 Park 变换和 PI 控制器嵌套了，初学者很难一眼看穿这个'自指'结构。

好消息是，一旦你这套写通了，从此你做任何并网设备都能复用。**SRF-PLL 是电力电子的通用钥匙**。

## 第四个谜：怎么让正弦波尽可能纯净

现在你已经能输出三相 50Hz 了。题目说'输出 THD ≤ 2%'。这个 THD 是什么？

**THD（Total Harmonic Distortion，总谐波失真）** 衡量一段波形有多接近纯正弦。把一段周期信号做傅里叶分解，会得到基波（50Hz）+ 一堆谐波（100Hz、150Hz、250Hz……）。THD 就是所有谐波能量的总和与基波能量的比值。

THD = 0% 表示完美正弦；THD = 5% 表示波形已经看出来扭曲；THD = 30% 表示波形丑得不像样。

你输出的'正弦波'其实是 PWM 调制出来的——一堆又快又窄的方波脉冲，平均下来才是正弦的形状。**调制方式决定了 THD**。

最入门的调制叫 **SPWM**（正弦波 PWM）。原理也直观：你心里有一个完美的正弦波（叫'调制波'），同时有一个高频三角波（叫'载波'，比如 20kHz）。两者比较，**调制波 > 载波时输出高电平，反之低电平**。这样输出的脉冲宽度自动随正弦变化，平均下来就是正弦波。

但 SPWM 有个先天缺陷——**直流母线利用率只有 86.6%**。

这话什么意思？假设你直流母线电压是 60V，用 SPWM 你最多只能输出**51.96V 峰值**的交流（即线电压有效值 36.7V）。剩下那 13.4% 的电压被'浪费'了。

你想啊，本题要求输出 32V 线电压（有效值），峰值是 32×√2 ≈ 45V。你的母线电压必须高于 45/0.866 ≈ 52V 才能不饱和。考虑余量你得用 60V。**60V 母线就比 52V 母线损耗高、危险高、器件贵**。

这时候有个叫德国工程师在 1980 年代发明了一招——**SVPWM**（空间矢量 PWM）。

SVPWM 的本质是：**它在调制波里偷偷注入了一点点三次谐波（150Hz）**。你可能会想：'啊？三次谐波是脏东西啊，THD 不就上去了？'。

但这里有个魔术——**三相系统里，三次谐波在线电压里会自动消失**。因为三相 a/b/c 各自的三次谐波是同相位的（都比基波快 3 倍），相减的时候完美抵消。所以**相电压里有三次谐波，线电压里没有**。

注入这点三次谐波之后，等效相电压能多输出 15.5%。**直流母线 60V 用 SVPWM 能输出 60V 线电压峰值**——母线利用率 100%。

回到本题：用 SVPWM，你的母线电压只需要 46V 就够了。**功率器件可以选低耐压版本（更便宜）、损耗也更小、整机效率自然更高**。

这就是为什么所有国一队伍清一色用 SVPWM——它**不是炫技，而是在'比谁更省电'的发挥项里给你天然的 5%~10% 效率优势**。

SVPWM 写起来比 SPWM 复杂大约 3 倍，需要扇区判断 + 矢量合成 + 时间分配。但它已经被 ST、TI 反复打磨了 30 年，开源例程一抓一大把。**你只需要看懂、搬过来、调通**。

## 真正的考点：效率比拼

现在我们终于可以谈这道题的灵魂了——**发挥部分的 30 分**。

基本要求 50 分是常规题，发挥 (1) 15 分只是确认能量回馈了，**剩下的 30 分全在比谁的 Pd 更小**。

Pd 是直流电源消耗的功率。如果系统是无损的（不可能），Pd = 0。实际上 Pd 等于全系统所有损耗的总和。

损耗来自四类：

第一类是**开关损耗**。MOS 管开通和关断的瞬间，电压电流是有重叠的——电流已经流起来但电压还没降到零，反过来也一样。这一段重叠区里有功率消耗，每秒钟开关 N 次就累计 N 倍损耗。**降低它的办法是降开关频率**：从 20kHz 降到 15kHz，开关损耗降 25%。但开关频率太低，THD 会变差，所以这是个权衡。

第二类是**导通损耗**。MOS 管完全开通后还有一点点电阻，叫 Rds(on)。电流穿过这点电阻时产生 I²·Rds(on) 的热。换更好的 MOS 管能直接降它——比如 IRF540 的 Rds 是 44 毫欧，换成 IRFP4710 是 14 毫欧，**导通损耗瞬间降 68%**。这一招最简单粗暴。

第三类是**铜损**。所有铜导线、铜绕线都有电阻，电流过去就发热。降它的办法是用更粗的线。本题里电流 2A 不算大，常见 0.8mm 漆包线就够；但如果你用粗到 1.2mm，铜损能再降 30%。

第四类是**铁损**。变压器和电感的磁芯不是免费的——磁场每秒翻转 50 次，磁芯里就有磁滞损耗和涡流损耗。降它的办法是选低损耗磁芯（铁硅铝、铁氧体），或者选大一档的尺寸（磁通密度低，损耗就低）。

做完基本盘之后，国一队伍的工作就是**用红外热像仪扫整机**。

那块发热最重？拆开看是什么器件。是 MOS？查 datasheet 找更低 Rds 的型号下单顺丰寄。是电感？拆下来用粗线重绕。是电容？换低 ESR 的换成钽电容或固态电容。

这个调试过程没有任何'技巧'可言，**纯粹是耐心 + 经验**。每解决一处发热点，Pd 降一点点。从 35W 调到 15W 大概要花一整天，从 15W 调到 8W 又要花一整天。**前几名队伍的 Pd 都压到了 10W 以下**，这就是 30 分排名分的真实分布。

### 基本要求 (1)：32V±0.25V，2A，50Hz 三相对称

> 变流器 1 能输出 f1=50Hz、线电压 U1=32V±0.25V、额定线电流 I1=2A 的三相对称正弦交流电。

表面看这就是'你的逆变器要输出 50Hz/32V/2A'，简单粗暴。但工程师拿到这条会立刻在草稿纸上算第一笔账。

**第一笔：直流母线电压怎么选？**

先解释一下'直流母线'这个词。打个比方，你家小区有一根总电缆从变电站接进来，然后小区里所有楼都从这根总电缆分电，这根总电缆就叫'母线'。我们这里的'直流母线 V_dc' 就是变流器 1 板子上那根**最粗的直流电源主轨**——所有 MOS 管都从这根轨上取电、还电。**它是整套电路的'压力源'**。

现在的问题是：这根直流母线选多少伏？

要让变流器输出三相 32V 交流（线电压有效值），就要先搞清楚几个相关电压。

> **小白补课**：
> - **有效值（RMS）**：交流电因为时大时小，没法直接说'多少伏'。我们规定：让一段交流电去给电阻发热，能发出和多少伏直流电相同的热量，这个直流电压就叫这段交流电的'有效值'。**家里 220V 就是有效值**。
> - **峰值**：交流波形最高那一瞬间的电压。正弦波峰值 = 有效值 × √2 ≈ 1.414 倍。
> - **线电压 / 相电压**：三相电有三根火线，任两根之间的电压叫'线电压'，每根火线对中线的电压叫'相电压'。三相对称时，**线电压 = √3 × 相电压**（约 1.732 倍）。

这套关系套到本题：线电压有效值 32V → 相电压有效值 32/√3 ≈ 18.5V → 相电压峰值 18.5 × √2 ≈ **26.1V**。

现在轮到**SVPWM** 出场。它是一种调制算法（前面讲过），最大能力是把'母线电压的一部分'搬到相电压上当作峰值。具体能搬多少？答案是 V_dc / √3。

所以你想让相电压峰值达到 26.1V，母线必须至少：

```
V_dc_min = 26.1 × √3 ≈ 45.2 V
```

这个式子说的其实是：**'你板子上那根直流主轨至少要有 45V'**。低于这个数字，SVPWM 就'调不出来'你想要的交流电压。

但工程上不能贴着理论极限设计——任何扰动（直流电源纹波、负载冲击）都让你瞬间不够用。**经验值是放 1.15~1.25 倍余量**：

```
45.2 × 1.2 ≈ 54 V
```

再考虑到直流电源本身的容差（你买的电源标 60V，实际可能 58V）和动态响应，**最终选 V_dc = 60V**。

这一步看似只是选个数字，**它直接决定了你后面所有器件的耐压等级**：

- MOS 管耐压选 **100V 的**（60V 母线的 2 倍裕量，工业惯例）
- 母线电容耐压选 **100V 的**
- 栅极驱动 IC 选**适配 12V~15V 驱动电压的**（栅极驱动的电压不是和母线一样，是独立的小电源）

> **小白补课**：MOS 管（金属氧化物半导体场效应管）就是一个'电控开关'——给它栅极加电它就导通让大电流过去，撤掉电它就断开。'耐压'是说漏极-源极之间最多能扛多少伏不被击穿。栅极驱动 IC 是专门给 MOS 栅极充放电的小芯片（直接用单片机引脚驱动太弱）。

**第二笔：电流多大？**

线电流 I1=2A 是有效值，峰值 2 × √2 ≈ 2.83A。

但你不能按 2.83A 选 MOS 就完事——开关瞬间会有过冲（电流突然冲高一下再回落），过冲幅度通常是稳态的 1.5 倍。**所以 MOS 必须能瞬时扛 4.5A 不饱和**。再加 2 倍工程裕量（半导体器件不能贴着规格用，温度一高性能就掉），**MOS 选 10A 以上的**。

IRFP4710 这颗常见 MOS 标称 56A，IRF540 标 28A，都远远够。**所以你不会卡在器件电流容量上**——这是出题人故意把电流压在 2A 的原因，让你不用为电流耐受焦虑，可以专心调控制。

**第三笔：功率多大？**

三相系统的视在功率公式：

```
S = √3 × U_line × I_line = √3 × 32 × 2 ≈ 110.85 VA
```

这个式子说的其实是：**'三相一起'输送的总功率，等于线电压乘以线电流再乘 √3**。VA（伏安）是视在功率单位，区别于 W（瓦特）的有功功率——只有当电压和电流完全同步（功率因数 cosφ = 1）时，二者相等。本题纯阻性负载下，**有功 P ≈ 110W**。

110W 这个数字几乎踩到了所有 **TO-220 封装** MOSFET 自然散热的上限。

> **小白补课**：MOS 的封装就是它的塑料/金属外壳形状，TO-220 是最常见的一种（看上去是个带金属背板的小方块，能直接拧到散热片上）。每种封装散热能力不同——TO-220 自然对流（不加风扇）大概能散 1~2W；加铝片散热片能到 5W；上风扇能到 15W。

所以本题 110W 摊到 12 颗 MOS 上，每颗平均 9W 损耗——**挂个铝片就够了，不需要风扇**。但如果电流定 5A，功率到 280W，每颗 MOS 23W，必须上风扇。**出题人把功率刻意压在 100W 量级，就是让你不用花时间做热设计，专注控制**。

**第四笔：±0.25V 容差是什么概念？**

0.25 / 32 = **0.78%**。这是个**只能用闭环达到**的精度。

> **小白补课：什么叫闭环？**
> 想象你要把汽车开到 60 公里/小时。'开环'就是踩油门踩到一个固定深度（比如 30%），然后听天由命——上坡了车自己就慢，下坡就快。'闭环'就是你眼睛盯着仪表盘，慢了就多踩点油门，快了就松点。**有反馈、能修正，叫闭环**。

开环 SPWM/SVPWM 输出受很多因素干扰：直流母线电压只要抖 1V（电源天然的纹波就有这个量级），输出就跟着抖约 0.55V；再加上 MOS 的开关死区效应、温度漂移、模拟参考源漂移……一堆因素叠加，**没闭环你绝对达不到 ±0.25V**。

这条要求隐式地告诉你：**你必须做电压闭环**，而且电压外环的带宽（响应速度的指标）必须够（≥100Hz），才能跟上 50Hz 基波周围的各种扰动。

这一条考完，14 分入账。更重要的是**你已经把整台变流器的硬件参数都算出来了**。这就是工程师拿到题第一小时干的事——不是急着焊板子，是把每个数字推一遍。

### 基本要求 (2)：THD ≤ 2%

> 在基本要求 (1) 的工作条件下，要求输出交流电压总谐波畸变率（THD）不大于 2%。

这一条是给你设的'波形质量门'。工程师拿到 2% 这个数字会立刻反推三件事。

**反推第一件：滤波器截止频率定多少？**

THD 来源是 PWM 开关纹波。如果你的载波 fs=20kHz，主要纹波集中在 fs 附近。LC 低通滤波器对 20kHz 的衰减必须足够强。

LC 滤波器在截止频率 fc 之上是 -40dB/decade 衰减。要把 20kHz 纹波衰减 40dB（即衰减为 1/100），fc 必须比 20kHz 低一个十倍频程：

```
fc ≈ fs / 10 = 2 kHz
```

fc 公式：

```
fc = 1 / (2π√(LC))
```

假设 L = 1mH，反算：

```
C = 1 / (L × (2π × fc)²) = 1 / (0.001 × (2π × 2000)²) ≈ 6.3 μF
```

实际选 **C = 10μF**（标称值常见档），fc 略低到 1.6kHz，余量更大。

这就是工业逆变器 L=1mH/C=10μF 这个'万金油'组合的由来——不是凭空记的，是按 fc=fs/10 反推出来的。

**反推第二件：调制方式选哪个？**

SPWM 在 fs=20kHz 下，输出 50Hz 正弦的 THD 理论极限大概 3%；SVPWM 能到 1.5%。**SPWM 直接没戏**，必须 SVPWM。

这不是经验之谈，有理论依据。算一下本题的调制度：

```
m = 相电压峰值 / (V_dc / 2)
  = 26.1 / 30
  ≈ 0.87
```

SPWM 的极限调制度是 m=1.0，超过就削波；SVPWM 极限是 m=1.155（注入三次谐波后）。**本题 m=0.87 已经踩到 SPWM 失真急剧上升的'肩膀区'**——这个区间里 SPWM 的输出已经不是漂亮的正弦，开始出现轻微平顶。

而 SVPWM 在 m=0.87 时还远在线性区中央，输出依然干净。这就是为什么 SVPWM 能做到 THD 1.5% 而 SPWM 卡在 3% 的内在原因。

**反推第三件：测量方法暗坑**

THD 的精度依赖测量方法。功率分析仪（如 Fluke 1735）测出来 1.8%，但你用示波器内置 FFT 看可能是 2.3%。

差异来源：示波器 FFT 是 1024 点定长采样，**频率分辨率 = fs/N**，谐波幅值精度受频率泄漏影响，会高估 THD。专业功率分析仪用整数倍周期同步采样 + 平顶窗，**幅度精度 0.01dB**，结果更准。

评委的标准答案以专业功率分析仪为准。**所以你设计完之后必须找一台正经的功率分析仪复测**，不能光信示波器自测，否则你以为达标实际上没达标，13 分丢得不明不白。

### 基本要求 (3)：负载调整率 ≤ 0.3%

> I1 在 0A~2A 间变化时，要求负载调整率 SI1 ≤ 0.3%。

这条是基本要求里最苛刻的一项。0.3% × 32V ≈ 0.1V。**0.1V** 的稳态电压偏差容差，工程师看到这数字心里会咯噔一下——这是真闭环活儿。

**为什么开环必死？算一下电感压降。**

负载从 0A 加到 2A，电流流过滤波电感。50Hz 基波下，电感的感抗：

```
X_L = ωL = 2π × 50 × 0.001 = 0.314 Ω
```

2A 电流通过电感产生的压降（基波下）：

```
V_L = X_L × I = 0.314 × 2 = 0.63 V
```

**仅这一项就让你的负载调整率打到 0.63 / 32 = 1.97%**——比 0.3% 大 6 倍。开环你绝对达不到。

**闭环怎么算？开环增益反推 PI 参数。**

要让 50Hz 处的稳态误差 < 0.3%，闭环增益必须 > 99.7%，意味着开环增益 |G(jω)| > 333 在 50Hz 处。

PI 控制器：

```
G_PI(s) = Kp + Ki/s
|G_PI(jω)| = √(Kp² + (Ki/ω)²)
```

50Hz 处 ω = 314 rad/s。如果只用 P，Kp 必须 > 333，**这个 Kp 会让相位裕度崩盘，系统振荡**。所以必须 PI 配合：

- 积分项 Ki 在低频段（<10Hz）提供高增益（因为 Ki/ω 在低频段很大）
- 比例项 Kp 在中频段（50~500Hz）保证带宽

**经验值**：Kp = 0.5，Ki = 100。代入 50Hz：

```
|G| = √(0.5² + (100/314)²) = √(0.25 + 0.10) ≈ 0.59
```

这显然不够。这就是为什么纯 PI 还不够，**必须再加'电流前馈'**：

```
u_ref = PI(v_err) + jωL × i_load
```

第二项是把测得的负载电流乘上感抗（90° 移相）直接补到输出，**预先抵消电感压降**。前馈做对，PI 的工作就只是消除残余 5% 误差，闭环带宽 100Hz 足够。

**电压环和电流内环带宽配比的金科玉律**

双闭环架构：

```
外环带宽 = 内环带宽 / 10
本题：电流内环 1kHz，电压外环 100Hz
```

为什么是 10 倍？因为级联系统稳定性要求外环看到的内环近似一阶惯性，相位滞后小于 5°。当外环带宽 < 内环 / 10 时，内环响应在外环看来'瞬间完成'，这个近似才成立。

13 分到手，你已经掌握了电源工程师的'闭环手感'。后面所有电源类项目，从 LLC 谐振变换器到光伏逆变器，**电压闭环的方法论都是同一套**。

### 基本要求 (4)：20~100Hz 步进 1Hz

> 要求变流器 1 输出交流电的频率范围为 20Hz~100Hz，步进 1Hz。

这一条看上去不起眼，实际给你的**软件架构**做了硬性约束。

**坑 1：PWM 周期不是整数**

SVPWM 的开关周期 Ts = 1/fs（载波周期），与输出基波频率 f1 无关。但**输出基波每个周期 T1=1/f1 必须是开关周期 Ts 的整数倍**，否则会产生'拍频'噪声。

50Hz 时 T1=20ms，Ts=50μs（fs=20kHz），20ms/50μs = 400，整数。OK。

但 33Hz 时 T1=30.303ms，30.303/0.05 = 606.06，**不是整数**。这意味着每个基波周期会有 0.06 个开关周期对不齐，长期累积引起低频拍频。

**解决办法**：让 fs 跟着 f1 变化。设定 N = T1/Ts 为整数，如 N=400 时 fs = N × f1。f1=20Hz → fs=8kHz；f1=100Hz → fs=40kHz。这样开关周期永远整除基波周期。

但 fs=40kHz 让 MOS 开关损耗翻倍，超出散热设计。**实际做法**：选定几个 N 值（如 200, 400, 800），按频率范围切换。

**坑 2：PLL 参数自适应**

SRF-PLL 是按 50Hz 调的：PI 参数 Kp、Ki，积分时间常数都是基于 50Hz 优化。但工程师都明白，PLL 的带宽 ωBW 应该比基波频率低 5~10 倍才稳定（避免高频纹波进入积分），又比频率扰动快 5~10 倍才能跟踪（响应快）。

50Hz 系统，PLL 带宽典型 5~10Hz；20Hz 系统，PLL 带宽必须降到 2~4Hz；100Hz 系统，PLL 带宽要拉到 10~20Hz。

**带宽和 Kp、Ki 的关系**（标准 PLL 二阶系统）：

```
ωBW ≈ Kp
ζ = Kp / (2 × √Ki)
```

要保证 ζ ≈ 0.7（标准过阻尼），Ki 大约是 (Kp/1.4)²。所以：

```
频率 20Hz：Kp = 2,  Ki ≈ 2    （慢工出细活）
频率 50Hz：Kp = 5,  Ki ≈ 13   （标称工作点）
频率 100Hz：Kp = 10, Ki ≈ 51  （高速跟踪）
```

国一队伍的做法：**预先打三套参数表，按当前目标频率切换**。代码里加 30 行查表逻辑搞定。**会的人一行代码，不会的人卡两小时**。

### 发挥 (1)：能量回馈，I1 ≥ 1A

> 试验装置能实现能量回馈，要求变流器 1 输出电流 I1 不小于 1A。

基本要求做完，你的变流器 1 已经稳如老狗。**发挥 (1) 才是这道题真正开始**。

这一条考变流器 2 + 全系统连接。题目要求 I1 ≥ 1A，**为什么是 1A 不是 2A**？

工程师视角的解读是：出题人在留余量。变流器 1 满载 2A 时，变流器 2 必须能吸收所有这些功率回馈给电源。但**第一次合闸时电流环未必稳，可能会冲到 3~4A**。如果指标定 2A，你的器件选型容差就一点都没有了。所以放宽到 1A，意思是'**你能把回馈机制跑通就给分**'，不强求满载。

**第一关：变流器 2 单独跑通整流——母线电容怎么选？**

变流器 2 把交流变成直流，但输出端必须有一颗大电容缓冲瞬时功率波动。

瞬时功率（单相分析）：

```
p(t) = u(t) × i(t) = U·cos(ωt) × I·cos(ωt) = (UI/2)·(1 + cos(2ωt))
```

注意到有个 **2ω 的二次谐波分量**——50Hz 系统对应 100Hz 纹波。三相系统下，三相功率叠加后理论上恒定（cos²(ωt) + cos²(ωt-120°) + cos²(ωt+120°) = 3/2，常数），但实际由于不平衡仍有少量 100Hz 纹波。

母线电容 C_dc 缓冲这个波动。能量平衡：

```
C_dc × V_dc × ΔV = ΔE = P / (2ω)
```

代入 P=110W, ω=2π×50, V_dc=60V，要求纹波 ΔV < 1V（母线纹波 1.7%）：

```
C_dc > 110 / (2π × 50 × 60 × 1) ≈ 5.8 μF
```

但单相不平衡时纹波可能大 5~10 倍。**实际选 470μF/100V 电解电容**，留出大量余量，同时降低电容 ESR 损耗。

这就是为什么变流器板上必须有那颗大电容的原因。

**第二关：合体之前必须做相位预同步**

变流器 1 已经在跑 50Hz，变流器 2 的 PLL 必须先锁住这个 50Hz 才能合闸。**没锁住就合闸 = 两个相位差 30° 的电源短路**。

算一下相位差 30° 时的环流：

```
I_环 = ΔU / Z_lcl
```

两个 32V 电源相位差 30°，电压差 ΔU = 2 × 32 × sin(15°) ≈ 16.5V。LCL 阻抗在 50Hz 处约 0.6Ω：

```
I_环 = 16.5 / 0.6 ≈ 27 A
```

**27A 瞬间能把所有 MOS 烧穿**。所以相位预同步是命门。

判定逻辑：让 PLL 跑 5 秒，监测 q 轴误差。当 |q轴误差| 持续 200ms 小于 0.5V（约相位误差 0.9°，对应环流 < 1A），认为锁定。**只有锁定标志置位，才允许合闸**。

**第三关：电流方向反转**

这是双向变换器和单向整流器最关键的区别。变流器 2 的 PWM 占空比是用电流环算出来的——电流目标为正时整流（电从交流到直流），电流目标为负时回馈（电从直流到交流）。

**两个方向的 PI 参数应该一致**，但符号要小心。具体做法是把电流目标 i_d_ref 当作有符号变量（带正负号），PI 输出直接送给 SVPWM。**不能写成两套独立的整流/回馈代码**——那样切换瞬间会有 dead band，电流断续。

做出来这一条 = 你已经有一台能工作的双向变流系统。**这是基本要求和发挥部分之间的真正分水岭，15 分到手**。

### 发挥 (2)：Pd 越小越好——逐项算损耗

> 变流器 1 输出 50Hz、U1=32V、I1=2A，要求直流电源输出功率 Pd = Id × Ud 越小越好。

**这是 30 分。这道题真正的胜负手。**

出题人的措辞是'越小越好'，没有上限分数线。**这意味着评委拿到所有队伍的成绩之后排序，按梯度给排名分**。前 5% 拿 30 分，前 20% 拿 22 分，剩下能做出来的 12~15 分。

工程师拿到这一条会先列等式，把 Pd 拆开。能量守恒：

```
Pd = P_out_变流器1 - P_in_变流器2 = P_loss_总
   = P_switch + P_conduction + P_copper + P_iron + P_aux + P_others
```

变流器 1 输出 110W，变流器 2 整流回去大概 100W。**那 Pd 就是 10W**。

这 10W 来自哪里？工程师会逐项算。

**第一项：MOS 开关损耗**

开关损耗的解析公式（线性近似）：

```
P_sw = (1/2) × Vds × Id × (tr + tf) × fs × N_mos
```

代入 Vds=60V, Id_avg=2A, tr+tf=100ns（IRFP4710 datasheet 典型值）, fs=20kHz, N_mos=12（变流器 1 + 变流器 2 各 6 颗）：

```
P_sw = 0.5 × 60 × 2 × 100e-9 × 20000 × 12 = 1.44 W
```

**第二项：MOS 导通损耗**

```
P_cond = I_rms² × Rds(on) × N_mos × duty
```

每颗 MOS 平均导通比 50%（PWM 占空比），**真实需要算每颗 MOS 在每个开关周期里的电流均方根**。简化估算 I_rms ≈ I_峰/√2 ≈ 2A（线电流峰值除以 √2）。Rds(on)=14mΩ：

```
P_cond = 2² × 0.014 × 12 × 0.5 = 0.34 W
```

（这里偏低估，实际由于 PWM 调制深度影响约 1.5W）

**第三项：电感铜损**

4 颗滤波电感（变流器 1 输出 LC 各 1 套 + 变流器 2 输入 LC 各 1 套，含 8 颗电感，每相电流 2A）。每颗电感铜电阻按线径估算：

0.8mm 漆包线，单位长度电阻：

```
R/m = ρ / A = 1.72e-8 / (π × 0.4e-3²) ≈ 0.034 Ω/m
```

绕 1mH 电感典型用线长 5m：R_cu ≈ 0.17Ω。但漆包线越粗 R 越小，实际取 50mΩ 估算。

```
P_cu = I² × R_cu × N = 2² × 0.05 × 8 = 1.6 W
```

**第四项：电感铁损**

按 EE25 磁芯典型损耗，50Hz 大概 0.25W/颗。8 颗 = **2W**。

**第五项：辅助电源**

栅极驱动 IC（Si8233）功耗 ≈ 0.3W × 6 = 1.8W。隔离运放 0.5W。MCU + OLED 0.5W。**合计 2.8W**。

**第六项：采样电阻 + 保护**

0.7W

**总计 Pd ≈ 1.44 + 1.5 + 1.6 + 2 + 2.8 + 0.7 = 10W**

这就是为什么基本盘做出来 Pd 在 8~10W 区间。**前几名队伍把 Pd 压到了 6W 以下**——他们逐项打破上面这些数。

**降 Pd 的四招（每招都是真公式真效果）**

**第一招：MOS 升级**。从 IRF540（Rds 44mΩ）换 IRFP4710（Rds 14mΩ）。导通损耗按 Rds 比例降到 14/44 = 32%。本来 1.5W → 0.5W。**Pd 降 1.0W**。

**第二招：电感重绕**。原 0.8mm 漆包线，截面积 π×(0.4)² = 0.50mm²。改 1.5mm 漆包线，截面积 π×(0.75)² = 1.77mm²，比原来粗 3.5 倍，**电阻降到 1/3.5**。8 颗电感铜损从 1.6W 降到 0.45W。**Pd 降 1.15W**。

**第三招：辅助电源整合**。原用 LM7812+LM7805 线性 LDO（48V→12V→5V），效率：

```
η_LDO = V_out / V_in = 5 / 48 ≈ 10%
```

你给 5V 0.5W 的负载，电源端要消耗 5W！**改用 LMR16030 buck 转换器**（48V→5V），效率 92%：

```
P_loss = 0.5 × (1/0.92 - 1) ≈ 0.04 W
```

辅助电源损耗从 5W 降到 0.04W。**Pd 降 4.5W！** 这一招最狠。

**第四招：冷启动延迟**。系统不工作时（待机），把变流器 2 的开关停掉、栅极驱动 IC 关掉。**待机功耗 < 100mW**。这一招对动态测试影响不大，但能让评委的功率计读数整体更低。

做完这些，**Pd 从 10W 优化到 4~5W 左右**。这不是单点突破能完成的，是 **20+ 个细节的叠加**。

所以发挥 (2) 玩的是工程师的耐心和经验。它不像基本要求那样有'对/错'，它是个**渐变的优化游戏**。**国一队伍在比赛最后一天 12 小时全在调这一项**。

### 说明里的暗坑

说明那部分看起来像免责声明，实际每一条都是出题人埋的雷。

**说明 (2)：'测试过程中不得重新连线及调整电路'**——这句话是天坑。

它的意思是：**你的变流器 2 必须能一次合闸成功，中途不能断电再来**。

这就要求你的合闸序列必须工程化。标准做法：

```
阶段 1（0~2s）：变流器 1 跑稳 50Hz 输出
阶段 2（2~7s）：变流器 2 进入'空载锁相'模式，PLL 跟踪（不开 PWM）
阶段 3（7s）：检查 PLL 锁定标志（q 轴误差 < 0.5V 持续 200ms）
阶段 4（7~9s）：合闸：PWM 占空比从 0 渐变到目标值（软启动）
```

软启动还有个细节：**电流环 PI 的积分项必须先清零**，否则上电瞬间积分项可能是上次比赛留的，输出立刻饱和。代码里在合闸前加 `pi.integral = 0;` 一行，省掉一台 MOS。

**省略任何一步都会 BOOM**。第一次接触这道题的人 95% 没做软启，按下启动键听到'啪'一声 + 看到烟，就是这条说明在'惩罚'他们。

**说明 (3)：'仅由图示直流电源供电'**

意思是你不能偷偷用 USB 给 MCU 加电、不能用 9V 电池给运放加电、不能在桌子下藏一个独立电源。**整套系统只有一根直流电源线**。

这就要求你的辅助电源全部从直流母线（60V）取。这意味着：

- 单片机 3.3V → buck 转换器（60V → 3.3V），效率 90%+
- 栅极驱动 12V → buck 转换器（60V → 12V），效率 92%+
- 隔离运放 5V → 从 12V 再 buck 一次或单独 buck，**不要用 LDO**
- 显示屏 5V → 同上

**这些辅助电源都是你 Pd 的一部分**。所以发挥 (2) 里第三招'辅助电源整合'之所以效果这么显著（降 4.5W），就是因为这条说明强行把所有辅助负载塞到母线上了。

**说明 (5)：'连接单元可根据变流器 2 的实际情况自行确定'**

这看似宽容，其实是最大的发挥空间。'连接单元'放在变流器 1 和变流器 2 之间。三种主流做法对比：

**L 滤波**（单一电感）：最简单，1 颗电感搞定。但开关纹波抑制只有 -20dB/decade。THD 大概 3%，**直接和基本要求 (2) 的 2% 标准冲突，不能用**。

**LCL 滤波**（电感 + 电容 + 电感）：三级滤波，对开关频率衰减 -60dB/decade。THD 1.5% 轻松达成。**但有谐振峰**——LC 谐振频率必须算清楚，否则系统失稳。设计公式：

```
f_res = (1/2π) × √((L1 + L2) / (L1 × L2 × C))
```

要求 f_res 远离基波（50Hz）和开关频率（20kHz）。一般取 f_res = 1~3kHz，加阻尼电阻防振荡：

```
R_d = (1/3) × (1 / (2π × f_res × C))
```

代入 f_res=1.5kHz, C=22μF：

```
R_d = (1/3) × (1 / (2π × 1500 × 22e-6)) ≈ 1.6 Ω
```

但 R_d 上有损耗，**取 0.5Ω 折中**。这是有源阻尼可以替代被动阻尼的工业做法（用控制器虚拟阻抗），但本科生时间紧，被动阻尼最稳。

**变压器隔离**：1:1 隔离变压器 + LC。安全性最好，但变压器铁损又增加 1~2W，**和'比谁省电'的发挥部分冲突，国一队伍很少选**。

国一队伍的标准答案是 **LCL**：电感 0.5mH + 电容 22μF + 电感 0.5mH，f_res ≈ 1.5kHz，配 0.5Ω 阻尼电阻。

这一条本身就贡献了 5 分的发挥空间——好的'连接单元'设计能让你的 THD 和 Pd 同时变好。
