## 想象一个场景

写字楼地下二层的弱电井里，运维师傅小王手边的笔记本电脑屏幕忽然黑了——会议室里 200 个人的视频会议刚开始 3 分钟，整层楼的网都没了。他打开维护手机，看到的告警很简单——**'交换机 G0/12 端口 link down'**。

故障在哪？

往上爬最容易：交换机面板灯亮，应该是好的。可疑的是从交换机到会议室那段 47 米的线——**它从天花板里穿过去**，中间过了 5 个走线槽、4 道防火墙、1 块强电干扰区。

老一辈电工的做法？**两端都拆水晶头**——掏出指针式万用表，**逐根线芯测**——

> '橙白对地通'  
> '橙对地通'  
> '绿白对地……不通？'

测一根 30 秒，8 根线测完 4 分钟——还不算两端轮换、做记号、判断。**会议已经废了**。

而小王手里掏出的那台**绿色塑料壳的小盒子**——只比手机大一圈、单价 800 块——叫**网线测试仪**：

| 厂商 | 型号 | 单价 | 测得的东西 |
|---|---|---|---|
| **Fluke MicroScanner** | MicroScanner 2 | ¥2500 | 长度、线序、衰减、双绞质量 |
| **Pakedge LinkRunner** | LRAT 2000 | ¥8000 | 加 PoE、协商速率、误码率 |
| **国产德力** | ST-248 | ¥800 | 长度、线序、屏蔽、短路定位 |
| **国产众兴** | ZX-3000 | ¥1200 | 同上 + 30MHz 衰减扫描 |

把测试仪的两端接到那 47 米线上，**按一个键**。3 秒钟之后小屏幕上跳出来一行字——**'46.8m, 直连线 568B, UTP, 短路位置: 23.4m'**。

故障定位完成。**回头爬到 23.4 米那个走线槽**，掀开盖板——果然有人新装空调时把网线压出来一个折，**线芯被金属边缘磨穿，两根撞一起短路了**。15 分钟换段线，会议恢复。

> **想象一下**——**网线测试仪就像 '线缆 X 光机'**——把不能看的东西显形成数字。
> - **'长度正常'** = 这根线身体完好  
> - **'线序错乱'** = 接错位置了，需要重新打水晶头  
> - **'短路位置 23.4m'** = 第 23 米处有故障，去那里掀盖板  
> - **'衰减 -8.2dB'** = 信号能透过去，传 1Gbps 没问题  
> - **'衰减 -22dB'** = 这根线已经废了，硬要用 100Mbps 都跑不满

本题让你做的——**就是这种网线测试仪的本科生入门版**。**用 200 块的成本，做出一台 1500 元商品的核心功能**。

这句话直接堵死了几条偷懒路线——

- **不让用商品 TDR 模块**（淘宝有 200 元的工业 TDR 模组，直接接 ARM 就能读距离）
- **不让用 Fluke 主板**（部分队伍想买二手 Fluke 拆主板伪装）
- **不让用激光测距**（线缆是软的，激光测两端距离 ≠ 线缆电气长度）

- **不让用称重**（一米线称重能算大概长度，但精度差且属于'非电参数'）

**强制留下的路径只有一条——TDR + 直接电参数测量**。这是本题的'命题铁壁'——**不会还得自己学**。

把三层意图拼起来——**2025 D 就是命题组对'仪器仪表方向'考生的诚意之作**：有产业需求、有题型沿革、有路线限定、有难度梯度。**做完这一题的人，简历上就能写 '能独立设计便携式 RF 测试仪表'**——这是仪表行业初级工程师的核心能力。

## 这题在做的事，其实是给一根线做'体检'

把测试仪当成医院。被测线缆是来体检的'病人'。**测试仪要在 5 秒内出一份完整体检报告**——这份报告包含 7 项指标，分两个'科室'体检：

**双端体检（线缆两头都接到测试仪）**：

像两个医生**'握手'**——两边各拿一个听诊器同时听。线缆全身被'夹'在两端中间，**电流可以从一头流到另一头**，所以能测：

1. **线对连接关系（直连/交叉）**——8 根芯一一对应关系
2. **线缆类型（UTP/SFTP）**——金属屏蔽层有没有
3. **直流电阻**——铜芯纯度、接触是否良好
4. **30MHz 交流衰减**——高频信号能不能透过去

**单端体检（只接一端，另一端开路）**：

像医生**'自言自语'**——一头喊话，听'回声'。线缆远端是开路的，**任何送进去的电信号都会原路反射回来**，所以能测：

5. **线缆长度**——回声往返时间反推距离
6. **短路位置**——如果中间有短路点，反射会提前回来
7. **远端开路状态**——验证远端确实没接东西

> **小白补课：'双端' vs '单端' 为什么是两个完全不同的物理原理？**
>  
> **双端**：信号从测试仪 A 端进、B 端出。**整条线是 '信号通路'**——测的是这条线 '通不通、通得好不好'。**像走完一段隧道**——能不能走通、走多久。
>  
> **单端**：信号从测试仪一端进、**线缆另一端开路**——信号撞到开路端就**反射回来**。**像对着山谷喊话听回声**——回声多久回来 → 山有多远。这种方法叫 **TDR（Time Domain Reflectometry，时域反射法）**——是雷达原理在线缆里的微缩版。

为什么要分两种模式？因为**它们测得的物理量根本不重叠**——

- 双端能测衰减但**测不了长度**（双端连接时回路里没有反射界面）
- 单端能测长度但**测不了衰减**（只接一端就只有反射波，没有'透射波'让你比较）
- 这两套是**互补的**，缺一不可

题面用一个按键切换两种模式——**这个按键的设计本身就是命题组的'教学温柔'**——**让本科生先理解 '为什么要分两种'**——**而不是上来直接堆功能**。

接下来按谜题逐个拆。

## 第一个谜：怎么识别线序——直连还是交叉

8 根线的线序识别问题，**乍一看挺简单**——'让一头送电、另一头接收，看谁亮'——但正经做起来藏着 4 道坎。

先看背景——双绞线物理结构：

```
水晶头 RJ45（顶视图，金属簧片朝上）：
        ┌───────────────────────────┐
位号    │ 1   2   3   4   5   6   7   8 │
线色    │橙白 橙  绿白 蓝  蓝白 绿  棕白 棕│
        └───────────────────────────┘

568B 标准（直连两端都用）：       568A 标准（交叉线缆 B 端用）：
1=橙白 2=橙   3=绿白 4=蓝         1=绿白 2=绿   3=橙白 4=蓝
5=蓝白 6=绿   7=棕白 8=棕         5=蓝白 6=橙   7=棕白 8=棕
```

**直连线缆（568B-568B）**：两端线序完全一样——**1↔1, 2↔2, 3↔3, ..., 8↔8**——做'电脑接交换机'用的标准线。

**交叉线缆（568A-568B）**：1 和 3 互换、2 和 6 互换——**1↔3, 2↔6, 3↔1, 6↔2, 其它不变**——给'两台电脑直接对接'用。

> **小白补课：为什么千兆网时代 '直连/交叉' 还需要识别？**  
>  
> 千兆以太网（1000Base-T）开始所有网卡都支持 **Auto-MDIX**（自动跨接）——意思是网卡会**自己判断对端发送的位置**，不管你接的是直连还是交叉，**它都能跑通**。  
>  
> **但识别这两种还是网线测试仪的标配**，因为：  
> 1. **百兆设备（如老式监控摄像头、工控 PLC）不支持 Auto-MDIX**——接错就不通  
> 2. **同一束 50 根线里如果混了 3 根交叉线、47 根直连线**——施工时识别错就接错了  
> 3. **质检环节'直连/交叉'是必填字段**——出厂的每根线都要标清楚类型

**识别方法的核心思想**：测试仪 A 端**逐根 '点亮' 8 根线**，B 端**记录每一次哪一根线收到信号**——反推出 A↔B 的连接映射表。

**坎 1：怎么 '点亮' 一根线**

最朴素的做法——A 端某根线送高电平（3.3V），其它 7 根接地。B 端 8 根线连 8 个 GPIO 输入——**读哪一根高，对方就接到 A 端这根**。

```c
for (int i = 0; i < 8; i++) {
    set_pin_a_high(i);          // A 端只有第 i 根送 3.3V
    set_pins_a_low_except(i);    // 其它 7 根拉 0V
    delay_ms(5);                 // 等信号稳定
    int j = read_pin_b_high();   // 读 B 端哪根是高电平
    mapping_a_to_b[i] = j;       // 记录映射
}
```

**这段代码说的其实是**——**'**逐根点亮 + 逐根记录 → 拿到映射表 → 比对模板 → 判断类型**'**。

**坎 2：怎么避免 '串扰' 把答案搞乱**

同一束线里 8 根线**互相挨着**，**A 端某根送 3.3V，会通过分布电容耦合到旁边的线**——B 端可能有 2~3 根都读到'高电平'，**辨不清到底是哪根**。

工程对策——**让信号不要太陡**：

| 信号方式 | 串扰严重度 | 抗干扰 |
|---|---|---|
| 阶跃电平（直接拉高/拉低） | **高** | **差** |
| 慢斜率电平（RC 充电 1ms） | **中** | **中** |
| **特定频率方波（1kHz）+ 频率检测** | **低** | **好** |
| **唯一调制码（不同根送不同 PRBS 码）+ 解调** | **极低** | **极好** |

入门做法——**1kHz 方波 + 阻抗匹配**：A 端某根线送 1kHz 方波，**剩余 7 根用 100Ω 电阻对地（吸收串扰）**。B 端 8 根线各接一个比较器，**只检测 1kHz 频率分量**——干扰信号是直流，会被高通滤掉。

```
A 端某根线: 1kHz 方波 ──► [双绞线] ──► B 端某根线: 1kHz 方波（衰减后）
其他 A 端线: 100Ω 端接 ──► 串扰被吸收 ──► B 端其他线: 几乎没信号
```

**这里有一段电路要落地**——

```
A 端 (8 选 1 模拟开关 ADG708 + 信号源 ─ 8 路 RJ45 引脚）
                                              │
                                            网线
                                              │
B 端 (8 个 100Ω 上拉电阻 + 8 路比较器 LM393)
```

ADG708 是 8 选 1 模拟开关，**单价 6 元**，导通电阻 4Ω，能精确把 8 个通道之一连接到 1kHz 信号源。LM393 比较器**单价 0.3 元**，0.3μs 响应，**够快**。

**坎 3：怎么处理 SFTP 屏蔽层带来的 '电容' 影响**

SFTP（双屏蔽双绞线）每对线外面都包了铝箔，**4 对线又共用一层金属编织网**——**寄生电容比 UTP 大 5~10 倍**。**这意味着信号上升边缘要 0.5ms 才能稳定**（UTP 只要 0.05ms）。

工程对策——**自适应延迟**：

```c
delay_ms(SFTP_detected ? 5 : 1);  // SFTP 等 5ms，UTP 等 1ms
```

**先做类型识别（第二个谜），再做线序识别**——这就是测试时间分配里 '先 SFTP/UTP 检测再线序' 的原因。

**坎 4：怎么应对 '线缆中间断了' 的异常**

如果线缆某根芯断了——A 端送信号，B 端**任何一根都读不到**——程序要识别这种异常并提示。

```c
if (mapping_a_to_b[i] == -1) {  // -1 表示 B 端无任何线收到
    display("线 %d 断路", i+1);
    return ERROR_OPEN_CIRCUIT;
}
```

实际产品里还会区分 '完全断路' 和 '高阻'——但本题题目要求只让 '识别直连/交叉'，**异常处理给个友好提示就行**。

**完整的 8 根线识别 + 比对**：

```c
// 步骤 1：先识别 SFTP/UTP（影响后续延迟参数）
detect_shielding_type();

// 步骤 2：8 根线逐根点亮
for (int i = 0; i < 8; i++) {
    excite_pin_a(i);
    delay_us(SFTP_mode ? 5000 : 1000);
    mapping[i] = read_pin_b_active();
}

// 步骤 3：模板匹配
if (memcmp(mapping, TEMPLATE_STRAIGHT, 8) == 0) {
    type = "直连";
} else if (memcmp(mapping, TEMPLATE_CROSS, 8) == 0) {
    type = "交叉";
} else {
    type = "异常";
}
```

**总测量时间**：8 根 × 5ms = 40ms（UTP）/ 8 × 5ms = 40ms（SFTP）—— **远低于 5 秒**。**线序识别 30 分入账**——这是基本要求 (2) 里最大头那一块。

## 第二个谜：UTP 还是 SFTP——一个电阻就能识别

第二个谜简单得令人发指——**'测一下水晶头金属外壳和铜芯之间的电阻'**——结束。

先看背景：

| 类型 | 全称 | 屏蔽层结构 | 水晶头外壳 |
|---|---|---|---|
| **UTP** | Unshielded Twisted Pair | **无屏蔽**，4 对线裸露 | **塑料**（无金属） |
| **SFTP** | Shielded Foil Twisted Pair | **每对线铝箔 + 整体金属网** | **金属外壳，连屏蔽层** |

**关键差异**——**SFTP 的水晶头金属外壳和内部 8 根线之间有连接**——**通过屏蔽层的接地点**。具体说——SFTP 线缆里**有一根'屏蔽地线'**，这根地线在水晶头处焊到金属外壳上。

**测量方法**——

```
       ┌─[水晶头金属外壳]─[10kΩ 上拉电阻]─[3.3V]
       │
       ▼
   测试仪 ADC → V_shield
       ▲
       │
       └─[8 根铜芯共同接地]
```

测得的电压 V_shield：

- **SFTP**：金属外壳通过屏蔽层连到内部接地——**V_shield ≈ 0V**（金属外壳-地之间是低阻 < 10Ω）
- **UTP**：金属外壳是塑料的——**V_shield ≈ 3.3V**（开路 > 1MΩ）

**这个判断说的其实是**——**'屏蔽层是不是和铜芯电气连接 → 是就 SFTP，否就 UTP'**——**单刀直入**。

**电路实现**——

```
RJ45 接口的金属屏蔽外壳 ─[10kΩ]─[3.3V]
                          │
                          ├─► STM32 ADC（PA0）
                          │
线缆 8 根芯共同 ─[GND]
```

软件——

```c
// 读 ADC，判断阈值
adc_value = read_adc(SHIELD_PIN);
if (adc_value < ADC_THRESHOLD_LOW) {  // < 0.5V
    type = "SFTP";  // 金属外壳-地短路
} else {
    type = "UTP";   // 金属外壳开路
}
```

**测量时间**：50ms（一次 ADC 转换 + 5 次平均消除噪声）。**整个识别流程 12 分入账**——基本要求 (2) 的子项。

> **小白补课：为什么 SFTP 比 UTP 贵 30%？**  
>  
> SFTP 多出来的 '铝箔屏蔽 + 金属编织网' 在工业现场抗干扰极强——**电焊机、变频器、雷达发射机** 旁边的网线必须用 SFTP，否则数据会被电磁干扰干扰得乱七八糟。  
>  
> **数据中心、医院 MRI 机房、广电演播室** 都强制用 SFTP——单价从 UTP 的 1.5 元/米涨到 SFTP 的 5 元/米。**家用环境用 UTP 就够了**——干扰源太少。

## 第三个谜：测 30MHz 衰减——专业仪器的味道

发挥要求 (1)——**测线缆对在 30MHz 频率处的交流衰减 dB 值**——这是题目最 '射频' 的一项。**没碰过 RF 的同学一看就头大**。

先理清概念——

**'衰减'（Attenuation）的物理定义**：信号沿线缆传输过程中**能量损耗的比例**——单位 dB，公式：

```
衰减（dB）= 20 × log10(U_out / U_in)
```

**这个式子说的其实是**——**'输出信号有多大、相比输入信号'**——**dB 是个比值的对数表示**。

| U_out/U_in | 衰减 dB |
|---|---|
| 1（不衰减） | 0 dB |
| 0.707（衰减一半功率） | -3 dB |
| 0.5（衰减一半幅度） | -6 dB |
| 0.1（衰减 90%） | -20 dB |
| 0.01 | -40 dB |

> **小白补课：为什么用对数表示衰减？**  
>  
> 信号经过两段相同的线缆，衰减是**乘**关系（每段乘 0.707 → 总共乘 0.5）；用 dB 表达就变成**加**关系（每段 -3dB → 总共 -6dB）。  
>  
> 工程师计算多级衰减时**加法比乘法直观 100 倍**——所以全行业用 dB。

**30MHz 是个特殊频率**——它落在以太网 100Base-TX（百兆网）信号频谱上沿的位置。**百兆以太网用的 MLT-3 编码主能量在 25~30MHz**。**测 30MHz 衰减 = 测百兆网能不能跑通**。

**测量原理**——

```
信号源（30MHz 正弦）
    │
   [50Ω 输出阻抗]
    │
   [100Ω 阻抗匹配（双绞线特征阻抗）]
    │
   [双绞线一对（如橙白-橙）]
    │
   [100Ω 端接电阻]
    │
   [幅度检测电路]
    │
   [STM32 ADC]
```

**关键工程问题**：

**问题 1：30MHz 信号源用什么？**

| 方案 | 单价 | 难度 | 精度 |
|---|---|---|---|
| **AD9851 DDS 模块** | 30 元 | ★ | 30MHz 输出 ±1Hz |
| **STM32 PWM 滤波** | 0 元 | ★★★ | 30MHz PWM 受限于主频 | 
| **ADF4351 PLL 模块** | 50 元 | ★★ | 35MHz~4.4GHz |
| **SI5351 时钟模块** | 25 元 | ★ | **8kHz~160MHz** |

**国一队伍的标配是 SI5351**——**比 AD9851 便宜，频率范围更广，I2C 控制方便**。SI5351 输出方波，但**经一颗 LC 低通滤波**就变成纯净 30MHz 正弦（5 阶椭圆滤波器，截止 35MHz，单价 5 元）。

**问题 2：阻抗匹配怎么搞？**

双绞线特征阻抗 100Ω（5e/6 类线标准）——但**信号源、ADC 端常用 50Ω**——必须做匹配。

**最简单的做法——电阻分压网络**：

```
50Ω 信号源 ─[24.9Ω 串联]─┬─► 100Ω 双绞线 ─[100Ω 端接]─► 检波
                          │
                        [82.5Ω 并联到地]
```

这是经典的 50Ω→100Ω '最小损耗匹配垫片'——理论损耗 5.7dB，**实测约 6dB**。**这 6dB 的固定损耗在校准时减掉**——不影响最终精度。

> **小白补课：为什么阻抗匹配很重要？**  
>  
> 高频信号在线缆上传输时，遇到**阻抗不匹配**就会**反射**——一部分信号反弹回信号源，**不到达接收端**。具体是 **驻波比（VSWR）** 越大反射越多——VSWR > 2 时反射 > 11%，30MHz 测量结果就会飘 ±1dB。  
>  
> '把信号送进线缆' 的难度不在于**提供多少电压**，而在于**让信号顺利进去 + 不反射回来**——阻抗匹配就是让 '入口和出口看起来都是一个无穷长的同型号线缆'。**整条线缆电气上 '看起来无穷长'，信号才不会反射**。

**问题 3：怎么测 30MHz 信号的有效值？**

STM32 内置 ADC 最快 2.4MSPS——**采不动 30MHz 信号**。

**两条路可选**——

**路径 A：高速 ADC + FFT**

用 AD9226 这种 65MSPS 的 12 位 ADC（**单价 30 元**）+ FPGA 缓存——硬件复杂、调试难。**国一才用得起**。

**路径 B：RMS-DC 转换器（推荐）**

**AD8362** 是 ADI 的对数检波 RMS-DC 转换器——**输入 30MHz 正弦，输出 0~1.5V 直流**——**直流值正比于输入信号的有效值（dBm 单位）**。

```
30MHz 正弦输入 ─► AD8362 ─► 直流电压输出 ─► STM32 ADC
                  ↑
              单价 80 元，封装 LFCSP-16
```

**精度**：±0.5dB（量程 -75dBm ~ -25dBm，约对应 38mV ~ 12mV）。**远超本题 10% 精度（约 ±1dB）要求**。

**完整的衰减测量流程**：

```c
// 1. 启动 30MHz 信号源
si5351_set_freq(30e6);
delay_ms(10);

// 2. 测输入端有效值（A 端）
int adc_in = read_ad8362(CHANNEL_INPUT);
float dbm_in = adc_to_dbm(adc_in);  // AD8362 输出 → dBm

// 3. 切换到输出端测量（B 端）
mux_select(CHANNEL_OUTPUT);
delay_ms(2);
int adc_out = read_ad8362(CHANNEL_OUTPUT);
float dbm_out = adc_to_dbm(adc_out);

// 4. 算衰减
float attenuation_db = dbm_out - dbm_in;  // dBm 相减就是 dB
display("30MHz 衰减: %.1f dB", attenuation_db);
```

**总耗时**：50ms（包含频率切换 + 2 次 ADC 测量）——**远低于 5 秒**——**10 分入账**。

**典型 5e 类网线衰减实测值**（对照表）：

| 长度 | 30MHz 衰减（理论） | 30MHz 衰减（实测） |
|---|---|---|
| 1m | -0.3 dB | -0.4 dB |
| 10m | -3.5 dB | -3.8 dB |
| 30m | -10.5 dB | -11.2 dB |
| 50m | -17.5 dB | -18.5 dB |

**误差 < 7%**——**轻松达标 10% 要求**。

## 第四个谜：单端 TDR 测线长——核心是 '反射时间差'

发挥要求 (2) 把单端测长度的精度从基本要求的 5% 直接拔到 **1%**——**5 倍提升**——这是技术含量最高的一项。

先抓核心——**TDR（时域反射法）的物理原理**：

```
测试仪发一个'陡峭脉冲'  ──► [线缆]  ──► 远端开路
                                            │
                                          反射回
                                            │
反射波回到测试仪    ◄── [线缆] ◄────────────┘
```

**时间差 Δt 和距离 L 的关系**：

```
L = (Δt × v) / 2
```

**这个式子说的其实是**——**'信号往返时间 × 传播速度 ÷ 2 = 单程距离'**——和雷达测距原理 100% 相同。

> **小白补课：信号在双绞线里跑多快？**  
>  
> 自由空间光速 c = 3×10⁸ m/s。但在双绞线里，信号要在塑料绝缘介质中传播——**速度会降低**。这个降低系数叫 **NVP（Nominal Velocity of Propagation，标称传播速度）**——5e 类双绞线 NVP ≈ 0.65~0.7。  
>  
> **实际信号速度**：v = c × NVP = 3×10⁸ × 0.67 ≈ **2×10⁸ m/s**——**每秒 20 万公里**。  
>  
> 1m 双绞线信号往返：Δt = 2 / 2×10⁸ = **10ns**——这就是 TDR 测量的时间精度量级。

**算一下 1% 精度的硬件要求**：

```
50m 线缆往返时间 Δt = 2 × 50 / 2×10⁸ = 500ns
1% 精度对应时间精度 = 500ns × 1% = 5ns
```

**ADC 至少要 1/(5ns) = 200MSPS 采样率**——**STM32 内置 2.4MSPS 完全不够**。

**怎么办？三条路径**——

**路径 A：高速 ADC + FPGA**

**AD9226（65MSPS）** 或 **AD9484（500MSPS）** 配 FPGA（如 EP4CE6）—— 单端 TDR 系统硬件成本约 200 元——**国一标配**。

**路径 B：等效采样（推荐入门）**

**等效采样**——利用 '信号是周期性的' 这个特点——**用慢 ADC 采多个周期的信号 + 重排成一个高速波形**。具体：

- ADC 1MSPS（采样间隔 1μs）
- 触发脉冲每 1ms 发一次（重复 1000 次）
- 每次触发后 ADC 采样的相位**故意错开 1ns**
- 1000 次触发后，**重排数据 → 等效采样率 1GSPS**

工程实现：

```c
for (int trial = 0; trial < 1000; trial++) {
    delay_ns(trial);              // 第 trial 次比第 0 次延迟 trial ns
    send_tdr_pulse();
    int sample = read_adc();
    waveform[trial] = sample;     // 拼接成高分辨率波形
}
// 现在 waveform[] 数组等效于 1GSPS 采样
```

**优点**：硬件极简（一颗 STM32 + 一个比较器）。  
**缺点**：测量时间 = 1000 × 1ms = 1 秒——**正好压在题目限制内**。

**路径 C：高速比较器 + 计数器（推荐进阶）**

**MAX9601（亚 ns 比较器）** + **STM32 内置 32 位定时器**——**最高 168MHz 计数 = 6ns 时间分辨率**——**接近 1% 精度**。

```
TDR 脉冲发送 ─► 启动计数器
                    │
反射波到达 ─► MAX9601 触发 ─► 锁存计数器值
                    │
[计数器值 × 时钟周期] = 往返时间
```

**国一队伍的最优解**——**FPGA + AD9484** 路径，3ns 时间分辨率，**精度 ±0.3%**——**超越 1% 要求 3 倍**。

**TDR 信号源用什么？**

需要一个**陡峭的脉冲**——上升时间越短越好，**这样反射波的边沿才尖锐**。

| 信号源 | 上升时间 | 价格 |
|---|---|---|
| **STM32 GPIO 直接拉高** | 5ns（受 GPIO 驱动电流限制） | 0 元 |
| **74LVC1G14（施密特反相器）** | 2ns | 0.3 元 |
| **MC100EP16（ECL 差分缓冲）** | 0.3ns | 5 元 |
| **专用 TDR 脉冲发生器（淘宝）** | 0.1ns | **不允许用（商品模块）** |

**入门用 STM32 GPIO + 74LVC1G14 整形** ——上升时间 < 2ns——**精度足够 1%**。

**校准——这一步省下 5 分**

题面说明 (1)：

> 测评现场提供 1m 长 SFTP 型和 50m 长 UTP 型的线缆，**供参赛队在测试前进行现场校准**。

这是一份**白送的礼物**——**主办方给你两个已知长度的线缆**——**让你现场测量、记录系统误差、写到 EEPROM 里**。

校准代码：

```c
// 上电后第一步：按 '1m 校准' 按键
press_calibration_button(LENGTH_1M);
int t_1m = measure_tdr_time();  // 测得 1m 线缆的反射时间
nvp_factor = (2 * 1.0) / t_1m / SPEED_OF_LIGHT;  // 推导 NVP
save_to_eeprom(nvp_factor);

// 按 '50m 校准' 按键
press_calibration_button(LENGTH_50M);
int t_50m = measure_tdr_time();
expected_t_50m = (2 * 50.0) / (SPEED_OF_LIGHT * nvp_factor);
nonlinear_correction = expected_t_50m - t_50m;  // 长距离非线性修正
save_to_eeprom(nonlinear_correction);
```

**'校准前精度 ±5%'** vs **'校准后精度 ±0.3%'** —— **15 分稳稳到手**。

> **小白补课：为什么必须现场校准？**  
>  
> 双绞线 NVP 因厂家、批次、年份、温度而变——**5e 类一般 0.65~0.72**——**你训练时用的线和测评现场提供的可能差 8%**。  
>  
> **没现场校准 = 长度测量精度天花板就是 8%**——发挥 (2) 要求 1%，**直接挂掉 15 分**。  
>  
> **国一队伍永远把 '现场校准' 写在调试清单第一行**——这是省赛/国赛的必杀技之一。

## 第五个谜：短路位置定位——这才是真正的 '炸场' 项

发挥要求 (3)——**测短路位置，长度 1m~50m，精度 1%**——**20 分**——这是这道题的'珠穆朗玛峰'。

为什么难？因为**短路点的反射比开路反射复杂得多**。

**开路反射**（已经在第四个谜里讲过）——单一陡峭反射峰，**'信号撞墙弹回来'**。

**短路反射**——

```
入射波 ──► [线缆 0~Lₛ 段] ──► 短路点 ──► [线缆 Lₛ~End 段]
              │                  │            │
            部分反射            部分反射     部分反射
              │                  │            │
              └─────────► 回到测试仪
```

**短路点不是 '完全的反射镜'**——一部分能量反射回测试仪、**一部分继续穿过短路点向远端传播**——远端开路再反射一次回来——**测试仪能收到两个反射峰**（短路点的 + 远端的）。

**朴素方法**——**找 '第一个反射峰' 的时间**：

```c
float* waveform = capture_tdr_waveform();
int peak_index = find_first_peak_above_threshold(waveform);
float t_short = peak_index * sample_period;
float L_short = t_short * nvp * c / 2;
```

**问题**——**短路反射波形不是干净的尖峰**——可能是**慢上升 + 振荡**——'阈值法' 容易误触发。

**进阶方法——FFT 域分析**：

把整个反射波形 FFT，**短路点的反射在频域呈现 '梳状'**——多次往返产生的谐波结构——**用 FFT 找最大谱线就能精确定位**：

```c
float* waveform = capture_tdr_waveform();
fft_compute(waveform, fft_result, N);
int peak_bin = argmax_magnitude(fft_result, N);
float t_short = peak_bin * sample_period;
float L_short = t_short * nvp * c / 2;
```

**精度**：**±10cm**（50m 线上 0.2%）——**远超 1% 要求**。

**国一队伍的算法栈**：

```
1. 时域反射波形（1024 点 @ 1GSPS 等效采样）
   ↓
2. 加 Hann 窗 + FFT
   ↓
3. 在 FFT 谱里找'最大反射峰'（短路点）
   ↓
4. 找'次大反射峰'（远端开路）
   ↓
5. 用'两个峰的位置比较'区分 '远端开路 + 中间无短路' 和 '中间短路'
   ↓
6. 输出短路位置 + 远端开路位置
```

**6 步算法 + 现场校准 = 20 分稳进**。

> **小白补课：'频域 FFT' 为什么比 '时域阈值' 精度高？**  
>  
> 时域阈值法对**单点**的判断敏感——一个噪声尖峰就能误触发。  
>  
> FFT 把整个波形的能量分散到 1024 个频率 bin 里——**任何一个 bin 的判断都基于 1024 个采样点的总信息**——抗噪声能力 √1024 ≈ **32 倍提升**。  
>  
> 这是 '群体智慧 vs 个体判断' 在信号处理里的体现——**总是要相信群体**。

### 任务那段话——'用 6V 单电源做一台 RJ45 测试仪'

题目原文（第 11 行）：

> 显示屏设计并制作一个简易以太网双绞线测试仪（简称测试仪），如图1所示。**待测以太网双绞线（简称线缆）通过 RJ45 连接器与测试仪连接**。线缆**双端接入测试仪，测量线缆的线对连接关系（直连、交叉）、类型(非屏蔽双绞线 UTP、双屏蔽双绞线 SFTP)、直流电阻，以及交流衰减**；线缆**单端接入测试仪，测量线缆的长度和短路位置**。**测试仪由不大于 6V 的单电源供电**。

这一段每一句话都是设计的边界条件——**少看一个字就掉一个分**。

**第一笔账：'RJ45 连接器' = 必须用 RJ45 母座**

RJ45 是 8P8C 标准——8 根线插进 1 个 8 位母座。你不能简化成 2 个 BNC 头（用同轴线接）——**评委一看不是 RJ45 就当场扣分**。

工程选型：

| 物料 | 型号 | 单价 | 备注 |
|---|---|---|---|
| RJ45 母座（带屏蔽） | Amphenol RJSA-5081 | 2.5 元 | 金属屏蔽外壳 + 8 路独立引脚 |
| RJ45 母座（无屏蔽，便宜版） | 通用 | 0.5 元 | 塑料外壳，**不能识别 SFTP 屏蔽** |
| RJ45 母座（带 LED） | Amphenol RJ-SE48 | 3.5 元 | 自带链路指示灯 |

**必须买带屏蔽的版本**——因为基本要求 (2) 要识别 UTP/SFTP——**屏蔽外壳是检测点**。买便宜的塑料版直接没法做这一项——丢 12 分。

**第二笔账：'双端接入' 要 2 个 RJ45 母座**

题面 (a) 图——'双端连接测量'——意味着**线缆的两端都接到测试仪上**。所以测试仪上有 **2 个 RJ45 母座**——'端口 1' 和 '端口 2'。

**这是为什么 BOM 表里 RJ45 母座的数量是 2**。

**第三笔账：'单端接入' 用同一个端口**

(b) 图——'单端连接测量'——线缆只接到端口 1（或端口 2），**另一端开路**。**端口 2 此时没插东西**。

工程上——**单端测量本质上就是 '一端接、一端开'**——电路上不需要做切换。**软件只要识别 '现在是双端模式还是单端模式'**——按键切换。

**第四笔账：'不大于 6V 的单电源' 是个甜蜜陷阱**

**6V 单电源**——意思是**电池组最大 6V 输入**——常见选择：

### 基本要求 (1)：按键切换两种工作模式 - 4 分

这是**全题最简单的 4 分**——**1 个按键 + LCD 切换两个界面**。

**实现要点**——

typedef enum {
    MODE_DUAL_END,   // 双端检测
    MODE_SINGLE_END  // 单端检测
} TestMode_t;

TestMode_t current_mode = MODE_DUAL_END;

void on_button_press() {
    if (current_mode == MODE_DUAL_END) {

**坑——按键防抖**：

```c
volatile uint32_t last_button_time = 0;

void button_isr() {

}
```

### 基本要求 (2)：双端检测 - 30 分

题目原文（第 24 行）：

> （2）'双端检测'模式。要求测量并显示线缆的**线对连接关系（直连、交叉）、类型(UTP 、SFTP)、直流电阻值(长度范围 1m~50m、相对误差的绝对值不大于 10%)**，**测量时间不超过 5s**。

这一条是**全题第二大头分（仅次于发挥 (3) 的 20 分）**——**30 分**。但**实际拆开来讲**，它包含 **3 个子任务**——

**子任务 A：线对连接关系（直连/交叉）**

前面 '第一个谜' 已经讲过——**1kHz 方波 + 8 选 1 模拟开关 + 比较器**——**预算约 50ms**。

**评分细节**——题目原文没明说每个子项分值，但根据 2025 年比赛实测——**3 个子任务大致 10 分 + 12 分 + 8 分**——大致符合 '复杂度比例'。

**子任务 B：类型识别（UTP/SFTP）**

前面 '第二个谜' 已经讲过——**测水晶头屏蔽层与铜芯电阻**——**预算约 50ms**。

**子任务 C：直流电阻值（长度 1m~50m、误差 < 10%）**

直流电阻测量——**经典的四线法**：

```
电流源 ─► [线缆 R_线] ─► 接地
                           │
                       同时测电压 V_线
                           │
                         R_线 = V_线 / I 源
```

> **小白补课：为什么不用普通的 '电源 + 电阻分压' 法？**  
>  
> 普通分压法的电流要经过 **'引线 + 测试仪内部走线'** ——这些**接触电阻和铜走线电阻** 也是几十毫欧——**如果测一根 1m 网线（标称电阻约 0.2Ω），引线电阻就跟它差不多大了**——**误差 100%**。  
>  
> **四线法**的核心思想——**'供电的两根线' 和 '测电压的两根线' 分开**——电压表无电流流过——**接触电阻不影响测量**。这是**毫欧级电阻测量的标配方法**。

**电路实现**——

```
[恒流源 1mA] ─► RJ45 端口 1 第 1 脚 ─► [线缆芯 1] ─► RJ45 端口 2 第 1 脚 ─► GND
                          │                                          │
                       [电压表+]                                   [电压表-]
                          │                                          │
                          └────► STM32 ADC 差分输入 ◄────────────────┘
```

**单芯典型电阻**——5e 类铜芯 **0.094 Ω/m × 长度**——

| 线缆长度 | 单芯电阻 | 测量电压（1mA 恒流） |
|---|---|---|
| 1m | 0.094 Ω | 94 μV |
| 10m | 0.94 Ω | 940 μV |
| 50m | 4.7 Ω | 4.7 mV |

**1m 线的 94μV 电压**——**STM32 12 位 ADC 分辨率 0.8mV**——**根本测不到**——必须用**仪用放大器（INA826）放大 1000 倍**——**94mV → 12 位 ADC 能分辨**。

**8 根线分别测 + 求平均** —— 总耗时约 **400ms**。

**坑——温度补偿**

铜的温度系数 **0.4%/℃**——20℃ 测的电阻值在 35℃ 比 0.4% × 15 = **6%**——**接近 10% 误差极限**。

工程对策——**用 STM32 内置温度传感器 + 温度补偿系数**：

```c
float temperature = read_internal_temp();
float corrected_resistance = measured_resistance * (1 + 0.004 * (20 - temperature));
```

**总测量时间**：线序识别 50ms + 类型识别 50ms + 直流电阻 400ms + 数据处理 100ms = **600ms** —— **远低于 5 秒**——**30 分稳稳吃下**。

**坑——5 秒限制是宽限**

题目要求 5 秒——你的最快方案 600ms——**剩余 4.4 秒可以用来 '多次平均消除噪声'**——**这一招把精度从 10% 提升到 3%**：

```c
const int N_AVERAGE = 20;  // 多测 20 次取平均
float sum = 0;
for (int k = 0; k < N_AVERAGE; k++) {
    sum += measure_resistance();
    delay_ms(50);  // 每次间隔 50ms 让电路稳定
}
float average_resistance = sum / N_AVERAGE;
// 总耗时 1.1 秒，仍远低于 5 秒
```

**这是国一队伍的标配做法**——**'有时间就多测几次'**。

### 基本要求 (3)：单端检测 - 16 分

题目原文（第 26 行）：

> （3）'单端检测'模式。要求测量并显示**线缆长度(长度范围 10m~50m、相对误差的绝对值不大于 5%)**，**检测线缆是否存在线对间短路**，**测量、检测时间分别不超过 5s**。

这一条是**单端 TDR 的入门版**——**精度 5%（基本要求）vs 1%（发挥 (2)）**——**5 倍精度差**——**软硬件难度天差地别**。

**子任务 A：长度测量（精度 5%）**

50m × 5% = 2.5m 精度——**对应 25ns 时间精度**——**40MSPS ADC 就够**——**STM32 内置 ADC 都能勉强达标**！

**这是为什么基本要求 (3) '看起来简单'**——**5% 精度门槛低**——**国二队伍 100% 都能做出来**。

但**陷阱在 '10m~50m' 这个范围里**——

- **10m 线**：往返 100ns —— **STM32 1MSPS（采样间隔 1μs）的 ADC 根本采不到 100ns 内的反射**！
- **50m 线**：往返 500ns —— **STM32 1MSPS 能采到 1 个数据点**——**精度极差**。

**所以基本要求 (3) 的最低硬件门槛——还是要 FPGA 或者高速比较器**——**不是 '随便用 STM32 就能做'**。

**最便宜的合规方案——MAX9601 比较器 + STM32 定时器**——**168MHz 时钟 = 6ns 分辨率**——**精度 ±0.6m / 50m = 1.2%**——**远超 5% 要求**——**单价 5 元**。

**子任务 B：短路检测**

**注意——题面只说'检测是否存在短路'——不要求定位短路位置**——**这一条是发挥 (3) 的事**。

简化版：**送入一个脉冲、看反射强度**——**远端开路 = 反射波平稳**； **中间短路 = 反射波非常陡峭，比远端开路还强**。

```c
int reflection_amplitude = measure_first_reflection_amplitude();
if (reflection_amplitude > THRESHOLD_SHORT) {
    display("有短路");
} else {
    display("无短路");
}
```

**5 行代码搞定**——**但注意——基本要求 (3) 仅要求'是否存在'——所以 16 分里可能 5 分给短路检测**。

**总分配**——**16 分 = 长度 10 分 + 短路检测 6 分**——**全做完入账**。

### 发挥 (1)：30MHz 衰减 - 10 分

题目原文（第 30 行）：

> （1）'双端检测'模式。要求测量并显示线缆对在 **30MHz 频率处**的**交流衰减 dB 值**(**长度范围 10m~50m**、**相对误差的绝对值不大于 10%**)，**测量时间不超过 5s**。

前面 '第三个谜' 已经详细讲过——**SI5351 + AD8362 + 5 秒内完成**——**10 分入账**。

**坑——'10m~50m' 范围里的衰减跨度**

| 长度 | 30MHz 衰减 |
|---|---|
| 10m | -3.5 dB |
| 30m | -10.5 dB |
| 50m | -17.5 dB |

**5 倍长度跨度对应 5 倍衰减跨度**——**AD8362 量程 50dB 完全覆盖**——**精度 ±0.5dB**——**对应误差**：

```
10m 线测得 -3.5dB ± 0.5dB = -3.0~-4.0dB → 误差 14%   ⚠ 接近边界
50m 线测得 -17.5dB ± 0.5dB = -17~-18dB → 误差 3%
```

**10m 线是临界点**——**为了稳过 10% 要求**——**多次平均**：

```c
const int N = 10;
float sum_dbm_in = 0, sum_dbm_out = 0;
for (int k = 0; k < N; k++) {
    sum_dbm_in += measure_input_dbm();
    sum_dbm_out += measure_output_dbm();
    delay_ms(50);
}
float attenuation = (sum_dbm_out - sum_dbm_in) / N;
```

**N=10 把误差 √10 倍降低**——**精度 ±0.16dB**——**远超 10% 要求**。

### 发挥 (2)：长度精度 1% - 15 分

题目原文（第 32 行）：

> （2）'单端检测'模式。要求测量并显示**线缆长度（长度范围 1m~50m、相对误差的绝对值不大于 1%）**，**测量时间不超过 5s**。

前面 '第四个谜' 已经详细讲过——**FPGA + 高速比较器 + 等效采样 + 现场校准**——**精度 ±0.3%**——**远超 1% 要求**——**15 分入账**。

**两个细节再强调**——

**细节 1：1m 线的测量难度反而比 50m 大**

- **50m 线**：往返 500ns —— **足够长，等效采样误差小**——**1% = 50cm 容许**
- **1m 线**：往返 10ns —— **极短，时间分辨率要求最严**——**1% = 1cm 容许**——**对应时间精度 < 100ps**

**所以 1m 线是设计的'底线'**——**这一段 1% 精度需要 FPGA + 内插算法**：

```c
// FPGA 1GSPS 等效采样后的内插
// 信号上升边在采样点之间时，用线性内插提升时间精度
float t_sub_sample = sample_point + (V_threshold - V[sample_point]) / 
                    (V[sample_point+1] - V[sample_point]);
```

**这一招把 1ns 分辨率提升到 0.1ns**——**1m 线精度也达标**。

**细节 2：现场校准必须做**

题面说明 (1) 已经讲过——**主办方提供 1m + 50m 标准线**——**校准前精度 ±5%**，**校准后精度 ±0.3%**。

**调试清单第一行**：上电后强制做现场校准——**用按键触发 '1m 校准' 和 '50m 校准'**——校准结果存 EEPROM。

```c
void on_calibration_1m_button() {
    int t = measure_tdr_round_trip_time();
    nvp_factor_calibrated = 2.0 / t / SPEED_OF_LIGHT;
    eeprom_save(NVP_OFFSET, nvp_factor_calibrated);
}
```

**这一步操作 30 秒搞定**——**15 分稳稳到手**。

### 发挥 (3)：短路位置 1% - 20 分（终极考验）

题目原文（第 34 行）：

> （3）'单端检测'模式。要求测量并显示**线缆的短路位置**（**长度范围 1m~50m、相对误差的绝对值不大于 1%**），**测量时间不超过 5s**。

前面 '第五个谜' 已经详细讲过——**FFT 域分析定位反射峰**——**精度 ±10cm**——**远超 1% 要求**——**20 分入账**。

**这里再次强调——1m 线的短路定位是'恶魔级'难度**

- **1m 线 1% 精度 = 1cm 短路定位精度**
- **对应 0.1ns 时间分辨率**——**1GSPS 等效采样 + 0.1ns 内插**

**国一队伍的算法栈**——

```
1. ADC 等效采样波形（1024 点 @ 等效 1GSPS）
   ↓
2. 加 Hann 窗（消除频谱泄漏）
   ↓
3. 1024 点 FFT
   ↓
4. 找前两个最大反射峰
   ↓
5. 时间内插（亚采样精度 0.1ns）
   ↓
6. 距离 = 时间 × NVP × c / 2
   ↓
7. 区分'远端开路'和'中间短路'
   ↓
8. 输出短路位置
```

**8 步 + FPGA + 现场校准 = 20 分稳进**。

**国二队伍的 90% 都没做出来这一题**——**因为算法门槛太高**——**这就是 '国一/国二分水岭'**。

### 说明里的暗坑

题目'说明'部分看起来像免责条款——**每一条都是出题人埋的雷区或礼物**。

**说明 (1)——白送的礼物**：

> 被测线缆由测评现场提供。**测评现场还提供 1m 长 SFTP 型和 50m 长 UTP 型的线缆，供参赛队在测试前进行现场校准**。

前面已经讲过——**30 秒校准 = 精度从 ±5% 提升到 ±0.3%**——**这是发挥 (2)/(3) 拿满分的关键**。

**调试清单第一行**——**'上电后立即做现场校准'**——**国一标配**。

**说明 (2)——'一键启动'强制约束**：

> 作品测评过程中，**除了按 '双端检测'、'单端检测' 一键启动相应功能并开始计时外**，**不允许对测试仪进行其他任何调整和操作**。

**核心限制——只允许 1 个按键**——**模式选择 + 启动测试 都靠这一个键**。

工程对策——**短按 = 切换模式**，**长按 = 启动测试**——**1 个按键搞定 2 个动作**：

```c
volatile uint32_t button_press_start = 0;

void button_isr_falling() {
    button_press_start = HAL_GetTick();
}

void button_isr_rising() {
    uint32_t duration = HAL_GetTick() - button_press_start;
    if (duration > 1000) {
        // 长按 = 启动测试
        start_measurement();
    } else if (duration > 50) {
        // 短按 = 切换模式
        toggle_mode();
    }
    // < 50ms 视为抖动，忽略
}
```

**'短按切模式 + 长按启动'**——**1 个按键 = 2 个功能**——**符合题目限制**。

**说明 (3)——'线对连接关系'的图示意义**：

> 基本要求 (2) 中的 '线对连接关系' 是指**直连线缆或交叉线缆**，如图 2 所示。

题目附图显示了直连和交叉的具体接线规则——**这是设计'线序映射模板'的依据**——**前面 '第一个谜' 已经详述**。

**说明 (4)——'线缆长度' 的精确定义**：

> 题目中的 '线缆长度' 为**线缆水晶头边缘的直线距离**，如图 3 所示。**发挥部分 (3) 中的 '短路位置' 为水晶头边缘到短路中心点的直线距离**。

**关键——水晶头边缘**——而不是 '水晶头电气接触点'——**两者差 5~8mm**——**直接影响 1m 校准的准确度**。

**校准时的注意点**——**用游标卡尺精确测量水晶头边缘到水晶头边缘的距离**——确保 1m 校准线**精确为 1.000m**——**否则 1m 校准 8mm 误差 = 0.8% 精度损失** = **直接挂掉发挥 (2)**。

**说明 (5)——'测量误差' 的精确定义**：

> 题目中检测**相对误差的绝对值 δ = | 测量值标准 - 标值 | / 标准值 × 100%**。**标准值是指由测量仪器测量得到的线缆参数值**。

**关键——'标准值由测量仪器测量得到'**——**不是用尺子测**——**评委用 Fluke MicroScanner 这种专业仪器测的值作为标准**。

**这意味着——你的测量仪需要和 Fluke 的测量仪 '保持一致'**——**校准是关键**。

**说明 (6)——交流衰减的精确定义**：

> 发挥部分 (1) 中的 '交流衰减' 是指**线缆对的输出电压值 UoPP 与输入电压值 UiPP 之比**，即**交流衰减 dB 值为 20lg(UoPP/UiPP)**。**测量时应注意阻抗匹配问题**。

**这是题目唯一一处明确给出公式的地方**——**'输出电压 / 输入电压'**——**意味着 dB 值是负数**（输出比输入小）。

**'测量时应注意阻抗匹配问题'**——**这一句话提示了你 '不做阻抗匹配 = 测量值漂 ±2dB'**——**前面 '第三个谜' 已经详述**。

**说明 (7)——SFTP 屏蔽外壳的提示**：

> 对于 **SFTP 型线缆**，应注意 **RJ45 连接器有屏蔽外壳**。

**这一句话提示了 '类型识别' 的检测点**——**就是 RJ45 屏蔽外壳和铜芯的电阻**。**前面 '第二个谜' 已经详述**。

**说明 (8)——禁令清单**：

**前面 '出题人是怎么想到这道题的' 已经详述**——**强制留下 '电参数测量 + 自制电路' 这一条路径**——**这是命题铁壁**。
