## 想象一个场景

凌晨 3 点 17 分，你开车走在京沪高速河北段。车窗外漆黑一片，连服务区的招牌都看不见。你的副驾正睡得死死的。**车里只剩下一个声音陪着你**——**收音机里那位声音沙哑、用河北口音念房产广告的中年男主播**。

主播的频率是 **102.3 MHz**，**叫'河北交通广播'**。

你开了 50 公里之后——主播的声音忽然开始**沙沙作响**——又过 10 公里——**几乎全是噪声**——**你出了这个台的覆盖区**。

你按一下方向盘上那个**'AS'按钮**（**Auto Scan，自动扫描**）。仪表盘上的频率数字开始**'88.0...88.5...89.1...90.3...'** 一路飙——**两秒钟后停在 96.7 MHz**——**冒出一段山东戏曲**。再按一下——**99.4 MHz，山东体育广播**。又按一下——**101.8 MHz，济南新闻综合**。

**这一连串的'扫频 → 锁定 → 解调'**——**整个过程不到 8 秒**——**车里那块巴掌大的电路板已经把 88~108MHz 这 20MHz 的频段从头到尾扫了一遍**——**找到了所有强信号 → 自动识别它们是 FM 还是 AM → 解调出音频送到扬声器**。

你脑子里浮现一个问题——**它怎么做到的？**

90 年前——1933 年——美国陆军通信兵阿姆斯特朗（Edwin Armstrong）发明了 FM 调频技术——**为这个画面奠定了第一块砖**。  
70 年前——1948 年——香农发表《通信的数学理论》——**告诉所有工程师'信道容量有上限'**。  
30 年前——1990 年代——美国军方提出'软件无线电（SDR）'概念——**一颗 FPGA + 一颗高速 ADC 替代一柜子模拟电路**。  
**今天**——你车里那块价值 80 元的收音机模块——**就是这 90 年技术演进的最终产物**。

> **想象一下**——**整个 88~108MHz 频段是一条 20 公里宽的高速公路**——**每 100kHz 一条车道**——**总共 200 条车道**——**有些车道上有车（电台），有些是空的**。  
>  
> 你开着车（接收机）从一头扫到另一头——**每条车道停 50 毫秒看看上面有没有车**——**有车就把它的'声音'转录下来**——**没车就跳到下一条**——**全程 10 秒扫完**——**这就是'自动接收机'的本质**。

题目让你做的——**就是这种汽车收音机的本科生入门版**——**用 200 元的预算 + 4 天 3 夜**——**把现代通信工程师 90 年来积累的技术做成一台手掌大小的设备**。

题目里的所有数字——**88-108MHz、100kHz 步进、300-3400Hz 音频、-85dBm/-95dBm 灵敏度、≤5s 响应**——**每一个都来自现实世界商品收音机的标准参数**——**做完这一题你就能看懂任何一台 FM 收音机的规格书**。

## 这题在做的事，其实是教接收机'扫频 + 听清 + 认调制'三件事

把整个题目压缩成一句话——**'让一台接收机自己扫遍 88-108MHz 的 200 条信道，找到强信号，认出它是 FM 还是 AM，解调成音频送到喇叭'**。

**三件事**——**每一件都是一个完整的通信工程子学科**：

```
事件 A：扫频          事件 B：听清          事件 C：认调制
（频率搜索）          （高灵敏度接收）       （模式识别）
   ▲                    ▲                    ▲
   │                    │                    │
[88-108MHz]           [-95dBm]              [FM/AM/CW]
   │                    │                    │
扫描算法 + RSSI 检测   LNA + 屏蔽 + 算法    包络/频偏分析
```

**事件 A——扫频**：把 88-108MHz 这 20MHz 切成 200 个 100kHz 信道——**逐个或并行扫描**——**用 RSSI（信号强度指示）找到有信号的信道**。

**事件 B——听清**：找到信道后**把信号干净地放出来**——**这考验的是接收机的'灵敏度'**——**-95dBm 是个挺低的功率（对应大约 0.05μV 在 50Ω 负载上）**——**需要低噪声放大器 + 屏蔽 + 信号处理算法**。

**事件 C——认调制**：拿到信号后**判断它是 FM 还是 AM 还是 CW（单频载波）**——**送到对应解调器**——**输出干净的音频**。

> **小白补课：FM、AM、CW 是什么？**  
>  
> **载波（Carrier）**——**100MHz 的高频正弦波**——**'空白纸'**。  
>  
> **AM（Amplitude Modulation，调幅）**——**在载波上'写信息'的方式是改变振幅**——**信号强 = 大喇叭，信号弱 = 小喇叭**。**像往汽水瓶里灌水**——**水位高低变化代表音频信号**。  
>  
> **FM（Frequency Modulation，调频）**——**在载波上'写信息'的方式是改变频率**——**音频高 = 载波频率高，音频低 = 载波频率低**。**像吹哨子**——**哨音高低代表音频信号**。  
>  
> **CW（Continuous Wave，连续波）**——**载波上不写信息**——**纯净的正弦波**——**像稳定的电话拨号音**。  
>  
> 历史上 **AM 比 FM 早出现 30 年**（1900 vs 1933）——**AM 容易做但抗干扰差**——**FM 难做但音质好抗干扰强**——**所以现在车载收音机几乎都是 FM 为主**（**88-108MHz 在中国几乎全是 FM 电台**）。

**这三件事各有难点**——**1 道题考完三个**——**这就是 2025 F 的含金量**。

接下来 5 个谜，把这三件事里每个关键工程点都拆开讲。

## 第一个谜：怎么把 100MHz 信号采样到 MCU 里——三条路径的分水岭

奈奎斯特定理告诉我们——**要数字化一个 108MHz 信号 → 采样率至少 216MHz**。

但**STM32F4 内置 ADC 最快 7.2MSPS**——**MSP430F5xxx 最快 200kSPS**——**根本采不动 100MHz 信号**。

怎么办？**通信工程师在 100 年里给出了三条路径**——**每条都对应一种工程哲学**。

**路径 A：直接 RF 采样（专业仪器路径）**

用**ADI 的 AD9484（500MSPS 14 位 ADC，单价 800 元）+ Xilinx Spartan-6 FPGA（300 元）+ 高速 LVDS 接口**——**直接把 RF 数字化**。

**优点**：**全数字处理 → 无模拟漂移 → 可同时处理整个频段**。  
**缺点**：**单价 1500 元 → 超电赛预算 → 不推荐**。

**用过这种方案的产品**——**Rohde & Schwarz 的频谱仪（30 万元）**、**Ettus USRP X310 软件无线电平台（5 万元）**——**专业仪器才用得起**。

**路径 B：超外差混频 + 中频采样（经典路径，1930 年代发明）**

阿姆斯特朗发明的超外差结构——**用一个'本振（LO）'和 RF 信号做乘法**——**把 RF 频率搬到一个固定的'中频（IF）'**——**MCU 只需要采样这个低频中频**：

```
RF 输入 (100 MHz) ─► [混频器 NE602] ◄── 本振 LO (99 MHz)
                          │
                          ▼
                     中频 IF = RF - LO = 1 MHz
                          │
                          ▼
                     [中频滤波器 1 MHz BPF]
                          │
                          ▼
                     [中频放大]
                          │
                          ▼
                     [STM32 ADC 4 MSPS]
```

**关键公式**：**IF = RF - LO**（**或 LO - RF，取低者）

**这个式子说的其实是**——**'两个频率相乘 → 出现差频（IF）和和频（RF+LO）'**——**用滤波器只留下差频 → 就是中频**。

**优点**：
- 中频固定 1MHz——**MCU 4MSPS 轻松采样**
- 整段 RF 频段（88-108MHz）通过**改 LO 频率**（**本振从 87MHz 扫到 107MHz**）就能扫描——**LO 是可调的**
- 这是**收音机/电视/雷达/卫星接收机**全部使用的结构

**缺点**：**电路复杂**——**LO 需要 PLL 锁相环 + VCO 压控振荡器 + 滤波器**——**调试 RF 电路对本科生不友好**。

**国一备选方案**——**国二队伍 60% 用这种**。

**路径 C：专用接收机芯片（现代路径）**

**Si4735 / Si4737**（Skyworks，2008 年推出）——**一颗 IC 把整个超外差接收机集成进去**——**包括 LNA、混频器、IF 滤波器、AM/FM 解调器、AGC、音频输出**。

**控制方式**：**I2C 接口**——**主控 MCU 发 4 个字节命令字 → 芯片自动调到指定频率 + 自动 AGC + 输出音频**。

**核心命令**：

```c
// 设置接收频率（FM 模式）
// 命令字格式：0x20（FM_TUNE_FREQ） + freq_high + freq_low + 0x00
uint16_t freq_10kHz = 1000;  // 100.0 MHz = 10000 × 10kHz
uint8_t cmd[5] = { 0x20, 0x00, freq_10kHz >> 8, freq_10kHz & 0xFF, 0x00 };
i2c_write(SI4735_ADDR, cmd, 5);

// 等待锁定（约 50ms）
delay_ms(50);

// 读 RSSI 信号强度
uint8_t resp[8];
i2c_read(SI4735_ADDR, 0x22, resp, 8);
int8_t rssi_dbm = -resp[4];
```

**这段代码说的其实是**——**'用 5 字节命令告诉 Si4735 调到 100MHz → 等 50ms → 读它给的 RSSI 反馈'**——**整个射频处理芯片自己做，MCU 只是发命令**。

**优点**：
- 单价 50 元
- 4 天能做完
- 性能稳定（厂家保证）

**缺点**：**'封装黑盒'感强**——**学不到 RF 底层原理**——**导师可能不喜欢**。

**Si4735 vs 设计自己的超外差**：

| 维度 | Si4735 | 自制超外差 |
|---|---|---|
| 时间投入 | 1 天 | 4~6 天 |
| 单价 | 50 元 | 80 元（电感电容多） |
| 灵敏度 | -103 dBm | -95~-100 dBm |
| 调试难度 | I2C 调命令 | RF 频谱仪 + 网络分析仪 |
| 报告分数 | 中等（'用现成芯片'扣分） | 高（'自主设计'加分） |
| 国一队伍选择 | **70%** | **30%** |

**国一队伍 70% 用 Si4735** + **30% 用自制超外差（拼报告分数）**。

**'用 Si4735 也能拿国一'**——**这是 2025 F 命题组的'温柔'** —— **不强迫每个人都成为 RF 工程师**——**让有兴趣的同学深入做超外差，有时间紧张的同学用 Si4735 也能拿高分**。

> **小白补课：'-85dBm' 这个功率到底有多小？**  
>  
> **dBm**：相对于 1 毫瓦的对数值。`P_dBm = 10 × log10(P_mW / 1mW)`  
>  
> **-85 dBm = 10^(-85/10) mW = 3.16×10^(-9) mW = 3.16 pW（皮瓦）**——**3 万亿分之一瓦**。  
>  
> 在 50Ω 负载上对应电压：**√(P × R) = √(3.16e-12 × 50) = 12.6 μV** 有效值——**比一节干电池电压小 12 万倍**。  
>  
> **-95 dBm 又比 -85 dBm 弱 10 倍** = **4 μV 有效值**——**是一片白噪声里的微弱信号**——**这就是题目要求的灵敏度**。

## 第二个谜：怎么自动扫遍 88-108MHz 不漏台

扫频策略其实就一句话——**'按 100kHz 步进，从 88MHz 扫到 108MHz，每个频点测 RSSI，超过阈值就停下来解调'**。

**朴素扫频**：

```c
#define FREQ_START_kHz   88000  // 88 MHz
#define FREQ_STOP_kHz    108000 // 108 MHz
#define FREQ_STEP_kHz    100    // 100 kHz
#define RSSI_THRESHOLD   -85    // dBm

void auto_scan() {
    for (int f = FREQ_START_kHz; f <= FREQ_STOP_kHz; f += FREQ_STEP_kHz) {
        si4735_set_frequency(f);
        delay_ms(20);                      // 等接收锁定
        int8_t rssi = si4735_read_rssi();
        if (rssi > RSSI_THRESHOLD) {
            // 找到信号，进入解调
            int8_t modulation = identify_modulation(f);  // 见第三个谜
            display(f, rssi, modulation);
            return;
        }
    }
}
```

**算一下耗时**：

```
扫描点数 = (108 - 88) / 0.1 = 200 点
每点耗时 = 设置频率 1ms + 等锁定 20ms + 读 RSSI 1ms = 22ms
总扫描时间 = 200 × 22 = 4.4 秒
```

**4.4 秒** vs **基本要求 (4) 的 ≤ 10 秒** = **轻松达标**。  
**4.4 秒** vs **发挥要求 (3) 的 ≤ 5 秒** = **紧张达标**。

**坑——'等锁定 20ms' 是必须的**

Si4735 内部 PLL 调到新频率需要时间——**典型 6~15ms**——**少于 20ms 读 RSSI 不准**。**国一队伍实测 25ms 是稳定阈值**——**短了精度差，长了超时**。

**优化方案——'分层扫频'**

为了把扫频时间从 4.4s 压到 2s 以下（拿满发挥 (3) 的 10 分），国一队伍用**两层扫频**：

```c
// 第一层：粗扫（步进 500kHz，40 点）
int8_t coarse_rssi[40];
for (int i = 0; i < 40; i++) {
    int f = 88000 + i * 500;
    si4735_set_frequency(f);
    delay_ms(15);
    coarse_rssi[i] = si4735_read_rssi();
}
// 总耗时 = 40 × 16 = 0.64 秒

// 第二层：找到 RSSI 峰附近精扫（步进 100kHz，10 点）
int peak_index = argmax(coarse_rssi, 40);
int peak_freq = 88000 + peak_index * 500;
for (int f = peak_freq - 250; f <= peak_freq + 250; f += 100) {
    si4735_set_frequency(f);
    delay_ms(20);
    int8_t rssi = si4735_read_rssi();
    if (rssi > RSSI_THRESHOLD) {
        // 找到精确频率
        return f;
    }
}
// 总耗时 = 5 × 21 = 0.1 秒
// 合计：0.64 + 0.1 = 0.74 秒，远超 5 秒要求
```

**两层扫频把 4.4s 压到 0.74s** —— **6 倍提速**——**国一标配**。

**坑——RSSI 阈值怎么定？**

题目要求**-85dBm 以上的信号都要找到**——**RSSI 阈值就该是 -85**。

但 Si4735 的 RSSI 读数**有 ±2dBm 误差**——**实际阈值要松一点**：

```c
#define RSSI_THRESHOLD  -83   // 比 -85 高 2dB，留出余量
```

**太松（-90）**——**会把噪声当信号**——**误锁**。  
**太严（-83）**——**真的 -85dBm 信号可能漏掉**——**漏台**。  
**国一队伍实测 -83 是甜点**。

**坑——多个电台同时存在时怎么办**

在城市里 88-108MHz 经常有 5~10 个电台同时存在——**朴素扫频找到第一个就停**——**实际上后面的电台被忽略了**。

**进阶——'扫频 + 列表'**：

```c
typedef struct { int freq; int8_t rssi; int8_t mod; } StationInfo;
StationInfo found_stations[10];
int station_count = 0;

void scan_and_list() {
    for (int f = 88000; f <= 108000; f += 100) {
        si4735_set_frequency(f);
        delay_ms(20);
        int8_t rssi = si4735_read_rssi();
        if (rssi > -83 && station_count < 10) {
            found_stations[station_count].freq = f;
            found_stations[station_count].rssi = rssi;
            found_stations[station_count].mod = identify_modulation(f);
            station_count++;
            // 注意：跳过相邻 200kHz 范围，避免同一电台重复
            f += 200;
        }
    }
}
```

**'扫到末尾后用户用按键浏览每个台'**——**5 分'其他'加分项**。

> **小白补课：什么是 RSSI？**  
>  
> **RSSI（Received Signal Strength Indicator）**——**接收机内部检测当前频点信号强度的电压/数字值**——**通常映射到 dBm 单位**。  
>  
> **物理来源**：接收机的中频放大器后端有一个**对数检波器**——**输出和信号功率成对数关系**——**典型 1 dBm 对应 10mV**。  
>  
> **典型 RSSI 范围**：
> - **-30 dBm**：非常强（你站在发射塔旁边）
> - **-50 dBm**：强（市区内主流电台）
> - **-70 dBm**：中等（郊区接收）
> - **-85 dBm**：弱（最低可解调）
> - **-100 dBm**：噪声底  
>  
> **RSSI 是接收机的'眼睛'——决定它能不能看到电台**。

## 第三个谜：怎么区分 FM、AM、CW——三种调制的'指纹'

发挥要求 (1) 给了**23 分**——**全题最大头**——**这就是命题组想看到的核心能力**。

让我们先看三种调制信号长什么样：

```
载波 RF（100 MHz 正弦波，没调制）：

       1V  ⌒⌒⌒⌒⌒⌒⌒⌒⌒⌒⌒⌒⌒⌒⌒
           
       0V                                         
           
      -1V  ⌣⌣⌣⌣⌣⌣⌣⌣⌣⌣⌣⌣⌣⌣⌣

```

**CW（无调制载波）**：纯净正弦波——**振幅恒定 + 频率恒定**——**'指纹特征：振幅方差小 + 频率方差小'**。

**AM（调幅）**：载波振幅被音频信号调制——**'高低起伏'**——**'指纹特征：振幅方差大 + 频率方差小'**。

**FM（调频）**：载波频率被音频信号调制——**'快慢起伏'**——**'指纹特征：振幅方差小 + 频率方差大'**。

**关键公式**：

**AM 调制度 m**：

```
m = (A_max - A_min) / (A_max + A_min)
```

**这个式子说的其实是**——**'振幅最大和最小的差异比例'**——**m 越大调制深度越深**。题目要求 30%~60%——**这是商业 AM 广播的典型范围**。

**FM 频偏 Δf**：

```
Δf = K_f × A_audio_max
```

**这个式子说的其实是**——**'载波频率最大偏离值'**——**FM 频偏越大音质越好（但占带宽多）**。题目要求 5kHz~75kHz——**75kHz 是商业 FM 广播标准**。

**自动识别算法的工程实现**——

**步骤 A：计算包络方差（振幅起伏）**

```c
// 从接收机的 IQ 数据（同相 I + 正交 Q）算包络
float compute_envelope(int16_t I[], int16_t Q[], int N) {
    float env_avg = 0, env_var = 0;
    float env[1024];
    
    for (int i = 0; i < N; i++) {
        env[i] = sqrtf((float)(I[i]*I[i] + Q[i]*Q[i]));
        env_avg += env[i];
    }
    env_avg /= N;
    
    for (int i = 0; i < N; i++) {
        env_var += (env[i] - env_avg) * (env[i] - env_avg);
    }
    env_var /= N;
    
    // 归一化（除以包络均值的平方）
    float env_var_normalized = env_var / (env_avg * env_avg);
    return env_var_normalized;
}
```

**这段代码说的其实是**——**'IQ 数据先求模 → 算它的方差 → 归一化**'。

**步骤 B：计算瞬时频率方差（频率起伏）**

```c
// 用相邻样本的相位差算瞬时频率
float compute_freq_variance(int16_t I[], int16_t Q[], int N, float fs) {
    float phase[1024], freq[1024];
    
    for (int i = 0; i < N; i++) {
        phase[i] = atan2f((float)Q[i], (float)I[i]);
    }
    
    // 算瞬时频率（差分相位）
    for (int i = 1; i < N; i++) {
        float dphi = phase[i] - phase[i-1];
        // 处理 -π ~ +π 跳变
        if (dphi > M_PI)  dphi -= 2 * M_PI;
        if (dphi < -M_PI) dphi += 2 * M_PI;
        freq[i] = dphi * fs / (2 * M_PI);
    }
    
    float freq_avg = 0;
    for (int i = 1; i < N; i++) freq_avg += freq[i];
    freq_avg /= (N - 1);
    
    float freq_var = 0;
    for (int i = 1; i < N; i++) {
        freq_var += (freq[i] - freq_avg) * (freq[i] - freq_avg);
    }
    freq_var /= (N - 1);
    
    return freq_var;  // 单位 Hz²
}
```

**这段代码说的其实是**——**'IQ 数据先算瞬时相位 → 差分得到瞬时频率 → 算频率的方差'**——**频率方差大 = FM**。

**步骤 C：联合判决**

```c
typedef enum { CW, AM, FM } Modulation;

Modulation identify_modulation(int16_t I[], int16_t Q[], int N) {
    float env_var = compute_envelope_var(I, Q, N);
    float freq_var = compute_freq_variance(I, Q, N, FS);
    
    bool env_changing = (env_var > 0.05);   // 振幅起伏明显
    bool freq_changing = (freq_var > 1e6);  // 频率起伏 > 1kHz
    
    if (!env_changing && !freq_changing) {
        return CW;  // 都稳定 → 单频载波
    } else if (env_changing && !freq_changing) {
        return AM;  // 振幅变 + 频率稳 → AM
    } else if (!env_changing && freq_changing) {
        return FM;  // 振幅稳 + 频率变 → FM
    } else {
        // 两个都在变 → 异常或测量误差
        // 取方差比的判据兜底
        return (env_var * 1e6 > freq_var) ? AM : FM;
    }
}
```

**这是这道题最'通信味'的代码**——**短短 20 行实现'认知无线电'的入门**——**国一队伍这一段代码就是 23 分**。

**坑——阈值怎么定？**

`env_var > 0.05` 和 `freq_var > 1e6` 这两个数字是经验值——**需要在题目给定的 RF 信号源（载波 -85~-60dBm）测一遍**——**不同信号强度阈值会变**。

**国一调试经验**：
- 信号 -60 dBm 时，`env_var(AM, m=50%) ≈ 0.10`，`env_var(FM) ≈ 0.005`，`env_var(CW) ≈ 0.001`
- 信号 -85 dBm 时（接近底噪），`env_var(AM) ≈ 0.05`，`env_var(FM) ≈ 0.02`，`env_var(CW) ≈ 0.01`
- **阈值用'0.03'**——**所有调制都能正确识别**

**进阶——用 IQ 解调器直接读 Si4735 内部数据**

Si4735 内部其实**已经做完了 FM 解调和 AM 解调**——**两路数据都在芯片内部缓冲区**——**用 I2C 命令 `RX_GET_FM_AGC_STATUS` 和 `RX_GET_AM_AGC_STATUS` 能直接读两路解调质量**——**质量好的就是真信号**：

```c
int8_t fm_quality = si4735_read_fm_agc();   // FM 解调质量分数
int8_t am_quality = si4735_read_am_agc();   // AM 解调质量分数

if (fm_quality > 30 && fm_quality > am_quality + 10) {
    return FM;  // FM 解调质量高且明显高于 AM
} else if (am_quality > 30 && am_quality > fm_quality + 10) {
    return AM;
} else if (fm_quality < 10 && am_quality < 10) {
    return CW;  // 两个解调都失败 = 单频载波
}
```

**这一招把 IQ 数据分析转移到了 Si4735 内部完成**——**MCU 只读两个字节**——**简单到极致**——**也是国一最常用的'懒人方案'**。

> **小白补课：'IQ 数据'是什么？**  
>  
> 一个高频信号 `s(t) = A(t) cos(2πf_c t + φ(t))` 可以拆成两路：
> - **I 路（同相分量）**：`I(t) = A(t) cos(φ(t))`
> - **Q 路（正交分量）**：`Q(t) = A(t) sin(φ(t))`  
>  
> 两路数据合起来——**完全等价**于原始 RF 信号——**但低速**——**适合 MCU 处理**。  
>  
> 包络 = √(I² + Q²)，相位 = atan2(Q, I)。  
>  
> **几乎所有现代 SDR 接收机都输出 IQ 数据**——**这是 SDR 的核心数据结构**。

## 第四个谜：怎么把灵敏度从 -85dBm 提到 -95dBm

发挥要求 (2) 是接收机性能的'珠穆朗玛峰'——**12 分**——**但 90% 的国二队伍拿不到**。

**'灵敏度从 -85dBm 提升到 -95dBm' 意味着什么？**

```
-85 dBm = 12.6 μV @ 50Ω
-95 dBm = 4.0 μV @ 50Ω

提升 10 dB = 10 倍功率 = 3.16 倍电压
```

**意味着接收机要从'能听到 12μV 信号'变成'能听到 4μV 信号'**——**信号弱到几乎是普通运放的输入失调电压**——**极其考验底噪控制**。

**接收机的灵敏度公式**：

```
S_min = -174 dBm/Hz + 10·log10(BW) + NF + SNR_required
```

**这个式子说的其实是**——**'最小可检测信号 = 热噪声功率密度 + 带宽对数 + 噪声系数 + 解调所需 SNR'**——**接收机能听到的最弱信号取决于这四个量**。

代入 FM 接收机参数：

```
热噪声: -174 dBm/Hz（自然界基础）
带宽: 200 kHz（FM 信道宽度）→ 10·log10(2e5) = 53 dB
NF（噪声系数）: 5 dB（典型接收机）
SNR_required: 12 dB（FM 解调最小信噪比）

S_min = -174 + 53 + 5 + 12 = -104 dBm
```

**理论极限 -104 dBm**——**目标 -95 dBm 留 9dB 余量**——**理论可行**。

**但实际接收机会有各种损耗 → 比理论差 5~10 dB**——**实测约 -94 dBm**——**要做到 -95 dBm 必须**优化每一步**。

**四招提升灵敏度**——

**第一招：低噪声放大器（LNA）—— 提升 5dB**

接收机第一级是 LNA——**它的噪声系数 NF 决定整机 NF**（**Friis 公式**）：

```
NF_total = NF_LNA + (NF_后级 - 1) / Gain_LNA
```

**这个式子说的其实是**——**'第一级 LNA 噪声系数主导整机 NF'**——**第一级 NF 越低整机越灵敏**。

| LNA 型号 | 噪声系数 | 增益 | 价格 |
|---|---|---|---|
| **MAX2611** | 3.5 dB | 18 dB | 30 元 |
| **GALI-21+** | 2.8 dB | 12 dB | 50 元 |
| **HMC476MP86** | **1.2 dB** | 17 dB | 80 元 |
| **ADL5523**（**国一标配**） | **0.8 dB** | 21 dB | 60 元 |

**ADL5523 NF = 0.8 dB**——**比 MAX2611 低 2.7dB**——**整机灵敏度提升 2.7 dB**。

**第二招：天线匹配 —— 提升 3dB**

天线必须和接收机阻抗匹配（50Ω）——**否则信号反射**。

**反射损耗与电压驻波比（VSWR）的关系**：

| VSWR | 反射损耗 |
|---|---|
| 1.0 | 0 dB（完美匹配）|
| 1.5 | -14 dB（损失 4%）|
| 2.0 | -10 dB（损失 11%）|
| 3.0 | -6 dB（损失 25%）|

**用 50Ω 阻抗匹配网络（电感电容 L 网络）**——**VSWR 压到 1.5 以内**——**节省 3 dB 反射损失**。

**实测 VSWR**——**用 NanoVNA（200 元的便携式网络分析仪）**——**电赛实验室必备工具**。

**第三招：金属屏蔽 —— 提升 5dB**

接收机暴露在空间中——**周围所有电磁干扰都会进 ADC**——**LED 灯、手机、电磁炉都是干扰源**。

**金属盒屏蔽**：
- **铝盒**：屏蔽 30 dB（减弱 1000 倍干扰）
- **铜屏蔽笼**：屏蔽 60 dB（减弱 100 万倍）
- **多层 PCB 内部铺地**：屏蔽 20 dB

**接收机国一标配**——**完整金属盒屏蔽 + 多层 PCB**——**消除空间干扰** = **整机底噪降 5dB**。

**第四招：相干检测代替包络检测 —— 提升 3dB**

包络检测：`A = √(I² + Q²)`——**简单但 SNR 低**。  
相干检测：**已知载波相位 φ**，**信号 = I·cos(φ) + Q·sin(φ)**——**只取信号方向的能量，丢弃正交方向噪声**——**SNR 提升 3 dB**。

**Si4735 内部用了相干检测**——**自动享受这 3dB**。

**四招合计：5 + 3 + 5 + 3 = 16 dB**——**远超 10dB 要求**——**12 分稳吃**。

> **小白补课：为什么噪声系数 NF 这么重要？**  
>  
> **噪声系数（Noise Figure，NF）**——**衡量一个放大器'引入多少噪声'的指标**——**单位 dB**。  
>  
> **完美无噪声放大器 NF = 0 dB**——**输入信号 SNR = 输出信号 SNR**。  
>  
> **NF = 3 dB** 意味着——**输出 SNR 比输入 SNR 低 3 dB**——**放大器把 SNR 砍掉一半**。  
>  
> **接收机的整机 NF 几乎完全由第一级 LNA 决定**——**因为后级的噪声会被第一级增益除掉**——**这就是为什么所有 RF 工程师在 LNA 选型上花最多心思**。

## 第五个谜：5V 500mA 的 '功耗死循环'

发挥部分要求**5V × 500mA = 2.5W 整机功耗**——**这是个紧约束**。

**功耗预算清单**——

| 模块 | 典型电流 | 功耗 |
|---|---|---|
| **Si4735 接收机芯片** | 25 mA | 125 mW |
| **STM32F103 主控（72MHz）** | 30 mA | 150 mW |
| **OLED 0.96 寸 SSD1306** | 15 mA | 75 mW |
| **音频功放 PAM8403** | 60 mA（3W 输出时）| 300 mW |
| **8Ω 喇叭** | 包含在功放里 | - |
| **LDO 损耗（85% 效率）** | 净增 30 mW | 30 mW |
| **LNA（如 ADL5523）** | 50 mA @ 5V | 250 mW |
| **LED 指示** | 5 mA | 25 mW |
| **其它（运放、按键等）** | 20 mA | 100 mW |
| **合计** | **205 mA** | **1.05 W** |

**1.05 W** vs **2.5 W 限制** = **2.5 倍余量**——**不紧张**。

**但有几个隐藏的功耗陷阱**——

**陷阱 1：LNA 的电源效率**

ADL5523 工作 5V × 50mA = 250 mW——**但它的实际工作电压是 4.0V**——**用 LDO 降压损失 10 mA × 1V = 10 mW**——**几乎没问题**。

**陷阱 2：音频功放在驱动 8Ω 喇叭时电流冲击**

PAM8403 的最大输出 3W @ 8Ω——**电流瞬态可达 800 mA**——**虽然均流可能 60mA，但瞬时电流会让 5V 电源轨跌到 4.5V**。

**对策——加大滤波电容**：

```
5V 输入 ─[1000μF 电解 + 100nF 陶瓷]─ 给功放
```

**1000μF 电容能缓冲 800mA × 1ms 的瞬态**——**电压不跌**。

**陷阱 3：屏幕和 MCU 的功耗**

LCD 比 OLED 费电 5 倍——**但 OLED 0.96 寸只能显示 4 行字**——**国一队伍用 OLED 显示频率 + 调制方式 + RSSI + 状态**——**够了**。

**MCU 主频从 72MHz 降到 48MHz**——**电流从 30mA 降到 18mA**——**节省 60mW**——**对题目无影响**（**只要扫频和解调跟得上**）。

**'恒流/恒压模式自动切换' 的含义**

题面说明 (4)：

> 接收机整机必须采用具有 **'恒流/恒压'模式自动切换** 的直流电源单电源供电， 供电电压设置为 5V， **最大供电电流设置为 500mA**。

**'恒压恒流自动切换'** 是实验室稳压电源的工作模式：

- **正常工作时**：电源在'恒压模式'——**输出 5V 不变**——**电流随负载变化**
- **当负载电流超过 500mA 时**：电源自动切到'恒流模式'——**保持 500mA 不变**——**电压会下降**

**意义**：**测评时如果你的接收机功耗超过 500mA，电源会自动限流到 500mA**——**输出电压会跌到 4V 甚至 3V**——**接收机会停止工作**。

**这就是题目的'功耗刚性约束'**——**不是软性建议**——**超功耗 = 接收机不工作 = 直接 0 分**。

**国一队伍的实战做法**——**用'万用表夹电流'实测整机电流**——**确保稳定 < 400mA**——**留 100mA 余量**——**比赛时即使有瞬态也不会触发恒流保护**。

**进阶——动态功耗管理**

```c
// 待机模式：扫频中不需要音频功放
si4735_set_low_power_mode();
audio_amp_power_off();

// 找到信号后：开音频，准备解调

si4735_normal_power_mode();
```

**国一队伍**——**待机时整机 100mA，工作时 350mA**——**比赛全程不超 400mA**。

到这里——5 个谜揭穿了从硬件选型到灵敏度优化的核心工程点。但**电赛拿分的关键还在题面文字里**。下面这一节我们就回到题目原件——把每一句话、每一个数字、每一处含糊都**像工程师一样掰开揉碎**——读完你不仅懂'要做什么'，**更懂'每个限制为什么是这个限制、自己拿到题该怎么动笔算'**。

### 任务那段话——'88-108MHz 自动接收 + 100kHz 步进 + 8Ω 负载'

题目原文（第 11 行）：

> 设计并制作一台简易自动接收机，**自动搜索并接收 88MHz~108MHz 频率范围内的调频或调幅信号**。**接收机接收的信号由射频信号源产生**，**载波频率调节步进为 100kHz**，**调制信号的频率范围为 300Hz~3400Hz**。**接收机输出端接 8Ω 负载电阻**。**自动识别调制方式**，解调输出信号用示波器观察，**波形应无明显失真**。

这一段每一个数字都是设计的边界——**少看一个字就少 2 分**。

**第一笔账：'88MHz~108MHz' 是商业 FM 广播频段**

| 频段 | 用途 | 国内/国际标准 |
|---|---|---|
| 87.5~108 MHz | 民用 FM 广播 | 中国 + 国际 |
| 76~95 MHz | 日本 FM 广播 | 日本 |
| 88~108 MHz | 欧美 FM 广播 | 欧美 |
| 中波 535~1605 kHz | AM 广播 | 全球 |
| 短波 2.3~26 MHz | 国际广播 | 全球 |

**题目用 88~108MHz 是国际标准**——**评测时 RF 信号源在这段里产生测试信号**——**设计接收机时只需要覆盖这一段**。

**国内除了 88-108MHz FM 广播——还有 525kHz~1605kHz 的 AM 中波广播**——**但题目限定了 88-108MHz 范围**——**意味着评测时也会有 AM 信号从这个频段进来**——**这是题目的'非典型设计'**——**RF 信号源会发出'载波在 88-108MHz、用 AM 方式调制' 的信号**——**而不是真实的 AM 中波**。

**这一点非常关键**——**真实世界 88-108MHz 的所有信号都是 FM**——**但本题里 AM 信号也在这个频段** —— **所以接收机必须能处理'88-108MHz 频段的 AM 信号'**——**这是题目的特殊性**。

**第二笔账：'100kHz 步进' 是 FM 信道的标准间隔**

为什么 100kHz？因为商业 FM 广播信道间隔就是 100kHz——**每个电台占一个 100kHz 的'信道'**——**88-108MHz 总共 (108-88)/0.1 = 200 个信道**。

**这意味着扫频时只需要测 200 个频点**——**不需要扫每 1kHz 或每 10kHz**——**节省 10~100 倍时间**。

**国一调试**——**Si4735 默认就是 100kHz 步进的 FM 模式**——**直接发命令字 'SET_PROPERTY 0x1402 = 10' 设置步进为 100kHz**——**1 行代码搞定**。

**第三笔账：'调制信号 300Hz~3400Hz' 是电话音频带宽**

300Hz~3400Hz 是**电话音频带宽**——**正好覆盖人类语音清晰度的核心范围**——**保留'声音可懂'但不要求音乐保真度**。

**对比标准**：

| 应用 | 音频带宽 |
|---|---|
| **电话** | **300~3400 Hz**（**本题**）|
| **AM 广播** | 100~5000 Hz |
| **FM 广播** | 30~15000 Hz（高保真）|
| **CD 音质** | 20~20000 Hz |
| **Hi-Fi** | 5~40000 Hz |

**为什么本题用电话带宽而不是 FM 广播带宽？**

因为评测要简单——**用电话带宽，评委可以用 1kHz 单频音频做测试**——**输入端发 1kHz 调制 → 接收机解调 → 示波器看 1kHz 正弦波是否清晰**。**用 FM 广播带宽就要测多种音频谐波**——**复杂**。

**这一条限制简化了评测**——**也降低了对接收机音频通路的要求**——**做基本的低通滤波就够**。

**第四笔账：'8Ω 负载' 是消费电子标准**

接收机输出接 **8Ω 喇叭** ——**音频功放必须能驱动 8Ω 负载**。

**功放选型**：

| 型号 | 最大输出 @ 8Ω | 单价 |
|---|---|---|
| **PAM8403** | 3W | 5 元 |
| **TPA3110** | 15W | 15 元 |
| **LM386** | 1W | 2 元 |
| **TDA2030** | 18W | 8 元 |

**国一标配 PAM8403**——**5 元 + 3W 功率 + 高效 D 类功放（85% 效率）**——**性价比最高**。

**注意**——**题面说 '8Ω 负载电阻及引腿应裸露在外，便于示波器测量'**——**评委要在 8Ω 电阻两端用示波器测信号波形**——**这意味着喇叭线必须留出'测试钩位'**——**用接线柱或者 BNC 接头**——**比直接焊喇叭更好**。

**第五笔账：'波形应无明显失真'是定性指标**

这个'明显失真'**完全是评委主观判断**——**没有具体 THD（总谐波失真）数字**——**只要示波器看到的波形'看起来像正弦波'就行**。

**国一队伍的做法**——**用'眼睛 THD'**：示波器看波形——**顶部和底部对称、没有削波（clipping）、过零点干净** = 失真小。

**保证波形不失真的方法**：
- **AGC 控制振幅**——避免削波
- **音频带通滤波器（300-3400Hz）**——去除调制信号外的噪声
- **电源滤波**——避免电源纹波耦合到音频

**这 3 条工程做完**——**示波器波形看起来'非常干净'**——**评委满意**。

### 基本要求 (1)：搜索并解调 FM 信号 - 15 分

题目原文（第 22 行）：

> （1）**搜索并解调调频信号**。调频信号最大频偏 **Δf_max 满足 5kHz ≤ Δf_max ≤ 75kHz**，**自动搜索解调一个调频信号**，要求**输出信号电压峰峰值 ≥ 0.9V**。

**这一项 15 分**——**是接收机的基础能力**。

**'最大频偏 5kHz~75kHz' 是 FM 信号的'调制深度'范围**

| 频偏 | 应用 | 音质 |
|---|---|---|
| **5 kHz** | **窄带 FM**（对讲机、业余无线电）| 一般 |
| **20 kHz** | 中等 FM | 较好 |
| **50 kHz** | 中等到宽带 FM | 好 |
| **75 kHz** | **宽带 FM**（商业广播）| **高保真** |

**评测时信号源会随机选 5~75kHz 中某个频偏**——**接收机必须**自适应地**解调出来**——**这就是 Si4735 内置 AGC + 频偏自适应的好处**。

**Si4735 的 FM 解调命令**：

```c
// 设置 FM 模式
si4735_send_command(POWER_UP, FM_MODE);

// 设置频率（100.0 MHz 例）
si4735_set_fm_freq(10000);  // 单位 10kHz，10000 = 100.0 MHz

// 等锁定
delay_ms(50);

// 读 RSSI
int8_t rssi = si4735_read_rssi();
if (rssi > -85) {
    // 解调成功，音频已从模拟输出口送到功放
    audio_amp_enable();
}
```

**'输出信号电压峰峰值 ≥ 0.9V'** —— **音频功放后端的'8Ω 电阻两端'电压**。

**功率计算**：

```
P = V_pp² / (8 × 8) = (0.9)² / 64 = 12.6 mW
```

**12.6 mW 输出 → 喇叭微弱响 → 距离 30cm 能听到**——**符合便携式收音机标准**。

**'输出 ≥ 0.9V'** 比基本要求 (3) 的 '1V±0.1V' 略低——**这是题目的'容错设计'**——**让 (1) 拿满分但 (3) 加 10 分**。

**15 分入账**——**前提是 Si4735 选好 + I2C 写好 + 音频通路通**——**1 天能做完**。

### 基本要求 (2)：搜索并解调 AM 信号 - 15 分

题目原文（第 24 行）：

> （2）**搜索并解调调幅信号**。调幅信号调制度 **m 满足 30%≤m≤60%**，**自动搜索解调一个调幅信号**，要求**输出信号电压峰峰值 ≥ 0.9V**。

**'调制度 m'**：

```
m = (A_max - A_min) / (A_max + A_min)
```

| m | 含义 |
|---|---|
| **30%** | 浅调制——**调制信号 A_audio 是载波 A_carrier 的 30%** |
| **60%** | 中等调制——**调制信号 A_audio 是载波 A_carrier 的 60%** |
| **100%** | 深调制——**A_audio = A_carrier**（**载波最低降到 0**）|

**'30%~60%' 是商业 AM 广播的典型范围**——**保证不过度调制（>100% 会失真）**。

**Si4735 的 AM 解调命令**：

```c
// 切换到 AM 模式（注意 88-108MHz 范围 AM 是非标准的）
si4735_send_command(POWER_UP, AM_MODE);

// 设置接收频段为 88-108MHz（即使是 AM 模式）
si4735_set_property(AM_FREQ_BAND, AM_BAND_FM);

// 设置频率
si4735_set_am_freq(10000);  // 100 MHz
```

**'88-108MHz 频段的 AM' 是 Si4735 本身不太擅长的工作模式**——**需要'非标准配置'** —— **多读 datasheet**。

**国一队伍的隐藏招数**——**用 FM 模式 + IQ 数据 + 软件 AM 解调**：

```c
// 1. Si4735 配置为 FM 模式 + IQ 数据输出
si4735_set_fm_freq(target_freq);
si4735_enable_iq_output();

// 2. 软件包络检波得到 AM 解调
int16_t I[1024], Q[1024];
si4735_read_iq(I, Q, 1024);

float am_audio[1024];
for (int i = 0; i < 1024; i++) {
    am_audio[i] = sqrtf((float)(I[i]*I[i] + Q[i]*Q[i]));
}
// 高通滤波去除直流分量
hpf_300hz(am_audio, 1024);
// 低通滤波到 3400Hz
lpf_3400hz(am_audio, 1024);
// DAC 输出到音频功放
dac_output(am_audio, 1024);
```

**这一招让 Si4735 不用切 AM 模式**——**用统一的 FM 模式 + 软件解调** —— **'认知无线电'的入门实践**。

**15 分入账**。

### 基本要求 (3)：AGC 自动控制 1V±0.1V - 10 分

题目原文（第 26 行）：

> （3）**解调输出信号幅度自动控制**。当调制信号为正弦波时，**在基本要求（1）和（2）的测试中**，要求**输出信号电压峰峰值自动控制在 1V±0.1V**。

**AGC（Automatic Gain Control，自动增益控制）**——**接收机输出幅度自适应保持恒定**。

**为什么要 AGC？**

因为输入 RF 信号强度变化范围 -85dBm ~ -60dBm = **25 dB 动态范围 = 18 倍电压**——**输出幅度也会变 18 倍**——**用户听到声音忽大忽小**——**不舒服**。

**AGC 算法**：

```c
#define TARGET_VPP 1.0f
#define DEADZONE   0.05f
#define KP         0.5f

void agc_control_loop() {
    // 1. 测当前输出峰峰值
    float current_vpp = measure_output_pp();
    
    // 2. 算误差
    float error = TARGET_VPP - current_vpp;
    
    // 3. 调整增益
    if (fabs(error) > DEADZONE) {
        float gain_adjust = 1.0f + KP * error / TARGET_VPP;
        current_gain *= gain_adjust;
        // 限位
        current_gain = clamp(current_gain, MIN_GAIN, MAX_GAIN);
        amplifier_set_gain(current_gain);
    }
    
    // 4. 等下一个采样周期
    delay_ms(50);
}
```

**这段代码说的其实是**——**'测输出 → 比较目标 → 误差正比调增益 → 收敛'**——**经典 P 控制器**。

**实现方式两种**：

**方式 A：硬件 AGC**

接收机自带 AGC（Si4735 内置），**输出幅度本来就稳定** —— **再加一级模拟可控增益放大器（VGA，Variable Gain Amplifier）**——**用 STM32 DAC 控制增益电压**：

```
ADC ───► STM32 ───► DAC ───► VGA（如 AD8367）─► 输出
              ▲                          ▲
              │                          │
            读 V_pp ─────────────────────┘
```

**AD8367 是 ADI 的 VGA，单价 30 元，30dB 增益范围**——**国一标配**。

**方式 B：软件 AGC**

如果用'软件 AM 解调'路径——**包络数据已经在 MCU 内**——**直接乘一个增益因子**：

```c
for (int i = 0; i < N; i++) {
    am_audio[i] *= software_gain;
}
```

**简单但只对软件解调路径有效**。

**精度链**：
- 测量精度 ±5%
- AGC 收敛 5 次 P 控制 → 误差 < 1%
- 输出 V_pp = 1.00 ± 0.05V

**远超 ±0.1V 要求**——**10 分稳吃**。

**坑——AGC 收敛速度 vs 稳定性**

KP 太大 → 响应快但震荡（`Vpp = 1.5 → 0.7 → 1.3 → 0.85 → ...` 来回跳）  
KP 太小 → 收敛慢（`30 秒才稳定`）

**国一调试**——**KP = 0.3 ~ 0.5**——**5 次循环（250ms）收敛**——**用户感受不到 AGC 起作用**。

### 基本要求 (4)：响应时间 ≤ 10s - 10 分

题目原文（第 28 行）：

> （4）**要求接收机响应时间 ≤ 10s**。

**'响应时间' 的定义**（说明 (2) 给出）：

> 响应时间是指**射频信号源输出开关开启后**，**接收机搜索解调输出稳定解调信号的时间**。

**评测过程**：
- t=0：评委按下信号源的'输出开关'——RF 信号开始输出
- t=T：接收机的音频输出**稳定**到 1V±0.1V，**示波器看到清晰波形**
- 响应时间 = T

**前面 '第二个谜' 已经讲过**——**朴素扫频 4.4s** —— **远低于 10s** —— **轻松达标**。

**10 分入账**——**这是题目最容易的 10 分**。

### 发挥 (1)：自动识别单频载波/调频/调幅 - 23 分

题目原文（第 35 行）：

> （1）**自动识别单频载波、调频或调幅信号**，**显示识别结果**，并**解调出调频或调幅信号**。

**23 分**——**全题最大头**——**前面 '第三个谜' 已经详细讲过**。

**实战策略**：

```c
typedef enum { CW, AM, FM } Modulation;

// 在每次找到信号后调用
Modulation classify_and_demodulate(int freq_kHz) {
    // 读 IQ 数据 1024 点
    int16_t I[1024], Q[1024];
    si4735_read_iq(I, Q, 1024);
    
    // 分析 IQ
    float env_var = compute_envelope_var(I, Q, 1024);
    float freq_var = compute_freq_var(I, Q, 1024, FS);
    
    // 判决
    Modulation mod;
    if (env_var < 0.03 && freq_var < 1e5) mod = CW;
    else if (env_var > 0.05 && freq_var < 1e5) mod = AM;
    else if (env_var < 0.05 && freq_var > 5e5) mod = FM;
    else mod = AM;  // 默认（题目里没规定的归类）
    
    // 显示
    display_modulation(mod);
    
    // 切换解调器
    switch (mod) {
        case FM: enable_fm_demod(); break;
        case AM: enable_am_demod(); break;
        case CW: enable_cw_pass(); break;  // 单频载波直接通过（无音频内容）
    }
    
    return mod;
}
```

```
┌──────────────────────────┐
│ FREQ: 100.30 MHz          │
│ MOD:  FM                  │
│ RSSI: -68 dBm             │
│ Δf:   62 kHz              │
└──────────────────────────┘
```

**额外加分项**——**显示频偏 Δf（FM）或调制度 m（AM）**——**评委一眼看出你的接收机能精确分析信号**。

### 发挥 (2)：灵敏度 ≤ -95dBm 的 AM - 12 分

题目原文（第 37 行）：

> （2）在基本要求（2）基础上，**提高接收机灵敏度**，要求搜索并解调**载波电平 ≤ -95dBm 的调幅信号**。

前面 '第四个谜' 已经详细讲过——**LNA + 屏蔽 + 阻抗匹配 + 算法 4 招 = 16dB 提升**——**远超 10dB 要求**。

**注意——只要 AM 灵敏度提到 -95dBm**——**FM 不要求**。

**为什么？**因为 FM 比 AM 'SNR 阈值低'——**FM 解调本身就有 12dB SNR 改善（FM 增益）**——**FM 灵敏度自然就比 AM 好 10dB**——**做到 AM 灵敏度 -95dBm 时 FM 灵敏度自然是 -105dBm 左右**。

**国一队伍的实战**：

```c
// 切换到高灵敏度模式
void enable_high_sensitivity_mode() {
    // 1. 启用 LNA
    lna_power_on();
    
    // 2. 启用前端窄带滤波器（5kHz BW vs 默认 10kHz）
    si4735_set_property(AM_AGC_BW_FILTER, 5);
    
    // 3. 启用相干检测
    si4735_set_property(AM_DEMOD_MODE, COHERENT);
    
    // 4. 降低噪声底阈值
    si4735_set_property(AM_NOISE_FLOOR, -110);
}
```

**LNA 启用是关键**——**+5dB 灵敏度** —— **达标**。

**12 分到手**。

### 发挥 (3)：响应时间 ≤ 5s - 10 分

题目原文（第 38 行）：

> （3）**要求接收机响应时间 ≤ 5s**。

前面 '第二个谜' 已经讲过——**分层扫频 0.74s** —— **远低于 5s**。

**优化方案**：

```c
void fast_scan_5s() {
    // 第一层：粗扫 500kHz 步进 0.6s
    int peak_freq = coarse_scan_500kHz();
    
    // 第二层：精扫 100kHz 步进 0.1s
```

### 说明里的暗坑

题目'说明'部分看起来像免责条款——**每一条都是关键工程信息**。

**说明 (1)——'SMA 母座 + 50Ω 电缆 + 输出开关 + 屏蔽 + 8Ω 暴露'**

> 接收机输入端采用 **SMA 母座**接口，**用 50Ω 电缆连接至射频信号源**。射频信号源应具有**射频输出开关功能**，以方便测量接收机响应时间。**接收机应注意采取屏蔽措施，抑制空间干扰**。**8Ω 负载电阻及引腿应裸露在外**，便于示波器测量。

**5 个工程要求**：

1. **SMA 母座接口**——**而不是 BNC、N、TNC**——**SMA 是 RF 的标准小型接口**——**淘宝 5 元一个**——**注意母座（K 头）和公座（J 头）**
2. **50Ω 电缆**——**RG-174 同轴线**——**淘宝 5 元/米**——**用 SMA 接头压制成跳线**
3. **'信号源有输出开关'**——**评测时信号源关闭→打开→接收机响应时间开始计时**
4. **'屏蔽措施'**——**金属盒屏蔽** —— **降低空间干扰** —— **提升灵敏度 5dB**
5. **'8Ω 负载暴露'**——**便于示波器测信号**——**用接线柱或 BNC 转接**

**国一队伍的标配机箱**：

```

│ ┌──────┐ ┌──────┐ ┌────┐ ┌──┐   │

│                                  │
│ [SMA 母座]  [8Ω 接线柱]            │
└──────────────────────────────────┘
```

**说明 (2)——响应时间定义**

> 响应时间是指**射频信号源输出开关开启后**，**接收机搜索解调输出稳定解调信号的时间**。

**关键——'输出稳定'**——**示波器观察 1 秒以上波形稳定才算'输出稳定'**——**所以接收机内部 AGC 必须 < 5s 收敛**。

**说明 (3)——'按键启动'**

> 按键启动接收机，**自动搜索接收指定频率范围内的信号**。

**仅 1 个按键**——**按下 → 自动扫频 → 自动识别 → 自动解调 → 自动输出**——**'一键全自动'**。

**说明 (4)——'恒流恒压电源 + 单端口输出 + 一键启动'**

> 接收机整机必须采用具有**'恒流/恒压'模式自动切换的直流电源单电源供电**，**供电电压设置为 5V，最大供电电流设置为 500mA**；**接收机只用一个端口输出解调信号**；**接收机必须具有一键启动功能**，**启动后接收机应自动完成全部功能并显示结果**，**不得人为操控接收机**。**不满足要求不进行测试**。

**4 个核心约束**：

1. **5V × 500mA 单电源**——前面 '第五个谜' 详述
2. **单端口输出**——FM 和 AM 的解调信号**共用一个 8Ω 输出端**——**不能搞两套输出**
3. **一键启动**——按键后**所有功能自动完成**——**不允许人工调频率/选模式**
4. **'不满足要求不进行测试'**——**这一句话是'死刑'**——**任何一项不满足整题 0 分**
