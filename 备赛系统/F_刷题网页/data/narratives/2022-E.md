## 第一个谜：怎么测两个麦克风的"时间差"

**核心问题**：**3 个麦克风听到同一声音 → 怎么算每对麦克风之间的"时间差"**？

**第一笔账：互相关（Cross-Correlation）**

```
R(τ) = Σ x1(n) × x2(n + τ)
```

**这个式子说的其实是**——**'**把信号 x1 和"延迟 τ 时刻"** 的 x2 相乘求和——τ 是延迟参数**'**——**当 τ 等于"真实时间差"** 时**，**R(τ) 取最大值**——**这就是 TDOA**。

> **小白补课**：互相关是干嘛？
> - **想象一下**：**你有两段录音 x1（左耳）和 x2（右耳）**——**它们记录的是同一声音**——**但 x2 比 x1 晚 0.5 ms 到达**
> - **互相关**：**把 x2 平移不同时间，每次都和 x1 比较"像不像"** —— **找到"最像"** 时的平移量 = 时间差
> - **直观**：**像把两张几乎一样的图片重叠，左右滑动找到"完全重合"** 的位置

**第二笔账：互相关的实现**

```c
// x1[N], x2[N] 是两个麦克风的采样数据
float max_corr = 0;
int best_lag = 0;
for (int lag = -MAX_LAG; lag < MAX_LAG; lag++) {
    float corr = 0;
    for (int n = 0; n < N - abs(lag); n++) {
        if (lag >= 0) corr += x1[n] * x2[n + lag];
        else          corr += x1[n - lag] * x2[n];
    }
    if (corr > max_corr) {
        max_corr = corr;
        best_lag = lag;
    }
}
// best_lag * (1 / fs) = 时间差
float time_diff = best_lag / SAMPLING_RATE;
```

**这段代码说的其实是**——**'**遍历所有 lag 值，找出相关性最大的 lag = 时间差**'**——**典型 O(N²) 算法**。

**第三笔账：FFT 加速（必做）**

互相关的 FFT 实现快 100 倍：

```
互相关定理：corr(x1, x2) = IFFT( FFT(x1) × conj(FFT(x2)) )
```

**这个式子说的其实是**——**'**互相关 = 傅里叶变换乘积的反变换**'**——**FFT 复杂度 O(N log N)**——**比直接算快 100 倍**。

```c
fft(x1, X1, N);
fft(x2, X2, N);
for (int k = 0; k < N; k++) {
    Y[k] = X1[k] * conj(X2[k]);
}
ifft(Y, y, N);
// y[k] 中峰值位置 = lag
int best_lag = argmax(y);
```

**国一队伍**：**FFT 加速 + GCC-PHAT（广义互相关）**——**抗噪声、高精度**——**TDOA 误差 ±10μs**。

**第四笔账：精度对成绩的影响**

**采样率 100kSPS** → **时间分辨率 10μs** → **空间分辨率 = 10μs × 343m/s = 3.43mm**——**够用**。

**采样率 1MSPS** → **时间分辨率 1μs** → **空间分辨率 0.34mm**——**远超需要**。

**国一队伍**：**1 MSPS 多通道同步 ADC**——**精度极高**——**满分**。

## 第二个谜：怎么从 TDOA 算出声源位置

**问题**：**3 个麦克风（在 C 区、间距 30cm 一字排）+ 3 对 TDOA → 怎么算声源 (x, y)**？

**第一笔账：双麦克风的"双曲线方程"**

设 mic1 在 (0, 0)，mic2 在 (d, 0)，**TDOA = Δt → 距离差 = c × Δt**：

```
√(x² + y²) - √((x-d)² + y²) = c × Δt
```

**这个式子说的其实是**——**'**声源到 mic1 的距离 - 到 mic2 的距离 = 距离差**'**——**这是一个双曲线方程**——**声源在双曲线上某点**。

**单对麦克风**——**只能确定声源在双曲线上**——**不能确定具体位置**——**需要"3 对麦克风、3 条双曲线、求交点"**。

**第二笔账：三麦克风的"三双曲线交点"**

3 个麦克风排成三角形 → **3 对 → 3 条双曲线 → 交点 = 声源位置**：

```c
// 简化：3 个麦克风排成等边三角形
mic1 = (0, 0)
mic2 = (d, 0)
mic3 = (d/2, d × √3 / 2)

// 算 3 对 TDOA
TDOA12 = compute_tdoa(x1, x2);
TDOA13 = compute_tdoa(x1, x3);
TDOA23 = compute_tdoa(x2, x3);

// 求 3 条双曲线交点（用最小二乘法）
(x_source, y_source) = solve_intersection(TDOA12, TDOA13, TDOA23);
```

**'**最小二乘法**'** 在题目里怎么用？——**3 条双曲线一般不会精确交于一点（噪声影响）**——**用最小二乘法找"最接近 3 条曲线"** 的点**。

**第三笔账：γ（距离）和 θ（角度）**

```c
// 检测点 A 是某个麦克风的位置（设为 mic1 = (0, 0)）
γ = √(x_source² + y_source²);  // 直线距离
θ = atan2(y_source, x_source);  // 角度
```

**精度**：**TDOA 误差 ±10μs → 距离误差 ±3.4mm → γ 精度 ±5mm（5m 距离时为 0.1%）**——**远超题目要求**。

**国一队伍**：**精度 ±2cm @ 5m 距离 = 0.4%**——**满分 36**。  
**国二**：**精度 ±10cm = 2%**——**18~25 分**。  
**国三**：**精度 ±50cm = 10%**——**5~10 分**。

## 第三个谜：二维云台怎么指激光笔

**问题**：**算出声源 (γ, θ) 后 → 怎么让激光笔指向那里**？

**第一笔账：二维云台**

```
水平角度（azimuth）：0~360° → 控制激光笔左右
俯仰角度（elevation）：-30~+30° → 控制激光笔上下
```

**'**二维云台**'** = **水平舵机 + 俯仰舵机**——**两个独立伺服**。

**舵机选型**：

| 型号 | 力矩 | 角度精度 | 价格 |
|---|---|---|---|
| **SG90**（9g 微型）| 1.6 kg·cm | ±1° | 6 元 |
| **MG90S**（金属齿轮）| 2.2 kg·cm | ±0.5° | 15 元 |
| **MG996R**（标准）| 11 kg·cm | ±0.3° | 30 元 |
| **DS3218**（数字）| 20 kg·cm | ±0.1° | 60 元 |

**国一**：**MG996R 或 DS3218 + 步进电机精确驱动**——**±0.3° 精度**。  
**国二**：**MG90S × 2**——**±0.5° 精度**。  
**国三**：**SG90 × 2**——**±1° 精度**——**勉强**。

**第二笔账：云台到激光笔的几何标定**

**问题**：**云台坐标系 ≠ 麦克风坐标系**——**需要标定**。

```c
// 用两个已知位置的"标定点"
mic_origin = (0, 0)
laser_pivot_offset = (offset_x, offset_y)  // 云台中心相对麦克风原点的位置

// 激光指向声源时
target_x = x_source - offset_x;
target_y = y_source - offset_y;
target_distance = √(target_x² + target_y²);

// 控制云台
servo_horizontal_angle = atan2(target_y, target_x);
servo_vertical_angle = atan2(声源高度差, target_distance);
```

**这段代码说的其实是**——**'**先把声源坐标转换到云台坐标系，再算水平 / 俯仰角度**'**——**典型坐标变换**。

**第三笔账：激光指向精度**

**5m 距离 + ±0.3° 角度精度**：

```
位置精度 = 5m × tan(0.3°) = 5m × 0.0052 = 26 mm
```

**'**±26mm 精度 @ 5m**'** = **激光点偏 B 点 < 3cm**——**远超题目"光点与 B 点偏差越小越好"** 的要求**。

**国一队伍**：**激光偏 B 点 < 1cm**——**满分 30**。

## 第四个谜：怎么实时跟踪 0.2 m/s 移动声源

**要求 4**：**声源以 0.2 m/s 移动**——**激光要追上**——**反应时间越短越好**。

**第一笔账：完整反应时间链**

```
ADC 采样 1024 点 @ 100kSPS：10 ms
FFT × 3 + 互相关 × 3：5 ms
TDOA → 坐标计算：1 ms
云台命令计算：0.5 ms
舵机移动到位（最坏情况 100ms 移动 5°）：100 ms
总反应时间：116 ms
```

**'**0.2 m/s × 116ms = 23 mm**'** = **激光点滞后 B 点 2.3cm**——**勉强达标**。

**国一队伍**：**反应时间 50 ms（用更快舵机 + 流水线）**——**滞后 1cm**——**满分**。

**第二笔账：流水线优化**

把"采样 + 计算 + 移动"** 做成流水线：

```
采样 → 计算 → 移动
   ↓         ↓
  采样 → 计算 → 移动  ← 重叠
       ↓        ↓
      采样 → 计算 → 移动  ← 重叠
```

**每个阶段独立**——**总反应时间 = 最慢阶段**——**而不是各阶段累加**。

**国一实现**：**FreeRTOS 多任务**——**采样任务、计算任务、移动任务并行**——**总反应时间 < 60 ms**。

**第三笔账：预测算法**

如果声源匀速移动 → **预测下一时刻位置**：

```c
// 简单线性预测
v_x = (x_source - x_prev) / dt;
v_y = (y_source - y_prev) / dt;
x_predicted = x_source + v_x × LATENCY;
y_predicted = y_source + v_y × LATENCY;

// 激光指向"预测位置"** 而不是"当前位置"
servo_aim(x_predicted, y_predicted);
```

**这段代码说的其实是**——**'**预测声源未来位置，提前指激光**'**——**抵消反应时间滞后**。

**国一队伍**：**线性预测**——**激光始终落在 B 点 ±1cm**——**满分 20**。

## 把题目逐条翻译一遍

### 任务那段话

> 设计制作一个声源定位跟踪系统，能够**实时显示及指示**声源的位置，**当声源移动时能够用激光笔动态跟踪**声源。

任务核心：**显示位置 + 激光指向 + 实时跟踪** = **三件套**。

### 要求 1：声源装置（4 分）

> 装置**最大边长或直径不超过 10cm**，装置可用支架安装，并可在地面移动；**声源中心点 B 用红色或其他醒目颜色标识**，并在 B 点所在的平面以 B 点为圆心，**直径为 5cm 画圆圈**。

**简单**——**蜂鸣器 + 9V 电池 + 红色贴纸 + 5cm 圆圈** = **4 分稳拿**。

**'**5cm 圆圈**'** 的作用——**测试时如果激光点落在 5cm 圆圈内 = 算"指中"** —— **5cm 容差**。

### 要求 2：声源定位（36 分）

> 拾音器或**麦克风传感器数量不超过 10 个**；**测量时间不超过 5s**，距离 γ 和角度 θ 的**测值误差越小越好**。

**前面已经讲过 TDOA + 互相关 + 三角定位**——**国一精度 ±2cm**——**满分 36**。

**'**5s 测量时间**'** = **充裕**——**100ms 算完一次 → 50 次平均 = 5s 内极高精度**。

### 要求 3：激光指向（30 分）

> 安装有**激光笔和二维电动云台**，能控制激光笔指向声源，**定位计算过程中时，激光笔关闭，定位运算完成时激光笔开启**。**反应时间不超过 10s**。

**'**算完才开激光**'** —— **避免"激光乱晃"** 干扰评委观察**。

**前面已经讲过云台 + 标定**——**国一 30 分稳拿**。

### 要求 4：动态跟踪（20 分）

> 当声源摆放在地面，用**细绳牵引**，**以 0.2m/s 左右的速度**在 D 区移动时，**激光笔光点指向 B 点**。

**'**细绳牵引**'** = **测试人员拉绳让声源走**——**0.2 m/s = 慢速**——**给系统留反应时间**。

**前面已经讲过实时跟踪 + 预测**——**国一 20 分稳拿**。

### 要求 5：其他（10 分）

**10 分自由发挥**：

- **3D 定位（高度 z）**——**4 分**
- **多声源分离**——**5 分**
- **声音类型识别（蜂鸣 / 拍手 / 说话）**——**3 分**
- **历史轨迹记录**——**2 分**
- **手机 APP 显示**——**3 分**

**国一**：**做 2~3 项**——**8~10 分**。

### 说明里的暗坑

**说明 (1)：'**音量以不造成严重噪声污染为宜**'**

**意味着**：**蜂鸣器音量适中**——**~70 dB**——**不要用 100 dB 工业蜂鸣器**——**测试场地噪声不允许**。

**说明 (3)：'**最大尺寸水平高度控制在离地面 100cm 以下**'**

**意味着**：**整个检测装置高度 < 1m**——**适合"桌面机器人"** 形态**——**麦克风阵列水平排布**。

**说明 (4)：'**先按启动按钮 + 一键启动**'**

**和 2024 H、2021 F 一样的"全自动"** —— **不允许人工干预**。

**说明 (5)：'**距离和角度显示稳定，跳动取最大偏离**'**

**意味着**：**显示要稳定**——**不能"数字一直跳"** —— **需要做平均滤波**：

```c
// 滑动平均滤波
gamma_filtered = 0.9 * gamma_filtered + 0.1 * gamma_new;
theta_filtered = 0.9 * theta_filtered + 0.1 * theta_new;
```
