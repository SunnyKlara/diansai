## 第一个谜：怎么让 MCU 自己产生 100Hz~1MHz 的精确正弦波

基本要求 (2) 给了 10 分——**'探究装置能产生正弦信号，频率可设置（步长 100Hz），最高频率不小于 1MHz，频率相对误差 ≤ 5%；峰峰值最大值 ≥ 3V'**。

这是**整套系统的'信号源核心'**——**没它整个题做不下去**。

**怎么用 MCU 产生 100Hz ~ 1MHz 的精确正弦？**

**路径 A：DAC + DMA + 正弦表（推荐）**

把一个完整正弦周期（256 点）放在内存里——**让 DMA 按指定速率把这 256 点循环送到 DAC**——**输出频率 = DMA 速率 / 256**：

```c
const uint16_t sine_table[256] = {
    2048, 2098, 2148, ..., 4095, ..., 0, ..., 1948, 1998
    // 12 位 DAC 中点 2048，用 sin() 函数预计算 256 点
};

void start_dac_dma_sine(uint32_t freq_hz) {
    uint32_t dma_rate = freq_hz * 256;  // DMA 时钟率
    timer_set_period(SYS_CLK / dma_rate);
    dma_start(DAC_DR, sine_table, 256, CIRCULAR_MODE);
}
```

**这段代码说的其实是**——**'让定时器产生指定频率的脉冲 → 每个脉冲触发 DMA 把表里下一个值送 DAC → 256 个值循环输出 = 一个正弦周期'**——**经典 DDS 思想**。

> **小白补课：什么是 DDS（Direct Digital Synthesis）？**  
>  
> **DDS（直接数字频率合成）**——**1970 年代航天工程师发明的'**不需要模拟振荡器**'的频率合成技术**——**核心是 '相位累加器 + 查表 + DAC'**：  
>  
> 1. **一个 32 位的'相位累加器'**——**每个时钟周期加一个固定数 K**——**K 越大相位增长越快 → 频率越高**  
> 2. **相位的高 8 位送给查表（256 点正弦表）**——**得到当前正弦值**  
> 3. **查表结果送 DAC** —— **输出模拟正弦**  
>  
> **特点**：  
> - **频率分辨率超高**（32 位累加器 → 0.01Hz 精度）  
> - **频率切换瞬时**（修改 K 即可）  
> - **失真低**（256 点表 → THD < 0.5%）  
>  
> **应用**：**所有现代信号发生器、雷达、5G 基站、医疗超声**都用 DDS 作为频率核心。**AD9851**、**AD9854** 这些专用 DDS 芯片就是把这套硬件化了。

**路径 B：PWM + 低通滤波**

```
PWM 占空比 50% + 频率 1MHz + RC 低通 → 直流 1.65V
PWM 占空比按正弦波规律变化 → 滤波后 = 正弦波
```

**优点**：**MCU 内置 PWM 模块都能用**——**不需要 DAC**。  
**缺点**：**滤波器设计复杂 + 高频精度差**——**1MHz 输出是天花板**。

**路径 C：专用 DDS 芯片（AD9851 / AD9833）**

**AD9833** 单价 35 元——**SPI 控制 + 内置 28 位 DDS + 12 位 DAC + 25MHz 主时钟**——**输出 0~12.5MHz**——**频率精度 0.1Hz**——**THD 0.6%**——**完爆 STM32 内置 DAC**。

**路径选择对比**：

| 路径 | 单价 | 最高频率 | 精度 | 难度 |
|---|---|---|---|---|
| **A. STM32 DAC + DMA** | 0 元（已有） | **1 MHz**（极限） | ±2% | ★ |
| **B. STM32 PWM + LPF** | 1 元（电感电容） | 100 kHz | ±5% | ★★★ |
| **C. AD9833 专用 DDS** | 35 元 | 12.5 MHz | ±0.1% | ★ |

**国一队伍选 C（AD9833）** —— **3 个芯片引脚 + SPI** —— **30 分钟搭好** —— **频率精度远超题目要求**。

**'峰峰值最大值 ≥ 3V'** 是个'限制'

DAC 直接输出**0~3.3V**——**峰峰值最大 3.3V**——**满足 ≥ 3V**。

**但 AD9833 输出只有 ±300mV** —— **必须加一级运放放大 5 倍**：

```
AD9833 输出 ─[运放 OPA1612 增益 5×]─► 输出
              0.6Vpp                    3Vpp
```

**OPA1612** 是 TI 的低噪低失真运放——**单价 25 元**——**1MHz 带宽 + THD < 0.001%**——**完美**。

**精度链**：

```
AD9833 频率精度: 0.1Hz @ 100Hz = 0.001% 
DAC 量化误差: 12 位 = ±0.024%
合计: ±0.1%  → 远超 5% 要求
```

**10 分稳吃**——**前提是用 AD9833**。**用 STM32 DAC + DMA 1MHz 输出非常吃力**——**不推荐**。

## 第二个谜：扫频识别滤波器类型——4 选 1 的'指纹'

发挥要求 (1) 给了 5 分——**'2 分钟内学习建模，显示未知模型电路的滤波类型'**——**4 种滤波类型：低通、高通、带通、带阻**。

**先看 4 种滤波器的'频率响应指纹'**：

```
增益 |H(f)|
  ↑
  │
  │ 低通：从平直高电平 → 转折后下降
  │     ┌──────────╲
  │     │           ╲
  │     │            ╲___
  │     ▲
  │  截止频率 fc
  │
  │ 高通：从低电平 → 转折后上升 → 平直高电平
  │              ╱──────────
  │             ╱
  │ ___        ╱
  │            ▲
  │         截止频率 fc
  │
  │ 带通：山峰形（中心频率附近最高）
  │           ╱╲
  │          ╱  ╲
  │ ___    ╱    ╲___
  │         ▲
  │      中心频率 f0
  │
  │ 带阻：山谷形（中心频率附近最低）
  │ ──────╲    ╱──────
  │        ╲  ╱
  │         ╲╱
  │         ▲
  │      中心频率 f0
  │
  └──────────────────────► 频率（对数轴）
```

**4 种类型的判别特征**：

| 类型 | f → 0 时 H | f → ∞ 时 H | 中频段 H |
|---|---|---|---|
| **低通** | **大** | 小 | 中（单调下降）|
| **高通** | 小 | **大** | 中（单调上升）|
| **带通** | 小 | 小 | **大（有峰）** |
| **带阻** | **大** | **大** | 小（有谷）|

**只看'两端 + 中间'三个频点就能区分 4 种**——**算法极简**。

**实战代码**：

```c
typedef enum { LOW_PASS, HIGH_PASS, BAND_PASS, BAND_STOP, UNKNOWN } FilterType;

FilterType identify_filter_type(float* H, int N, float* freqs) {
    // 1. 找最低频点和最高频点的增益
    float H_low  = H[0];
    float H_high = H[N-1];
    
    // 2. 找最大值和最小值
    float H_max = H[0], H_min = H[0];
    int idx_max = 0, idx_min = 0;
    for (int i = 0; i < N; i++) {
        if (H[i] > H_max) { H_max = H[i]; idx_max = i; }
        if (H[i] < H_min) { H_min = H[i]; idx_min = i; }
    }
    
    // 3. 判别（用 -3dB = 0.707 作为阈值）
    bool low_pass_attenuated  = H_low  > 0.707 && H_high < 0.707;
    bool high_pass_attenuated = H_low  < 0.707 && H_high > 0.707;
    bool peak_in_middle       = idx_max > N/4 && idx_max < 3*N/4;
    bool valley_in_middle     = idx_min > N/4 && idx_min < 3*N/4;
    
    if (low_pass_attenuated && !peak_in_middle)        return LOW_PASS;
    if (high_pass_attenuated && !peak_in_middle)       return HIGH_PASS;
    if (peak_in_middle && H_low < 0.707 && H_high < 0.707) return BAND_PASS;
    if (valley_in_middle && H_low > 0.707 && H_high > 0.707) return BAND_STOP;
    return UNKNOWN;
}
```

**这段代码说的其实是**——**'看两端衰减 + 看中间峰谷 → 4 选 1'**——**简单可靠**。

**精度**：**100% 识别率**（**只要扫频精度足够**）。

**'扫频范围怎么定？'**

题面说明 (4)——

> **未知模型电路'中元件值范围**：R(1kΩ~10kΩ), L(1mH~10mH), C(10nF~100nF)。

算一下 LC 谐振频率范围：

```
f = 1 / (2π × √(LC))

L_min × C_min: f_max = 1 / (2π × √(1mH × 10nF)) = 50.3 kHz
L_max × C_max: f_min = 1 / (2π × √(10mH × 100nF)) = 5.03 kHz
```

**未知电路的'特征频率'在 5kHz~50kHz**——**扫频范围必须覆盖这个区间**。

加上 RC 一阶滤波的可能（**fc = 1/(2πRC)**）：

```
R_min × C_min: fc_max = 1 / (2π × 1kΩ × 10nF) = 15.9 kHz
R_max × C_max: fc_min = 1 / (2π × 10kΩ × 100nF) = 159 Hz
```

**RC 滤波特征频率在 159Hz ~ 16kHz**——**扫频范围最好 100Hz ~ 100kHz**——**覆盖所有情况**。

**扫频时间预算**：

```
对数扫频 30 个点（覆盖 100Hz ~ 100kHz）
每点设置频率 1ms + 等待稳定 30ms + ADC 测量 50ms = 81ms
总扫频时间 = 30 × 81 = 2.43 秒
```

**2.43 秒** vs **2 分钟限制**——**留出 117 秒余量**——**做拟合 + 滤波识别 + 系数计算**——**绰绰有余**。

> **小白补课：'对数扫频'为什么比'线性扫频'好？**  
>  
> **线性扫频**：100, 200, 300, ..., 100000 Hz——**点距均匀**。  
>  
> 但人耳和电路特性都是**对数感知**——**100Hz 到 200Hz 听起来差异大，10000Hz 到 10100Hz 听起来差异小**。**电路的频率响应也是对数特性**——**线性扫频会让低频段稀疏、高频段密集**——**精度不均**。  
>  
> **对数扫频**：100, 110, 121, ..., 100000 Hz（每点乘 1.1 倍）——**点距按比例均匀**——**全频段精度一致**。  
>  
> 100Hz~100kHz 对数扫频 30 点 = **每点 1.26 倍** = 30 个点完整覆盖 1000 倍频程。

## 第三个谜：怎么把'频率响应'拟合成'传递函数 H(s)'

发挥要求 (2) 是这道题的**'珠穆朗玛峰'**——**40 分**——**核心难点是'**把扫频得到的离散数据点拟合成连续的传递函数**'**。

**RLC 一阶滤波的传递函数（最复杂的形式）**：

```
H(s) = (b0 + b1·s) / (1 + a1·s + a2·s²)
```

**这个式子说的其实是**——**'分子分母都是 s 的多项式 → 系数 b0、b1、a1、a2 决定滤波特性'**——**4 个未知数**。

**4 个未知数 → 至少需要 4 个独立的扫频测量点（4 个方程）才能解出**。但**扫频测量有噪声**——**只用 4 个点会拟合出很差的结果**——**典型做法是用 30 个点 + 最小二乘法过约束求解**——**抑制噪声**。

**最小二乘法实战代码（伪代码）**：

```c
// 输入：N 个频点的频率响应 H[i] = |H(j*ω_i)|
// 输出：传递函数系数 b0, b1, a1, a2

void least_squares_fit(float* freqs, complex_t* H_complex, int N,
                       float* b0, float* b1, float* a1, float* a2) {
    // 1. 构造矩阵 A 和向量 y
    // 对每个频点：H * (1 + a1·jω + a2·(jω)²) = b0 + b1·jω
    //          → b0 + b1·jω - H·a1·jω - H·a2·(jω)² = H
    // 设 x = [b0, b1, a1, a2]
    
    float A[2*N][4];  // 2N（实部 + 虚部）行 × 4 列
    float y[2*N];
    
    for (int i = 0; i < N; i++) {
        float w = 2 * M_PI * freqs[i];
        complex_t H_i = H_complex[i];
        
        // 实部方程
        A[2*i][0] = 1;                       // b0
        A[2*i][1] = 0;                       // b1（虚部贡献）
        A[2*i][2] = w * H_i.imag;            // a1
        A[2*i][3] = w*w * H_i.real;          // a2
        y[2*i]    = H_i.real;
        
        // 虚部方程
        A[2*i+1][0] = 0;
        A[2*i+1][1] = w;
        A[2*i+1][2] = -w * H_i.real;
        A[2*i+1][3] = w*w * H_i.imag;
        y[2*i+1]    = H_i.imag;
    }
    
    // 2. 求解 A·x = y 的最小二乘解
    // x = (A^T · A)^(-1) · A^T · y
    float x[4];
    arm_matrix_solve_lstsq(A, y, 2*N, 4, x);
    
    *b0 = x[0]; *b1 = x[1]; *a1 = x[2]; *a2 = x[3];
}
```

**这段代码说的其实是**——**'把传递函数公式 H(s) 在每个频点变成一个线性方程 → 30 个频点 = 60 个实虚分离方程 → 用最小二乘法解 4 个未知数 → 得到拟合结果'**——**经典系统辨识方法**。

**精度链**：

```
ADC 量化误差：±0.1%
扫频相位精度：±2°
频率响应测量精度：±2%
最小二乘拟合误差：±3%（30 个点）
合计：±5%
```

**5% 拟合误差**——**对应'输出峰峰值误差 ±5%'**——**远超题目要求 ±10%**——**40 分目标**。

## 第四个谜：怎么把'连续传递函数 H(s)' 转成'数字 IIR 滤波器'

拿到 H(s) 之后还差最后一步——**离散化**——**把 s 域（连续模拟）变成 z 域（离散数字）**。

**双线性变换公式**：

```
s = (2/T) × (z - 1) / (z + 1)
```

**这个式子说的其实是**——**'用 z 替换 s 的一个数学映射 → 连续滤波器变成数字滤波器'**——**Tustin 变换**——**1947 年瑞典工程师 Tustin 发明的方法**。

代入 H(s)：

```
H(z) = (b0_d + b1_d·z⁻¹ + b2_d·z⁻²) / (1 + a1_d·z⁻¹ + a2_d·z⁻²)
```

**得到 5 个数字系数 b0_d, b1_d, b2_d, a1_d, a2_d**——**这就是 IIR 二阶滤波器的'**指令集**'**。

**双线性变换的代码**：

```c
void bilinear_transform(float b0, float b1, float a1, float a2, float fs,
                        float* b0_d, float* b1_d, float* b2_d, 
                        float* a1_d, float* a2_d) {
    float T = 1.0 / fs;
    float K = 2.0 / T;
    float K2 = K * K;
    
    // 分母（归一化为 1 + a1·z⁻¹ + a2·z⁻² 的形式）
    float denom = 1 + a1*K + a2*K2;
    
    *b0_d = (b0 + b1*K) / denom;
    *b1_d = (2*b0 - 2*b1*K) / denom;
    *b2_d = (b0 - b1*K) / denom;
    
    *a1_d = (2 - 2*a2*K2) / denom;
    *a2_d = (1 - a1*K + a2*K2) / denom;
}
```

**'fs 怎么定？'**

发挥 (2) 要求处理 **1kHz ~ 50kHz 的输入信号**——**奈奎斯特要求采样率 ≥ 100kHz**——**留 5 倍余量** —— **fs = 500kHz**——**STM32H743 ADC 1MSPS 完全跑得动**。

**实时 IIR 滤波代码（Direct Form II Transposed，最稳定的形式）**：

```c
typedef struct {
    float b0, b1, b2, a1, a2;
    float z1, z2;
} IIR_Filter_t;

float iir_filter_step(IIR_Filter_t* f, float in) {
    float out = f->b0 * in + f->z1;
    f->z1 = f->b1 * in - f->a1 * out + f->z2;
    f->z2 = f->b2 * in - f->a2 * out;
    return out;
}
```

**这段代码每次调用只做 5 次乘法 + 4 次加法**——**STM32H743 单精度浮点 1 个时钟周期 = 5/480M = 10ns**——**1MSPS 实时跑无压力**。

**完整流程**：

```c
// 阶段 1：学习建模（一次性，2 分钟内）

    // 1. 扫频 30 个频点
    complex_t H[30];

    for (int i = 0; i < 30; i++) {
        freqs[i] = 100 * powf(10, i * 3.0/29);  // 对数扫频 100Hz~100kHz
        dac_output_sine(freqs[i], 1.0);

    }

    FilterType type = identify_filter_type(H, 30, freqs);

    // 4. 双线性变换 → IIR 系数
    bilinear_transform(b0, b1, a1, a2, FS_500k, 
                       &iir.b0, &iir.b1, &iir.b2,

    }
}
```

**精度链**：

```
扫频精度：±0.1%（AD9833）

拟合误差：±3%

合计：±5%
```

**5% 误差** vs **题目要求 10%** = **2 倍余量** = **40 分稳吃**。

> **小白补课：'双线性变换' 为什么是离散化的标准方法？**  
>  
> 离散化模拟滤波器有 **3 种方法**：  
>  
> 1. **冲激响应不变法**：保持时域脉冲响应一致——**简单但有混叠**——**不适合宽带滤波器**  
> 2. **后向差分法**：用 (1-z⁻¹)/T 代替 s——**简单但稳定性差**——**不推荐**  
> 3. **双线性变换法**：用 (2/T)·(z-1)/(z+1) 代替 s——**无混叠 + 稳定性最好**——**所有 DSP 教材的标配**  
>  
> **代价**：双线性变换有'频率扭曲'——**模拟滤波器的截止频率 fc 经过双线性变换后会偏移**——**特别是 fc 接近 fs/2 时偏移大**。**预扭曲补偿**：拟合 H(s) 时把 fc 预先调高 → 双线性变换后回到原值。这是 IIR 设计的高级技巧。

## 第五个谜：怎么对付各种周期信号——'矩形波 / 三角波 / 锯齿波'

题面发挥 (2) 提到——

> 信号发生器的输出为频率 1kHz~50kHz、峰峰值 2V 的**周期信号**，类型分别为：**正弦波、矩形波（占空比 10%~50%）和其他周期信号**。

**'其他周期信号'** 是个'**陷阱**'——**通常包括三角波、锯齿波、半波整流波**。

**问题来了**——**你拟合的 H(s) 是用正弦扫频拟合的**——**对正弦输入完美**——**但对矩形波、三角波是否还正确？**

**答案——是！**——**因为线性时不变（LTI）系统的奇妙特性**。

> **小白补课：什么是线性时不变（LTI）系统？**  
>  
> **线性**：**输入×2 → 输出×2**；**输入1 + 输入2 → 输出1 + 输出2**。**RLC 滤波器是天生的线性系统**。  
>  
> **时不变**：**今天测和明天测结果一样**。  
>  
> **LTI 系统的奇妙性质**：**任何输入都能分解成正弦的叠加（傅里叶级数）**——**输出 = 每个正弦分量分别经过滤波器的叠加**。  
>  
> **意思是**——**只要你拟合的 H(s) 在所有正弦频点都对**——**对任何复杂周期信号都自动对**——**这就是傅里叶分析的力量**。

**矩形波 = 基波 + 3 次 + 5 次 + 7 次... 谐波叠加**

```
矩形波(1kHz, 50%) = (4/π) × [sin(1000·2π·t) + sin(3000·2π·t)/3 + sin(5000·2π·t)/5 + ...]
```

每个谐波都通过滤波器——**输出 = 滤过的谐波之和**。**只要 H(s) 在 1kHz, 3kHz, 5kHz, ... 都拟合对**——**输出形状就和真实未知电路一致**。

**所以 IIR 滤波器对矩形波 / 三角波 / 锯齿波都自动正确**——**前提是扫频范围覆盖了所有重要谐波**。

**坑——'扫频范围必须覆盖谐波'**

输入信号 1kHz~50kHz——**矩形波的 5 次谐波最高达 250kHz**——**扫频只到 100kHz 不够**。

**对策——扫频上限提到 250kHz**：

```c
freqs[i] = 100 * powf(10, i * 3.4/29);  // 对数扫频 100Hz~250kHz
```

**29 个点覆盖 3 个数量级 + 4 倍**——**'高频精度'稍降但仍可接受**。

**或者——告诉学生 '其他周期信号' 是受限的'**

题目里**没明确说支持多高的谐波**——**国一队伍读题后判断**：'**1kHz~50kHz 的矩形波 → 主要能量在前 5 次谐波 → 250kHz 内**'——**扫频上限 250kHz 安全**。

**'波形无失真 + 同频稳定显示 + 相位无要求 + 峰峰值误差 ≤ 10%'** 的精确解读

**'波形无失真'**——**输出波形和真实电路输出**目视一致**——**没有奇怪的振荡或畸变**。

**'同频稳定显示'**——**示波器双踪显示真品和复刻 → 频率一致 + 不漂移**——**两者跟着信号源同步变**。

**'相位无要求'**——**关键的妥协！** —— **相位差不算分**——**只要振幅对就行**——**这极大降低了 IIR 滤波器的难度**——**因为 IIR 滤波器自然有几个采样的群延迟**——**评委允许这个延迟**。

**'峰峰值误差 ≤ 10%'**——**唯一的定量指标**——**前面已经分析 ±5% 余量** = **稳吃 40 分**。

### 任务那段话——'已知模型 + 未知模型 = 双轨制'

题目原文（第 11 行）：

> 设计并制作 **RC 有源滤波电路**（简称**已知模型电路**）和**电路模型探究装置**（简称**探究装置**）。**基本要求中**，**探究装置可自动调节本身的输出信号并加给'已知模型电路'**，使该电路按要求输出信号；**发挥部分中**，**探究装置可对测评现场提供的'未知模型电路'进行自主学习、建模**，并**根据该电路输入端的信号推理生成与该电路相同的输出信号**。

这一段是**整道题的'**任务声明**'**——**短短 3 句话定义了 4 个角色 + 2 个工作模式**。

**4 个角色**：

| 角色 | 来源 | 工作 |
|---|---|---|
| **已知模型电路（RC 有源滤波）** | **你自己设计 + 焊** | 评测时**接探究装置**让它做闭环控制 |
| **未知模型电路（RLC 滤波）** | **测评现场提供** | 评测时**让探究装置学习它**——**事后克隆** |
| **探究装置** | **你自己设计** | **同时做 '控制器'（基本要求）+ '克隆者'（发挥）** |
| **信号发生器**（外部） | **赛场提供** | 发挥 (2) 中独立给未知电路 + 探究装置喂信号 |

**注意——'已知模型电路'是一块独立的板子**——**和'探究装置'是物理分开的**——**焊在两张 PCB 上**。

**为什么要分开？**因为**评委要确认 '已知模型电路' 的实际特性**——**用信号发生器 + 示波器测它的频率响应**（基本要求 (1) 第一步）——**所以它必须能独立工作**。

**'已知模型电路'的传递函数 H(s) 是什么？**

题面只说 **'电压传递函数 H(s)'** —— **没具体写**。但根据图 1 标注 + 题目背景——**这是个'RC 有源二阶滤波器'**——**用一个运放 + 4 个 R + 2 个 C**——**Sallen-Key 拓扑**。

**Sallen-Key 二阶低通**：

```
H(s) = K / (s² + (ω/Q)·s + ω²)
```

**这个式子说的其实是**——**'低通二阶滤波器的传递函数 → 由 ω₀（自然频率）和 Q（品质因数）决定'**——**经典二阶系统**。

**典型设计参数**：
- **K = 1**（增益 0dB）
- **ω₀ = 2π × 1000 = 6283 rad/s**（fc = 1kHz）
- **Q = 0.707**（巴特沃斯特性）

**对应电路**：
- **R1 = R2 = 11.3 kΩ**
- **C1 = 22 nF, C2 = 11 nF**
- **运放：OPA1612**（或便宜版 NE5532）

**14 分**（基本要求 (1)）就是评委用信号发生器测你这个电路的实际频率响应——**和你写的 H(s) 比对**——**误差 ≤ 10%**——**14 分到手**。

**第二笔账：'探究装置'是题目的'明星角色'**

它要做 **3 件事**：

1. **基本要求 (2)(3)(4)**：**给已知电路做闭环控制**——**输出指定幅度的信号**
2. **发挥 (1)**：**给未知电路做扫频学习**——**识别滤波类型**
3. **发挥 (2)**：**克隆未知电路的输入输出特性** —— **'**变身**' 成它**

**3 件事用同一颗 MCU + 同一套硬件**——**这是题目的设计'**约束**'**——**强迫你做模块化软件架构**。

### 基本要求 (1)：搭建已知 RC 有源滤波电路 - 14 分

题目原文（第 18 行）：

> （1）在单独的电路板上搭建**电压传递函数为 H(s)** 的'已知模型电路'。**由信号发生器输入频率 100Hz~3kHz、峰峰值 1V 的正弦信号**，使用示波器测量该电路输出电压幅度，如图 1 所示。**要求该电路输出电压幅度与传递函数 H(s) 表征的输出电压幅度的相对误差绝对值不大于 10%**。

**14 分** —— **题目最容易的'基础分'** ——**前提是你的电路设计 + 焊接质量过关**。

**实战流程**：

**步骤 1：设计 H(s)**

国一标配——**Sallen-Key 二阶巴特沃斯低通，fc = 1kHz**：

```
                R1                R2
信号输入 ──[10kΩ]──+──[10kΩ]──┬──> 运放 OPA2134 +输入
                  │            │
                C1│        C2  │
                  │            │
                 GND          GND
                              ↓
                          输出
                              ↓
                         R4(反馈)
                              ↓
                         运放 -输入
                              ↓
                         R3 → GND
```

**电路计算**：

```
ω₀ = 1 / √(R1·R2·C1·C2) = 1 / √(10k × 10k × 22n × 11n) ≈ 6420 rad/s
fc = ω₀ / (2π) ≈ 1022 Hz   ✓
Q = √(R1·R2·C1·C2) / [R1·C1 + R2·C1 + (1-K)·R2·C2] ≈ 0.7  ✓
```

**步骤 2：焊接 + 测试**

焊好后用 NanoVNA 或者你的探究装置自己扫频——**测 100Hz、500Hz、1kHz、2kHz、3kHz 几个点的实际增益和相位**——**和理论值对比**。

**典型实测**：

| 频点 | 理论 |H(f)| | 实测 |H(f)| | 误差 |
|---|---|---|---|
| 100 Hz | 1.000 | 0.998 | 0.2% |
| 500 Hz | 0.972 | 0.965 | 0.7% |
| 1 kHz | 0.707 | 0.703 | 0.6% |
| 2 kHz | 0.236 | 0.232 | 1.7% |
| 3 kHz | 0.110 | 0.105 | 4.5% |

**所有点误差 < 10%** —— **14 分到手**。

**坑——焊接不良会让电容寄生**

电容焊接后引线长——**寄生电感 5~20nH**——**在 50kHz 以上影响显著**——**1kHz 以下没影响**——**对本题不致命**。

**国一队伍的标配**——**用贴片元件 + 短引线 + 专用滤波 PCB 模块**——**误差 < 1%**。

### 基本要求 (3)：1kHz 闭环控制输出 2V - 10 分

题目原文（第 22 行）：

> （3）**将探究装置的输出端连接'已知模型电路'的输入端**，如图 2 所示。**设置探究装置输出 1kHz 的正弦信号**，并依据基本要求（1）中的 H(s) 确定**输出信号幅度**，使得'已知模型电路'**输出电压峰峰值为 2V**。要求该电路输出电压与设定值（2V）的**相对误差绝对值不大于 5%**。

**核心算法——'**反算输入幅度**'**

已知 H(s) 在 1kHz 处 = 0.707（前面表格）——**要让已知电路输出 2V**：

```
V_input_required = V_output_target / |H(1kHz)| = 2 / 0.707 = 2.83V
```

**探究装置输出 2.83V → 已知电路输出 2V**——**理论计算**——**简单**。

**精度链**：

```
H(1kHz) 理论值 = 0.707
H(1kHz) 实测值 = 0.703（前面表格）
理论 V_in = 2 / 0.707 = 2.83V
实际 V_out = 2.83 × 0.703 = 1.99V
误差 = (2 - 1.99) / 2 = 0.5%
```

**远低于 5% 要求** —— **10 分稳吃**。

**进阶——'**自动闭环**'**

如果 H(s) 实测值和理论有偏差——**测一次 V_out，调一次 V_in**——**自动收敛**：

```c
float V_in = V_out_target / H_theoretical;
dac_set_amplitude(V_in);
delay_ms(50);
float V_out_measured = adc_measure_pp();
while (fabs(V_out_measured - V_out_target) > 0.05) {
    V_in *= V_out_target / V_out_measured;
    dac_set_amplitude(V_in);
    delay_ms(50);
    V_out_measured = adc_measure_pp();
}
```

**3 次迭代** = **误差 < 0.5%** —— **超越 5% 要求 10 倍**。

### 基本要求 (4)：扫频闭环 - 16 分

题目原文（第 24 行）：

> （4）基本要求（3）中，探究装置可设置并**输出 100Hz~3kHz 频率范围内的正弦信号**，依据基本要求（1）中的 H(s) 确定输出信号幅度，使得'已知模型电路'**输出电压峰峰值为设定值（范围 1~2V、步长 0.1V）**。要求该电路输出电压与设定值的**相对误差绝对值不大于 5%**。

**实现**：

### 说明里的暗坑

题目'说明'部分看起来像免责条款——**每一条都是关键工程信息**。

**说明 (1)——'预留各输入、输出端信号测试端口'**

> 预留各输入、输出端信号测试端口。

**简单要求**——**所有信号点暴露给示波器测试**——**用接线柱或 BNC 接头**——**便于评委测量**。

**说明 (2)——'输入输出仅 1 根信号线 + 地线 + 无反馈连接 + 5s 启动'**

> 基本要求（3）（4）和发挥部分（2）中，'已知模型电路'和'未知模型电路'的**输入、输出端均只有 1 根信号线和地线**，**探究装置与'已知模型电路'和'未知模型电路'输出端无任何反馈连接**；**探究装置需在启动后 5s 内生成信号输出**。

**3 个关键限制**：

1. **'1 根信号线 + 地线'** = **单端信号传输**——**没有差分线**——**简化接口**
2. **'无任何反馈连接'** = **基本要求 (3)(4) 是开环控制**——**探究装置不能直接看到已知电路输出**——**只能根据 H(s) 反算 V_in**
3. **'5s 内生成信号输出'**——**装置不能开机后慢慢热起来** —— **必须立即工作**

**'无反馈连接' 的隐藏意义**

如果允许反馈——**探究装置可以测 V_out → 闭环修正 V_in**——**精度无限高**——**简单**。

**禁止反馈意味着 '只能开环'**——**精度完全取决于 H(s) 的拟合精度**——**这是题目的难点**。

**对策——基本要求阶段**：**先做扫频得到 H(f) 表 → 反算 V_in 时直接查表**——**精度依赖 H(f) 表准确度**。

**'5s 启动' 的实现**——**预扫频结果存 EEPROM** —— **下次开机直接读取**：

```c
void startup_sequence() {
    // 1. 读 EEPROM 里的 H(f) 表
    if (eeprom_has_calibration()) {
        load_H_table_from_eeprom();
        // 0.5s 完成
    } else {
        // 没校准过 → 现场扫频
        run_full_calibration();  // 30s
    }
    
    // 2. 启动 DAC + 信号源
    ad9833_start();
    
    // 3. 显示就绪
    display("READY");
}
```

**典型 0.5~30 秒** —— **远低于 5s 限制**（**事后扫频**）—— **达标**。

**说明 (3)——'按键设置 + 一键启动'**

> 基本要求（3）（4）中，**探究装置具有通过按键等设置所产生信号的频率、所控制的'已知模型电路'输出电压值功能**。**设置完成后，一键启动信号输出，后续不可人工干预**。

**说明 (4)——'未知电路元件值范围 + 唯一学习键'**

> 发挥部分（1）中，'未知模型电路'中**元件值范围**：**R（1kΩ~10kΩ), L（1mH~10mH), C（10nF~100nF）**；**电路连接完成后**，**使用唯一'学习键'启动探究装置学习建模**，**后续不可人工干预**；**'未知模型电路'的滤波类型指低通、高通、带通或带阻**。

**前面 '第二个谜' 已经分析过**——**RLC 元件值范围决定了特征频率范围 5kHz~50kHz** —— **扫频范围 100Hz~250kHz 安全**。

**'唯一学习键'**——**只有 1 个按键 → 按下 → 全自动完成扫频 + 拟合 + 显示** —— **'一键学习'体验**。

**说明 (5)——'触发通道 + 双踪显示 + 无漂移'**

> 发挥部分（2）中，**信号发生器设置完成后，一键启动探究装置，后续不可人工干预**。**示波器以'未知模型电路'输出为触发通道**，**要求双踪显示的探究装置与'未知模型电路'输出波形相同、无漂移**。

**'无漂移'** 是关键要求——**意味着探究装置的输出和未知电路的输出**长时间保持同步**——**不能 1 秒内还对，10 秒后就漂移**。

**'漂移'的来源**：

1. **数字滤波器累积误差**——**32 位浮点几乎不会有累积**——**OK**
2. **采样时钟漂移**——**STM32 内置 RC 振荡器精度 ±1%**——**1 秒漂 0.1°相位**——**长时间会偏**
3. **温度漂移**——**MCU 发热 + 时钟温度系数** —— **5 分钟漂 1°相位**

**对策——用外部高精度晶振**：

- **TCXO（温补晶振）**：**精度 ±1ppm** —— **30 元** —— **1 小时只漂 ±0.0036°**
- **OCXO（恒温晶振）**：**精度 ±0.01ppm** —— **300 元** —— **完全不漂**

**国一标配 TCXO** —— **'无漂移'达标** —— **40 分稳吃**。
