## 0b. ⚠ 硬约束(用户定死,新对话别再建议违反)

1. **激光位置不可动**:必须装管顶朝下测 0-40cm 全程(题目量程要求)。距球 ~32-47cm、0.3cm跳变**躲不掉,只能软件(状态观测器/卡尔曼)从噪声里估干净值**。
2. **电压不可锁**:电池标称 12V,**实际使用会放电掉压**,设计必须对电压漂鲁棒。**当前锁 8.87V 当"放电最坏情况"调,达标则全程都达标。**
   → **这把"转速串级(CTRL_MODE=2)"从可选变成必须**:它锁转速(tach实测)、对电压漂免疫,电池掉压照样悬停。**这是本题鲁棒性的正解,也是报告/发挥分的核心叙事。**

→ 既然两个物理杠杆(挪激光/锁压)都被合理排除,**解法必须是算法**:**转速串级(抗电压漂)+ 状态观测器(从固定噪声激光里抠干净的位置&速度)**。

## 1. 完整根因链(今晚最大的产出,务必读懂)

1. **供电电压 = 主控变量**。风扇 PWM 是占空比,真实功率=占空比×电压。换电池/调压 → 悬停 PWM 和工作点都移位。
   - 12V:悬停≈3420 PWM(35%);~9V:悬停≈4090;8.87V:悬停≈4240。
2. **但电压只改"PWM→RPM",改不了"RPM→升力"**。球离地恒在 **~6700 RPM**,与电压无关(气动特性)。
   → **悬停在"转速空间"稳定(~6700RPM),在 PWM 空间才漂 → 控转速(串级)对电池电压免疫**(已实现,见§3)。
3. **升力是一道气动悬崖**:~6700RPM 突然离地,PWM 上仅 ~15-40 计数就从底到顶。**降电压不能削平它(试过 8.87V,悬崖照旧 + 还多了"球赖在顶上"的滞后)。** 这是不稳定对象的固有高增益。
4. **激光逐样本跳 0.3cm(峰值1.1cm)**(实测:静态 std 0.26,逐样本|Δ|均值 0.30/最大1.1;风扇几乎不增噪,是 VL53L0X 在 47cm 远处的固有噪声)。
   → 裸差分速度被放大成 ±12cm/s 假速度 → 逼出重滤波 → 滞后 → **~2-4s、幅值~1.3cm 的极限环**。这就是 std≈0.85 地板的来源。

**结论:控制器(PID/ADRC/串级)三者都撞 std≈0.85 地板,因为限制来自①气动悬崖②激光速度噪声,不是控制律。**

## 2. ±1cm 的真正下一步(物理,非调参)

1. **激光挪近球工作区(最高性价比)**:现在管顶朝下、距球 ~32-47cm。VL53L0X 在 **10-15cm** 精度高得多,0.3cm 跳变可降到 ~0.1cm → 直接把测量这堵墙推后。考虑:传感器下移、或换 VL53L1X、或缩短量程。
2. **电压固定在 12V**(std 地板 0.85 优于 9V 的 1.3;且别再来回调电压,工作点稳定才能做受控实验)。
3. 软件侧已到位的增益:**α-β 速度观测器(vo1)+ kp8 kd6 + deadband0**(观测器实测降速度噪声37%、std 1.43→1.32)。
4. 若仍差,考虑机械削气动悬崖(管加长/锥形/扩散段/略重的球)。

## 3. 已建基础设施(代码,均未提交!见§6)

- **CTRL_MODE(`Z0/Z1/Z2` 切换)**:

  - **1 = LADRC 自抗扰**:ESO + 跟踪微分器TD(消起浮阶跃)。`Zb`b0/`Zc`ωc/`Zo`ωo/`Zt`ωt。开箱未调好(被电池/悬崖confound),留作"外环升级"备选。
  - **2 = RPM 转速串级**:外环高度PID输出目标转速 rpm_sp,内环转速PI→PWM(电池免疫)。`h`悬停转速/`ya``yb`PWM→RPM映射/`yp``yi`内环PI。真机跑通、稳、内环RPM std~43,外环std~1.0。
- **α-β 观测器**:`va`alpha(0.35)/`vb`beta(0.05)/`vo`开关。`d`误差死区。
- 心跳字段加:`CM:`(模式) `FH:`(ADRC扰动估计z3) `RS:`(目标转速) 已有 H/T/E/P/M/D/R/RAW/A/F。

工具(`Main/tools/`,均未提交的新文件标*):

- `find_hover.ps1`*:自动标定——扫PWM找球离地点=当前电压的悬停。**换电压/电池后先跑它**。

- `meas_noise.ps1`*:量激光跳变噪声(就是它定位了测量瓶颈)。

## 4. 关键实测数据(新对话直接用,免重测)

- **悬停(随电压)**:12V≈3420PWM;~9V≈4090PWM;8.87V≈4240PWM。**离地RPM恒≈6700(电压无关)**。
- **PWM→RPM映射**:随电压变(12V≈2.0·PWM−167;~9V≈3.1·PWM−3738)。换电压必重测(find_hover/sysid)。
- **激光噪声**:静态 std 0.26cm,逐样本|Δ| 均值0.30/最大1.1cm,风扇开几乎不增(0.28/1.2)。
- **观测器A/B(同条件,~9V)**:开 D std 2.46 / H std 1.32;关(EMA) 3.91 / 1.43。**观测器更优,锁定**。
- **整定结论**:kd6甜区(kd12炸到2.79);slew l40最好(l150更差);deadband 0。
- **控制率**~42Hz(激光高速模式),非曲线界面刷新时。
- 几何:管顶朝下,球底 RAW≈47cm,管长~43cm,球40mm。

## 7. 给新对话的开场建议(按硬约束修正)

**前提**:激光不可动、电压不可锁(电池放电),当前锁 8.87V 当最坏情况。两个物理杠杆已排除 → 纯算法解。

1. 读本文 + `调试日志.md`(尤其"电池=主控变量""转速串级""α-β观测器"几段)。
2. **主攻 = 转速串级(CTRL_MODE=2)**,因为它对电池放电免疫(本题刚需)。流程:
   - `find_hover` 在 8.87V 标出当前 hover_rpm(≈6700,基本恒定)+ PWM→RPM 映射(`sysid` 或两点拟合,8.87V≈3.0·PWM−5828)。
   - 设 `ya/yb`(映射)、`h`(hover_rpm)、外环 kp/ki/kd(RPM空间)、内环 yp/yi。`Z2` 开。
   - 难点:外环骑高/地板钳位/位置依赖悬停——需调运行带 n/x 给足下行权限,外环弱积分对中。
3. **叠加状态观测器吃掉激光跳变**:α-β(`vo1 va/vb`)已验证降速度噪声37%。可进一步:
   - 用观测器的**平滑位置 obs_x** 喂误差(不只 obs_v 喂速度),在"降抖 vs 加滞后"间找平衡。
   - 或上完整2态卡尔曼(位置+速度,用已知输入预测)→ 比单样本更准地估位置,有效降 0.3cm 噪声。
4. **冲到稳后再做抗干扰**(§5):拨球/吹气测恢复时间。
5. 全程固定一切、单变量、tune_step 定量裁决。**8.87V 下达标 = 全电压区间达标。**
6. 现实预期:激光 0.3cm 跳变是 ±1cm 的硬底;目标是用 串级+观测器 把 std 从 ~1.3(8.87V当前)压向 ~0.7-0.8,尽量进 ±1cm 误差带;同时确保**电压漂时不崩**(这本身就是发挥分)。
