## 一、系统方案（800~1000 字）

### 1.1 任务分析

题目要求设计气流悬浮式球体定高控制装置：风机吹动标准 40mm 乒乓球在透明导管内悬浮，非接触测高（3~40cm，误差 ≤±1cm），按键设定目标高度（10/15/20cm），闭环定高（稳态误差 ≤±2cm），LCD 显示当前/目标高度、PWM、控制状态。进阶要求任意高度（±1cm）、动态跟踪（≤5s）、高度曲线显示；发挥部分考核抗扰与风速闭环。

**核心难点（按致命度排序，均经真机验证）**：

1. **被控对象天生不稳定**：竖直直筒中"气流升力随高度衰减"构成近似双积分对象，开环不稳定。实测升力曲线极陡——PWM 3300 时球落底、3500 时冲顶，整管升力压缩在约 300 个计数（25kHz/9600 标度）内，中间无自然平衡点，必须靠 D 项（球速阻尼）+ 前馈才能稳住。
2. **执行器秒级滞后 + 非线性 / 死区**：四线风扇 PWM→转速存在转子惯量带来的 ~0.42s 时间常数，且冷启动死区/静摩擦需 ~3s 才能爬到目标转速；低占空比段近似开关特性。
3. **测高微分噪声**：测高噪声底虽仅 std 0.26cm，但在 42Hz 下做裸微分估球速，噪声被 √2/dt 放大到 ~15cm/s，D 项变"噪声发生器"，是单环卡在 ±1.5cm、进不了 ±1cm 的根因。

### 1.2 总体方案设计

系统分为传感层、主控核心、执行层、人机界面四部分。闭环以"测距新样本到达"为**事件节拍**驱动（dt 取相邻样本真实间隔），避免固定节拍与传感器错相产生的锯齿速度。

## 二、理论分析与计算（1500~2000 字，**最重要**）

### 2.1 被控对象建模 —— 为什么必须有前馈 + D 项

设球质量 m、高度 h，受向上气流升力 F(u,h) 与重力 mg。在悬停点附近线性化：升力随控制量 u 增大而增大（∂F/∂u>0），随高度增大而减小（球上升离风口远、升力降，∂F/∂h<0）。运动方程：

$$ m\ddot{h} = F(u,h) - mg \approx F_u\,\Delta u + F_h\,\Delta h \tag{2-1} $$

记 b₀ = F_u/m（输入增益）、a = −F_h/m。由于 F_h<0，特征方程 s² + a' ... 缺自然阻尼，对象**开环不稳定**，纯比例控制必然等幅/发散振荡。引入对球速的微分反馈与前馈：

$$ u = u_{hover} + K_p e - K_d \dot{h} + K_i \!\int e\,dt \tag{2-2} $$

其中 e = h_target − h。前馈 u_hover 托住重力配平点（实测删去前馈、仅靠积分供不上约 3420 计数的悬停量 → 球趴底）；−K_d·ḣ 提供等效阻尼把闭环极点拉入左半平面；K_i 消除前馈/PD 必留的稳态静差。**这从机理上解释了真机中 bang-bang 必产生极限环、纯 P+D 留静差、而前馈+PD+弱I 才收敛的全部现象。**

### 2.2 系统辨识 —— 用模型代替试凑（本作品方法学核心）

不在不稳定对象上盲调，而是先测出"5 个数"再算参数（脚本 `tools/sysid.ps1` / `tools/sweep_rpm.ps1` 由上位机自主驱动采集+拟合）：

**(1) 执行器（风扇）辨识**：PWM 阶跃，采 tach 转速 R(t)。
- PWM→转速线性拟合：**RPM = 2.0·PWM − 167**（悬停 PWM 3420 算得 6673 RPM，对上实测心跳 ~6654，交叉验证通过）；另一台架同源拟合 R²=0.995。
- 暖机阶跃 63% 交叉法：**风扇时间常数 τ_fan ≈ 0.42s**；冷启动从静止约 6s（即风机预热 3s 的依据）。

**(2) 被控对象增益辨识**：用稳定参数把球兜住，闭环双点交叉法。
- uh=3360 → 球稳 11.6cm；uh=3500 → 球稳 17.8cm，两次稳态 PWM 均 ≈3442。
- 由 e_ss = (u_hover − PWM_平衡)/K_p 推得**静态增益 ≈ 22.7 PWM/cm**，零静差悬停点 **u_hover ≈ 3430**。
- 由 15→18cm 阶跃用对数衰减法（Mp=42% → ζ≈0.27、Td=2.53s → ωn≈2.58）反算**输入增益 g ≈ 0.333 cm/s²/计数**。

**(3) 噪声底/帧率**（已测）：测高噪声 σ≈0.26cm（静止 251 样本 ptp 1.5cm）；激光出样 ~42Hz（22ms）。

### 2.3 极点配置算 PID 参数

把对象近似为 ÿ = g·u + f（双积分 + 总扰动），目标二阶闭环阻尼 ζ=0.75、调节时间 ts=2s，得 ωn = 4/(ζ·ts) ≈ 2.67 rad/s。极点配置（脚本 `tools/pidcalc.ps1`，每参数附公式）：

$$ K_p = \frac{\omega_n^2}{g},\quad K_d = \frac{2\zeta\omega_n}{g},\quad \alpha_{EMA}=e^{-\omega_d \cdot dt}\;(\omega_d\approx5\omega_n) \tag{2-3} $$

算得 **Kp≈21.4、Kd≈12.0、Ki≈1.1、球速 EMA α≈0.76、slew≈17**。**交叉验证**：计算 Kp 21.4 ≈ 早期试凑稳定值 20 → 模型与公式可信。

**保守增益修正（真机关键发现）**：极点配置按单点（15cm，g=0.333）算出的增益在 20cm 处会过热——实测 kp21/kd12 在 10/15cm 良好（std0.94），到 20cm 出现极限环（std2.82、PWM 两轨 bang-bang），因对象增益 g 随高度升高变陡（g(20cm)>g(15cm)）。取"略低于计算值"的保守增益 **Kp12 / Kd7** 后，三高度全稳且**无需增益调度，一套值通吃**，代价仅是带宽略降（对 ±2cm 绰绰有余）。

### 2.4 控制律离散实现

事件驱动离散化（dt = 相邻测距样本真实间隔，~24ms / 42Hz）：

```
e_k      = h_target - h_k                       // h_target 经斜率限幅软启动
v_raw    = (h_k - h_{k-1}) / dt                 // 裸球速
v_filt   = α·v_filt + (1-α)·v_raw               // EMA 平滑，α=0.76（压 D 项噪声）
I_k      = clamp(I_{k-1} + e_k·dt, ±I_lim)      // 条件积分抗饱和（饱和时停止积分）
u_k      = u_hover + Kp·e_k - Kd·v_filt + Ki·I_k
u_k      = slew_limit(u_k, ±PWM_SLEW_PER_TICK)  // 斜率限幅(40/拍)，匹配风扇滞后带宽
u_k      = clamp(u_k, PWM_RUN_MIN, PWM_RUN_MAX)  // 运行限幅[3300,3668]，保怠速+封天花板
```

**已整定并回填 config.h 的终值**：Kp=12、Ki=1.1、Kd=7、u_hover=3420、EMA α=0.76、slew=40、运行限幅 [3300, 3668]、误差死区 ±0.3cm、积分限幅 ±200。

> α、slew 的物理意义：42Hz 裸微分会把 0.26cm 噪声放大成 ~15cm/s 球速噪声，使 Kd·v ≈ 800 计数远超控制区间（±192 计数）。EMA（α=0.76）滤掉高频微分噪声、slew 限速让控制器输出带宽匹配风扇 0.42s 滞后带宽——二者是把残余浮动从 ±1.5cm 压向 ±1cm 的第一杠杆。

### 2.5 执行器线性化 —— 25kHz 改造的定量依据

**实测现象（1kHz 时）**：手动 PWM（满标 1000、步进 10），PWM=400→球冲顶，390→瞬间落底，整管升力压缩在约 10 个计数内，控制被量化死。

**根因**：4 线风扇规格 PWM 频率 25kHz，1kHz 下占空比→转速严重非线性。

**改造**：TIM8 Prescaler=0 / Period=9599 → 25kHz，占空比寄存器 0~9600，分辨率提升约 **10×**。config.h 全量按 9600 标度重算。改造后整管升力区间从约 10 计数拉宽到约 300 计数（lift-off~3500、配平~3450、落底~3300），控制器才有可调空间。

### 2.6 测高链路与几何标定

VL53L0X 高速模式（20ms 预算）连续测距，非阻塞轮询 DataReady；以 RangeStatus==0 + 量程窗 [20mm,500mm] 门控有效性。球高由几何关系：

$$ h = \text{TOF\_ZERO\_CM} - d_{raw} \tag{2-4} $$

零点标定常数 **TOF_ZERO_CM = 47cm**（球静止管底激光读 ~47cm，传感器装管口上方约 4cm + 管长 43cm 自洽）。滤波：3 点中值剔孤立假回波（近距饱和的 0.0 尖刺）→ 滑动平均（窗口 FILTER_SIZE=3，小窗降延迟以保 D 项相位）。

> 窄管激光陷阱：VL53L0X 视场 ~25°，光锥在 ~10cm 处填满 45mm 管，>10cm 后外圈打管壁。因球几乎塞满管径（间隙 2.5mm/边），中心强回波仍是球；透明管近壁串扰用哑光黑限光套筒缓解。

STM32H750XBH6 最小系统，12V 输入经降压供 MCU 3.3V、风机 12V。代码 XIP 于 QSPI 外部 Flash（H750 内部仅 128KB）。

#### 3.1.2 风机驱动（执行器）
TIM8_CH2 输出 25kHz PWM 至风机 PWM 控制线（四线：GND / +12V / PWM / TACH）。TACH 转速线经 10k 上拉 3.3V 接 **PC6（TIM3_CH1, AF2）**，输入捕获测周期换算 RPM（每转 2 脉冲），实测干净 3.3V 方波，供串级内环使用。

#### 3.1.3 激光测距（VL53L0X）
位带（软件）I2C，复用超声波空出的两根线，零新增引脚：

| VL53L0X | MCU | 功能 |
|---|---|---|
| SCL | PD11 | GPIO 推挽（主机驱动） |
| SDA | PD12 | GPIO 开漏 in/out |
| XSH | 3.3V | 单传感器常使能，免地址重置 |
| INT | NC | 每控制周期查 DataReady 寄存器 |

> 模块板载无上拉时需补 4.7k 到 3.3V。上电自检读 model id（0xC0 应=0xEE）确认 I2C 通。

#### 3.1.4 显示（GC9A01 圆形彩屏）
硬件 SPI1 寄存器级直驱（本工程缺 `stm32h7xx_hal_spi.c`，不引入 HAL SPI）。SPI1 内核时钟 = pll1_q 240MHz，MBR=/32（7.5MHz，飞线信号完整性稳定点）。接线：

| GC9A01 | MCU | 功能 |
|---|---|---|
| SCL | PB3 | SPI1_SCK (AF5) |
| SDA | PB5 | SPI1_MOSI (AF5) |
| DC | PG13 | GPIO |
| CS | PE6 | GPIO |
| RST | PG14 | GPIO |

> 接线务必按信号名接，DC/CS/RST 易接反（调试中曾因三脚错位黑屏，见附录 D 独到经验）。

- **预热**：风机先在怠速地板（PWM_RUN_MIN）空转 3s，越过四线风扇冷启动死区/静摩擦/~3s 转速爬升，再以当前球位干净投入闭环（不积分、不更新 D 基准）。
- **起飞→定高**：接近目标带连续 5 周期确认（防虚假读数）才切 PID。

#### 反馈看门狗（防"在死数据上调 PID"）
闭环下若超过 CTRL_FEEDBACK_TIMEOUT_MS=150ms 无新有效样本（激光被管壁串扰/球未对准而拒帧），不让 PWM 静默冻结在旧值，改为保持开环前馈 u_hover 并复位 D 基准；心跳打 `A:`（距上次有效样本 ms）字段，肉眼即可区分"反馈死"还是"PID 没调好"。这是吸取超声波时代"H=0 卡死被误判为 PID 问题"的教训而设。

### 3.3 关键算法（伪代码）

球速阻尼 PD（核心）：
```c
v_filt = alpha*v_filt + (1-alpha)*(h - h_prev)/dt;   // 球速 EMA，alpha=0.76
I      = clamp(I + e*dt, -I_lim, +I_lim);            // 条件积分抗饱和
u      = u_hover + Kp*e - Kd*v_filt + Ki*I;          // 前馈 + PD + 弱I
u      = clamp(slew(u), PWM_RUN_MIN, PWM_RUN_MAX);   // 斜率+运行限幅
```

GC9A01 示波器采左滚动 strip-chart：环形缓冲存目标/实际两条曲线，每帧只刷绘图区并左移，与控制环解耦（防显示全刷阻塞拖慢闭环）；framebuffer 存"字节已交换"RGB565 使 8 位 SPI 流恰为 MSB-first。

### 3.4 在线整定能力（调参效率关键）
全部参数串口在线可调免重烧：`kpNN/kiNN/kdNN/uhNNNN/fN.N（EMA）/lNNN（slew）/nNNNN（min）/xNNNN（max）/tNN（目标）/mNNN（手动PWM）/a（自动）/g（启）/s（停）/q（查参）`；一行可含多条命令（空格/分号/逗号分隔）。配合上位机脚本 `tune_step.ps1`（采 30s 自动算 avg/std/ptp/漂移/振荡 + 反馈健康门）形成"改参→采集→定量裁决"闭环。

### 4.1 测试设备

### 4.2 测试方法

#### 4.2.1 基本要求(1) 高度测量
**方法**：CALIB 界面手动放球至尺子 5/10/15/20/30cm，对比装置读数，重复读取看抖动。
**判据**：误差 ≤±1cm（满分）/ ≤±2cm，读数不乱跳。

#### 4.2.2 基本要求(2) 高度设定
**方法**：CONTROL 界面按键切 10/15/20cm，看屏显目标值。
**判据**：三档可设、屏显正确。

#### 4.2.3 基本要求(3) 定高控制
**方法**：分别设 10/15/20cm，启动，串口采 20~30s，统计稳态均值/std/ptp/漂移。
**判据**：稳态误差 ≤±2cm。

#### 4.2.4 基本要求(4) 数据显示
**方法**：观察 CONTROL 界面是否同时显示当前高度/目标/PWM/状态。

#### 4.2.5 进阶(1)(2)(3) 高精度 / 动态跟踪 / 曲线
- 高精度：测任意高度稳态误差 ≤±1cm（**优化中**，靠串级/LADRC 压悬停漂移）。
- 动态跟踪：10↔20cm 切换，软目标 ramp 平滑，计进入并保持 ±1cm 误差带的时间。
- 曲线：CURVE 界面验证坐标刻度、目标参考线、双色曲线。

#### 4.2.6 发挥 抗扰（**优化中**）
**方法**：吹/吸管口、扇风、敲管、瞬间遮挡传感器、模拟电池跌压，看恢复。
**判据**：及格=吹气不掉球 10s 内回稳；优秀=波动 1~2cm，3s 内恢复。

### 4.3 测试环境
室温约 25°C，电源 12V，导管内径 45mm，标准 40mm 乒乓球。

| 模型量 | 实测值 | 方法 |

| 测高噪声底 σ | 0.26cm（ptp 1.5cm，251 样本） | 静止采集 |
| 激光出样率 | ~42Hz | 帧率遥测 |

### 5.2 定高稳态误差（真机，同一套保守增益 Kp12 Ki1.1 Kd7）

| 目标 | 稳态均值 | std | 平均误差 | 漂移 | 达标(≤±2cm) |
|---|---|---|---|---|---|
| 10cm | 9.94cm | 0.73cm | −0.06cm | −0.02cm/s | ✅ |
| 15cm | 15.71cm | 0.87cm | +0.71cm | −0.08cm/s | ✅ |

### 5.3 动态跟踪（真机，10→20cm 阶跃）

| 指标 | 实测 | 达标(≤5s) |
|---|---|---|
| 开始响应 | ~0.85s | — |
| 到目标邻域 | ~2.5s | ✅ |
| 基本稳定 | ~5s | ✅ |

## 六、总结（300~500 字）

### 6.1 创新点
1. **系统辨识驱动设计**：不在不稳定对象上试凑，而是先测对象增益 g、风扇时间常数 τ_fan、PWM→转速关系，再以极点配置算 PID，计算值与试凑值交叉验证一致，方法学严谨可复现。
2. **执行器 25kHz 线性化**：定位"升力区间被量化压窄"根因并定量改造，控制分辨率提升约 10 倍。
3. **保守增益鲁棒于 g(h) 变化**：发现对象增益随高度变陡，取"略低于极点配置值"的一套增益通吃 10/15/20cm，免增益调度。
4. **圆屏示波器自证曲线**：GC9A01 双色（红目标/绿实际）滚动曲线 + cm 刻度，与控制环解耦不阻塞闭环。
5. **工程化在线整定 + 反馈看门狗**：全参数串口在线调 + 上位机定量采集脚本 + 反馈健康门，杜绝"在死数据上调 PID"。

### 6.2 不足与改进方向（对应进阶 ±1cm / 抗扰，**优化中**）
1. **单环天花板 = 悬停 PWM run-to-run 漂移 ±25 计数（≈±1cm）**：风扇热态/电压漂导致连平衡点都在动，外环增益治不了。
2. **串级转速内环已就绪但当前结构不成立**：内环与外环同为 42Hz（被 ToF 样本驱动），无带宽优势，实测越开越差；正确出路是把转速 PI 解耦到独立高速定时器（200Hz~1kHz）形成真正串级——这是冲 ±1cm 的明确工程改动。
3. **LADRC 自抗扰作为备选**：代码已落地（默认关，串口可切），用扩张状态观测器估计"悬停漂移+g(h)+外扰"总扰动并补偿，是抗强扰发挥分的另一条路径。

### 6.3 收获与展望
已完成"激光测高 → 系统辨识 → 前馈+PD 定高（三高度 ±2cm）→ 动态跟踪（≤5s）→ 圆屏曲线显示"主链路。下一步上高速定时器串级内环压悬停漂移冲 ±1cm，并以 LADRC/串级补抗强扰发挥分。
