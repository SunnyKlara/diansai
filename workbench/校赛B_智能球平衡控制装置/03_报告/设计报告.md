## 一、系统方案（800~1000 字）

### 1.1 任务分析

题目要求设计气流悬浮式球体定高控制装置：风机吹动标准 40mm 乒乓球在透明导管内悬浮，非接触测高（3~40cm，误差 ≤±1cm），按键设定目标高度（10/15/20cm），闭环定高（稳态误差 ≤±2cm），LCD 显示当前高度/目标高度/PWM/控制状态。进阶要求任意高度（±1cm）、动态跟踪（≤5s）、高度曲线显示，发挥部分考核抗扰与风速闭环。

**核心难点（按致命度排序）**：

1. **被控对象天生不稳定**：竖直直筒中"气流升力随高度衰减"构成近似双积分对象，开环不稳定，必须靠 D 项（球速阻尼）才能稳住，是整套控制的命门。
2. **执行器强非线性 / 死区**：风机 PWM→风速→升力高度非线性，低占空比段近似开关特性，升力区间被量化压窄。
3. **测高噪声与延迟**：超声波回波易受管壁反射、气流扰动干扰，滤波越重则相位滞后越大，与 D 项需求直接冲突。

### 1.2 总体方案设计

系统分为传感层、主控核心、执行层、人机界面四部分，闭环以"测距新样本到达"为事件节拍驱动（dt 取真实样本间隔），避免固定节拍与传感器错相产生的锯齿速度。

└──────────────┘     └───────┬────────┘     └──────────────┘

## 二、理论分析与计算（1500~2000 字，**最重要**）

### 2.1 被控对象建模 —— 为什么必须有 D 项

设球质量 m、高度 h，受向上气流升力 F(u,h) 与重力 mg。在悬停点附近线性化，升力随高度增大而减小（球上升时离风口远、升力降），即 ∂F/∂h < 0，∂F/∂u > 0。运动方程：

$$ m\ddot{h} = F(u,h) - mg \approx F_u\,\Delta u + F_h\,\Delta h \tag{2-1} $$

由于 F_h 项的存在，开环极点位于复平面右半侧附近，对象**开环不稳定**。纯比例控制 u = u_h + K_p e 得特征方程缺阻尼项，必然等幅/发散振荡。引入对球速的微分反馈：

$$ u = u_{hover} + K_p e - K_d \dot{h} + K_i \!\int e\,dt \tag{2-2} $$

其中 e = h_target − h。−K_d·ḣ 提供等效阻尼，把闭环极点拉入左半平面。**这解释了 §5 实测中 bang-bang 必产生极限环、而前馈+PD 才能收敛的根本原因。**

### 2.2 控制律离散实现

事件驱动离散化（dt = 相邻测距样本真实间隔，标称 80ms / 12.5Hz）：

```
e_k      = h_target - h_k
v_k      = (h_k - h_{k-1}) / dt          // 球速，原始
v_filt   = α·v_filt + (1-α)·v_k          // EMA 平滑，α=PID_DERIV_ALPHA=0.6
I_k      = clamp(I_{k-1} + e_k·dt, ±I_lim) // 条件积分抗饱和
u_k      = u_hover + Kp·e_k - Kd·v_filt + Ki·I_k
u_k      = slew_limit(u_k, ±PWM_SLEW_PER_TICK)  // 斜率限幅防过冲
u_k      = clamp(u_k, 0, PWM_FULL_SCALE)
```

起调参数（config.h，**均待真机整定**）：Kp=150、Ki=8、Kd=120、积分限幅 ±200、误差死区 ±0.3cm。

> 控制周期受 HC-SR04 最小触发间隔（~60ms）限制定为 80ms；该带宽足以镇住直筒 ~1–2Hz 的振荡模态。升 TOF 后可降到 20ms（50Hz）提升带宽。

### 2.3 执行器线性化 —— 25kHz 改造的定量依据

**实测现象（1kHz 时）**：手动 PWM（满标 1000、步进 10），PWM=400→球冲顶，390→瞬间落底，整管升力压缩在约 10 个计数内，控制被量化死。

**根因**：4 线风机规格 PWM 频率 25kHz，1kHz 下占空比→转速严重非线性。

**改造**：TIM8 Prescaler=0 / Period=9599 → 25kHz，占空比寄存器 0~9600，分辨率提升约 **10×**。config.h 全量按 9600 标度重算（PWM_BASE=3800≈40%、BOOST=5800）。

### 2.4 测高链路与几何标定

距离换算：`d(cm) = 回波(us) / 58`。球高由几何关系：

$$ h = \text{TUBE\_HEIGHT} - d_{raw} - \text{SENSOR\_OFFSET} - \text{BALL\_DIAMETER修正} \tag{2-3} $$

标定常数（config.h，标 `[标定]` 待尺子校准）：TUBE_HEIGHT=46cm、SENSOR_OFFSET=2cm、BALL_DIAMETER=4cm。

滤波：原始测距 3 点中值剔尖刺 → 滑动平均（窗口 FILTER_SIZE=3，取小窗降延迟以保住 D 项相位）→ 相邻跳变 >10cm 丢弃（连续丢弃 3 次强制接受防卡死）。

## 三、电路与程序设计（2000~2500 字）

### 3.1 主电路设计

> 完整原理图见 `02_硬件/`，BOM 见 `02_硬件/材料清单_BOM.md`（附录 B）。

#### 3.1.1 主控与电源
STM32H750XBH6 最小系统，12V 输入经降压供 MCU 3.3V、风机 12V。风机 0420 四线（40×40×20mm，12V/0.6A）。

#### 3.1.2 风机驱动（执行器）
TIM8_CH2（PI6）输出 25kHz PWM 至风机 PWM 控制线（4 线：GND / +12V / PWM / TACH）。
> **TACH 转速线当前未接**——风速串级闭环（§发挥）的硬件前提，需 TACH→3.3V 上拉→空闲 TIM 输入捕获脚（TIM4 已被超声波占用，另选 TIM3/TIM2）。

#### 3.1.3 超声波测距
HY-SRF05：TRIG 触发、ECHO 回波经 TIM 输入捕获测脉宽。触发间隔 ≥60ms（ULTRA_TRIG_PERIOD_MS=80ms）。

#### 3.1.4 显示（GC9A01 圆形彩屏）
硬件 SPI1 寄存器级直驱（本工程缺 `stm32h7xx_hal_spi.c`，故不引入 HAL SPI）。接线：

| GC9A01 | MCU | 功能 |
|---|---|---|
| SCL | PB3 | SPI1_SCK (AF5) |
| SDA | PB5 | SPI1_MOSI (AF5) |
| DC | PG13 | GPIO |
| CS | PE6 | GPIO |
| RST | PG14 | GPIO |

> 接线务必按信号名接，DC/CS/RST 易接反（调试中曾因三脚错位黑屏，见 §独到经验）。

### 3.3 关键算法（伪代码）

球速阻尼 PD（核心 3 行）：
```c
v = ema(alpha, (h - h_prev) / dt);          // 球速，EMA 平滑
I = clamp(I + e * dt, -I_lim, +I_lim);       // 条件积分
u = u_hover + Kp*e - Kd*v + Ki*I;            // 前馈 + PD + 弱I
```

GC9A01 示波器只刷绘图区（FlushRegion 184×152）降低 CPU 阻塞，framebuffer 存"字节已交换"RGB565 使 8 位 SPI 流恰为 MSB-first。

### 4.2 测试方法

#### 4.2.1 基本要求(1) 高度测量
**方法**：CALIB 界面手动放球至尺子 5/10/15/20/30cm，对比装置读数，重复读取看抖动。
**判据**：误差 ≤±1cm（满分）/ ≤±2cm，读数不乱跳。

#### 4.2.2 基本要求(2) 高度设定
**方法**：RUN/CONTROL 界面按键切 10/15/20cm，看屏显目标值。
**判据**：三档可设、屏显正确。

#### 4.2.3 基本要求(3) 定高控制
**方法**：分别设 10/15/20cm，启动，记录球稳定后 30s 内高度波动范围。
**判据**：稳态误差 ≤±2cm，肉眼无剧烈晃动。

#### 4.2.4 基本要求(4) 数据显示
**方法**：观察 CONTROL 界面是否同时显示当前高度/目标/PWM/状态。

#### 4.2.5 进阶(1)(2)(3) 高精度 / 动态跟踪 / 曲线
- 高精度：升 TOF + 弱 I，测任意高度稳态误差 ≤±1cm。
- 动态跟踪：10↔20cm 切换，ramp 平滑，计进入 ±1cm 误差带并保持的时间。
- 曲线：CURVE 界面验证坐标刻度、目标参考线、±1cm 误差带、双色曲线。

#### 4.2.6 发挥 抗扰
**方法**：吹/吸管口、扇风、敲管、瞬间遮挡传感器、模拟电池跌压，看恢复。
**判据**：及格=吹气不掉球 10s 内回稳；优秀=波动 1~2cm，3s 内恢复。

## 六、总结（300~500 字）

### 6.1 创新点
1. **执行器 25kHz 线性化**：定位"升力区间被量化压窄"的根因并定量改造，把控制分辨率提升约 10 倍。
2. **前馈+PD 事件驱动闭环**：以测距样本为节拍消除错相锯齿速度，针对直筒双积分对象用球速阻尼稳住。
3. **圆屏示波器自证曲线**：GC9A01 双色曲线 + ±1cm 误差带 + cm 刻度，让评审一眼读出是否达标。

### 6.2 不足
1. 控制率受超声波限制为 12.5Hz，带宽偏低 → 升 TOF 可提至 50Hz。
2. 风速串级闭环 TACH 转速线当前未接 → 抗扰与一致性提升空间未释放。

### 6.3 收获与展望
完成"测高→前馈+PD 定高→曲线显示"主链路，下一步补风速串级 + 抗强扰冲发挥分。
