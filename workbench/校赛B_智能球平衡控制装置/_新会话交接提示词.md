## 1. 硬件事实（已真机确认）
- 主控 STM32H750XBH6；Keil MDK + **ARM Compiler 6(AC6/armclang)**。工程在 `workbench/Main/`（未进 git，全本地）。
- 显示：**GC9A01 1.28" 圆形彩屏**，寄存器级硬件 SPI1（SCL=PB3 SDA=PB5 DC=PG14 CS=PG13 RST=PE6），驱动 `gc9a01.c/.h`，**已点亮可用**。注意旧 `oled.c`(SSD1306) 已弃用但还在工程里(实例化中文字库 cn16)。
- 测高：**HY-SRF05 超声波**。TRIG=PD11，ECHO=PD12→TIM4_CH1 输入捕获(1MHz)。已做：量程门限 + 3点中值 + 滑动平均(3) + 跳变剔除 + 事件标志 `height_updated`。
- 执行器：**0420 四线PWM风扇 12V/0.6A**。PWM=PI6→TIM8_CH2，**已改 25kHz / 占空比 0~9600**(原1kHz非线性已废弃)。管径~45mm直筒，标准乒乓球 Ø40mm(4cm)。
- 转速：风扇第4根 **tach 线→PC6(TIM3_CH1)**，10kΩ上拉3.3V + 1kΩ串联。示波器已验：0~3.3V干净方波，满速~317Hz→**2脉冲/转→~9520RPM**。
- 按键：PC8/PC12/PC11/PC9 = K1/K2/K3/K4，上拉接GND。统一键义：**K1=上/加 K4=下/减 K2=进入/切换 K3=返回**，8ms扫描+长按连发。
- 串口：USART1 @115200，CH340 在 **COM8**。

## 2. 关键物理结论（决定控制思路，别忘）
**直筒=开环不稳定对象(双积分)**：固定 PWM 永远托不住球(稍高一点一直升、低一点一直降，无自然平衡点，已真机证实)。
→ **必须闭环；D项(球速阻尼)是稳定命门**；控制律：`u = u_hover(前馈) + Kp·e − Kd·球速 + Ki·积分`。
→ 25kHz 已把"PWM→升力"线性化(原1kHz时390-400十个计数从底到顶)。

## 4. AI 实时调参工作流（核心能力，已验证可用）
COM口独占，需用户先关自己的串口工具。然后 AI：
1. `control_pwsh_process` start：`powershell -ExecutionPolicy Bypass -File workbench/Main/tools/serial_bridge.ps1 -Port COM8 -Baud 115200`
2. `get_process_output` 读实时心跳 `H/T/E/P/M/D`。
3. 发指令：`fs_append` 追加一行到 `workbench/Main/tools/serial_cmd.txt`（如 `kp120`），桥自动转发，板子回 `>>` ack。
→ AI 边看 D(球速)/E(误差)/P(PWM) 边改参，用户只报现象与看球。

## 6. 单环整定 playbook（上电+球在管内，串口桥在线调）
0. 先做§5任务2几何标定。
1. **找悬停前馈**：进 CALIB 手动调 PWM 到球"不快升不快降"的刀刃点→ `uh<该值>`(≈40%≈3800起)。
2. **只留前馈+D**：`kp0 ki0`，给中等 `kd`。进 CONTROL：D太小→发散冲顶/落底；D太大→高频抖；调到球速被压住、晃而不发散。
3. **加P拉回**：逐步加 `kp` 到能回目标但刚开始过冲就退一点。±2cm即基本达标。
4. **加弱I消静差**：`ki` 给小值消除稳态偏差；过大→慢振荡。
5. 测 10/15/20 三点；记录达标参数+现象进调试日志，回填 config。
看板：`D`=球速判阻尼，`E`=误差判静差，`P`=PWM判饱和。
