## 1. 上一轮的核心教训（别重蹈覆辙）
1. **反馈不可信前调 PID = 纯浪费**。上一轮花数小时调 PID，最后发现：闭环时球在物理上动，但串口 `H=0.0 / RAW≈41 / D=0` **卡死不跟随**。在垃圾数据上调参毫无意义。
2. **不要乱改传感器物理时序**。上一轮为"治快对象"把超声波触发周期从 80ms 提到 20ms，结果**窄管(~45mm)回波混响 20ms 散不掉 → 下次 ping 撞残响 → 读数冻结/乱跳**，亲手弄坏了唯一可信反馈。已改回 80ms。**改采样率前必须先验证新时序下测高仍能跟随球。**
3. **真机现象 vs 数据矛盾时，第一时间让用户用眼睛裁决**，别在数据上空转。
4. 操作铁律：**每次烧录后用户必须按复位**（否则 PWM 脚被拉满、风扇满功率）。复位键只有用户能按。

## 2. 真机已验证的事实（新会话别再重新踩）
**硬件**：主控 STM32H750XBH6；Keil AC6/armclang。串口 USART1 = PA9(TX)/PA10(RX)，CH340 在 **COM9 @115200**（PA10 必须接 CH340 TXD，否则收不到命令——上一轮踩过）。
- 显示：GC9A01 圆屏，已点亮可用（SPI1 寄存器级，MODF 顺序坑已解）。
- 测高：HY-SRF05 超声波，**管顶朝下**。TRIG=PD11，ECHO=PD12→TIM4_CH1(1MHz)。**球在底 RAW≈41cm 稳(±0.5)，H≈0**。
- 执行器：0420 四线 PWM 风扇 12V，PWM=PI6→TIM8_CH2，**25kHz，占空比 0~9600**。
- 转速：tach→PC6→TIM3_CH1（寄存器级，本轮新增并验证，R=RPM 进串口心跳）。tach 工作正常。
- 几何：`H = TUBE_HEIGHT(46) - RAW - SENSOR_OFFSET(2) - BALL_DIAMETER(4)`，底部算出微负被钳0；可微调 TUBE_HEIGHT 让底读0。

**对象特性（真机实测，注意可能被失真测高污染，需重测确认）**：
- 开环**不稳定**：~3000PWM 球落底，~4000PWM 球升顶，中间无稳定点。**高增益**（±100PWM≈满行程）。
- 从底起飞需 ~4000PWM 破静摩擦；一旦airborne 托住更低（迟滞）。
- **风扇冷启动有死区+惯性**：从静止 P3900 要 ~3s 才转到 7500RPM。→ 控制应让风扇**保持怠速旋转**(给个 min PWM 不停)消除冷启动滞后。

**测高致命问题（待解决）**：风扇高速时超声波读数冻结/失真（声学干扰 + 之前的过快触发）。早期 80ms 触发 + `m4000` 时 H 平滑 0→34 是可信的；高转速下仍需重新验证。

## 5. 完整方案（按 gate 顺序，禁止跳步）

### Phase 0 — 让测高在"风扇运行下"可信（最高优先，gate）
**不解决这步，后面全是空中楼阁。**
1. 烧录当前固件(80ms)，复位。让用户**手持球在管内不同高度移动**，AI 看 H/RAW 是否平滑跟随(±1cm)、不冻结。
2. 然后**风扇逐挡升 PWM**(m1500/m2500/m3500…)，用户报球真实位置 vs H，确认 fan-on 下测高是否仍可信。
3. 若 80ms 下 fan-on 测高失真 → 决策：
   - (a) 调触发周期(60/100ms)找混响散尽的可信点；或加测量门控/滤波。
   - (b) **换 ToF 激光测距(VL53L1X，I2C，抗声学干扰)**——原计划的±1cm升级路径，最稳。**先问用户是否有 ToF 模块**。
4. 验收：fan 全速时，手持球移动，H 跟随误差 ≤1cm，无冻结/乱跳。

### Phase 1 — 用可信反馈重测对象 + 风扇怠速
1. 风扇加 **min idle PWM**(如~1500，不停转)消除冷启动 3s 滞后与静摩擦。
2. 可信反馈下重新标定：起飞PWM、各高度悬停PWM(u_hover表)、风扇 PWM→RPM→升力曲线。

### Phase 2 — 串级控制（核心架构，治本）
- **内环**：转速环(tach 反馈，快)。把"PWM→实际风速"线性化，吸收风扇滞后/非线性/电压跌落。
- **外环**：高度环(慢传感器即可)→ 给定目标转速。
- 这是"慢传感器+滞后非线性执行器"的标准解，也是题目发挥部分的"风速串级"(~15分)。当前固件是单环，需加内环转速PID(用 R/tach)。
- 软启动斜坡 + 小增益 + 准确前馈 + 弱积分，串口在线整定。

### Phase 3 — 达标
定高±2cm@10/15/20(基本20分) → 高度曲线(进阶,GC9A01已就绪) → 动态跟踪≤5s → 抗扰。
