# K230高负载散热与供电方案

## 推荐方案

比赛使用建议采用：

```text
K230芯片
→ 合适厚度的导热垫或非导电导热膏
→ 铝制鳍片散热片
→ 30×30×7mm 5V风扇持续送风
```

风扇应让气流穿过散热片鳍片，并留出进风和出风通道。

## 被动散热

1. 检查现有散热片是否真正压在K230芯片上。
2. 检查导热垫两面的保护膜是否已经撕掉。
3. 导热垫不能过厚，否则热阻会增大；也不能太薄导致接触不到。
4. 散热片底面应平整，固定后不能晃动。
5. 可以更换表面积更大的鳍片铝散热片，但不能碰到周围器件造成短路。
6. 使用导热膏时应选择不导电类型，少量均匀涂覆，避免流到器件引脚。

## 主动散热

标准版庐山派K230没有板载风扇接口，建议使用独立5V电源给风扇供电：

```text
外部稳定5V → 风扇正极
外部GND    → 风扇负极
外部GND    → K230 GND（需要控制信号时共地）
```

不要从普通GPIO信号脚直接给风扇供电。若需要PWM调速，应使用MOSFET驱动，GPIO只输出PWM控制信号。

比赛时建议风扇直接全速常开，结构简单、可靠性最高。

## 外壳和安装

- 不要让亚克力板紧贴散热片顶部。
- 在风扇进风侧和出风侧留孔。
- 摄像头排线不能挡住风道，也不能被风扇叶片碰到。
- 风扇振动不能传到摄像头支架，否则会影响像素位置稳定。
- Type-C线和风扇线应固定，避免拉扯开发板接口。

## 软件降温

- 保持`to_ide=False`，避免USB视频编码与传输负担。
- 保持`PREVIEW_ENABLE=False`。
- 比赛开始前再进入高帧率识别，不需要时停止模型。
- 后续416×160 ROI模型的计算量低于480×480模型，通常也有利于降低单位帧计算量。
- 不要同时运行无关的显示、录像、网络和图像保存任务。

## 供电

- 舵机必须独立供电，不能从K230的USB或3.3V引脚取电。
- 风扇和舵机启动电流可能导致K230复位，建议与K230分开稳压供电。
- 各电源需要可靠共地，但大电流舵机回流不要经过K230地线，建议星形接地。
- 若使用屏幕、风扇和摄像头，普通电脑USB口可能供电不足，优先使用质量可靠的5V稳压电源。
- 电源入口和舵机附近分别增加合适的电解电容及0.1μF去耦电容。

## 验收

安装散热后连续运行高帧率模型至少10分钟：

- FPS不应随时间明显下降。
- K230不应自动复位。
- USB或UART不应因舵机动作而中断。
- 摄像头支架不能因风扇振动产生明显像素抖动。
- 散热片温度应趋于稳定，不能持续升高。
