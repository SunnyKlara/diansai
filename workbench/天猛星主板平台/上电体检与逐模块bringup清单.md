## 1. 三条铁律（违反过，代价真实）

1. **新板 = 所有硬件事实归零。** 老板真机实测过的那些结论（电流通道反挂 / 编码器上拉 / 电机极性 / 编码器 A-B 符号）
   在新板上**只是先验假设，不是事实**。逐条重验，别拿老值继续算。反例清单见 §4。
2. **轮子架空，直到差速方向与编码器符号全部验完。** 整车已装好 ⇒ 默认轮子在地上，第一次给 PWM 就可能窜出去
   撞东西或拽断 SWD/UART 线（老板已因线绷着毁掉一次横偏测量）。
3. **三态判据，"没测到" 记 `INCONCLUSIVE` 不记 `PASS`。** 缺第三态会把"没测到"当"没问题"，本仓库踩过。

## 2. 阶段表

顺序不是随便排的：**先证供电 → 再证芯片 → 再拿到观测通道 → 再验传感器 → 最后才动执行器**。
执行器排最后的理由是它唯一能造成物理破坏，而前面每一步都在为"看得见它干了什么"做准备。

### S0 断电静态检查（人 · 万用表 · ~5 min）

| 查什么 | 怎么查 | PASS 判据 | FAIL 就 |
|---|---|---|---|
| 电源轨短路 | 万用表电阻档，12V-GND / 5V-GND / 3V3-GND | **都不是 ~0Ω**（几百 Ω~几 kΩ 或带电容充放电现象都正常） | **停，别上电**。先找连焊/锡珠/贴反的件 |
| 极性件 | 目视 | 电解电容负极标记、SS34 续流二极管、DRV8231 丝印方向、AMS1117 方向 全对 | 拆焊改正再上电 |
| 电池输入 | 目视 + 万用表量电池 | 不反接；电池电压足（3S ≈ 11.1~12.6V） | 电量低先充——**欠压会伪装成"板子半死"**（2026-07-27 实测：诊断了一小时，换电池就好） |

### S1 只上电源、**先不插核心板**（人 · 万用表 · ~3 min）

| 轨 | PASS 窗口 | 依据 |
|---|---|---|
| 12V（Buck-Boost 出） | 11.5~12.5V | 载板设计 §2.1，DRV8231 的 VM |
| 5V | 4.9~5.1V | 给天猛星核心板 + 屏背光（**核心板吃 5V，不从电源板 3V3 供**，§2.3） |
| 3V3（AMS1117 出） | 3.2~3.4V | 给 ESP×2 + ICM + DRV VREF |
| ADJ | 按你设定值 | 平时空 |
| 温度 | AMS1117 / Buck 电感**不烫手** | §2.3 警告过 AMS1117 余量紧 |

> **⚠️ 这一步一旦跳过就补不回来**：核心板插上去之后，3V3 偏高就是直接打在 MCU 上。
> 本次（2026-07-28）**已跳过** —— 板子到手时核心板已装好，见 §5 执行记录。

### S2 芯片活 + SWD 通（AI · ~1 min · 只读零风险）

```powershell
# 只读 openocd 会话：读复位向量，不写不擦
cd workbench\mspm0\car
. .\_tools.ps1
$ocd=(Find-Openocd).Exe; $sc=Find-OpenocdScripts
& $ocd -s $sc -f interface/cmsis-dap.cfg -f target/ti_mspm0.cfg `
       -c "adapter speed 500" -c init -c "mdw 0x0 2" -c exit
```

| 结果 | 判读 |
|---|---|
| `SWD DPIDR 0x6ba02477` + `Cortex-M0+ ... Examination succeed` | **PASS** —— MCU 那路 3V3 好、SWD 三线好、芯片没锁 |
| `Could not find MEM-AP` | 芯片 lockup ⇒ 走 `unbrick_flash.ps1`（全自动，不用按 RST） |
| `DPIDR` 通但 `Examination failed` | **半死态 = 先查供电**（欠压/掉压），别急着怀疑 lockup |
| 完全找不到适配器（`unable to find a matching CMSIS-DAP device`） | 只处理 USB/线，**别跑 flash** |

> `mdw 0x0 2` 顺带告诉你**片上是哪版固件**：与本地 `arm-none-eabi-objcopy -O binary` 出来的镜像
> 前 8 字节比一下，不同就是"没烧过我们的固件"。⚠️ 每次 openocd `init` 都会复位芯片（SSOT §D）。

### S3 烧入固件（AI · ~90 s · 不可打断）

```powershell
powershell -File build.ps1        # 先拿到 text+data，这就是对账值
powershell -File flash.ps1
```

- **PASS 判据** = `wrote N bytes` **且** `verified N bytes`，且 N == `build.ps1` 报的 text+data。**别记死数字**，每改一行码它就变。
- 看到 `diff <n> address 0x...` ⇒ **别重烧**（已 5 次是假失败）。跑 `verify_addr.ps1 -Addresses 0x4,0x<那个地址>` 独立只读复核。
- 三行 CRC helper 超时（`timed out while waiting for target halted` 等）是**已知且无害**的。

| # | 模块 | 谁做 | 命令 / 动作 | PASS 判据 | INCONCLUSIVE / FAIL 该查什么 |

### S5 合起来（顺序有理由）

1. **架空** `m7` 闭环差速 —— 判据：`v100 r0` 两轮 rpm 与计数增量对称（左右不对称被闭环压到 ≈1.00）。
2. **急停 + 超时自停** —— `z` 后 `PWM:0,0` 且 `D:0,0`；`tools\hardcap_test.ps1` 三态。**落地前必过**。
3. **陀螺零偏标定** `k` —— 车按行驶姿态放稳松手（**别用手扶**，手抖会被烙进零偏）。手转 90° 看 `Y:≈±900`。
4. **落地走直线** —— `tools\run_straight.ps1`；判据：左右计数比值 ≈1.0、丢包 0%。
5. **重标里程** `ENC_COUNTS_PER_MM` —— **换板/换轮/换地面必重标**，回填 `config.h` 再重烧。
6. **转向** `j<deg>` —— 用黑线/量角器**外部量**，别信固件内部 `DONE`（2026-07-27 实测：内部 5/5 DONE 而外部累计偏差 >30°）。

## 4. ⚠️ 新板必须重验的"老板经验陷阱"

这一节是本清单的核心价值：下面每条在**老板上是真机实测事实**，但在新板上**只是待验证的先验**。
拿老值直接算 = 本仓库反复踩过的那类错误。

| 事实（老板实测） | 为什么新板可能不同 | 重验方式 |
|---|---|---|
| **电流通道映射 M1=`PA26` / M2=`PA27`**（与 syscfg 原假设**相反**） | 老板是飞线接出来的实测结果；新板若按 §10.1 走线，设计值是 `PA27`=M1、`PA26`=M2 ⇒ **可能正好反过来** | S4-#5：单路给占空，看**哪个 ADC 通道跟着动** |
| 编码器上拉靠手焊 | 新板若做成板载上拉，可靠性更高；但**焊接质量未知**，老板正是这里虚焊 | S4-#3 手转（**必须真手转**） |
| 编码器 A/B 顺序 ⇒ 两轮前进同为正 | 接插件插反 ⇒ 前进读负 | S4-#3 判据② |
| 电机极性 ⇒ `v>0` 前进 | 电机线正负反接 ⇒ 车倒着走 | S4-#6 |
| `ENC_COUNTS_PER_MM` = 已标定值 | 换板/换轮/换地面必变 | S5-#5 重标 |
| 速度环 / 位置环增益"已达标" | 那是**旧电机 MG310P20 + 旧标尺**整定的，换电机后没重整定过 | 架空重跑 `tools\tune_step.ps1` |
| 车端 ESP 的 `VCC` 挂在哪 | 老板上曾误挂 DAP 的 USB 3V3（拔 DAP 就死），后改到电池 3V3 | **脱缆前先拔掉调试器跑一次** |
| 电磁铁那颗 DRV8231 在板 | 四驱改版定版把它标了 DNP；新板到底有没有要看实物 | 目视 + S4-#8 |
