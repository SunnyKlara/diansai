# 天猛星四驱改版 · 定版接线设计（四轮差速原地转弯）

> **本文定位**：自制底板**四驱定版**施工文档——目标 = **原地转弯（半径≈0）减小转弯半径**，走 **四轮差速 / 坦克式（skid steering）**：左组正转 + 右组反转绕中心自转。**不是麦轮、不是独立四轮控制，控制上只有 2 路（左组 / 右组）**。
> **决策已锁定（本会话自主拍板，理由见 §1，用户可推翻）**：方案 A（输入并联扇出）+ 弃电磁槽 + 编码器板级电平转换 + IMU 陀螺仪测转角。
> **⚠️ 全文 `待打板 + 真机验证`**：引脚复用已按 `资料/mspmg3507.pdf` §6.2 IOMUX(PINCM)表逐脚核，**打板前用 TI SysConfig 摆一遍导出 pinmux 为准**。
> 现有 2WD 板真值源 = [`00_载板接线设计_天猛星平台.md`](00_载板接线设计_天猛星平台.md)；本文是其 §10.9「4 电机满配」的定版落地。

## 0. 30 秒看懂

- 现板 3 颗 DRV8231（前左 M1、前右 M2 双向 + 电磁单向）。
- **加 2 颗 DRV8231**（后左 M3、后右 M4），凑满 **4 路轮 H 桥**；**弃用电磁槽**（车用不上，且腾出引脚）。
- **4 轮分左右两组**：`左组 = M1(前左)+M3(后左)`、`右组 = M2(前右)+M4(后右)`。
- **接线核心（方案 A 扇出）**：M3 的 IN 脚**直接并到 M1 的 PWM 网络**、M4 并到 M2 → **零新引脚、驱动固件零改、每电机独立 H 桥（电流不翻倍）**。
- `原地左转 = 左组反 + 右组正`，`原地右转 = 左组正 + 右组反`。
- **顺带修掉现板已知致命坑**：编码器 5V 直连 3.3V 脚（中断风暴）→ 板级加施密特电平转换。
- **转角靠 IMU 陀螺仪、不靠轮编码器**（原地转轮子打滑，编码器测角会骗人）。

## 1. 关键决策 + 为什么（精心思考，非拍脑袋）

### 决策① 方案 A（输入并联扇出），不是方案 B（独立引脚）

固定轮（非转向轮）的差速车做原地转弯，**运动学上只需 2 路控制**：左组、右组永远同动。四轮独立控制（方案 B）**对固定轮车没有任何额外机动性**——你既不能横移（那是麦轮，被禁），也不能让同侧前后轮反向（那会互相打架）。所以：

| | 方案 A（★锁定·扇出） | 方案 B（独立引脚） |
|---|---|---|
| 新增 MCU 引脚 | **0**（M3 并 `PA8/PA9`，M4 并 `PB12/PB13`）| +4（M3→TIMG7 `PA17/PA18`，M4→TIMG6 `PA21/PB27`）|
| 驱动固件 | **零改**（`motor_set(M1)`=左组、`motor_set(M2)`=右组）| `motor.c` 扩到 4 通道 + 映射层 |
| 电流 | **每颗 DRV8231 只带 1 电机**（≠并联，不翻倍，避开重载过流）| 同左 |
| 对原地转弯的机动性收益 | 完整（就是差速本身）| **零额外收益**（固定轮车） |
| 复杂度/风险（7 天冲刺） | 最低 | 高（固件重构 + 4 编码器 + 4 电平转换）|

> **结论**：方案 B 的唯一卖点"独立控每轮"对本车型毫无用处，却显著加复杂度/风险。方案 A 是最优解、不是妥协。
> **可选保险（几乎零成本）**：M3/M4 的 IN 脚用 **0Ω 跳线** 引出——默认位并到 M1/M2（方案 A），另一位接到 `PA17/PA18`、`PA21/PB27`。将来万一要独立控制，改 4 个 0Ω 即切到方案 B，不用重打板。
>
> ⚠️ **方案 B 选脚待核实（2026-07-27 补）**：外部资料（[mspm0-skill](https://github.com/mc3545dada/mspm0-skill) 引 LCKFB 天猛星文档，**我们未核实**）称 **PA21 / PA23 / PA02 / PA18 / PA10 / PA11 为特殊脚、非必要不用**——方案 B 用到的 **PA18、PA21 都在名单里**（PA17/PB27 不在）。方案 A 零新引脚故**当前不受影响**；**真要翻 0Ω 切方案 B 前，先查清 PA18/PA21 特殊在哪**（疑与 BSL/复位期行为或板上既有连接有关，未证实），必要时换用 §10.12 的其它空闲脚。详见 [`AI调试工具链_借鉴mspm0-skill.md`](AI调试工具链_借鉴mspm0-skill.md) §4。

### 决策② 弃用电磁槽（车用不上 + 腾资源）

四驱车不需要电磁铁。**不焊电磁那颗 DRV8231**（保留 PCB 焊盘做通用性）→ 腾出 `PA24`(ADC0 A0_3) 给 M4 电流采样、`PB0`(TIMA1) 空出。这样 4 个轮的电流采样正好占满 ADC0 的 A0_0~A0_3，对称干净。

### 决策③ 转角用 IMU 陀螺仪，不靠轮编码器（⭐最关键的"适配项目"洞察）

**原地转弯时四个轮都在侧滑刮地（scrub）**——轮子转的圈数 ≠ 车实际转的角度，**用轮编码器积分算转角会严重失真**。板上已有 **ICM42688（SPI1）**，用它的**陀螺仪 Z 轴积分得偏航角(yaw)** 来闭环控制"转多少度"，才准。分工：

- **轮编码器（前左/前右各 1）**：测**直线速度/里程**（直行时轮子不打滑，编码器可信）。
- **IMU 陀螺仪**：测**原地转弯的角度/角速度**（打滑场景唯一可信）。

### 决策④ 编码器板级电平转换（修现板中断风暴根因）

现板 v1.3 把 5V 霍尔编码器 A/B **直连** MSPM0（3.3V 非 5V 耐受）脚 → 过压 + 脏边沿 → **中断风暴（实测 ISR 计数 829 万 ≫ 软件轮询 48）、计数不可信**（见 `调试日志.md` M-编码器）。新板必须板级修：**编码器供电仍 5V，A/B 输出经施密特缓冲降到 3.3V**。

## 3. 施工操作（EasyEDA 逐步改原理图）

> 原则：**新增两颗 DRV8231 = 复制现有 CBB1/CBB2 电路，改网络名**。逐步：

1. **复制驱动电路**：把 `CBB1` 整块复制两份 → `CBB3`(后左)、`CBB4`(后右)；`CBB2` 不用再复制（CBB4 照 CBB1 复制即可，输入网名单独接）。
2. **CBB3（后左 M3）改网名**：
   - `AM+12V` → **`+ADJV`**（与 M1/M2 同母线）
   - `VERF+3.3V` → `3V3`
   - `IN1` → **`A08`**、`IN2` → **`A09`**（**与 CBB1 同网 = 扇出**）
   - `ADC` → **`A25`**（ADC0 A0_2）
   - `OUT1/OUT2` → **`CM1`/`CM2`**（新网名）
   - `GND` → 星型地
   - IN1/IN2 各 **10kΩ 下拉到 GND**（照 CBB1，上电默认不动）
3. **CBB4（后右 M4）改网名**：
   - `IN1` → **`B12`**、`IN2` → **`B13`**（**与 CBB2 同网 = 扇出**）
   - `ADC` → **`A24`**（ADC0 A0_3，弃电磁后空出）
   - `OUT1/OUT2` → **`DM1`/`DM2`**、其余同 CBB3
4. **删/不焊电磁驱动**：电磁那颗 DRV8231 标"不贴片(DNP)"或删除（保留焊盘可选）。
5. **加编码器电平转换芯片 `U_LS`（见 §5）**：把编码器连接器的 A/B（5V）先进 `U_LS`，输出（3.3V）再连 `PA7/PB19/PB20/PB21`。
6. **后轮连接器**：M3/M4 用 2 pin（仅 `CM1/CM2`、`DM1/DM2`）或沿用 6 pin（编码器脚留空），电机线接 OUT。
7. **（可选）0Ω 跳线保险**：CBB3/CBB4 的 IN 脚各串 0Ω，另引 `PA17/PA18`、`PA21/PB27` 的备用焊盘（默认贴到 A08/A09、B12/B13 那侧）。
8. **电源功率链加粗**（见 §6）。
9. 全部过 **SysConfig** 核对导出 pinmux。

## 4. 逐脚接线逻辑表（定版·方案 A）

### 4.1 四颗驱动

| DRV8231 脚 | CBB1(M1前左) | CBB2(M2前右) | **CBB3(M3后左)** | **CBB4(M4后右)** |
|---|---|---|---|---|
| VM | +ADJV | +ADJV | **+ADJV** | **+ADJV** |
| VREF(3.3V) | 3V3 | 3V3 | 3V3 | 3V3 |
| IN1 | `PA8` | `PB12` | **`PA8`(并M1)** | **`PB12`(并M2)** |
| IN2 | `PA9` | `PB13` | **`PA9`(并M1)** | **`PB13`(并M2)** |
| ADC(IPROPI) | `PA27` A0_0 | `PA26` A0_1 | **`PA25` A0_2** | **`PA24` A0_3** |
| OUT1/OUT2 | AM1/AM2→FL电机 | BM1/BM2→FR电机 | CM1/CM2→RL电机 | DM1/DM2→RR电机 |
| GND | 星型地 | 星型地 | 星型地 | 星型地 |
| IN 下拉 | 10k→GND | 10k→GND | 10k→GND | 10k→GND |
| VM 去耦 | 100µF+0.1µF | 同 | 同 | 同 |

### 4.2 扇出的电气校核（为什么 1 个 MCU 脚能驱 2 颗 DRV）

DRV8231 的 IN1/IN2 是**高阻 CMOS 输入**（内部弱下拉，输入电流 µA 级）。`PA8` 同时驱 CBB1.IN1 + CBB3.IN1 = 扇出 2，MCU 推挽输出（mA 级）绰绰有余；20kHz PWM 下双输入的容性负载可忽略。**电气上零风险**。

### 4.3 极性 / 方向接线逻辑（最易错，按此做）

- **同侧两轮同动**：左组 M1、M3 共用 `PA8/PA9`，所以 CBB1、CBB3 输出同步。**把 FL、RL 两电机的 OUT1/OUT2 按相同方式接**（同侧同向）；右组 M2、M4 同理。
- **左右差异已在固件里**（现 2 电机车 `M1 正 + M2 正 = 直行`已调好）→ M3 照 M1 接、M4 照 M2 接，直行/转向逻辑自动成立。
- **哪个轮转反了**：只对调**那一个轮**的 OUT1/OUT2（或软件符号），不动别的。

## 5. 编码器电平转换（板级修中断风暴）

- **芯片**：`74LVC14A`（六路施密特反相器，SOIC-14，**VCC=3.3V，输入 5V 耐受**）。一颗覆盖 2 个编码器的 A/B 共 4 路，余 2 路备用。
  - 施密特迟滞**顺带清掉脏边沿**（一举根治风暴）；反相无害（四倍频/1x 解码只关心边沿，方向反了软件 `cnt=-cnt`）。
  - 不想反相就用 `74LVC17`（六路施密特同相缓冲）。
- **接法**：编码器连接器 `+5V` 供编码器；A/B（5V 摆幅）→ `U_LS` 输入；`U_LS` 输出（0~3.3V）→ MCU `PA7/PB19/PB20/PB21`。`U_LS` 的 VCC=3V3、GND 共地。
- **软件配套**：SysConfig 里这 4 个输入脚**开内部迟滞(HYSTERESIS) + 上拉**，双保险。
- ⚠️ **编码器供电别改喂 3.3V**（MG310 霍尔常需 ≥3.5V，喂低输出更弱）——供电留 5V，只降 A/B 信号。

| 编码器信号 | 连接器脚(5V) | 经 U_LS | 到 MCU |
|---|---|---|---|
| enc1 A(左) | 6pin.4 | ch1 | `PA7` |
| enc1 B(左) | 6pin.3 | ch2 | `PB19` |
| enc2 A(右) | 6pin.4 | ch3 | `PB20` |
| enc2 B(右) | 6pin.3 | ch4 | `PB21` |

## 6. 电源 / 功率预算（原地转弯是重载，务必留够）

- **+ADJV 现挂 4 个轮电机**。**原地自转 = 4 轮侧滑刮地，电流远大于直行**。按 `4×(运行~1A + 峰值 scrub 2~3A)` 估 → **+ADJV 轨/汇流/线径按 ~8~12A 峰值**（原 §2.2 的 6A 需上调）。
- 电源板 Buck-Boost 输出能力、输入连接器（XT30/XT60）、防反接 FET、保险丝按该峰值选。
- 每颗 DRV8231 VM 就近 `100µF + 0.1µF`；4 颗功率 GND 走**星型单点地**，与信号地分离；IPROPI 就近 Kelvin 回采样点。
- **7.4V 电机**：把 ADJV 调到 ~7.4V，或 PWM 封顶 ~60%（现 `PWM_CAP=60`）防超压过热。

---

## 7. 机械 / 整定（比电控更决定原地转弯成败）

- **轴距(前后) ≈ 轮距(左右)**，接近正方形底盘 → 侧滑最小、转得利索、有效半径最小；轴距越长越难原地转、越费电流。
- **轮胎中等抓地**：太黏刮不动/电流爆，太滑定位差。
- **重心居中**：左右转对称不跑偏。
- **扭矩**：原地转比直行费劲，PWM 别封太低（够转 + 盯电流两头平衡）。

## 8. 固件方案（方案 A → 驱动零改，只加"车级差速层 + 陀螺转角"）

### 8.1 底层不变
`motor.c` / `car.syscfg` 的 TIMA0 四通道原样——**`motor_set(MOTOR_M1, duty)` 现在物理上驱"左组"（CBB1+CBB3 扇出），`motor_set(MOTOR_M2, duty)` 驱"右组"（CBB2+CBB4）**。一行不用改。

### 8.2 新增：车级差速运动学层（`car.c` 加）
```c
/* 差速: 线速度 v(前进+) + 角速度 w(左转/逆时针+) -> 左右组占空 */
/* 说明: 方案A下 MOTOR_M1=左组, MOTOR_M2=右组 */
static int clampi(int x, int lo, int hi){ return x<lo?lo:(x>hi?hi:x); }

void car_drive(int v, int w)              /* v,w: -100..100 量纲 */
{
    int left  = clampi(v - w, -PWM_CAP, PWM_CAP);   /* 左组 */
    int right = clampi(v + w, -PWM_CAP, PWM_CAP);   /* 右组 */
    motor_set(MOTOR_M1, (int16_t)left);
    motor_set(MOTOR_M2, (int16_t)right);
}
/* 原地转弯: v=0 -> 左右反向等速自转 */
/*   car_drive(0, +40) 原地左转 ;  car_drive(0, -40) 原地右转 */
```

### 8.3 新增：陀螺仪闭环"转 N 度"（原地转弯精度靠它，不靠编码器）
```c
/* 前置: ICM42688 驱动(SPI1)——★现固件还没接IMU, 需先移植; 待验证。
 * 思路: 读陀螺 Z(°/s) 积分得 yaw; PD 闭环转到目标角。
 *   err = target_deg - yaw;  w = clampi(Kp*err - Kd*gyro_z, -W_MAX, W_MAX);
 *   car_drive(0, w);  直到 |err|<容差 且 |gyro_z|<静止阈 -> 停。
 * 为什么不用编码器: 原地转轮子打滑, 编码器积分的角度会偏大/漂; 陀螺直接测车体转角。*/
```

### 8.4（可选）四轮电流采样
想要 4 轮都读电流：`car.syscfg` 的 ADC0 序列从 2 通道（MEM0/1=PA27/PA26）扩到 4 通道（MEM2/3=PA25/PA24），`motor.c` 的 `motor_read_current_raw` 扩成读 4 个。差速不依赖电流，此项**可选**（用于堵转/卡死检测，原地转重载时有用）。

### 8.5 提醒
现 `car.c` 有 `ENC_PROBE=1`（编码器排查探针），**改板/上四驱固件前先改回 `0`** 恢复控制固件。

## 9. 上电验证 / bring-up（打板回来照此逐步，别一步到位）

1. **不接电机**：万用表量 CBB3/CBB4 的 IN1/IN2 对地 = **0V**（下拉生效，上电不乱动）。
2. **编码器电平**：给编码器 5V，示波器/万用表量 `U_LS` 输出摆幅 = **0~3.3V**（不是 5V）；手转轮子看 MCU 脚有干净方波。
3. **单轮点动**（先低占空 20%）：`car_drive` 只驱一侧，确认 **左组两轮同向、右组两轮同向**；转反的轮对调 OUT。
4. **直行**：`car_drive(30, 0)` → 四轮同向前进、走直线（跑偏则查某轮方向/机械）。
5. **原地转**：`car_drive(0, 30)` → 绕中心自转；**同时看电流**别超 DRV8231 额定（重载）。
6. **编码器计数**：直行时看 enc1/enc2 计数干净递增（对比 §5 修复前的风暴），标定 `ENC_CPR`。
7. **陀螺转角**（移植 IMU 后）：闭环转 90°/180°，用量角器/地砖校准精度。
