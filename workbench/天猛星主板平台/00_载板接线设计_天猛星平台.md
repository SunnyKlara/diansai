# 天猛星(MSPM0G3507) 通用载板接线设计 —— 打板前基线

> 本文是"打板/接线"的唯一事实源，回答一个问题：**天猛星 + K230 + ICM42688 + ESP-01S + DRV8231×N + 多路电源板，每根线怎么连、每个脚怎么分。**
> 格式:每根杜邦线一行(信号/源引脚/目标引脚/备注)。**引脚一律按天猛星丝印标签找**（板子把每个脚的功能都印出来了），不依赖物理引脚号。
> ⚠️ MSPM0 引脚复用有冲突陷阱（见 2024H 教训）：下表实例是**基线草稿**，正式定版前务必用 **TI SysConfig** 逐外设核一遍可用引脚清单再锁死。
>
> 📌 **引脚定版唯一真值源 = 本文 §10.1 定版主表（V1.1 实物板）**。任何选脚必须同时过"**引出 ∩ 空闲 ∩ 功能**"三重闸：① 芯片手册 IOMUX 有该功能；② **这块核心板把脚引到了排针**（§10.2 排布图）；③ §10.1 里未被占用。缺任一条都不能选。
> 🚫 **本核心板未引出（选脚黑名单）**：`PA3/PA4/PA5/PA6`（= LFXT/HFXT 晶振脚，被板载晶振占用）、`PA19/PA20`（= SWD 烧录）。别再选到它们（PA6=HFXOUT 的教训）。
> 🔒 **改脚只改 §10.1 一处**，原理图 / SysConfig / config.h / 各分节接线全部跟随它；任何地方与 §10.1 不一致，一律以 §10.1 为准并回改。

## 1. 系统总框图

```
                 3S LiPo 9~12.6V ──[XT30]──▶ 电源板
                                              │ 防反接+开关 → Buck-Boost
                        ┌──────────┬──────────┼──────────┬──────────┐
                     12V(2~4A)  5V(≈2A)    3V3(净)     ADJ      GND(星点)
                        │          │          │          │
        ┌───────────────┤          ├──────────┤          └─(模拟实验预留)
        ▼               ▼          ▼          ▼
  DRV8231 VM×4      K230(5V)    ESP-01S×2   天猛星5V脚
   (电机功率域)      天猛星5V    ICM42688    (板载LDO→MCU 3V3)
        │            背光         DRV VREF
        ▼
   OUT1/OUT2 → 电机/风机/电磁铁

============================ 信号链路 ============================

K230(摄像头→AI) ──UART1(坐标/指令)──▶ 天猛星 MSPM0G3507 ──┬─ TIMA0/TIMG PWM ─▶ DRV8231 IN1/IN2 ─▶ 执行器
   └─ 显示屏(≥6吋)挂K230侧              (控制环 1kHz)         ├─ ADC0 ◀── DRV8231 IPROPI(电流采样)
                                                             ├─ SPI1 ◀─▶ ICM42688(姿态)
ESP-01S ×2 ──UART2/UART3(遥测/指令)──▶                        ├─ ADC1 ◀── 电池分压
                                                             └─ I2C0 ─▶ 小OLED(可选,MCU状态屏)
```

**分工铁律**：K230 只"看"、只出结果；**实时控制环 100% 在天猛星上**，绝不放 K230（它带 OS、抖动大、冷启动数秒）。

## 2. 电源分配 + 整机电流预算

### 2.1 电源域划分

| 电源域   | 电压 | 来源                 | 负载                                        | 备注                                |
| -------- | ---- | -------------------- | ------------------------------------------- | ----------------------------------- |
| 12V      | 12V  | 电源板 Buck-Boost    | DRV8231 ×4 的 VM                           | 功率域，电机堵转峰值大              |
| 5V       | 5V   | 电源板 MP2315        | **K230(大户)** + 天猛星5V脚 + 屏背光  | K230 是主要负载                     |
| 3.3V     | 3.3V | 电源板(独立)         | **ESP-01S ×2** + ICM42688 + DRV VREF | 见 §2.3 硬伤                       |
| ADJ      | 可调 | 电源板 MP2315        | 运放/模拟实验预留头                         | 平时空                              |
| MCU 3.3V | 3.3V | 天猛星板载 LDO(吃5V) | MCU 内核 + GPIO                             | 与电源板 3.3V**分开**，只共地 |

### 2.2 整机电流预算（⚠️ 估算值，打板后实测校准）

| 轨                     | 逐项                                          | 合计(典型)              | 峰值                    | 结论                                             |
| ---------------------- | --------------------------------------------- | ----------------------- | ----------------------- | ------------------------------------------------ |
| 12V                    | 4×电机 0.3~0.8A / 或风机~1A / 或电磁铁~1.5A | 2~3A                    | 堵转可 5A+              | 从 Buck-Boost 出，需大电容                       |
| 5V                     | K230 ~1.2A + 天猛星 0.1A + 背光 0.3A          | **≈1.8A**        | K230 推理+摄像头可冲 2A | ←**5V 别只按 2A 卡，留裕量**              |
| 3.3V                   | 2×ESP 各 70mA + ICM 几mA + 上拉              | ~0.2A                   | 2×ESP 发射瞬间 ~0.6A   | 见 §2.3                                         |
| **总(折到电池)** | (12×2.5 + 5×1.8 + 3.3×0.2)/η ≈ 55W       | **≈5~6A @11.1V** |                         | ←**输入连接器/保险丝/防反接FET 按 6A 选** |

> **反推结论**：5V、ADJ、3.3V 都从 12V 取电 → **Buck-Boost 是总汇流点**，它要扛 12V负载 + 下游各转换器的输入电流之和。按上表电池侧 ~5~6A，**DC 座 KH-DC-005(~2.5A) 明显不够，电池输入换 XT30/XT60**。

### 2.3 🔴 必须先解决的 3.3V 硬伤（承接上轮评审）

- 你电源板 3.3V 用 **AMS1117**（LDO，≤1A）。若"每路 2A"照搬到 3.3V → **不成立**（5→3.3V @2A 耗散 3.4W，烧）。
- 本载板的 3.3V 负载其实不大（2×ESP + ICM ≈ 0.2A 典型、0.6A 峰），AMS1117 **勉强够但发射尖峰时会发烫**。
- **两条路选一**（打板前定）：
  1. **推荐**：电源板 3.3V 换同步 Buck（MP2315/MP2359），真做到 2A，一劳永逸；
  2. 保 AMS1117：则**如实标 3.3V≤0.8A**，且 ESP VCC 就近加 **10~22µF + 100nF** 缓冲发射尖峰，AMS1117 铺大铜散热。
- **天猛星不要从电源板 3.3V 供**：给它 **5V**，让它板载 LDO 自己出 MCU 的 3.3V（隔离数字噪声）。

### 2.4 接地策略（照抄 2024H，有效）

- **星型单点共地**：所有 GND 在电源板一点汇合，禁止环形地。
- **功率地与信号地分离再单点合**：DRV8231 的电机回流(OUT/GND大电流)别串进 ICM/ADC 的地。
- **IPROPI 电流采样地就近 Kelvin 回采样点**，别借电机功率地。
- **K230↔MCU、ESP↔MCU 的 UART 必须共地**（这是新手最常忘、导致串口全乱码的坑）。

## 4. 电机驱动 DRV8231 —— 每槽接线（对齐你模块的 H1/H2）

你的模块引出(原理图已核实脚序)：**H1 = [1:+12V · 2:IN1 · 3:+3.3V · 4:IN2]**，**H2 = [1:GND · 2:ADC(IPROPI) · 3:OUT1 · 4:OUT2]**。载板每个电机槽这样连：

| 模块脚       | 连到                              | 说明                                                                            |
| ------------ | --------------------------------- | ------------------------------------------------------------------------------- |
| H1.+12V      | 12V 轨                            | VM 功率，就近并 100µF+0.1µF                                                   |
| H1.+3.3V     | **3.3V(与MCU ADC同一参考)** | 这是 DRV 的 VREF，只吃µA；**和 MCU 的 ADC 参考同源**才能比例式电流采样准 |
| H1.IN1       | MCU PWM(见 §3)                   | 逻辑输入，3.3V 直连                                                             |
| H1.IN2       | MCU PWM 或 GND                    | 双向→PWM；单向风机/电磁铁→**接 GND**                                    |
| H2.GND       | 星型地                            | 功率地，粗线                                                                    |
| H2.ADC       | MCU ADC0 通道                     | IPROPI 电流采样，模块上已 RC 滤波                                               |
| H2.OUT1/OUT2 | 电机/风机/电磁铁两端              | 方向不对改软件符号，别拔线                                                      |

**上电默认关断（安全命门）**：IN1/IN2 由 MCU 驱动，**上电/复位瞬间 MCU 引脚是高阻**，模块上的 **R7/R1=10k 已确认是下拉到 GND（原理图核实 ✓）**，否则电机上电自转 → 车冲出去/电磁铁猛吸。打板前万用表量 IN1/IN2 对地默认 = 0V。

**电流采样定标**：A_IPROPI≈1575µA/A。原理图已核实：**R17=680Ω 对地采样 → 满量程约 3A 对应 3.3V**，定标合理 ✓；R2=100Ω + C2=100nF 为 ADC 抗混叠滤波。建议 ADC 节点再加一只到 3.3V 的钳位防堵转过压。

### 5.3 ESP-01S ×2（按丝印连，别按物理位置）

ESP-01S 8 脚：`VCC / GND / TXD / RXD / EN(CH_PD) / RST / IO0 / IO2`。

> **为什么 §3/§10.1 的 MCU 引脚表里每个 ESP 只出现 2 个脚？** 8 脚按去向分 3 类：
> - **① 数据 2 脚**（TXD / RXD）→ 接 MCU 的 UART，**这才占用 MCU 引脚**（每个 ESP 就这 2 根）；
> - **② 电源 2 脚**（VCC / GND）→ 接 3.3V 电源轨和地，**不占 MCU 引脚**；
> - **③ 启动配置 4 脚**（EN/CH_PD、RST、IO0、IO2）→ 接 10kΩ 上拉到 3.3V 的**固定电平**，**不占 MCU 引脚**（RST/IO0 可选再引到 GPIO 做硬复位/刷机，非必须）。
>
> 所以"每个 ESP 只连 2 根线到 MCU"是对的，但**下面这 8 脚一个都不能省**——尤其 EN/IO0/IO2 只要悬空，ESP 直接不启动（§9 头号坑）。

| ESP 脚              | 连到                        | 备注                                               |
| ------------------- | --------------------------- | -------------------------------------------------- |
| VCC                 | **3.3V(带缓冲电容)**  | 发射瞬间拉~300mA，就近 10~22µF+100nF             |
| GND                 | 星型地                      | 与 MCU 共地                                        |
| TXD                 | MCU UARTx-RX                | 交叉                                               |
| RXD                 | MCU UARTx-TX                | 交叉                                               |
| **EN(CH_PD)** | **10kΩ 上拉到 3.3V** | ⚠️ 悬空 = ESP 根本不启动（头号坑）               |
| RST                 | 10kΩ 上拉到 3.3V           | 可选引到 MCU GPIO 做硬复位                         |
| IO0                 | 10kΩ 上拉到 3.3V           | 正常运行=高；**留一个跳线到 GND 用于刷固件** |
| IO2                 | 10kΩ 上拉到 3.3V           | 上电不能为低                                       |

> 上电启动条件：EN=H, IO0=H, IO2=H, RST=H。打板时把这 4 个上拉画进去，别指望模块自带。

### 5.4 ⚠️ UART 数量约束（现在用满了）

天猛星共 **4 个 UART**：调试×1 + K230×1 + ESP×2 = 4，**刚好用满**。若某题要**同时**挂 >2 个 ESP：

- 方案A：调试口不占独立 UART（用板载调试器 USB / SWO），腾出 1 个给第 3 个 ESP；
- 方案B：ESP 之间用一颗 UART 复用/切换芯片；
- 方案C：部分 ESP 改 GPIO 软件模拟 UART（低速遥测够用）。

> 你说有 4 个 ESP——**确认是"备件"还是"要同时在线 4 个"**。同时 4 个就得上上面的方案，我可以帮你出复用电路。

### 5.5 4位串行数码管（TM1637，配 1 片）

> 材料清单里的"4位串行数码管"按最常见的 **TM1637 模块**（Titan Micro 驱动 IC + 4位 0.36″ 共阳 7 段）设计。**若实物是 74HC595 级联或 MAX7219 则接线不同**（595=3线带锁存、MAX7219=SPI），拿到实物先看丝印确认。⚠️ 以下为纸面基线，`// 待真机验证`。

TM1637 模块 4 脚：`VCC / GND / CLK / DIO`。CLK+DIO 是**类 I2C 但非标准 I2C 的两线时序**（无从机地址、时序自定义），用**普通 GPIO 软件位操作(bit-bang)** 驱动，**不占用硬件 I2C0**（I2C0 留给 OLED）。

| 数码管脚 | 连到               | 备注                                                          |
| -------- | ------------------ | ------------------------------------------------------------- |
| VCC      | **3V3**      | 模块支持 3.3~5.5V；**用 3.3V** 则 DIO 电平与 MCU 一致，最省心 |
| GND      | 星型地             | 与 MCU 共地                                                   |
| CLK      | `B24`(GPIO 输出) | 时钟，MCU 单向输出                                            |
| DIO      | `B25`(GPIO 双向) | 数据，写段码时输出；读 ACK/按键时切输入                       |

- **为什么别用 5V 供电**：TM1637 用 5V 时 DIO 高电平≈5V，超过 MCU 3.3V 输入容限，可能伤引脚。除非该 GPIO 是 5V 容限脚，否则统一 **3.3V 供电**（3.3V 下略暗但够看）。
- **DIO 上拉**：模块多带板载上拉；显示不稳可在 DIO 对 3.3V 补 4.7~10kΩ。
- 走线：CLK/DIO 远离电机 OUT 线、长度 ≤20cm，避免噪声导致段码错乱。
- 驱动：软件 bit-bang 四原语（起始/停止/写字节/读ACK），赛时可快速撸出；毕业后进 `library/通用能力/常用模块驱动/`。

### 5.6 蜂鸣器（高电平触发有源，配 1 只）

> 材料清单标注"**高电平触发**"= 控制脚给**高电平**时发声。按**有源蜂鸣器模块**（自带振荡器，通电即响固定频率；模块多板载三极管驱动）设计。⚠️ 纸面基线，`// 待真机验证`。

| 蜂鸣器脚     | 连到              | 备注                                              |
| ------------ | ----------------- | ------------------------------------------------- |
| VCC(+)       | 3V3 或 5V         | 按模块标称；有源模块 3.3V 多能响，5V 更响         |
| GND(−)      | 星型地            |                                                   |
| I/O(S,触发)  | `A22`(GPIO 输出)| **输出高=响、低=停**；模块内三极管，触发脚只吃 µA |

- **驱动能力判断（关键，决定要不要加三极管）**：
  - **有源蜂鸣器模块（3 脚，板载三极管）**：触发脚是高阻输入，GPIO 直接接，任意空闲 GPIO 都够。
  - **裸有源蜂鸣器（2 脚，就是蜂鸣元件本身）**：工作电流 20~30mA，**接近/超过 MSPM0 普通 GPIO 的标准 ~6mA 驱动上限** → 别直连！加一颗 **NPN 三极管(如 S8050)**：GPIO→1kΩ→基极，蜂鸣器串集电极与电源之间，发射极接地，GPIO 只出基极电流。
- **续流**：压电式有源蜂鸣器偏容性，一般不需续流；若为电磁式/换成继电器，集电极并 1N4148 续流。
- **软件**：GPIO 推挽输出，`高=响`。要"滴—滴"提示就定时翻转 GPIO（有源不用 PWM 调频，靠通断时长控节奏）。

### 5.7 电磁铁执行器（DRV8231 单向 + 闭环预案，按"最难=磁悬浮 PID"设计）

> 按最坏情况（磁悬浮/力控闭环）设计这一路，"开关吸放"是它的子集自然覆盖。**执行器 = 一个独立 DRV8231 槽**（V1.1 定版，见 §10.1）：IN1=`PB0`(TIMA1_C0，PWM)、IN2 接 GND(单向)、IPROPI=`A24`(ADC0，原电机4电流脚复用)。**用独立的 TIMA1，不占电机的 TIMA0**。只有"位置反馈"要额外占 1 路 ADC。⚠️ 电磁铁本身仓库**未真机验证**，以下是工程设计 + 校赛B 气流悬浮经验（同构）迁移，`// 待真机验证`。

**5.7.1 驱动接线（独立 DRV8231 槽，单向）**

| DRV8231 脚 | 连到 | 说明 |
|---|---|---|
| H1.+12V | 12V 轨（按电磁铁额定；5V 电磁铁则接 5V） | VM 功率，就近 100µF+0.1µF |
| H1.IN1 | `B0`(TIMA1_C0，PWM) | **PWM 调平均电流 = 调吸力**，频率 kHz 级；独立 TIMA1 不撞电机 TIMA0 |
| H1.IN2 | **接 GND** | 单向，不需反向 |
| H1.+3.3V | 3.3V（VREF，与 MCU ADC 同源） | 电流比例采样基准 |
| H2.OUT1/OUT2 | 电磁铁线圈两端 | 吸力∝I²，极性不影响吸/放 |
| H2.ADC(IPROPI) | `A24`(ADC0_A0_3) | 电流采样 → **电流内环**（原电机4电流脚复用） |
| H2.GND | 星型地（功率地粗线） | |

**5.7.2 🔴 续流二极管（电磁铁比电机/风机多的硬件，必加）**

电磁铁是大电感，PWM 关断/断电瞬间 `V=−L·di/dt` 会打出上百伏反向尖峰。**在线圈两端并一颗快恢复二极管（SS34，阴极朝 OUT 高端）**。DRV8231 内有体二极管，但单向大电感频繁通断，外补一颗更保险、也降低 DRV 发热。这是电磁铁与普通电机接线最大的区别。

**5.7.3 位置反馈（磁悬浮闭环必需）——选型是成败关键**

| 方案 | 接口 | 带宽 | 适用 |
|---|---|---|---|
| **红外光电对管(模拟输出)** ✅首选 | ADC（占 1 路空闲模拟脚） | 高，可 kHz 采样 | **真磁悬浮**（kHz 闭环）|
| 激光 TOF VL53L0X | I2C0（与 OLED 共总线，地址不同，不占新脚） | 仅 ~42Hz（校赛B 实测） | 慢速定高，**扛不住磁悬浮 kHz** |
| 霍尔 | ADC | 中 | ❌ **被电磁铁磁场干扰**，别用 |

> 磁悬浮要 kHz 闭环 → 位置反馈也要高带宽 → **用光电对管模拟量进 ADC**，别用 TOF/霍尔。从 §10.2 空闲模拟脚取 1 路（如 J1 的 `A17`/`A14` 一带），**具体 ADC 通道打板前 SysConfig 定**。传感器远离线圈、避开磁场。

**5.7.4 闭环架构（串级：位置外环 + 电流内环）**

```
位置设定 ─▶[位置外环 PD]─▶ i_ref ─▶[电流内环 PI]─▶ PWM ─▶ DRV8231 ─▶ 电磁铁 ─▶ 磁力 ─▶ 铁块位置
               ▲ 光电位置反馈(ADC, ≥1kHz)        ▲ IPROPI 电流反馈(ADC0, ≥5kHz)
```

- **电流内环**（PI，≥5~10kHz）：把 `F∝I²` 非线性 + 线圈电感延迟线性化，让外环面对近似线性对象。
- **位置外环**（PD 为主，≥1kHz）：出电流设定 `i_ref`。

**5.7.5 控制律 + 整定（直接复用校赛B `实战复盘/校赛B_智能球平衡控制装置/00_经验总结.md` §2 铁律）**

- **C2 前馈到工作点**：`i_ref = i_hover + Kp·e_pos − Kd·v_pos`，前馈 i_hover 扛住悬停点，PID 只修残差（不稳定平衡对象恒定输出守不住任何点）。
- **C1 整定顺序**：先 D(阻尼) → 再 P(刚度) → 最后弱 I，一次只拧一个。
- **C3 Kd 有甜区**：越加越差 = 方向反了，立刻砍。
- **磁悬浮特有**（比气流悬浮更狠）：吸力 `F∝I²/d²`，d 越小力越大 = **开环正反馈不稳定**；**纯 PI 必发散、必须有 D**（超前补偿机械惯量延迟）；**Ki 取 0 或极小**；闭环频率要 **kHz 级**。

**5.7.6 安全 + 坑**

- **上电默认关断**：IN1/IN2 已 10K 下拉（§4），上电不猛吸（磁悬浮尤其怕一上电吸死）。
- **限流 + 超时保护**：失控吸死/掉落时软件限最大占空比 + 超时切断。
- **发热**：吸合后降"保持电流"（维持吸力所需电流 << 吸合电流），省电又降温；DRV 散热焊盘打满过孔。
- **电源**：吸合冲击电流大，走 12V 功率域，与逻辑只共地。

### 5.8 编码电机转速反馈（编码器 A/B 相 → TIMG8 QEI + GPIO 中断）

> **"转速反馈线" = 编码器的 A/B 两相正交输出，不是电机电源线**（最容易接错）。带编码器减速电机（如 JGA25-370）通常 **6 根线**，功率与信号必须分开走：

| 电机线 | 接到 | 类型 | 说明 |
|---|---|---|---|
| 电机电源 M+ | DRV8231 `OUT1` | 功率 | 转速/方向由 PWM 控制，**不是**反馈 |
| 电机电源 M− | DRV8231 `OUT2` | 功率 | 同上 |
| 编码器 VCC | **3.3V** | 供电 | 霍尔编码器多 3.3~5V；**必须用 3.3V**（⚠️ V1.1 实物板接了 +5V → A/B 相 5V 灌 MCU，须改 3.3V 或 A/B 分压） |
| 编码器 GND | GND | 地 | 与 MCU 共地 |
| **编码器 A 相** | MCU TIMG QEI 输入 | **反馈** | ← 你问的"转速反馈线" |
| **编码器 B 相** | MCU TIMG QEI 输入 | **反馈** | A/B 错相 90°：数脉冲测速、看谁超前判方向 |

> ⚠️ 线色各厂不同，**务必按电机数据手册接**——接错编码器 VCC/A/B 可能烧编码器。

**接哪个脚（V1.1 定版，见 §10.1）**：⚠️ **重要纠正**——芯片手册确认**硬件 QEI 全芯片只有 TIMG8 一个**（不是之前误记的 TIMG6/TIMG7），且原电机 3/4 的脚 `B10/B11/B26` 已被板载 H8 显示屏占死。所以编码器**不能**用那几个脚，定版改为：

| 信号 | 定版脚 | 方式 | 依据 |
|---|---|---|---|
| 编码器1 A 相 | `PA7` | **TIMG8_C0**(硬件 QEI PhA) | 手册 PA7=TIMG8_C0；引出✓ 空闲✓ |
| 编码器1 B 相 | `PB19` | **TIMG8_C1**(硬件 QEI PhB) | 手册 PB19=TIMG8_C1；引出✓ 空闲✓ |
| 编码器2 A 相 | `PB20` | **GPIO 中断**计数 | TIMG8 只一个,第 2 个走中断 |
| 编码器2 B 相 | `PB21` | GPIO 输入(判方向) | 引出✓ 空闲✓ |

- **编码器1** 走 TIMG8 硬件 QEI（不占 CPU、不丢脉冲）；**编码器2** 走 PORTB GPIO 中断（A 相 `PB20` 上升沿计数、读 B 相 `PB21` 判向），小车转速下够用。想对称也可两个都用中断。
- **为什么不用 B10/B11/B26/B27**：① 硬件 QEI 只 TIMG8，TIMG0/TIMG6 做不了正交解码；② `B10/B11/B26` 被板载 H8 屏占死（见 §10.3b）。
- **方向反了**：SysConfig 里把 QEI 的 Phase A/B 对调，或软件 `cnt = -cnt`（MSPM0 骨架踩坑 §八-3）。

**降级（TIMG8 QEI 配不通时）**：编码器1 也改 GPIO 中断，4 个相全走中断，脚从 §10.12 空闲脚里挑。低速够用，CPU 负载略升。

**参数**：`ENCODER_PPR = 线数 × 4倍频 × 减速比`（骨架示例 11×4×30 = 1320 脉冲/圈）；`速度 = Δ脉冲 × MM_PER_PULSE / Δt`。

## 9. 常见错误（照抄+新增）

### 10.3b 显示屏 —— 板载"常用 SPI-LCD 接口"(H8)，已实测点亮 GC9A01 ✅

### 10.9 ⚠️ 定时器资源竞争提醒（按题裁剪）

4 个电机全上 PWM 时，用掉了 TIMA0(电机1/2) + TIMG0(电机3) + TIMG6(电机4)。**若某题要编码器 QEI**（如 2024H/2021F 小车测速）：⚠️ **硬件 QEI 全芯片只有 TIMG8 一个**（芯片手册确认，TIMG0/TIMG6/TIMG7 都做不了正交解码）——所以最多一个编码器走硬件 QEI，其余走 GPIO 中断。实战按题裁：

- **循迹小车**（常见）：2 电机 + 2 编码器 → 电机用 TIMA0（4 通道）；编码器1 走 TIMG8 硬件 QEI(A相=`A7`/B相=`B19`)、编码器2 走 GPIO 中断(A相=`B20`/B相=`B21`)，见 §5.8。
- **磁悬浮 / 单风机**：1 电机 → 只用 TIMA0_C0/C1，其余定时器全空。
- **球盘 / 双轴**：2 执行器 → TIMA0 4 通道足够。

> 也就是说：本主表是"4 电机满配"基线；真到某题，把用不上的电机槽退掉、把 TIMG 让给编码器即可，主表其余部分（UART/SPI/I2C/ADC）不动。
> **编码器 A/B 相接哪个脚见 §5.8（已定版）**：编码器1 走 TIMG8 QEI（A相=`A7`、B相=`B19`）、编码器2 走 GPIO 中断（A相=`B20`、B相=`B21`）。原电机3/4 脚 B10/B11/B26 已被板载 H8 屏占用，不能给编码器。

### 10.10 SysConfig 定版清单（打板前最后闸门）

摆完导出 pinmux，若与 §10.1 有出入以 SysConfig 为准，并同步 `config.h`：

- **PWM**：TIMA0（4 通道 → 双电机 PA8/9/PB12/13）、**TIMA1（1 通道 → 电磁铁 PB0）**
- **QEI**：**TIMG8（编码器1，A相 PA7 / B相 PB19）**；编码器2 走 PORTB GPIO 中断(PB20/PB21)，不占定时器
- **ADC0**：A0_0/A0_1（电机1/2 电流 PA27/PA26）、**A0_3（电磁铁电流 PA24）**；**ADC1**：A1_1（电池 PA16）；+ 电磁铁位置反馈预留 1 路
- **SPI1**（IMU + 板载屏共享：SCK=PB9/MOSI=PB8/POCI=PB7/CS0=PB6，屏 CS=PB14）、**I2C0**（可选 OLED）
- **UART0/1/2**（串口接口/K230/调试）/ **UART3**（ESP-01S PB2/PB3）
- **GPIO**：显示屏 RES/DC/CS/BLK(PB10/11/14/26)、状态灯(PB22)、超声波(PB17/18)、数码管(PB24/25)、蜂鸣器(PA22)、编码器2(PB20/21)
- **SWD**（PA19/PA20）；⚠️ 晶振脚 PA3/4/5/6 本板未引出

### 10.12 空闲引脚清单（V1.1 定版后，接新外设先查这里）

> 口径：80 排针位 − 电源/地 21 − CHIP/AGND 2 − SWD 2 − RST 1 = **54 可用信号脚**。V1.1 实配（双电机+双编码器+电磁铁+板载屏+超声波+数码管+蜂鸣器+ESP+IMU）占用后，**完全空闲 GPIO ≈ 10 个**。

**A. 完全空闲、可直接用（约 10 个）**

| 排针 | 空闲脚 |
|------|--------|
| J1 上排 | `A14`(6R) `A17`(7L) `A21`(9L) `A23`(10L) `A2`(10R) `B1`(15L) `A18`(18L) |
| J2 下排 | `A28`(2L) `A31`(3L) `B23`(16R) |

> `A28`/`A31` 名义预留第 2 片 IMU、不扩就自由；`A14`/`A17` 是 ADC 脚，电磁铁位置反馈(§5.7)会占其中 1 个。

**B. 🚫 选脚黑名单（本核心板未引出，别选）**

| 脚 | 原因 |
|----|------|
| `PA3` `PA4` | 低频晶振 LFXT（LFXIN / LFXOUT） |
| `PA5` `PA6` | 高频晶振 HFXT（HFXIN / HFXOUT）——"找不到 PA6"就是这原因 |
| `PA19` `PA20` | SWD 烧录（SWDIO / SWCLK） |

**C. 已占但按题可释放**

| 项 | 脚 | 释放条件 |
|----|-----|---------|
| CAN 预留 | `A12`/`A13` | 不做 CAN 多机 |
| DAC 预留 | `A15` | 不做模拟输出（也是电磁铁位置反馈候选脚） |
| 第 2 片 IMU | `A28`/`A31` | 不扩第 2 片 |
| B27（原电机4脚） | `B27` | 现空闲，可留扩展 |

> **一句话**：V1.1 满配后净空约 **10 个 GPIO**，控制题够用。选脚务必过文首"**引出 ∩ 空闲 ∩ 功能**"三重闸，别再选到晶振脚（PA3/4/5/6）。
