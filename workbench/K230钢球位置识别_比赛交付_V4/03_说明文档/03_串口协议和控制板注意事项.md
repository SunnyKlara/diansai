# 串口协议和控制板注意事项

## 接线

```text
K230 IO11（UART2 TX） → 控制板 UART RX
K230 GND              → 控制板 GND
```

目前只需要K230向控制板单向发送，因此可以不连接K230的IO12。

如果控制板串口TX是5V电平，不要直接连接K230 IO12。需要双向通信必须使用合适的电平转换。

## 串口参数

```text
UART2
115200 baud
8 data bits
No parity
1 stop bit
No flow control
```

## 数据格式

有效位置：

```text
$BP,1,+5.23*12\r\n
```

无效位置：

```text
$BP,0,0.00*3C\r\n
```

格式：

```text
$BP,<valid>,<position_cm>*<checksum>\r\n
```

- `valid=1`：位置有效。
- `valid=0`：位置无效，控制板必须忽略`position_cm`。
- `position_cm`：以管子中点为0，左负右正。
- `checksum`：从`B`开始到`*`之前所有ASCII字符逐字节异或，结果用两位十六进制表示。

## 控制板必须做的检查

1. 检查帧头`$`和帧尾`\r\n`。
2. 检查`BP`类型。
3. 校验XOR。
4. 检查`valid`。
5. 检查位置范围，正常球心范围约为`-12.0～+12.0cm`。
6. 记录最后一次有效数据时间。
7. 超过约150ms没有收到有效新数据时进入保护状态。

## PID控制建议

- 视觉位置约24Hz更新一次。
- 控制板PID建议50～100Hz固定周期运行。
- PID不能阻塞等待UART；每次循环使用最近一次有效位置。
- 新UART数据到来时更新位置和时间戳。
- `valid=0`时不要把位置改成0，否则会造成舵机突然动作。
- 连续短暂丢失时可保持上一输出；超时后输出安全角度或限制动作。
- 积分项必须限幅，并在视觉失效或模式切换时清零，防止积分饱和。
- 舵机命令必须限制角度、速度和变化率，首次调试从小幅度开始。

## 供电和抗干扰

- 舵机应使用独立且电流充足的稳压电源。
- 不要让舵机直接从K230的USB或3.3V引脚取电。
- K230、控制板、舵机电源需要共地，建议采用星形接地点。
- 舵机电源附近增加足够的电解电容和去耦电容。
- UART线尽量短，远离舵机电源线和PWM大电流回路。
- 不要用两个不同电源同时反向给K230供电。

## 控制方向确认

上电后必须先做低幅度方向测试：

- 钢球在右侧时，控制输出应让球向左回到中点。
- 钢球在左侧时，控制输出应让球向右回到中点。

如果方向相反，只能修改一次方向映射；不要在PID符号、舵机映射和机械安装三个位置同时反转。
