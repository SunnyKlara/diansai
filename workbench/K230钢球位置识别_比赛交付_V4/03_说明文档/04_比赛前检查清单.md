# 比赛前检查清单

## K230

- [ ] 模型文件路径正确。
- [ ] 校准文件能够显示`CALIBRATION_LOADED`。
- [ ] V4显示`PIPE_BALL_UART_STABLE_V4_READY`。
- [ ] `PREVIEW_ENABLE = False`。
- [ ] 稳定FPS约23～24。
- [ ] `uart_hz`与`fps`一致。
- [ ] `heap_kb`长时间稳定。
- [ ] `uart_ms_max`没有异常增大。
- [ ] `/sdcard/main.py`能够上电自动运行。

## 摄像头和机械

- [ ] 摄像头支架已锁紧。
- [ ] 管子与校准时位置一致。
- [ ] 钢球左右端、中点位置显示基本正确。
- [ ] 光照没有强烈反射或闪烁。
- [ ] 摄像头和Type-C线有应力释放，不拉扯接口。

## UART

- [ ] K230 IO11连接控制板RX。
- [ ] K230与控制板共地。
- [ ] 115200、8N1。
- [ ] 控制板校验XOR。
- [ ] `valid=0`不会被当成0cm。
- [ ] 超过150ms无有效数据会进入保护。

## 控制

- [ ] PID循环固定50～100Hz。
- [ ] 积分限幅。
- [ ] 舵机角度限幅。
- [ ] 舵机变化率限幅。
- [ ] 控制方向测试正确。
- [ ] 断开K230数据时不会失控。
- [ ] 舵机堵转或掉线时有安全策略。

## 供电

- [ ] 舵机独立供电。
- [ ] 所有系统可靠共地。
- [ ] 没有5V信号直接输入K230 IO。
- [ ] 舵机动作时K230不会复位或USB断线。
- [ ] 连续运行至少10分钟。
