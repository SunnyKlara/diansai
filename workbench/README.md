## 一个必须知道的切分理由

`mspm0/`（代码，全 ASCII）与 `天猛星主板平台/`（文档，中文名）**是同一个平台的两半，不能合并** ——
GCC 工具链处理中文路径会乱码报 `device.opt ... not found`（2026-07-24 实测），
所以固件必须待在 `workbench/mspm0/` 这种纯 ASCII 路径下。这条是铁律，写在 [`天猛星主板平台/编译烧录操作手册.md`](天猛星主板平台/编译烧录操作手册.md) 文首。

## 目录纪律（2026-07-28 定，照此维持）

1. **新题一个文件夹**，按规范 §1 建，别往现有 5 个目录里塞。
2. **资料一律不解压**：厂家素材以 `.zip` 原样存在 `资料/`（`.gitignore` 已按后缀整体忽略），需要时再解。平台/用途写进**文件名**而不是靠目录层级。
3. **`_` 前缀 = 元文件/可丢弃**（`_工作台工作规范.md` · `car/_tools*` · `car/_logs` · `car/_scratch*`）。
4. 采集产物只落 `car/_logs/`，有意义的数字当场 curated 进 `调试日志.md` —— `_logs/` 不在 git 里，换机即蒸发。

> 本轮（2026-07-28）目录整理实测：**目录数 43 → 22，最大深度 8 → 4 层**。
