## 【模拟题面 · 官方格式】

### 视觉引导磁吸搬运分拣小车（模拟-C 题）

#### 一、任务

设计并制作一辆**采用 TI MSPM0 系列 MCU 控制**的自主小车。在约 **200cm×200cm** 的白色场地内，小车用**车载摄像头**识别场上目标，自主行驶，用**车载电磁铁**吸取直径约 1cm 的**钢球**，并按颜色/编号将钢球搬运、投放到相应的目标料仓，完成自动分拣。

场地布置（示意）：
- 白色场地约 200cm×200cm，地面用深色引导线（宽约 2cm）连接各功能区（供光电循迹）。
- **取球区**：场地一端设一装载台，台面标记位上放置若干 **⌀约1cm 钢球**（4~6 颗），球位已知、颜色不同或旁贴颜色/编号标签。
- **目标料仓**：场地另侧设 **3 个料仓**（分别标 **红/绿/蓝** 或 **1/2/3**），每个仓口为约 **12cm×12cm** 的框格区。
- **起点 S**：场地一角。

```
   [取球区: ●红 ●绿 ●蓝 ... 钢球⌀1cm]
        │(深色引导线)
        │
   ┌────┴───── 200×200 白场 ─────┐
   │  S(起点)                     │
   │           [料仓1红][料仓2绿][料仓3蓝]
   └──────────────────────────────┘
```

#### 二、要求

**基本要求**

1. **自主行驶到位**：小车从起点 S 出发，自主行驶到取球区并停靠，停靠时**声光提示**；车体前沿对准装载台，误差 ≤±3cm。用时不大于 **30s**。（15 分）
2. **视觉识别**：用车载摄像头识别 3 个料仓的**颜色（或编号）及其位置**，并在**显示屏上显示**识别结果；识别正确率要求全对。（15 分）
3. **磁吸取球**：小车用**车载电磁铁**吸起 1 颗钢球并保持（行驶中不掉落），在显示屏/数码管上显示"已取球"。（20 分）

**发挥部分**

1. **单球分拣**：小车将吸起的钢球搬运到**指定颜色/编号**的料仓上方，**断电投放**，钢球落入 12cm×12cm 仓格内。（15 分）
2. **多球按序分拣**：按颜色对应关系（红球→红仓…）或评委临场指定顺序，**依次搬运 3 颗钢球**入对应料仓，全部正确，总用时不大于 **150s**。（15 分）
3. **图像/协同**：用**无线图像传输模块**将车载摄像头画面或识别结果实时回传显示（或用**短距无线**实现双车协作搬运）。（12 分）
4. **速度/数量**：在完成发挥要求 2 的前提下，**搬运正确的钢球数越多、总用时越少越好**。（8 分）

#### 三、说明

1. **必须采用 TI MSPM0 系列 MCU** 作为主控，不得用其他型号 MCU 承担控制；安装时需**暴露 MSPM0 芯片**便于查验。
2. 小车为**轮式**，外形尺寸不大于 **35cm×25cm**；**不得采用履带和麦克纳姆轮**。允许原地转向。
3. 允许使用**可带处理器的摄像头模块**做视觉识别；**不得使用车外遥控、外部定位或其他导航辅助**。
4. 取放机构**仅限电磁式**（电磁铁通断吸放），钢球为清单所列 ⌀约1cm 钢球。
5. 投放判据：钢球最终**静止落在目标仓 12cm×12cm 框格内**计为成功；错仓或落在框外不计。
6. 为适应测试场地，**允许测试前小车试跑标定**。
7. 小车**车载电池供电**，进入测试后中途不得更换电池。
8. 完成时间超过规定时间**一倍以上**时，该项目不得分。

## 【逐层解析】

### 这题在做的事：一台"会看、会走、会抓"的迷你物流机器人

一句话：**看见球（相机）→ 走过去（运动控制）→ 吸起来（电磁铁）→ 送到对应仓（导航+投放）**。这就是仓储 AGV / 分拣机器人的最小闭环。它把清单里的"枪"串成一条链：摄像头（识别）→ 小车（运动）→ 电磁铁（作用）→ 钢球（对象）→ 光电/角度（导航反馈）→ 显示/图传（人机）。

**难度定位**：基本盘（行驶+识别+取球 50 分）认真备赛能拿；拉开差距的是**吸取对准的精度**和**多球分拣的流程可靠性**——这需要把"相机看见的球在哪"翻译成"车/电磁铁怎么怼上去"，还要保证"吸得住、放得准、不放错仓"。

---

### 第一个谜：吸一颗 4 克的钢球，力从来不是问题——**对准**才是

先算力，破除"电磁铁吸力够不够"的焦虑：

> **小白补课：吸起钢球需要多大力？**
> ⌀10mm 钢球，钢密度 7.8 g/cm³，体积 = (4/3)π(0.5cm)³ ≈ 0.52 cm³，质量 ≈ **4.1 g**，重力 ≈ **0.04 N**。
> 小型电磁铁的吸力通常在 **0.5~5 N**（气隙贴紧时）。**吸起 4 克的球，力有 10~100 倍余量——力根本不是问题。**

**真正的难点是气隙（对准）**。电磁铁吸力随距离急剧衰减：

```
F ∝ (N·I)² · A / x²      （x = 电磁铁面到球的气隙）
```

气隙从 1mm 变到 5mm，吸力掉到 1/25。**所以车必须把电磁铁面怼到离球 1~2mm 内**——这才是考点：**视觉引导下的毫米级对准**。

> **工程决策**：电磁铁**固定装在车头前下方**，面朝下或朝前、离地高度刚好能贴到地面/台面上的球（**无舵机，靠固定几何 + 车体运动对准**）。车用摄像头把球怼到"电磁铁正下方/正前方"那个点，然后通电。**对准全靠车走位，不靠机械臂**——这正是绕开"清单无舵机"的关键设计。

---

### 第二个谜：相机怎么把"看见球"变成"车怼上去"

和上一版一样，这里有个"图像语言 → 运动语言"的翻译问题，但对象换成了**小而反光的钢球**。

> **小白补课：钢球比色块难识别**
> 钢球是镜面金属，**反光、无固定颜色、随光照变**——纯颜色阈值抓不稳。实战靠：① 圆形检测（霍夫圆/轮廓圆度）；② 球旁贴的颜色/编号标签（清单允许"可带处理器摄像头"，识别标签比识别裸球稳）；③ 找"亮斑+暗环"的高光特征。**题目里让球带颜色/编号标签，正是为了让识别可行。**

**翻译桥（承上一版的视觉伺服思路）**：
- 车对准球 = 让球在画面中"目标锚点"（比如画面下方中央，对应电磁铁位置）。球偏左→车微左转/平移，直到球落在锚点。**偏差法，不用标定相机。**
- 关键是**标定"画面锚点 ↔ 电磁铁实际位置"**：上板时放一颗球，手动挪车让电磁铁正好贴上，记下此刻球在画面的像素位置——那就是锚点。**这是发挥项上板第一件事。**

> **对你的直接含义**：摄像头（带处理器）大概率 UART 出"目标类别+中心像素坐标+半径"。MCU 端写稳的串口解析 + **丢帧保护**（视觉 10~30Hz，比控制环慢，做"最新值保持+超时判空"）。**这条 UART 链是场景 B/C/D 全都要的公共投资。**

---

### 第三个谜：没有夹爪反馈，"到底吸没吸住"怎么知道

舵机夹爪能测夹持力，电磁铁不能。**吸没吸住、放没放掉，是个盲区**——车吸空了却以为拿到球，跑到仓上放了个寂寞，白跑一趟扣分。

> **小白补课：三种"吸取确认"手段（不用夹爪）**
> 1. **电流**：电磁铁吸住铁磁体后磁路闭合、电感变大，**稳态电流/动态响应会变**——你天猛星的 DRV8231 IPROPI 电流采样正好能读（和吸空对比）。
> 2. **光电**：在电磁铁旁装一颗光电传感器（清单有#30），球吸上来会挡光/反光 → 有球=触发。**最直接可靠。**
> 3. **视觉复查**：吸取后摄像头看电磁铁位置还有没有球（球被吸走则原位空了）。
>
> **推荐光电确认为主 + 电流为辅**：投放前也用它确认"球真的掉了"（防剩磁粘住）。

> **投放的坑（剩磁）**：断电后铁芯**剩磁**可能把 4 克的球粘住不掉。解法：① 断电 + 轻微反向短脉冲消磁；② 靠球自重（4 克通常够）；③ 投放点轻抖一下。**这是发挥(1)的隐藏坑，赛前要试。**

---

### 第四个谜：怎么在场地里"认路"到各个区——相机、光电、角度传感器分工

小车要在取球区、3 个料仓、起点之间往返。**导航靠三种传感器分工**（清单里都有，无 GPS/无激光雷达）：

| 任务 | 靠谁 | 为什么 |
|---|---|---|
| 沿引导线走 | **光电传感器**（#30，循迹） | 地面深色线，光电最省事 |
| 走直/转准角 | **角度传感器**（#31，测航向） | 承 2024-H：轮子打滑时只有姿态传感器可信 |
| 认区/认仓/认球 | **摄像头**（#9，识别颜色/编号/圆） | 只有相机能"认出这是几号仓" |
| 到位距离 | 里程（电机测速累积）+ 相机粗校 | 短程里程准，相机确认 |

> **深点**：这道题**不需要 2024-H 那种"无线段惯导盲走"的高难**——场上有引导线连各区，循迹为主、角度传感器辅助转向即可。**运动难度比 2024-H 低，省下的精力砸在"识别+吸放"上。** 这是命题友好度的体现。

---

### 第五个谜：MSPM0 算力 + 分拣流程状态机

分拣是个多步骤流程，要用**状态机**管（承 2024-H）：

```
IDLE → 去取球区 → 视觉对准球 → 通电吸取 → 光电确认吸住
  → 识别/查目标仓 → 导航到对应仓 → 仓上对准 → 断电投放 → 确认掉落
  → 回取球区取下一颗 → ...(循环 N 球)... → 回起点停车
```

**MSPM0 无 FPU**（承 2024-H），但这题的重活（视觉识别）**甩给了带处理器的摄像头**，MCU 只收结果 + 跑运动 PID + 状态机——**算力压力比"打靶车"小得多**。float 省着用（arctan 查表、分频）即可。

### 高频坑 + 解法

| 坑 | 现象 | 解法 |
|---|---|---|
| 裸钢球识别不稳 | 反光/无色，抓不住 | 认球旁颜色/编号标签 + 圆形检测 |
| 气隙太大吸不起 | 电磁铁离球远 | 电磁铁固定到贴地高度 + 视觉把球怼到锚点 |
| 吸没吸住不知道 | 吸空还跑去放 | 光电确认 + 电流辅证 |
| 剩磁放不掉 | 断电球还粘着 | 反向短脉冲消磁/靠自重/轻抖 |
| 视觉帧率当实时 | 对准时车冲过头 | 最新值保持+超时；对准段降速 |
| 循迹弧线里程虚长 | 到位距离飘 | 到位段走直、角度传感器对正 |
| 电磁铁大电流拉垮电源 | 吸合瞬间 MCU 复位/车抖 | 分电源、单点共地、大电容、续流二极管（SS34） |
| 放错仓 | 颜色识别偶错 | 投放前再确认一次仓号 + 多帧投票 |

### 降级方案（翻车救命，5 分钟原则）

- **摄像头识别死活不稳** → 降级为"**预编程走固定路线**"（球位/仓位固定，靠循迹+里程走到每个点，放弃视觉识别，保运动+吸放分）。
- **磁吸对准做不到毫米级** → 加大取球区球的间距、降速慢怼、多试几次；实在不行电磁铁面做大一点增大容错。
- **多球按序乱套** → 退回"只搬 1 球"拿单球分拣分，别追 3 球翻车。
- **图传(发挥3)调不通** → 直接放弃，时间投给多球+提速。
- **投放剩磁粘球** → 投放点加个"轻碰边框"的小动作蹭下来。
- **四驱转向不干净** → 退两轮差速+万向轮（你四驱平台本就能当差速用）。

### 评委隐性加分点

- **吸取/投放前"停稳 + 确认灯"**：光电确认吸住就亮绿灯、投放确认掉落再亮一下——评委一眼看出你有"闭环确认"，不是盲抓。
- **显示屏做成"分拣仪表盘"**：当前任务、识别到的仓色、已搬球数、成功/失败——专业度加分（你天猛星有 GC9A01 屏）。
- **无线图传把"车的第一视角"打到大屏**：最抓眼球，评委直观看到你的视觉在工作。
- **报告里画"识别→对准→吸取→投放"状态机图 + 吸力/气隙计算**：证明你"懂物理"不是"瞎试"。

> **这道模拟题的一句话总纲**：它是"**会看的车 + 会吸的电磁铁**"。地基是你的主场（电机测速/循迹/走直/定点），发挥分战场在**相机识别 → 车怼准球**和**吸取/投放的闭环确认**。清单里没有舵机，所以**用电磁铁通断当"手"**——这是这道题（也是这份真清单）最巧的地方。
>
> ⚠️ 全为纸面推演，电磁铁吸力/气隙、视觉锚点、循迹 PID、投放消磁等**必须上板标定验证后才算数**。这是一道**虚构模拟题**，真题 2026-07-29 才知道；且真题也可能根本不是小车（清单最响的控制信号是磁悬浮，见 `01/02`）。
