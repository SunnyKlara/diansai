## 构建与判读

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

结论以 `_gate.txt` 为准。

- **`RESULT` 现在会真的报 FAIL**。此前它是硬编码的 `PASS`：2026-07-31 缺 `fancyhdr.sty` 触发 `Emergency stop` 与两个 LaTeX error，gate 仍打 `PASS` —— **一个不会说 FAIL 的头条不是闸门**。现改为「任何 `[X]` 阻塞 ⇒ FAIL + 退出码 1」。
- **`[X]` 与 `[!]` 的分工**：守则违规、LaTeX error、缺字、未定义引用、算术自检失败 = `[X]` 阻塞；TODO 计数与 ASCII 引号 = `[!]` 提示。理由：TODO 在开发期是正常的，**超页永远不是**。
- **TODO 计数与引号扫描已先剥离 LaTeX 注释**。此前不剥离，于是解释性注释里引用的 `\TODO{}` 与守则原文的 ASCII 引号被计入，报出 2 个幻影 TODO 和 6 个幻影引号，「必须归零」按构造就归不了零。

## 排版与工具注意

- 定宽表格列用导言区定义的 `L{宽}`，不要直接用 `p{}`，否则中文窄列会被两端对齐拉散。
- `build.ps1` 必须保持 ASCII-only；Windows PowerShell 5.1 可能按 ANSI/GBK 解析无 BOM 脚本。
- MiKTeX 由脚本自动探测；本机无 pandoc，Word 导出会跳过，PDF 不受影响。
- 改动上游参数后必须重跑 `check_numbers.py`；失败时核对推导，**不得改脚本去迁就正文**。
- 增删摘要文字后必须重跑 `check_rules.py`：300 字是按 PDF 实际渲染的汉字数算的，**含 `\TODO` 占位文字**（回填成数字后字数会降）。
