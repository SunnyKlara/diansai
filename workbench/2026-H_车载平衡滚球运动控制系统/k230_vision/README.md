# K230 球位视觉传感器 —— 上板与标定

> 这里只有一份运行文件 [`main.py`](main.py)（CanMV MicroPython，放 K230 的 TF 卡根目录会**开机自跑**）。
>
> **它做什么**：拍摆杆槽内那颗 ⌀10mm 钢球 → 算出沿槽轴的一维位置(mm) → 从 UART 发
> `$V,id,cx,cy,area*HH` 给 MSPM0。
> **它不做什么**：不跑控制律、不驱舵机、不循迹、不做图传。那些全在 MSPM0 上（答疑 Q2/Q4/Q34 允许多 MCU）。

## 上板顺序（别跳，每步都有判据）

**1. 先只验纯逻辑**（不插相机也能做）
把配置里 `SELFTEST = True`，运行 → 应打 `RESULT: PASS`。不 PASS 说明文件传坏了。

**2. 核 UART**（这一步不过就别往下走）
配置块里 `UART_ID=2 / UART_TX=11 / UART_RX=12` 是**猜的**，庐山派的可用脚要按立创 wiki 的引脚表核。
`SELFTEST=False` 跑一次，看
- `[api] FPIOA UART_TXD OK` + `[api] UART open OK` ⇒ 过
- 有 FAIL ⇒ 改引脚号或 `UART_ID`，别继续

判据（不用 MCU 也能验）：K230 的 TX 接一个 USB-TTL 到电脑，串口助手应看到不停刷 `$V,-1,0,0,0*7A`（还没看到球时就该发这个）。**看到这一行 = 帧格式、校验和、UART 全通。**

**3. 对 ROI**
`USE_LCD=True` 时屏上会画出 ROI 框。调 `ROI=(x,y,w,h)` 让框**只压在槽内**，
🔴 **刻度线不许进框**（说明 7 规定刻度贴在槽外边沿；刻度条纹会产生假峰）。

**4. 两点标定 px→mm**
球放到槽边刻度 **−10cm**，读屏/串口里的像素列（`cy` 字段就是原始像素列），填 `CAL_P1_PX`；
再放 **+10cm**，填 `CAL_P2_PX`。`CAL_P1_MM/-100`、`CAL_P2_MM/+100` 不用动。
- 分辨率自检：脚本启动会打 `x.xxx mm/px`。1280 宽覆盖 250mm ⇒ 约 **0.2 mm/px**。
  低于 3 px/mm 会打 `[warn]`。
- **相机装反（像素轴与刻度反向）不用改代码**，把两个点按实际填进去即可，公式自动处理符号。

**5. 验收（M4 的过判据，三条都要）**
| # | 判据 | 说明 |
|---|---|---|
| 1 | 球不动，连读 100 帧，读数 **std < 1mm** | 看 `[stat]` 行的 x 抖不抖 |
| 2 | 球放 −10/−5/0/+5/+10cm，读数与刻度**最大偏差 < 1.5mm** | 真值 = 槽边刻度带 |
| 3 | **帧率 ≥30fps**，端到端**延迟 <100ms** | 延迟要定量测，见下 |
| 4 | 🔴 **原地转动钢球**（镜面球任意转），读数变化 **< 1mm** | 专门证伪"我们在跟着高光点跑"。答疑 Q35 明确球不许喷漆磨砂 ⇒ 必须直面镜面反光 |

延迟测法（别用"看着不滞后"）：MCU 点亮相机视野里一颗 LED 并记 `t0` → K230 检出亮度跳变立刻发一帧 → MCU 收到记 `t1`，`t1−t0` 就是含曝光+处理+串口的全链延迟。依据：ω_n=3 rad/s 时 τ=75ms ⇒ 相位滞后 12.9°（可接受），τ=200ms ⇒ 34°（危险）。

## 接线（K230 ↔ MSPM0）

| K230 | MSPM0 天猛星 | 备注 |
|---|---|---|
| UART TX | **`PB16` = UART2_RX** | 交叉 |
| UART RX | **`PB15` = UART2_TX** | 交叉（暂时用不到，先接上） |
| GND | GND | **必须共地** |

两边都是 3.3V，直连即可，不用电平转换。载板把 `B15/B16` 引到 **J2-6R / J2-7R**（原留给 ESP#1，那块没装）。

🔴 **MSPM0 侧唯一改动**：`car.syscfg` 现在只有 3 个 UART 实例（UART0 调试 / UART3 ESP 遥测 / UART1 八路巡线），**要加第 4 个 UART2(PB15/PB16)**，并把它的字节喂给已有的 `uf_push()`。
⚠️ 还要记一句：**`cx` 字段这一题装的是 `x_mm × 100`（0.01mm），不是像素** ⇒ MCU 侧取值写 `x_mm = cx / 100.0f`，并在 `config.h` 视觉那一节注明。

## 检测模式怎么选

- **`MODE="dark"`（默认，推荐）**：让槽底亮、球遮光成暗斑。暗斑边缘由球的轮廓决定，**与反光无关**，对镜面球最鲁棒。
- `MODE="bright"`：吃镜面高光。**必须环形/漫射对称补光**（相机四周一圈白光 LED + 描图纸漫射）。
  ⛔ 绝不能用点光源侧照 —— 高光点在球面上的位置会随球移动，等于跟着光斑跑，会引入随球位变化的系统性偏移。

## 为什么不写亚像素质心

1280px 覆盖 250mm = **5.1 px/mm**，整像素 `cx` 的量化误差只有 **0.2mm**，而控制目标是 ±3~5mm（判分门限 ±10mm，答疑 Q37 明确"考察全程"取最坏值）。
⇒ **提分辨率比写亚像素便宜**。先按整像素上，`[stat]` 的 std 若被量化限制住了再加。
