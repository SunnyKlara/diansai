## 四、控制视角标注（分析，非原文）

> 用"契诃夫的枪"逻辑：贵的/专门的/非常规器件通常是"给出来必被用到"的信号。仅标注控制相关项，完整推演见与本文件同批的对话分析。

| 器件（清单编号） | 指向题型 | 信号强度 |
|---|---|---|
| 小型电磁铁 + 钢球(#6/#7) + 漆包线(#5) + 镀锌薄铁片(#25) | **电磁悬浮(EMS)**：自绕线圈+铁磁目标闭环 | 🔥🔥🔥 最强 |
| 光电传感器(#30) | 悬浮球位置检测 / 循迹 | 🔥🔥（与悬浮套件呼应） |
| 电动小车(#2，禁履带禁麦氏轮) | 自主小车：循迹/定位/追踪/双车 | 🔥🔥 |
| 四旋翼飞行器(#1) | 飞行器任务（定点/循迹/投放/追踪） | 🔥🔥 |
| 摄像头可带处理器(#9) | 视觉识别/追踪（K230 出坐标） | 🔥🔥 |
| 角度传感器(#31) | 倒立摆 / 云台 / 平衡 | 🔥 |
| 小型电机及驱动器(#22)、短距无线(#3)、无线图传(#4) | 运动控制、双机协同、遥测 | 🔥 |
| TI MSPM0 系统板(#12) 单列 | 可能有题点名/暗示用 MSPM0（同 2024-H 商业约束） | 🔥 |

**"没给什么"也是信号**：清单**未出现激光笔、舵机、超声波模块** → 纯"激光对射/瞄准"题(2023-E/2025-E 类)概率下降；视觉若出走"摄像头识别目标"路线。

**跨方向的枪（非控制，供全局判断）**：
- 电源类：三相可变电阻(#8)、大功率器件(#18)、滑线变阻器(#19)、自耦调压器(#20)、隔离变压器(#21)、磁环磁芯(#23)、铁芯磁环 80/50/25(#24) → 逆变 / AC-AC / 无线电能传输(WPT) 等。
- 测量与放大类：DDS(#14)、ADC/DAC(#15)、运放-比较器-乘法器(#16)、可变增益宽带放大器(#17)、功率分析仪(仪器#4) → 测量 / 放大 / 信号处理题。
- 存疑 wildcard：4 分 PPR 水管(#33) 内径约 13.2mm，1cm 钢球可入 → 或为管道内定位类冷门题，或属别方向（液位/声学），暂不作控制主线。
