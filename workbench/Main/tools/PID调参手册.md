# PID 调参手册（悬浮球定高 · 串口在线整定）

> 配套分析见 `workbench/校赛B_智能球平衡控制装置/04_调试记录/开源项目参考与简化控制方案.md`。
> 核心思想（来自同款开源项目 davidoises/AirLevitatorPIDControl 实测）：
> **先砍到最小三参数(Kp/Kd/Ki)，按"先D后P最后I"的顺序、一次只拧一个，禁止靠眼睛、全程串口抓数。**

---

## 0. 串口命令速查

| 命令 | 作用 | 调参建议 |
|---|---|---|
| `kpNN` / `kiNN` / `kdNN` | 设 Kp / Ki / Kd | 主旋钮 |
| `uhNNNN` | 悬停前馈 u_hover | **保留**：先用 CALIB 扫出悬停 PWM 设好，PID 只修残差 |
| `fN.N` | 球速 EMA 系数 alpha | 调参先 `f0`(裸微分)，末端抖再加 0.2~0.4 |
| `lNNNN` | PWM 每拍斜率限速 | 调参先 `l9600`(等于关) |
| `cNNNN` | D 项钳位 | 激光干净，调参先 `c9600`(等于关) |
| `rNN` | 目标 ramp 速率 cm/s | 调参先 `r0`(关)，达标后开 8~12 |
| `mNNN` / `+` / `-` / `a` | 手动 PWM / 微调 / 回自动 | 标定升力曲线用 |
| `tNN` | 设目标高度 cm | 阶跃测试 |
| `g` / `s` | 启动 / 停机 | |
| `q` | 查询当前参数 | 每步前后查一次 |

**心跳看板字段**：`H`=当前高度 `T`=目标 `E`=误差 `P`=PWM输出 `D`=球速 `R`=转速 `RAW`=原始测距。

---

## 1. 调参前置检查（不过关别调，否则全是无用功）

1. **传感器支架刚性固定**：晃支架零点就漂，每次重烧 TOF_ZERO 都变。先用热熔胶/螺丝固死。
2. **几何标定**：球静止管底 RAW≈47cm → `TOF_ZERO_CM=47`，确认 H≈0@底、H≈43@管口。
3. **反馈可信**：手持球上下移动，串口 `RAW`/`H` 应平滑跟随、无冻结无大跳。（06-11 已验 50Hz 假跳变 0%）
4. **风机预热**：`g` 启动后风机应先空转 ~3s（心跳 `PRE:1`）再进闭环（`PRE:0`），解决冷启动死区/静摩擦。**已在代码实现**（`FAN_PREHEAT_MS=3000`）。

## 2. 整定流程（照此顺序，逐参数）

### Step 0 — 设好前馈 + 关掉补丁，回到"干净 PID"
先用 CALIB 手动扫出悬停 PWM（球不快升不快降的"刀刃点"），`uh<该值>` 设好前馈；再：
```
f0    l9600    c9600    r0    ki0
```
此时控制律 = `u = u_hover + Kp*e - Kd*v`（**保留 u_hover 前馈**：悬浮球是不稳定对象，
前馈到工作点是正解；删了它积分供不上悬停量，球会趴底——见参考方案 §3 更正框）。

### Step 1 — 调 Kd（阻尼，最先调，决定能不能稳）
- `kp0 ki0`，`kd` 从小到大：如 `kd10` → `kd20` → `kd40` ...
- **看现象**：球从"发散冲顶/落底" → "晃但不发散" → 球速被压住。
- **判据**：`D` 字段(球速)峰值明显变小、球不再撞顶撞底。
- 太大 `kd` → 高频抖(`D` 来回快速变号)，退一档。

### Step 2 — 调 Kp（刚度，把球拉回目标）
- 保持 Step1 的 kd，`kp` 逐步加：`kp5` → `kp10` → `kp20` ...
- **看现象**：球开始能回到目标附近，`E`(误差) 变小。
- **判据**：稳在目标 **±2cm**（基本分到手）。
- 加到"刚开始来回过冲"就退一档。

### Step 3 — 加弱 Ki（消静差 + 长出悬停量）
- `ki` 给小值：`ki1` → `ki2`（David 比例约 Ki≈Kp/10）。
- **看现象**：球原本停在目标下方/上方的固定偏差被慢慢顶到目标线。
- 太大 → 慢振荡(球缓慢大幅摆)，减半；必要时抬 `PID_INTEGRAL_LIMIT`。
- **判据**：稳态误差进 **±1cm**（进阶分）。

### Step 4 — 末端微调滤波（按需）
- 若末端高频抖：`f0.2`~`f0.4` 加点 EMA 压抖。
- 若加 EMA 后变发散：相位滞后过大，退回 `f0`，靠 Kd。

### Step 5 — 动态跟踪 + 软启动
- 阶跃 `t10`→`t20`、`t20`→`t10`：测调节时间(<5s)、超调。
- 大阶跃超调大 → 开 `r8`~`r12`(ramp) 平滑目标。
- 末端来回过冲 → 退一点 Kp 或加一点 Kd。

## 3. 达标后收尾
- `q` 记录最终 `Kp/Ki/Kd/f/l/c/r` → 回填 `config.h` 默认值。
- 测 **10 / 15 / 20cm** 三点都达标。
- 把参数 + "为什么这样简化"写进 `03_报告/设计报告.md` 程序设计段（采分点）。

## 4. 比例参考（只抄比例和顺序，绝对值必须自标）

| 来源 | Kp | Ki | Kd | 比例 | 备注 |
|---|---|---|---|---|---|
| David(同款,brushed/100Hz/8bit) | 170 | 15 | 17 | 10 : 0.9 : 1 | Kp≈Kd, Ki≈Kp/10 |
| 我们 06-11 实测可稳 | 20 | 0 | 45 | 1 : 0 : 2.25 | D 比 P 重(不稳定对象偏爱大阻尼) |

> 我们是四线风扇 25kHz / 9600 标度，执行器增益与 David 完全不同，**绝对值别照抄**。
> 真正可移植的是：**结构(P+I+D，无前馈)、比例(Kd 与 Kp 同量级、Ki 小)、顺序(先 D 后 P 最后 I)。**

## 5. 常见坑速查
| 现象 | 大概率原因 | 处理 |
|---|---|---|
| 球大幅上下荡不收敛 | Kd 太小 / 有 bang-bang 残留 | 先只调 Kd；删 boost 两段式 |
| 球稳但总停在目标下方 | Ki=0(纯 PD 抗重力必留静差) | 加弱 Ki |
| 球缓慢大幅摆 | Ki 太大 / 积分饱和 | Ki 减半，查抗饱和 |
| 越界后拉不回 | slew 限速削掉了 D 的快速制动 | 调参期 `l9600` 关掉 |
| 偶发瞬间窜飞 | 假球速喂出大 D（超声波时代）| 激光下应消失；否则 `c` 钳位 |
| 闭环 PWM 卡住不动 | 事件驱动下反馈拒帧→不更新 | 看门狗超时保持 u_hover(见调试日志 06-11) |
