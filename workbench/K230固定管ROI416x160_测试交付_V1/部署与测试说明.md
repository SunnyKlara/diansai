# K230 固定管钢球 ROI 416×160 V1

## 1. 本版做了什么

- 摄像头仍输出 640×480 AI 图像。
- 只截取固定管区域：`x=16, y=208, w=608, h=160`。
- 上下各补 37 像素灰边，形成 608×234，再等比例缩放到 416×160。
- Kmodel 的真实输入是 `1×3×160×416`，不是 416×416。
- 模型输出坐标会还原到原来的 640×480 摄像头坐标，因此原有左右端点标定仍可使用。
- 原始照片和原始标注均未修改。

## 2. 训练与测试结果

- 训练集：190 张，其中 30 张无球负样本。
- 验证集：20 张。
- 独立测试集：21 张，其中 5 张无球负样本。
- 独立测试：Precision 1.000，Recall 0.998，mAP50 0.995，mAP50-95 0.527。
- ONNX 输入：`[1, 3, 160, 416]`；输出：`[1, 5, 1365]`。
- INT8 Kmodel：3,340,648 字节，使用 40 张实拍 ROI 图量化。

以上电脑端指标用于筛选模型。最终帧率、量化后置信度和长时间稳定性必须以 K230 实测为准。

## 3. 上传到 K230

在 SD 卡建立：

`/sdcard/steelball/fixed_pipe_roi416x160_v1/`

只需上传以下文件：

1. `fixed_pipe_ball_roi416x160_v1.kmodel`
   → `/sdcard/steelball/fixed_pipe_roi416x160_v1/fixed_pipe_ball_roi416x160_v1.kmodel`
2. `position_calibration.json`
   → `/sdcard/steelball/fixed_pipe_roi416x160_v1/position_calibration.json`
3. 首次观察框时上传 `fixed_pipe_roi416x160_visual_test_v1.py`
   → `/sdcard/steelball/fixed_pipe_roi416x160_v1/fixed_pipe_roi416x160_visual_test_v1.py`
4. 比赛运行文件 `fixed_pipe_roi416x160_uart_v1.py`
   → 可先放同一目录测试；确认后复制为 `/sdcard/main.py`

不要向 K230 上传 `.pt`、`.onnx`、`calibration_images` 或 `nncase_work`。

## 4. 第一次可视化测试

1. 停止当前程序，不要让两个脚本同时使用摄像头。
2. 打开并运行 `fixed_pipe_roi416x160_visual_test_v1.py`。
3. 启动信息应包含：

   `PIPE_BALL_ROI416X160_V1_READY ... input=416x160 ... to_ide=1`

4. 黄色矩形是固定 ROI，绿色矩形和红色十字应跟随管内钢球。
5. 重点测试左端、中点、右端以及快速滚动。
6. 记录稳定后的 `fps`、`raw`、`filtered` 和是否出现 `valid=0`。
7. 该文件会开启 USB IDE 图传，只用于短时间看框；观察完成后停止。

如果绿色框整体上下偏离钢球，不要重新训练，先调整脚本中的 `ROI_Y`。如果钢球离开黄色 ROI，则需要重新确定 ROI 或重新制作数据集。

## 5. 长时间与控制器测试

运行 `fixed_pipe_roi416x160_uart_v1.py`。默认：

- `PREVIEW_ENABLE=False`
- `IDE_STREAM_ENABLE=False`
- GC 每 25 帧执行一次
- 每次推理发送一次 UART 数据

此模式不向 CanMV IDE 传视频，适合测最高帧率和长时间稳定性。启动信息应包含 `to_ide=0 preview=0`。

串口为 UART2：

- K230 IO11：TX
- K230 IO12：RX
- 115200，8N1
- K230 GND 与控制板 GND 必须共地

数据格式：

- 有效：`$BP,1,+5.23*CS\r\n`
- 无效：`$BP,0,0.00*CS\r\n`
- `CS` 是 `$` 与 `*` 之间字符的逐字节异或校验。

控制板应按完整行解析并校验 CS。收到 `valid=0`、校验失败或超过 150 ms 没有新数据时，不要继续使用旧位置做积分控制，应进入丢球保护或保持安全输出。

## 6. 标定

包内 `position_calibration.json` 是当前固定摄像头的已有标定：

- 左端球心：`(55.6, 307.5)` → `-12.0 cm`
- 右端球心：`(569.6, 291.5)` → `+12.0 cm`

只要摄像头、管子、分辨率和安装位置不变，可以直接复用。如果移动了摄像头或管子，删除新目录中的 `position_calibration.json`，程序会要求重新做左右端点标定。

程序也会尝试读取旧路径：

`/sdcard/steelball/fixed_pipe_480_v1/position_calibration.json`

## 7. 切换为开机运行

1. 先备份原 `/sdcard/main.py`。
2. 把 `fixed_pipe_roi416x160_uart_v1.py` 复制为 `/sdcard/main.py`。
3. 复位 K230。
4. 检查启动行、连续帧率、UART 数据和控制板超时保护。

如果只是测试，不要覆盖 `main.py`，直接在 CanMV IDE 中打开脚本并运行即可。
