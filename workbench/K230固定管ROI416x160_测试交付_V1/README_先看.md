# K230 固定管 ROI 416×160 测试交付 V1

## 定位与验证边界

这是 480×480 模型高帧率方案不足时的矩形 ROI 降算力版本：摄像头仍输出 640×480，只截取固定管区域，经补边后送入真实输入尺寸为 `416×160` 的 INT8 Kmodel，检测坐标再还原到 640×480。

- **包内记录的 PC 侧结果**：训练集 190 张、验证集 20 张、独立测试集 21 张；Precision 1.000、Recall 0.998、mAP50 0.995、mAP50-95 0.527。以上数据来自交付包说明，**本次整理未重新训练或复跑**。
- **本次已验证**：原始 ZIP 可正常解包；模型与两份脚本的原始 SHA256 和包内记录一致；目录内 `SHA256.txt` 已重建并覆盖实际入库的 5 个交付文件。
- **待验证**：K230 真机初始化、量化后置信度、实际 FPS、UART 频率、左右端/中点位置、快速滚动、长时间内存稳定性。

## 第一次使用顺序

1. 先备份 K230 的 `/sdcard/main.py`，不要直接覆盖现有程序。
2. 建立 `/sdcard/steelball/fixed_pipe_roi416x160_v1/`，上传模型、校准文件和两份脚本。
3. 先手动运行 `fixed_pipe_roi416x160_visual_test_v1.py`，核对黄色 ROI、绿色框和红色球心是否覆盖左端/中点/右端及快速滚动全过程。
4. 再运行 `fixed_pipe_roi416x160_uart_v1.py`，记录 FPS、UART 频率、`valid=0`、内存和长稳数据。
5. 只有上述真机判据通过后，才备份并替换 `/sdcard/main.py`。完整步骤见 [`部署与测试说明.md`](部署与测试说明.md)。
