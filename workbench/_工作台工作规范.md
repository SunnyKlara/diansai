# 工作台工作规范（workbench 操作手册）

> **workbench = 正在攻的题的唯一战场。** 一道题从"丢进来"到"做完毕业进 cases"，全程在这里，按本规范操作。
> 设计原则一句话：**文档是做题的副产物，不是额外负担——边做边长，赛中零整理开销，毕业才归档。**

---

## 0. 为什么要这套规范（赛场效率是命）

87 小时里，**文档归类、找文件、整理归档都是纯损耗**。规范的目标不是"管理得漂亮"，是**让你做题时顺手就把该留的留下，永远不为"文件放哪/之前数据在哪"浪费一秒**。

三条铁律：
1. **赛中只维护 2 份活文档**：`作战地图`（指挥）+ `调试日志`（流水）。其余都是产出物，不专门维护。
2. **边做边记**，不赛后补（报告数据、坑，当场进调试日志）。
3. **归档只在"毕业"时做一次**（题做完 → 整理进 cases），赛中绝不打断心流去整理。

---

## 1. 单题标准结构（丢进来就建这个）

```
workbench/<年>-<题号>_<题名>/
├── 00_破局作战地图.md     ★指挥中心：MVP/地基假设/里程碑/降级表/真机回报模板/坑——做题就看它
├── 00_深度审题与方案论证.md  深度分析(skill01产出)；也是网页展示源
├── 00_题目原件.md          题目文字版(PDF提取)；PDF 原件放 赛题/原件/<年>/
├── 调试日志.md             ★边做边记：时间/里程碑/真机数据/现象/坑(流水账)
└── 工程/ 或 工程_<平台>/    真代码(MCU工程)，遵守 §2 代码规范
```

- **两个 ★ 是赛中实时维护的活文档**，其余产出后基本不动。
- 题目素材（图片/datasheet）放工程或 `_素材/`，只读。
- 命名：年-题号用 ASCII（`2026-B`），题名中文。**题号 ASCII 是硬规定**（网页路由、避免编码坑，见 `web/网页调试记录.md`）。

## 2. 代码规范（赛场要"可复用 + 快改 + 不返工"）

| 规则 | 要求 | 为什么 |
|---|---|---|
| **三层分离** | `Core/`(主逻辑+状态机) `Drivers/`(硬件HAL) `Algorithm/`(纯算法) | 算法层不依赖 HAL → 能在 PC 单独验证；改一层不动其他 |
| **参数集中** | 所有可调量(PID/采样率/阈值/限幅)进 `config.h` | 调参不翻遍代码；一处改全局生效 |
| **命名** | 函数 `snake_case`，宏 `UPPER_SNAKE`，每个 .c 配 .h(include guard) | 一致、可读、跨人协作不打架 |
| **参数溯源** | 关键参数注明来源，如 `// u_min=42%，M1 实测标定` | 赛后/答辩说得清；区分"实测值"和"猜测值" |
| **复用优先** | 写功能前先查 `library/` 有没有现成积木 | 不重造轮子，省时间 |
| **真机标注** | 没上板验证的代码顶部标 `// 待真机验证` | 不把没跑过的当成果(北极星铁律) |

> 驱动层禁写业务逻辑，算法层禁碰硬件寄存器。

## 3. 两份活文档怎么写

### 00_破局作战地图.md（指挥中心，按 skill02 产出）
MVP + 地基假设登记表 + 里程碑(timebox/判据/降级) + kill触发表 + 真机回报模板。**随真机进展实时改假设状态**（假设/已验证/已推翻）。

### 调试日志.md（流水账，边做边记）
格式：每条一个时间戳 + 里程碑 + 做了啥 + 真实数据 + 现象 + 结论/坑。
```
## 2026-XX-XX HH:MM  M1 风机标定
- 做了：风机 50%/70%/90% 各试
- 数据：50% 球不动；70% 球浮起~12cm；90% 顶到管口
- 坑：80% 时风机启动瞬间 MCU 复位 → 加 1000uF 电容解决
- 结论：u_min≈65%，G4 假设✅成立
```
**它就是报告的素材库 + 坑库的来源**——赛后整理报告/沉淀坑库直接从这里抄，不用回忆。

---

## 4. 归档/毕业规范（workbench → cases）

题**做完 + 真机验证达标**后，才"毕业"：
1. 整理成 cases 标准六件套（深度审题/做题指南/代码/硬件BOM+电路/报告/调试记录）。
2. 调试日志里的坑 → 沉淀进 `04_调试记录/独到经验总结` + `index/题型图谱`(该题型的坑)。
3. 真机验证过的代码/参数 → 可复用的提炼进 `library/`。
4. 移到 `cases/<年>/<题>/`，从 workbench 清出。

**毕业 = 一次性归档**。在那之前，workbench 里乱一点没关系，只要 2 份活文档清楚。

---

## 5. 一页作战卡（赛时态，可选但强烈建议）
从作战地图坍缩出 1 页：指标表 + 地基决策 + 里程碑timebox + 降级触发 + 当前坑。**赛场 hour 2 看这个，不翻长文档。**
