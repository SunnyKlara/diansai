## 2026-07-24 · 天猛星编码器"不计数"全程排查并修复（commit 90c1c8c `fix(mspm0)` + 配套 docs commit）

- **做了什么**：从"手转也不计数"一路排到**两路干净计数(真机验证)**。根因链：① 编码器 5V 信号**直连** 3.3V MCU 脚过压 → 中断风暴(计数虚高) → ② 加"1k串+2k对地"分压 → 因是**开集(OC)输出**被对地钳死 → **完全不计数** → ③ 拆 2k 对地 + 编码器供电 5V→3.3V + 四脚上拉 → 救活但**电机 EMI 致边沿抖、中断计数虚高~50x** → ④ **改 `encoder.c`：边沿中断解码 → 定时采样 4x 正交解码(`encoder_poll` 每 tick)→ 治本**，真机 enc1/enc2 均 `I≈4×E` 干净、方向对、静止冻结。顺带：电流采样通道按实测校正(M1↔PA26/MEM1)、`ENC_CPR` 225→899(4x)、`ENC_PROBE`→0 回控制固件。
- **关键决策/被推翻**：`已作废`「软件开迟滞+上拉即可修」= 5V直连事实曝光前的错判；`已作废`「分压降压」= 没先判 OC/推挽就荐分压，对开集输出是错的(应上拉)。最终治本 = **采样解码**(外部上拉治"慢沿"有用、治"电机EMI快毛刺"无用)。
- **协作方式**：AI 自主编译/烧录/读串口(openocd + COM30) + **分层探针**(原始电平L / 软件轮询E / 中断I 三视图) + **电机自动轻转替手转**(电流佐证真转)；用户接线/供电/示波器/万用表。
- **可迁移经验**(已入 `跨题坑库.md`)：分层探针分软硬件、多路读数锁步=共模电源地、开集要上拉别分压对地、内部上拉仍读0=外部强对地、中断计数≫轮询=风暴、采样解码>上拉治EMI、屏灭先SWD+串口验非砖、遥测变慢=中断吃CPU探针、静止读上拉电平不证线接好。
- **真值源**：`workbench/mspm0/car/{encoder.c,car.c,motor.c,car.syscfg}`。**剩(不阻塞)**：手转 N 整圈实测微调 `ENC_CPR`；电机 EMI 串扰调试UART(不影响计数)。

- **先纠一个前提**（用户预期里的一半是错的）：**屏幕给不了 AI 数据**——AI 的通道是 UART，屏上的东西我看不见。但屏幕解决另外两个真问题：① **COM30 独占**（人看串口 AI 就读不到，反之亦然，这两天一直如此）；② **脱缆落地时屏是唯一观测通道**。第 ② 条是查 guide 落地前置时撞出来的：那里明写"SWD/UART 线不能拽车、会毁掉横偏测量" ⇒ 真脱缆就没串口。**于是"显示"从锦上添花变成落地的必需件，排期顺序也得跟着改**（已写进 guide 落地前置 ④ + 坑库）。
- **查实一个代码级事实（本轮最硬的产出）**：`GC9A01_DrawChar` **每字符调 64 次 `FillRect`**（字模逐 bit），每次都发整套 `set_window`。纸面估 scale-3 单字符 ~3.7ms、一行 9 字 ~33ms、`FillScreen` ~115~230ms（**未实测**）。⇒ 这是 `4bbaae5` 那个"数主循环拍×假设1ms → RPM 虚高 5x"的**机制层根因**——当时只治了症状（改 SysTick 真实时基），没往下查"LCD 为什么这么慢"。修法=一次设窗+整块流式写（1856→1163 字节 + 省 63 次窗口/CS 开销），估快 2~3 倍，纯收益。已入 guide §四 + 坑库（含"有效字节/实发字节比"这个判据）。
- **设计决策 + 理由**：
  1. **原则定为"跑完的成绩单"而非"实时仪表盘"**。理由：车在地上跑时人在看车、不看屏；结束时冻结一屏判据量（yaw 净变化 / 左右 counts / DIFF / 峰值\|wz\| / 耗时）既最有用、又最便宜（只画一次），而且**它就是脱缆状态下的数据回流路径**（人念一遍或拍照给 AI）。
  2. **每帧像素预算定死 ~3000 px（≈5 个 scale-3 字符）**。从 2 字节/像素反推，为的是不重演"LCD 拖慢时基"。静态元素只画一次、每帧只重画变化的小矩形、控制模式下降频或冻屏。
  3. **三页**：P1 RUN（落地核心）/ P0 AXIS（三轴条 + 两个判据灯，判据与 `imu_axis.ps1` 完全一致，可边挪车边看着放平）/ P2 SYS（只画一次）。翻页用串口命令不占引脚。圆屏安全内容区 x40..200 / y40..200（四角被切，上下边缘可用宽度仅 ~130px）。
  4. **建议现在不做**，理由三条：① 芯片还 lockup、写了验不了；② **已有一批未烧录改动（IMU 航向层 + `z` 彻底急停 + `flash.ps1` 闸门），再叠 UI = 下次烧录一次引入四类变量，起不来就难归因**（"一次只动一个变量"在固件层的样子）；③ 按"不做会怎样"排，落地 > UI。**但明确告诉用户一个例外：若选"脱缆跑"，UI 就得排在落地之前。** 把选择权连同判据一起交出去，而不是替他决定。

## 2026-07-27(十六) · "镀锡铁片剪形状+称重测面积"押题思路评判 + 5060Ti 定位（**纯讨论·无代码·未改押题概率**）
- **起因**：用户提两件事——① 有一台 5060Ti 机器可跑视觉模型（K230 配置由队友 zhy-ss 负责，不在本线）；② 今年有个说法：清单里的"镀锡铁片"可能被设计成剪成不同形状再算表面积或称重，正好用上电磁铁 + 电子秤。
- **先核原件（守坑库"押题第一步核对清单来源"，本仓库有拿错清单押错整套的前科）→ 纠三处事实**：
  1. 是 **"镀锌薄铁片，厚约 0.3mm"**（清单 §二 #25），不是镀锡。物理上都能被吸、不影响推理，但报告/答辩写错材质掉分。
  2. **电子秤（#14，300~500g）在「仪器设备清单」里**，与秒表 / 卷尺 5m / 直尺 1m / 多功能量角器并列 ⇒ 属**评分量具**，不是进作品 BOM 的器件。
  3. 清单**没有称重传感器 / 应变片 / HX711** ⇒ **"作品自主称重闭环"这条路清单不支持**（负空间证据）。
- **用户思路里真正值钱的一半（我们押题 6 份文档确实漏了）**：电子秤不是"我们去称"，而是**"评委用秤当真值标尺"**。硬先例来自本仓库自有资料：`web/data/narratives/2025-D.md` 记的 2025-D 原文明文禁止"**使用称重、超声、激光和其他非电参数方法**"测线缆参数 ⇒ 出题人清楚"称重能反算几何量"并会主动堵。**推论：若 2026 真有测面积/形状的题，大概率也禁称重** ⇒ 该准备的是"**不能称的前提下把面积测准**"，不是准备称重。方向反了一半，但挖出的维度是真的。
- **量级自洽性检查（可当审题判据）**：0.3mm × 7.85 g/cm³ ≈ **0.236 g/cm²**；300~500g 量程 ⇒ 约 1270~2120 cm²（36×36 ~ 46×46cm 整张）；20×30cm 一片 = 141g（量程中段舒服）；秤典型 0.1g 分辨率 ≈ 0.42 cm² ⇒ **若真是称面积，被测图案在 10~30cm 级**（5×5cm=5.9g 时分辨率只剩 1.7% 余量，撑不起严格误差要求）。量级不自洽即说明题型假设错了。
- **为什么不据此改押题概率（决策）**：① 电子秤三种解释**都吻合 300~500g 量程、靠量程分不出来**——称电磁力（自绕线圈吸持力正是几十~几百克，与悬浮簇 🔥🔥🔥 直接呼应）/ 称负载配重 / 称几何量；② **"谁剪"要翻转**——若考面积测量，赛方更可能**预制标准形状发各队**（各队自剪则铁片不一、无法统一评分），且清单无任何加工工具 ⇒ 要准备的是**测量能力不是加工能力**；③ 把电磁铁+电子秤+摄像头拼成同一道题属**超集陷阱**（押题 01 §超集警示；仪器清单服务所有题目）。⇒ **押题 6 份文档一个字没改**，只把方法论记进坑库。
- **5060Ti 定位（决策）**：**只作赛前离线验证台/开发机，绝不设计成运行时依赖**（测评是把作品搬上测试台，带塔机+显示器+供电不现实；"作品不得…"类条款历史常见，2025-D 连测量手段都限定了）。**且这类几何量测量不该上神经网络**——高对比度剪影用传统 CV 更稳更快更好解释、还能在 K230 上跑；上模型多一条 nncase 量化部署的半天坑，精度反而更差（分割边缘比阈值更抖）。形状分类要用则 Hu 矩 / 轮廓顶点数即可。**GPU 的正确用法** = 赛前批量跑"阈值/离焦/倾斜/光照 → 面积误差"敏感度曲线，产出一张误差预算表带进赛场（属 `library/通用能力/算法层PC验证方法论/`）。
- **押中后赛场该走的路（记下来免得现场想）**：`S待测 = S标定件 × (N待测像素 / N标定件像素)`，标定件与待测件**同框共面**拍 ⇒ 透视缩放对两者相同、直接约掉，绕开相机内参与高度标定。三个真实翻车点（比算法难）：① **镀锌镜面反光**会让二值化崩（漫射/背光 > 侧光 > 偏振；背景用黑卡纸/黑绒布）；② **待测件要占满画幅 >1/3**（边缘 1px 阈值误差造成的面积误差 ≈ 周长/面积，100×100px 图案就 4%）；③ **放画面中央**避开广角桶形畸变。
