# 决策与交接归档

> **性质＝冻结历史**：每条是「当时」的正确记录，**不随现状更新**（更新反而毁了记录）。被推翻的决策标 `已作废`，别删（留着知道「为什么当初那样、后来为什么改」）。

## 归档写法（供后续维护参照）

一条归档 = 标题（日期 + 工作线）+ 「做了什么 / 为什么 / 结果或指向」三句内。被推翻的旧决策：保留原文 + 追加 `> 已作废（YYYY-MM-DD）：原因 + 新做法指向`。冗长的技术推演/迭代史压缩成一句 + 指向真值源文件，别整段搬进来。
