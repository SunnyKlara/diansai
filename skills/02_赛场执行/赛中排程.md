# 赛中 4 天每小时排程（合并:小时级排程 + 时间分配模板）

> 精确到小时 + 关键里程碑 + Go/No-Go 检查点。三人队:硬件 H / 软件 S / 报告兼测试 R。
> **绝对原则:Day3 中午前必须跑通基本要求**,否则停下全队救火。

## Day 0（赛前一天）
不熬夜!按 [`赛前24h终检清单.md`](赛前24h终检清单.md) 自检,22:30 前睡。

## Day 1（周三）
- **08:00–09:00 选题(全员)**:全队扫完所有题;按 [`../01_审题破局/审题与选题SOP.md`](../01_审题破局/审题与选题SOP.md) B 部分打分;**09:00 必出结果**,不犹豫超 1h。
- **09:00–11:00 审题方案(全员)**:按审题SOP写 1.5h;指标硬约束写白板;关键算法选定(FFT/DFT、PID/LQR、SPWM/SVPWM)。
- **11:00–12:00 分工**:H 列 BOM+核库存;S 搭代码骨架;R 起草报告绪论+方案选择章。
- **13:00–18:00**:H 焊电源板(最优先)→17:00 完成;S 完成 Drivers 层→点亮板子;R 补理论分析章。
- **18:30–22:00**:H 焊主控+信号板;S 写 Algorithm 层;R 写硬件框图章。
- **22:00 检查点1(Go/No-Go)**:☐主控可烧录+UART hello ☐电源 5V/3.3V 正确 ☐OLED 显示字符 ☐一路 PWM 有波形。**4项不全→强制填坑到23:30必睡**。

## Day 2（周四）
- **08:00–09:00** 上电确认昨日 4 项仍 OK;定今天必须实现的核心函数。
- **09:00–12:00**:H 焊传感器接口+调理(精度链路);S 搭 PID 闭环(先空载);R 用 [`../03_报告答辩/测试数据记录模板.md`](../03_报告答辩/测试数据记录模板.md) 准备测试表。
- **12:30–14:00 闭环跑通**:传感器→ADC→算法→PWM 串通,输出跟随设定(不求精度,先动)。
- **14:00 检查点2**:☐闭环能跟随 ☐OLED 实时数据 ☐UART 调试通道可用。**不过→全员救火**。
- **14:00–18:00 调精度**:用 [`../04_赛场速查/PID实战调参表.md`](../04_赛场速查/PID实战调参表.md) 起步值;每改一次 R 记录;18:00 前达基本要求 50% 精度。
- **18:30–22:00 基本要求冲刺**:过一遍所有基本项;R 写软件设计+测试方法章;H 杜邦线扎带固定。
- **22:00 检查点3**:☐**基本要求 100% 跑通**(逐项演示) ☐指标测 3 次 ☐报告 6000 字。**未通→果断启用 [`../04_赛场速查/赛场降级清单.md`](../04_赛场速查/赛场降级清单.md)**,仍不通→23:30 全队休息 5h。

## Day 3（周五）
- **08:00–09:00** 上电**立刻全部基本要求重测**(夜间元件漂移),稳定再做发挥。
- **09:00–12:00 发挥项1(最易拿分的先做)**:S 写算法;H 焊额外硬件;R 测试记录。
- **12:00 检查点4**:☐第1发挥项完成 ☐测试 3 组。
- **13:00–18:00 发挥项2 + 报告**:同流程;R 填测试结果章(图表+误差分析)。
- **18:30–22:00 发挥项3 + 报告**:报告冲 9000 字。
- **22:00 检查点5**:☐≥2 发挥项 ☐报告 9000 字 ☐测试数据完整。**不达标→接受现状,转优化报告+整理数据**。

## Day 4（周六,提交日）
- **08:00–09:30** 报告封面+摘要(300~500字含关键指标)+总结(呼应基本/发挥)。
- **09:30–11:30 装置最终装配**:测试点贴标签(TP1/TP2)、螺丝紧固、杜邦扎带、电池充满、绝缘。
- **12:00–14:00 封箱 + 演示彩排**:走一遍上电→功能→数据;**每人至少演示一次**(评委可能问任一人)。
- **14:00–16:00 报告打印装订**(封箱1+评委2+自存1),检查页码。
- **16:00–17:00 提交**:装置+纸质+电子,三人签字。

## 四大忌(Anti-pattern)
1. Day1 末仍在选题(死线 9:00 就是 9:00)。
2. Day2 末不做基本要求(先保底线再发挥)。
3. Day3 才动报告(报告从 Day1 每天写)。
4. Day4 改硬件(只准调软件/改报告,禁焊接)。
