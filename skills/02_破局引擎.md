# 技能：破局引擎（做题第二步 · 深度分析之后用）

> 深度分析(skill 01)让你"懂题"；本引擎让你"在 87 小时、高不确定下，把方向定对、不返工、稳定推到现场达标"。
> 哲学根在 `ARCHITECTURE.md` 北极星；本文是能直接照做的操作骨架。
> 活范例：`cases/2026/校赛B_智能球平衡控制装置/00_破局作战地图.md`。

---

## 一条统一公理（随时拿来做决策）

> **87 小时的本质 = 把"怎么打中指标"的不确定性尽快降到零。每一步都选"单位时间消除不确定性最多"的动作。**

它一条管三事：选题=选不确定性最低的题；里程碑排序=先做信息增益最大的实验；要不要死磕=当一个动作再做也学不到新东西（信息增益≈0），立刻停、换路。
随时自问：**"我现在做的事，能消除多少不确定性？有没有更高增益的事？"**

---

## 破局五步

### ① 锁 MVP（保底，方向绝不能错）
写出"基本要求的最小可行方案"。基本要求 100% 完成是底线，**基本没做完=白干**。MVP 先于一切发挥项。

### ② 地基决策 + 假设登记（一次定对，错了推倒重来的那些）
区分两类：
- **地基决策**：平台 / 传感器接口 / 控制架构 / 执行器 —— 选错要推倒重来 → 慎重，2~3 方案打分 + 写死理由。
- **可调血肉**：PID 参数 / 滤波窗 / 显示样式 —— 边跑边改，不心疼。

**关键**：每个地基决策本质是**假设**，真机才证实。建"假设登记表"，每条标 `假设 / 已验证 / 已推翻`。**别把纸面当真理。**

### ③ 按"最致命假设优先"排里程碑（不是先易后难）
先打掉"不成立则整套全废"的假设。每个里程碑带四件套：
```
里程碑 = { 要验证的假设, timebox(给几小时), 过/退判据(量化、可演示), 没过怎么降级 }
```

### ④ 预先写死 kill-criteria + 降级触发表（治"hour 70 做蠢决策"）
清醒时把决策标准外部化，疲劳/panic 时照表执行：
- kill：某里程碑超 timebox 未达标 → 无条件触发预案，**绝不无限死磕**（5 分钟原则的工程化）。
- 降级触发：写死"指标 X 做不到 → 退守 Y，停止投入"。
- 基本 gate：基本要求未 100%，**禁止碰发挥**。

### ⑤ 真机回报闭环 + 坑库强制沉淀（AI×人协同的命脉）
板子在人手上、AI 碰不到 → 胜负在"AI 出码/分析 → 人上板测 → 回报 → AI 改"这个环的**速度与保真**。
- **AI 产出自带验证锚点**：交代"烧进去你应该看到 X，没看到说明 Y"。
- **人按《真机回报模板》喂数据**：现象 + 真实读数 + 波形/照片，别只说"不行"。
- **每个里程碑（尤其失败的）→ 坑库**：现象/根因/解法/下次预防。**坑是头号资产，比分析值钱。**

---

## 两个交付物

1. **《破局作战地图》**（每题一份，放题目目录，**随真机进展实时更新**）：MVP + 假设登记表(地基决策) + 里程碑(含timebox/判据/降级) + kill/降级触发表。这是活的，不是静态文档。
2. **一页作战卡**（赛时态）：从作战地图坍缩出——指标表 + 地基决策 + 里程碑timebox + 降级触发 + 坑清单。**赛场 hour 2 看这个，不看 17KB 深度分析。**

---

## 完成即沉淀（飞轮）
每题破局做完，强制更新系统资产：`index/题型图谱`(+本题型/复用块/坑) + `cases/_PID实战调参表`等积木。系统能力 = 覆盖题型数 × 复用积木数 × 坑库条数 × 真机验证比例。
